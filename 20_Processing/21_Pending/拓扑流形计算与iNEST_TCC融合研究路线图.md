# 拓扑流形计算与iNEST/TCC融合研究路线图

## 一、研究背景与核心命题

后摩尔时代，智能计算的瓶颈已从资源供给问题演变为系统组织问题。冯·诺依曼架构下的存算分离、拓扑固化、离散生成三大瓶颈，推动计算范式从"计算中心"向"拓扑中心"迁移。

本路线图围绕三方理论与技术的深度融合展开：

- **贾志豪拓扑流形计算**：纯软件模拟存算一体三层架构，SDDE 主方程，已在 GPU 上完成 Qwen2.5-7B 端到端验证
- **ICML 2026 拓扑可解释性（CoH）**：ε-连贯矩阵理论，CoH 损失函数，从"稀疏激活"转向"连贯激活"
- **iNEST / TCC 框架**：拓扑中心计算范式，CST 理论体系，软件定义晶上系统（SDSoW），液态拓扑织构（LTF）

**核心命题**：如果计算表征必须与数据拓扑连贯，那么承载计算的物理拓扑（晶上互连）也必须与之连贯——拓扑即计算，通信即计算。

---

## 二、理论层融合：CST 体系的拓扑流形深化

### 2.1 SDDE 主方程与 CST 理论的相互校准

**贾志豪侧已有基础**：SDDE 主方程覆盖单元演化、邻接延迟耦合、惯性制动、破缺噪声四部分，谱半径判据 ρ(A) 划分收敛/临界/混沌三区。

**iNEST 侧已有基础**：CST 理论中结构-功能耦合系数 Γ_st、智能能级（L1-L6）、四条调控规则（STDP/FEP/BCM/SOC）。

**融合方向**：

1. **谱半径判据直接复用**：ρ(A) ≈ 1 定义为自组织临界态，对应 iNEST L2 协同级，作为 T_c 的工程化操作定义
2. **三元生成内核与四条规则对齐**：
   - 破缺 ↔ BCM 滑动阈值可塑性（维持破缺有效性）
   - 简单规则 ↔ STDP 局部因果学习（局域同质交互）
   - 惯性制动 ↔ FEP 自由能原理（预测误差最小化）
   - 时空时序 ↔ SOC 自组织临界态（悬浮混沌边缘，尺度跃迁）
3. **最优传输同构 → Route ≡ Transform 证明路径**：拓扑网络权重直接定义 Wasserstein 流形度量，信号沿边传播等价于分布式 Sinkhorn 迭代，为 TCC "Route ≡ Transform" 定理提供最优传输视角的数学证明

### 2.2 Dowker 对偶性与 CST 结构-计算对偶

ICML 2026 论文指出：经典 Dowker 对偶性对所有矩阵成立，但几何过滤（Vietoris-Rips）下不自动成立，需要连贯性约束。

**对 CST 的启示**：CST 理论中"结构-计算"的对偶关系，需要类似连贯性的约束条件才能在几何层面成立。ε-连贯矩阵为 CST 拓扑对偶部分提供了可参考的证明框架和约束条件设计思路。

### 2.3 拓扑复杂度度量的统一

ICML 2026 的 Theorem 3.12 表明：ε-连贯 + 重心映射 1-利普希茨 → 样本空间与特征空间的 Vietoris-Rips 过滤是 √ε-交错的。

**对 iNEST 的价值**：拓扑保真度可以量化（√ε 精度），为 iNEST 的复杂度理论提供可操作的误差界。晶上互连拓扑与任务内在拓扑"连贯"时，通信开销不是额外成本，而是计算本身的结构性表达。

## 三、架构层融合：从软件模拟到晶上液态拓扑

### 3.1 三层软件架构 → 五层液态架构的映射

贾志豪的三层软件架构可作为 iNEST 五层液态统一架构的**软件模拟验证栈**，在晶上硬件流片前完成算法验证。

| 贾志豪三层 | iNEST 五层对应 | 融合价值 |
|---|---|---|
| L1 微观存算融合（SRAM 算子同构） | L1 微观级 SRAM 算存融合 | 验证算子级存算融合的能效上限，为晶上 SRAM 阵列设计提供软件基准 |
| L2 动态可塑性路由（MoE + LoRA 在线更新） | L2 器件级 + L3 网络级（SDI 软件定义互连） | 验证推理时拓扑自适应的收益边界，为 SDIoN 交换单元的拓扑重构策略提供算法原型 |
| L3 连续时间弛豫（SSM + 安德森加速） | L4 物理可训练层 + L5 智能涌现验证层 | 验证连续动力学 vs 离散层叠的计算效率差异，为 SDDE 物理实现提供数值参照 |

### 3.2 关键架构创新点

1. **从拓扑切换到拓扑形变**：将 TCC 中 "Topology Page" 的概念从"离散配置切换"升级为"流形连续形变"——每次拓扑重构是流形上的光滑过渡，而非硬切换
2. **拓扑可读的最优互连**：在 AllReduce 拓扑优化中引入连贯性约束，搜索"拓扑可读"的最优互连结构——每个最优解都对应一种合理的计算组织方式
3. **分层连贯架构**：局部高保真（小范围精确连贯）+ 全局路由（大范围近似连贯），平衡拓扑保真度与计算复杂度

### 3.3 类脑计算的生物启发对齐

贾志豪的三元生成内核（破缺+简单规则+时空时序）与生物脑的涌现动力学高度一致；ICML 2026 论文的灵感来源（网格细胞、头朝向细胞的连贯激活区）进一步验证了"连贯编码是高效计算的基础"。

**融合方向**：iNEST 的类脑计算方向（脉冲神经网络、液态神经网络）应追求"连贯编码"而非"稀疏编码"——激活区域的拓扑连通性是可量化的设计目标。

## 四、训练方法层融合：时空双正则训练框架

### 4.1 双正则框架设计

将 CoH 拓扑正则与 SDDE 动力学约束结合，形成 iNEST 的**时空双正则训练框架**：

- **空间拓扑正则（CoH 损失）**：强制表征空间与输入数据空间拓扑连贯，保证激活区域在数据流形上连通，解决"算得对不对"
- **时间拓扑正则（SDDE 动力学约束）**：强制状态演化满足连续时间弛豫动力学，保证计算过程在时间流形上连续，解决"算得稳不稳"

### 4.2 CoH 损失的工程接入

CoH 损失函数可直接嵌入 iNEST 表征学习：

1. **适用场景**：脉冲神经网络状态编码、液态神经网络状态表征、存算一体阵列的激活模式
2. **接入方式**：作为拓扑正则项加入损失函数，强制表征空间与输入数据空间拓扑一致
3. **关键技术细节**：
   - 平方 L1 归一化：比普通 L1 更"专注"，无额外超参，工程实现简洁
   - Top-k 聚合：只惩罚最差的 k 个违规者，对异常值鲁棒，适应晶上系统的噪声环境
   - 阈值 τ 机制：方差超过目标阈值才产生损失，可灵活调节拓扑保真度要求

### 4.3 复杂度挑战与应对

CoH 损失每批次复杂度为 O(B²L + BL²)，主要来自重心计算。大规模晶上系统需进一步近似或分块处理：

- 与 iNEST 的分层/分块拓扑思路结合
- 探索分层连贯、局部连贯 + 全局路由的混合架构
- 利用贾志豪 L2 层的 EWC / EMA / 权重裁剪三重稳定性约束，叠加 CoH 作为第四重拓扑连贯性约束

## 五、验证范式层融合：三级验证链条

### 5.1 第一级：GPU 软件模拟验证

**基础**：贾志豪已在 Qwen2.5-7B 上跑通，额外开销 0.25%，速度提升 10.7%，SRAM 命中率 100%。

**验证指标**：
- 推理速度与额外开销
- 谱半径 ρ(A)（收敛性判据）
- 注意力集中度
- 参数变动幅度（稳定性）
- 离散度（可塑性）

**作用**：快速验证算法设想，迭代架构设计，作为晶上硬件实现前的筛选漏斗。

### 5.2 第二级：拓扑可解释性验证

**方法来源**：ICML 2026 论文的评估体系。

**验证指标**：
- **特征调谐率**：多少特征对应数据流形上的连续区域 → 评估计算节点的表征质量
- **纯度**：每个连贯区域内语义的一致性 → 评估拓扑分块的计算效率
- **持久同调 H₁ 类对齐**：用拓扑不变量验证表征空间是否学到数据内在结构
- **特征空间几何可导航性**：路由距离 = 语义距离的验证

**作用**：验证"拓扑即计算"的定性正确性——证明表征确实有拓扑意义，而非仅仅是数值优化的副产品。

### 5.3 第三级：晶上系统验证

**方法来源**：iNEST / TCC 评估体系。

**验证指标**：
- Γ_st 结构-功能耦合系数
- C_ST 时空协同复杂度
- 智能能级跃迁（L1→L6）
- 端到端执行时间与任务能耗
- 可扩展临界规模

**作用**：验证晶上硬件带来的超线性增益和智能涌现，完成从"拓扑启发"到"拓扑约束的计算理论"的闭环。

### 5.4 三级验证的递进逻辑

先在软件上证明"拓扑计算有效"，再用拓扑数据分析证明"为什么有效"，最后在晶上硬件上证明"能效提升有数量级跃迁"。

## 六、分阶段落地路径

### 阶段一：基础融合（0-3 个月）

**目标**：建立软件仿真平台，完成算法级验证。

- 基于贾志豪 cim-design 开源代码，搭建 iNEST 软件仿真平台
- 将 CoH 损失嵌入 L2 动态可塑性路由层，完成双正则训练的初步验证
- 在 Qwen2.5-7B 上跑通基准测试，建立 GPU 侧 baseline
- 产出：iNEST 算法 GPU 验证基准、双正则训练方法论文初稿

### 阶段二：架构深化（3-12 个月）

**目标**：完成拓扑流形计算架构的系统性设计。

- 用 SSM 模块替换部分 Transformer 层，提升长序列处理能力
- 实现"拓扑形变"机制，验证从离散切换到连续形变的收益
- 引入 AllReduce 拓扑优化的连贯性约束，搜索拓扑可读的最优互连
- 完成持久同调验证工具链开发，实现 H₁ 类对齐的自动化评估
- 产出：拓扑流形计算架构白皮书、AllReduce 拓扑优化算法、持久同调评估工具

### 阶段三：全流形原生架构（12-24 个月）

**目标**：从"兼容 Transformer"转向"原生流形架构"。

- 基于小世界拓扑与连续动力学设计原生模型，取消离散层级划分
- 验证分层连贯架构（局部高保真 + 全局路由）的可扩展性
- 完成脉冲神经网络的时空连贯编码验证
- 晶上系统原型设计，SDI 软件定义互连的流形计算映射
- 产出：原生流形计算架构原型、晶上系统设计方案、CST 理论完善版

### 阶段四：晶上硬件落地（24 个月+）

**目标**：软件模拟架构迁移至存算一体晶上芯片，实现数量级能效提升。

- 将软件验证的拓扑流形计算架构直接映射到 SDSoW 硬件
- 验证忆阻器 / SRAM 存算一体阵列上的连贯编码
- 完成 Γ_st 与 C_ST 的硬件级测量，验证智能涌现
- 面向超低轨、自动驾驶、电磁大模型、算力服务器等场景落地
- 产出：晶上流形计算芯片原型、场景验证报告、iNEST 完整理论体系

## 七、预期成果与科学价值

### 理论成果

1. 将 iNEST 从"拓扑启发的计算架构"推进为"拓扑约束的计算理论"
2. 完善 CST 理论的拓扑对偶部分，提供可证明的约束条件与误差界
3. 建立时空协同复杂度的量化评估体系，统一空间拓扑与时间动力学的度量

### 技术成果

1. 一套可在 GPU 上验证的拓扑流形计算软件栈
2. 时空双正则训练方法，可推广至脉冲神经网络、液态神经网络
3. 拓扑可读的最优互连搜索算法，服务于 AllReduce 与片上网络设计

### 工程价值

1. 为 SDSoW 软件定义晶上系统提供算法设计依据和验证方法
2. 为 TCC 拓扑中心计算范式提供从软件到硬件的完整落地路径
3. 支撑晶上联盟从"项目研发型"向"产业落地型"转型的技术底座
