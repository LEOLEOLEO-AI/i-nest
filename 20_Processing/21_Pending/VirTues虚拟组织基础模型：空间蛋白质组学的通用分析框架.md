# VirTues虚拟组织基础模型：空间蛋白质组学的通用分析框架

### 🏆 这篇研究解决了什么核心问题？

现有空间蛋白质组分析**无法跨数据集迁移**，不同研究的标志物和流程差异大。
- **行业痛点**：各研究自定义抗体标记面板 + 实验流程不统一 → 传统模型仅适配单一队列，难以跨数据集筛选稳健生物标志物。
- **传统方法局限**：VIT/CNN 随通道增多算力呈二次增长，高 multiplex 效率极低。
- **研究目标**：打造通用基础模型 → 支持跨异质标志物面板、跨数据集的**零样本注释**。

### 🧬 VirTues 是什么，核心架构有什么创新？

VirTues 是**首款跨平台空间蛋白质组通用基础模型**，用蛋白先验 + 双稀疏注意力实现多尺度表征。
- **底层创新**：**ESM-2 蛋白语言模型**嵌入 + 分解式双注意力（标记注意力 + 空间注意力）分层 ViT 架构。
  - 说白了，就是让模型先懂蛋白本身的生物学含义，再分别从"蛋白互作"和"空间分布"两个角度看组织，比一股脑全连的注意力省算力多了。
- **多尺度表征输出**：Patch 块 → 单细胞 → 微生态 Niche → 整张组织，**四层统一嵌入指纹**。
- **训练方式**：编码器-解码器 MAE（掩码自编码器）自监督框架，三种掩码策略联合训练。

| 掩码模式 | 平均重建相关性 r | 相对均值基线提升 |
| :--- | :--- | :--- |
| 独立随机掩码 | **0.800** | +0.295 |
| 全通道标记掩码（虚拟染色） | **0.700** | +0.195 |
| 全域微环境掩码 | **0.668** | - |

### 📊 训练数据规模有多大？

基础 IMC 库覆盖**15 个队列、3102 名患者、146 种蛋白标记**，扩展库规模更大。
- **基础 IMC 库**：15 个队列、8 类器官、3102 名患者、8887 个样本、约 24.7 万个 256×256 图像切片、146 种不同标记。
- **扩展多技术库**：32 个临床队列、5100+ 患者、239 种标记，兼容 **IMC / CODEX / MIBI / Orion** 四大空间成像平台。
- **数据预处理**：99 分位数强度截断、对数变换、通道标准化、高斯平滑；按 80/20 划分患者级训练测试集，避免同患者跨集泄露。

### 🔬 VirTues 能完成哪些下游任务？

**一套预训练主干网络**就能搞定 5 大类任务，覆盖从分子到临床全流程。
- **标志物重构（虚拟染色）**：零样本预测训练集未见过的标记，训练内 r≈0.8，零样本新标记仍可精准预测。
- **细胞分割与分型**：
  - 零样本跨队列细胞分型，粗/精细亚型 F1 显著优于 MAPS / Astir。
  - 跨数据集细胞实例分割，IoU 指标超越 Cellpose / StarDist。
- **组织微生态注释**：区域聚合为 Niche 表征，支持微环境结构识别。
- **空间生物标志物挖掘**：无监督 Leiden 聚类筛选预后相关细胞特征 Signature。
- **患者分层与临床预测**：
  - 肿瘤亚型、分级、ER / ERBB2 / PAM50 分型。
  - 三阴性乳腺癌免疫治疗响应预测，AUROC ≈ **0.823**。
  - 相似病例检索：基于 Wasserstein 距离匹配表型相似的历史样本。

### 🩺 在三阴性乳腺癌上的临床效果如何？

挖掘的生物标志物**优于现有最优方案**，能有效预测免疫联合化疗疗效。
- **训练队列（NeoTRIP）**：138 名三阴性乳腺癌患者，67 名应答者，采集治疗前/中/后三期活检。
  - 识别出两类有效应答特征：**RS1（凋亡 + PD-L1+ 细胞）**、**RS2（CD4 辅助 T 细胞）**。
  - 标志物跨队列可重复，显著优于单一细胞比例基线。
- **独立验证队列（Meyer 等）**：163 名患者。
  - 高低风险组生存显著分离（P < 0.001）。
  - **C-index 高于传统肿瘤/免疫细胞比值分型方案**。

### ⚖️ 跟现有主流模型比，优势在哪？

在参数效率、零样本迁移、多任务能力上**全面领先**。

| 模型/工具 | 核心短板 |
| :--- | :--- |
| ResNet / 通用视觉 ViT | 通道无生物学含义，不支持可变标记面板 |
| CA-MAE | 40 标记下参数量是 VirTues 的 **25 倍** |
| KRONOS | 依赖核标记强制输入，IMC 数据适配差 |
| Cellpose/StarDist | 仅能分割细胞，无多尺度临床分层能力 |
- **缩放优势**：标记越多效果稳步提升，40 标记时参数量仅为 CA-MAE 的 1/25。
- **跨平台泛化**：跨 IMI / CODEX / Orion 零样本泛化性能领先 KRONOS / CA-MAE。
- **稀有细胞提升大**：NK 细胞、B 细胞等稀有免疫细胞分型提升幅度最明显。

### ⚠️ 研究有哪些局限？

仅完成回顾性队列验证，**缺少前瞻性临床试验**。
- 与训练集蛋白序列差异大的标记，零样本重建精度下降。
- 稀有细胞/组织样本数量不足，表征学习不完善。

### 💾 开源资源有哪些？

模型、代码、数据集**全部在 GitHub 开源**。
- 两套预训练模型：仅 IMC 训练版、多技术扩展训练版。
- 配套两套开源数据集 + 自动化蛋白序列下载脚本。
- 代码基于 PyTorch + FlashAttention-2 实现，支持 GH200 / A100 GPU。
- 仓库地址：github.com/bunnelab/virtues

- **模型全称**：VirTues = Virtual Tissues（虚拟组织基础大模型）。
