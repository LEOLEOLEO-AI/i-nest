# 实施方案意见

**建议：** 表 1 增补国内对标行（措辞客观、只引用公开信息）：


| 对标对象                      | 形态                                   | 与本项目的代差点                                     |
| ------------------------- | ------------------------------------ | -------------------------------------------- |
| 国内主流 DPU/智能网卡（云豹、驭数等公开产品） | ASIC 标准网卡/DPU，25G~100G 为主，少数 200G    | **IP 不可授权、RTL 不可见**，无法嵌入 SDSoW 介观尺度集成        |
| 国内 FPGA RDMA IP（公开供给极少）   | 100G 档位为主                            | **200G 双链路聚合 + 跨域中间件 + 双场景验证体系**三位一体国内未见公开供给 |
| 本项目                       | **可综合 RTL IP + 板卡 + 中间件 + 验证系统组合交付** | 源码级可控、可裁剪、面向 SDSoW 双场景                       |


"**国内 200G 级可授权 RDMA RTL IP 目前无公开供给，本项目填补该空白**"

### 表述错误

- 第 183 段："并实现**实现** RDMA IP 的在线配置"——重字；
- 第 199 段："GPU/XPU****NVMe、FPGA等异构端点"——文档内存在乱码字符
- 天数智芯 MR100，这个型号是否不对？

### 板卡指标

- **从板卡硬性指标中移出**：第 143 段改为"**支持在网计算功能扩展能力**（预留 RISC-V 处理核接口与报文旁路通道）"；
- **在表 2 新增一条独立、功能性、降速的指标**："**在网计算能力**：完成不少于 3 类在网处理算子（AllReduce 规约、数据过滤、AES/SM4 加解密）的**功能正确性验证**（验证速率档位不低于 10Gbps 等效通道，验证结果经联合测试报告确认）"。

### "等效验证场景"全文出现 6 次，零定义

- **原文锚点：** 表 2 第 2、3 行"封装内短距通信**等效验证场景**下 ≤8μs""晶圆间网络化延伸**等效验证场景**下 ≤15μs"；第 271、278、280 段重复引用，但全文无一处定义"等效"的拓扑、介质、距离、设备。



- **200Gbps线速转发是指的聚合转发速率？通常转发速率测试的时候需要指定最短（或平均）包长，这个基于FPGA不要有瑕疵。**
