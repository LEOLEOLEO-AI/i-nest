# Claude辅助设计7B端侧AI芯片全流程架构分析报告

### 🎯 初始设计约束与目标定位

本次芯片设计的核心应用场景为机器人、AR眼镜或边缘计算盒，目标承载约7B参数的多模态模型，支持图像问答、视觉推理和机器人感知能力，具体量化约束如下：
1.  上下文规格：2K文本token + 单张图像生成的576个视觉token，总输入token数约2624
2.  性能指标：首个token延迟（TTFT）<1秒，生成速度≥50 token/s
3.  功耗范围：5~20W，同时支持模型持续迭代更新

### 🧮 第一步：基于TTFT目标推导算力规格

大模型推理分为两大核心阶段：prefill（处理全部输入，决定首个token等待时长）、decode（逐个生成token，决定持续输出速度）。
- 7B模型prefill阶段计算量公式：`2 × 参数量 × 输入token数`，代入参数后总计算量约为36.7万亿次操作
- 按50%硬件利用率计算，理论最低峰值整数算力需求约73 TOPS
- 叠加视觉编码器、非矩阵算子、数据调度和工程余量后，最终选定**96 TOPS、原生支持W4A8（4位权重8位激活量化）**的NPU核心
- 该配置下50%利用率完成多模态prefill的理论耗时约0.78秒，可满足1秒以内的TTFT要求

### 🔍 关键洞察：7B端侧解码的核心瓶颈并非算力

7B多模态模型经4bit量化后权重仅约3.5GB，在batch=1的自回归解码过程中，每生成1个token就需要近似遍历一次全部模型权重，带宽需求远高于算力需求：
| 计算维度 | 数值测算结果 |
| :--- | :--- |
| 50 token/s对应的理论权重带宽 | 3.5GB × 50 ≈ 175GB/s |
| 按70%有效带宽利用率的需求带宽 | 约250GB/s |
| 叠加KV cache后的实际带宽需求 | 约257GB/s |
- 最终结论：7B端侧解码首先是内存带宽问题，其次才是计算问题。

### ⚙️ 第二步：从面积与功耗边界选定6nm工艺

设计团队并未选择成本更低的12nm工艺，核心原因是其无法满足晶圆对晶圆堆叠的硬性约束：
| 工艺节点 | NPU面积系数 | 96 TOPS NPU总面积 | 单位算力能效 | 50% prefill利用率下计算功耗 |
| :--- | :--- | :--- | :--- | :--- |
| 12nm | 1.5mm²/TOPS | 约144mm² | 4 TOPS/W | 约12W |
| 6nm | 0.75mm²/TOPS | 约72mm² | 10 TOPS/W | 约4.8W |
- 晶圆堆叠要求逻辑芯片面积进入约95mm²的窗口，12nm方案直接超出面积上限，6nm是让整个方案具备工程可实现性的唯一选择，而非单纯的性能或成本最优选项。

### 📦 第三步：基于生成速度完成内存架构选型

团队对5种主流存储方案进行多维度对比，最终选定3D-DRAM作为核心存储方案：
| 存储方案 | 带宽表现 | 能效表现 | 灵活性 | 成本 |
| :--- | :--- | :--- | :--- | :--- |
| 纯LPDDR5X | 中 | 低 | 高 | 高 |
| 片上SRAM | 高 | 高 | 低 | 高 |
| 固化权重 | 低 | 中 | 低 | 低 |
| 3D-DRAM | 高 | 高 | 高 | 中 |
| 3D-DRAM+LPDDR | 高 | 中 | 高 | 较高 |
- 功耗对比：在257GB/s持续带宽下，LPDDR5X数据搬运功耗约12.3W，3D-DRAM仅约1.3W，内存子系统可节省约11W功耗，能效提升近9倍
- 最终配置：两层堆叠DRAM，单颗容量2.5GB，总容量约5GB，峰值带宽达1.9TB/s，预留充足带宽余量换取低功耗运行空间，理论可支持最高约380 token/s的解码速度。

### 💾 第四步：精准测算片上SRAM容量

无需将数GB权重存入昂贵的片上SRAM，SRAM仅承担激活存储、权重分块和流水线双缓冲功能：
- 2K上下文、4096 hidden size、FP16激活的单层张量约16MB，叠加16个NPU tile各512KB的本地缓冲，总SRAM容量约24MB
- 6nm工艺下SRAM面积系数约0.4mm²/MB，24MB SRAM仅占约9.6mm²
- 逻辑芯片总面积测算：72mm² NPU + 9.6mm² SRAM + 7mm²基础逻辑 + 5mm² 3D接口 ≈ 93.6mm²，刚好进入95mm²的晶圆堆叠面积窗口，仅预留极小工程余量。

### 📋 最终概念芯片方案汇总

该方案为架构筛选级验证原型，尚未完成物理设计与流片验证，核心规格如下：
1.  核心架构：6nm逻辑芯片 + 5GB 3D-DRAM 3D堆叠设计
2.  核心计算单元：96 TOPS W4A8 NPU，相比128 TOPS设计主动降低25%算力，换取更优功耗与良率
3.  片上存储：约24MB共享SRAM
4.  性能预估：目标解码速度50 token/s，3D-DRAM动态功耗约1.3W，整片decode功耗约4~5W，prefill峰值功耗约12~16W
5.  核心价值：通过严谨的工程推理，将模糊的产品需求快速转化为可计算、可质疑、可验证的工程假设，大幅降低芯片前期架构探索成本。
