### 第2页 · 为什么是井芯微？
**标题**：为什么是井芯微？
**副标题**：赛道好、壁垒高、确定性强、弹性大——四重逻辑支撑一次估值重算

**四个数字卡片（横排）**：
- **80%+** SRIO国内军口市占率 → 垄断地位 = 利润底板
- **500家** 累计行业客户 → 客户基数 = 第二曲线起点
- **20家** 民口新增客户（5个行业） → 民用突破 = 天花板打开
- **全球唯一** 单芯片四协议融合 → 技术壁垒 = 具身智能入场券

**底部：三个问题，一页回答**：
- **为什么是现在**：算力瓶颈从"算"转向"连" + Chiplet产业链重组 + 国产替代加速
- **为什么是井芯微**：SRIO垄断基本盘 + 多协议融合唯一玩家 + 四层价值交付能力
- **为什么要重新估值**：从军工芯片PS 8-10x → 互连平台PS 15-20x

### 第3页 · 赛道：端边侧互连——AI下沉的基础设施
**标题**：我们身处的赛道——端边侧互连的结构性机会
**副标题**：不是缩小版数据中心，是一套完全不同的技术体系和市场逻辑

**端边侧互连的三个独特性**：
1. **算力分散 + 协议异构**
   - 不是几千颗GPU的同构集群，是CPU/NPU/DSP/FPGA/传感器的异构拼图
   - PCIe/SRIO/以太网/FC/JESD等十余种协议长期共存，融合交换是刚需
2. **确定性优先于峰值带宽**
   - 控制闭环、实时感知、安全可靠——"最坏时延"比"平均带宽"更重要
   - 硬件级QoS是入场券，不是锦上添花
3. **军民双体系 + 国产替代**
   - 军口已验证（80%+市占率），民口可外溢——技术复用率高
   - 出口管制升级，国产替代从"可选"变"必选"

**市场空间**：
- 全球端边侧互连芯片+模组市场：百亿美元级，CAGR 25%+
- 中国市场：军口+民口合计数百亿人民币，国产化率不足20%

**底部金句**：
> 这不是一个"蹭AI热点"的细分赛道。
> 这是**AI产业价值重心从计算向互连迁移**的大趋势中，端边侧这个结构性机会。

## 第二幕：技术壁垒与产品能力

### 第4页 · 三层护城河——为什么这个位置别人拿不走
**标题**：三层护城河——为什么这个位置别人拿不走
**副标题**：协议积累是地基，软件栈是城墙，生态位是护城河

**第一层：异构协议积累（地基）**
- SRIO + PCIe + 以太网 + FC，单芯片四协议融合全球唯一
- 每种协议都需要年深日久的调试和验证，多协议融合不是功能叠加，是架构级重构
- 国内没有第二家能在单芯片里做到同样的协议覆盖度
- **类比**：就像一个人同时精通英语、中文、日语、西班牙语，还能做同声传译——不是学不会，是需要时间堆

**第二层：硬件级QoS + SDI软件栈（城墙）**
- 硬件级QoS三层体系：物理级（电路交换）+ 协议级（RapidIO虚通道/FC信用量）+ 调度级（TSN）
- 芯片 + IP + 中间件 + 网管 + 工具链，五层能力闭环
- 硬件可以抄，软件栈和工具链抄不走——客户的系统是围绕你的软件栈建的
- 客户一旦导入，迁移成本极高——不是换一颗芯片的事，是换整个开发环境

**第三层：生态位（护城河）**
- 军口垄断地位 + SDSoW专项核心参与 + 联合定义客户 + 军民双体系桥接
- 生态位不是技术问题，是时间、信任、关系、标准参与的综合结果——别人有钱也买不到
- 一旦占据了"军民双体系桥接者"的位置，后来者几乎没有翻盘机会

**底部金句**：
> 第一层让你"能做别人做不了的产品"。
> 第二层让你"客户用了就离不开"。
> 第三层让你"站在别人挤不进来的位置上"。
> **三层叠加，就是井芯微真正的壁垒。**

### 第5页 · 产品矩阵：一条数据通路，四层价值交付
**标题**：产品矩阵——一条数据通路，四层价值交付
**副标题**：从芯片到系统，每往上走一层，离客户问题越近，价值越高

**四层价值模型（从下到上）**：

| 层级 | 产品形态 | 核心产品 | 状态 |
| --- | --- | --- | --- |
| **L4 解决方案层** | 行业解决方案 | 低空/工业/AI基础设施/安防互连方案 | 民用突破中 |
| **L3 模组层** | 板卡/模组/芯粒封装 | 交换加速卡、桥接模组、SDI模块 | 军口已量产 |
| **L2 IP+软件层** | IP核 + 驱动 + 中间件 | RapidIO/PCIe IP、RDMA/P2P中间件、SDK | 持续迭代 |
| **L1 芯片层** | 互连芯片 | SRIO交换芯片、PCIe交换芯片、多协议融合芯片 | 军口垄断 |

**核心产品亮点**：
- **SRIO交换芯片**：国内军口80%+市占率，四代迭代，成熟稳定
- **PCIe交换芯片**：120+军口项目植入，20家民口客户验证，第二曲线放量
- **多协议融合芯片**：全球唯一单芯片四协议融合（SRIO+PCIe+以太网+FC），具身智能"神经中枢"
- **0420桥接芯片**：实现多协议生态互通，存量系统升级关键抓手

**底部金句**：
> 同样是做互连，做芯片的PS 5-8倍，做系统方案的PS 15-20倍。
> 井芯微正在从L1向L4快速爬升——**每升一级，估值天花板上一个台阶**。

### 第6页 · 端边侧产品布局全景
**标题**：端边侧产品布局：从芯片到系统的完整拼图
**副标题**：围绕端边侧核心场景，构建从芯片到解决方案的全栈能力

**五大产品系列**：

**第一系列：多协议融合交换芯片**
- 全球唯一单芯片四协议融合（SRIO + PCIe + 以太网 + FC）
- 面向具身智能、多传感器融合、异构计算平台
- 状态：验证完成，量产推进中

**第二系列：PCIe交换与桥接芯片**
- 覆盖PCIe Gen3/4/5，多端口、低功耗
- 面向AI服务器、边缘计算、工业控制
- 状态：军口120+项目植入，民口20+客户验证

**第三系列：SDI确定性互连模组**
- 硬件级确定性时延，百ns级抖动
- 面向工业控制、车载、飞控等强实时场景
- 状态：军口批量应用，民口试点中

**第四系列：RDMA/P2P通信中间件**
- 零拷贝、低时延、高吞吐的数据通路软件
- 减少CPU介入，释放硬件互连性能
- 状态：100G端口验证，SDK交付中

**第五系列：行业解决方案**
- 低空机载互联、工业机器人互联、AI边缘节点互联等
- 芯片+模组+软件+网管一体化交付
- 状态：5个行业突破，2单解决方案订单

**底部金句**：
> 不是单点产品，是**围绕端边侧数据通路的一整套产品矩阵**。
> 客户需要什么形态，我们就交付什么形态——这就是平台型公司和芯片公司的区别。

### 第7页 · 六大堵点 vs 井芯微能力——一一对应
**标题**：六大堵点 vs 井芯微能力——一一对应
**副标题**：判断一家互联公司的能力，不看它会不会讲趋势，看这六类问题有没有闭环

| 端边侧六大堵点   | 井芯微的对应能力                             | 成熟度         |
| --------- | ------------------------------------ | ----------- |
| **协议异构**  | 单芯片融合SRIO+PCIe+以太网+FC；0420桥接芯片实现生态互通 |  全球领先  |
| **确定性时延** | 硬件级QoS三层体系（物理级+协议级+调度级），P999时延可设计可验收         |  军口已验证 |
| **数据搬移**  | RDMA/P2P中间件，100G端口RDMA，减少CPU介入与无效拷贝  |  工程化中  |
| **拓扑扩展**  | 交换Fabric + 路由调度 + 统一网管，从百节点到万节点可扩展   |  军口场景深 |
| **可靠安全**  | 内生安全架构 + RAS设计 + 军品级可靠性验证 + 抗辐照规划    |  军口标准  |
| **工程交付**  | 四层价值交付（芯片→IP+软件→模组→解决方案），平台化交付       |  快速完善中 |

**底部金句**：
> 前三项（协议/时延/数据搬移）是"能不能活"的问题——井芯微已经跑通了。
> 后三项（拓扑/安全/交付）是"能走多远"的问题——井芯微正在从军口向民口快速复制。
> **六类堵点都有对应产品和工程闭环，这在国内互联公司里是独一份。**

## 第三幕：市场验证与增长引擎

### 第8页 · 典型案例：端边侧的落地实践
**标题**：典型案例——从军工到民用的场景验证
**副标题**：每一个案例都是一次场景打磨，也是下一个客户的入场券

**案例一：某重点型号装备——多传感器融合互联**
- **场景**：高端装备多传感器（雷达+光电+电子战）数据融合
- **核心指标**：端到端时延降低70%+，系统体积减少60%，功耗降低55%
- **价值**：首次实现单芯片四协议融合，为装备升级和民口外溢奠定技术底座

**案例二：工业机器人头部企业——确定性控制互联**
- **场景**：多关节工业机器人实时控制
- **核心指标**：抖动<1μs（传统方案10~50μs），控制环频率从1kHz升至8kHz，定位精度提升5倍
- **价值**：满足SIL 3功能安全要求，打开高端制造和汽车产线准入

**案例三：无人机领军企业——机载互联架构**
- **场景**：中大型无人机机载计算与传感互联
- **核心指标**：机载系统重量减轻35%，协议转换时延降低70%
- **价值**：从芯片供应升级为联合定义机载互联架构

**案例四：国内头部服务器厂商——AI边缘节点互联**
- **场景**：AI边缘服务器多加速器互联
- **核心指标**：算力利用率从30~40%提升至75~85%，推理吞吐提升110%
- **价值**：性能达到国际同类水平，进入国产替代供应链

**底部金句**：
> 军口案例证明了**技术的极限**，民口案例验证了**市场的接受度**。
> 每一个打透的场景，都是下一个场景的"模板"——这就是平台能力的复利效应。

> 中心侧和端边侧，不是谁替代谁的关系，是一张完整互连网络的两个组成部分。
> 中心侧解决"大流量怎么高效跑"的问题，端边侧解决"异构数据怎么确定性传"的问题。
> **井芯微专注的端边侧路径，是国内互连产业中技术壁垒高、竞争格局好、确定性更强的一条。**

### 第11页 · Chiplet与晶上系统——历史性机遇
**标题**：Chiplet与晶上系统——互联公司的历史性机遇
**副标题**：产业链正在重组，互联第一次有机会从"配角"变成"系统定义者"

|           | 旧范式（单芯片时代）              | 新范式（Chiplet/晶上时代）           |
| --------- | ----------------------- | --------------------------- |
| **产业链分工** | 设计公司定义芯片 → 制造 → 封测 → 组装 | 标准芯粒 + 先进封装 + 互联架构 + 软件定义系统 |
| **互联角色**  | 周边器件、被动配套               | 系统骨架——芯粒怎么摆、怎么连、怎么调度，全由互联定义 |
| **价值分配**  | 芯片设计拿大头（60-70%）         | 互联与系统调度价值占比大幅上升（30-50%+）    |
| **迭代速度**  | 2-3年一代，跟着制程走            | 3-6个月一代，靠芯粒组合迭代             |

**井芯微的位置**：
- 深度参与国家SDSoW重大专项（晶圆级互联网络方向）
- 不是"蹭概念"，是晶上时代的核心工程实现方
- 今天的估值不依赖它（军口+民口已经撑得住）
- 但如果路线跑通了，井芯微就不是"一家互连芯片公司"——而是**晶上时代的基础设施提供商**

**最底部金句**：
> 这是一笔免费的期权——下行有军口利润底板，上行有范式跃迁的想象空间。
> 就算晶上系统晚来两年，公司该增长还是增长。
> 但如果它真的来了，今天的估值就是地板价。

## 第四幕：财务与融资

### 第12页 · 商业模式与收入结构
**标题**：商业模式——四层价值，多元收入
**副标题**：从芯片销售到解决方案，收入结构持续升级

**四类收入来源**：
