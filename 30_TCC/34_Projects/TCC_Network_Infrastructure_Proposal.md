**项目类别**：智能生态基座专项·网络底座方向
**实施周期**：3年（36个月）
**总经费**：4200万元

## 一、为什么要做这件事

### 1.1 一句话说清问题

**算力有了，但跑不起来。**

现在的智能计算系统，芯片算力越来越强，但40%到70%的时间都花在了"等数据"上——卡在了芯片之间的连接上。就像修了很多超级跑车，但路还是乡间小道，车越多越堵。

### 1.2 三个层面的判断

**第一个判断：算力竞争的焦点，正在从"算"转向"连"。**

全球AI算力竞赛已经进入下半场。上半场拼单芯片性能，下半场拼的是**怎么把成千上万颗芯片高效地连起来**。

- 华为刚发布的Atlas 950超节点，8192张NPU全光互联，单跳时延压到300纳秒，互联带宽达到16PB/s——超过全球互联网峰值带宽的10倍
- 谷歌TPU v8训练端用3D Torus连9600颗芯片，推理端用Boardfly拓扑把1152颗芯片组织成7跳直径的全连接网络
- 英伟达、微软、Meta都在砸钱做光互联、超节点、百万卡集群
- 国内昇腾超节点已经部署超过1000套，华为明确提出"韬定律"——与其死磕晶体管尺寸，不如压缩信号传输延迟，用架构创新在成熟制程上跑出高性能

**结论很明确：互连网络已经从"算力的附属品"变成了"算力的决定因素"。** 谁掌握了互连技术，谁就掌握了下一代算力的制高点。

**第二个判断：固定拓扑是当前最大的结构性浪费。**

现在的计算集群，互连拓扑是固定的——要么是胖树，要么是Mesh，要么是Torus，建好了就不能变。但智能任务的通信模式千差万别：

- 训练的时候，主要是All-Reduce集合通信，需要高带宽的对称拓扑
- 推理的时候，MoE模型需要All-to-All全局路由，需要全连接拓扑
- 图计算的时候，是不规则的消息传递，需要低直径的灵活拓扑
- 出故障的时候，需要快速绕过失效区域，需要可重构的容错拓扑

**一种拓扑打天下，就像用一把钥匙开所有的锁——每一把都能捅开，但每一把都不是最优的。** 大量的算力资源，就在这种"拓扑不匹配"中被白白浪费了。

**第三个判断：连接结构决定智能涌现，这不是工程问题，是科学问题。**

这一点有最新的脑科学研究做支撑。

2024年到2026年，果蝇全脑连接组的研究取得了里程碑式的突破。谷歌研究团队联合HHMI Janelia，先后发布了雌性和雄性果蝇的完整大脑连接组图谱——14万到16.6万个神经元、5000万到1.25亿个突触连接，全部精确到单个突触级别。

更震撼的是后续实验：有人把这张完整的果蝇大脑接线图，1:1复刻成数字模型，直接驱动虚拟果蝇——**没有训练、没有奖励函数、没有梯度下降，这只"数字果蝇"自己就会爬行、觅食、躲避障碍**。智能行为，完全从连接结构中"涌现"了出来。

甚至有人把简化版的果蝇连接组模型接到真实无人机上——摄像头画面喂给"果蝇眼睛"，神经活动直接转成油门和转向指令，**没有一行飞行控制代码，无人机就能悬停、绕障、降落**。

这些实验传递了一个极其重要的信息：**智能的本质，可能不只是参数和权重，更是连接结构本身。** 连接方式对了，智能行为自然就会出现。

生物脑靠什么适应不同的任务？不是换神经元，而是**动态调整神经连接的拓扑结构**——不同的认知任务，脑网络会切换到不同的拓扑构型。

**如果人工计算系统的连接拓扑永远固定，那它能实现的智能形态，天然就受限于拓扑的表达能力。**

### 1.3 我们要做什么

我们要做的，就是把互连拓扑从"固定的硬件布线"，变成**可软件定义、可运行时切换、可任务自适应**的一等计算资源。

这个方向，我们称之为**拓扑中心计算（Topology-Centric Computing, TCC）**。

简单说就是三句话：
- **拓扑可重构**：一套物理互连，能切换成多种拓扑模式（Ring、Mesh、Torus、全连接、胖树等）
- **切换够快**：微秒级甚至纳秒级切换，能跟上智能任务的阶段变化
- **自动适配**：编译器自动分析任务，自动选择和切换最优拓扑

这不是遥远的科学幻想——我们已经有了完整的理论体系，也完成了FPGA原型验证：拓扑重构时间<3微秒，运行时切换约5纳秒。在相同节点和链路预算下，TCC相比最优静态拓扑，平均端到端执行时间降低44.9%，任务能耗降低48.9%，可扩展临界规模提升约14倍。

### 1.4 对智能生态基座的价值

**对基座来说，这是网络底座的核心技术。**

- **现在**：解决"算力有了但跑不起来"的燃眉之急，把现有算力的效能提升30%以上
- **未来**：为更高阶智能的涌现提供结构性基础——连接拓扑可塑，智能形态才能多样
- **生态**：掌握拓扑方向的标准定义权，带动整个生态向"拓扑可定义"的路线靠拢

这是一项底座性、奠基性的工作——不仅解决今天的算力释放问题，更为下一代智能的架构演进预留技术空间。

## 二、国内外发展现状与趋势

### 2.1 产业界：超节点与光互联成为主战场

**超节点架构已成产业共识。**

超节点不是多台服务器简单堆叠，而是靠专用高速互联，把成百上千颗AI芯片整合成"逻辑上单一的超级计算机"。中国信通院等机构在《超节点发展报告》中明确提出："超节点将成为AI时代的核心计算单元。"

产业进展非常快：

- **华为**：2026年9月全联接大会上发布昇腾960超节点，全球首个采用近封装光学（NPO）技术的AI超节点，单超节点可互联4096张NPU，依托灵衢UnifiedBus协议最高可扩展至百万卡集群
- **Atlas 950 SuperPoD**：8192卡规模，全液冷+全光互联，FP8算力8 EFLOPS，互联带宽16PB/s，训练/推理性能较上代提升17倍/26.5倍
- **光互联全面爆发**：2026年被称为"光互联规模商用元年"。NPO（近封装光学）、CPO（共封装光学）、OCS（光电路交换）三条技术路线同步推进，光模块需求呈爆发式增长
- **全球趋势**：英伟达、谷歌、Meta、微软都在押注光互联+超节点。OFC 2026大会上，"Scale Across"（跨数据中心规模扩展）成为核心议题，千兆瓦级AI集群正在驱动骨干网重构

**一个关键观察**：所有这些产业投入，都集中在"材料层"（光互联）和"协议层"（高速互联协议）上。**在"结构层"——也就是拓扑本身能不能动态变化——这个方向上，产业界还没有大的突破。**

这正是我们的切入窗口。

### 2.2 学术界：可重构拓扑是前沿方向

可重构拓扑不是新概念，但一直受限于切换速度太慢。现有方案的情况：

- **数据中心OCS光交换**：拓扑可以重构，但切换速度是毫秒级，只能做粗粒度、低频的调整
- **FPGA动态部分重构（DPR）**：可以改NoC拓扑，但重构时间也是毫秒级，而且工具链不完善
- **HPC领域的"不频繁拓扑重构"**：靠历史流量矩阵指导拓扑调整，本质还是静态优化的延伸

**所有这些方案都面临同一个天花板：切换速度慢、粒度粗、与计算任务脱节。**

谁率先突破微秒级运行时可重构拓扑的工程化与工具链，谁就掌握了下一代AI计算架构的主动权。

### 2.3 脑科学的启示：连接组学提供了新的科学依据

果蝇全脑连接组的研究，从另一个维度支撑了我们的方向：

- **FlyWire项目**（2024年Nature封面）：首次完整构建成年雌性果蝇全脑连接组，139,255个神经元、超5000万个突触，发表了9篇Nature系列论文
- **雄性果蝇中枢神经系统连接组**（2026年9月Cell）：谷歌联合HHMI Janelia发布，16.6万个神经元、1.25亿个突触，覆盖大脑+腹神经索，是迄今规模最大的经过人工校对的完整脑图谱
- **从连接组到行为**：多个独立实验证明，忠实复刻生物连接组的数字模型，能够自然涌现出复杂行为——这为"拓扑决定计算形态"提供了最直接的实证

脑科学的结论很清楚：**智能不是神经元数量的简单堆砌，而是连接结构的复杂产物。** 不同的连接拓扑，对应不同的计算能力和智能形态。

这给我们的启示是：**让计算系统的拓扑可重构，本质上是在向生物脑的工作方式靠近。** 这不仅是工程优化，更是计算范式的跃迁。

## 三、项目定位与研究目标

### 3.1 项目定位

面向智能生态基座对网算一体的核心需求，开展拓扑中心计算（TCC）的关键技术研究与验证。构建"一入口三分层"四大技术平台体系，完成典型智能场景的效能验证，形成白皮书、验证报告、标准规范三大类核心产出。

**技术路径**：FPGA原型验证 + 仿真验证双轨推进
**编程模型**：以P4语言拓扑扩展（P4-T）为统一编程接口
**三大产出**：技术白皮书、系列验证报告、标准规范草案

### 3.2 研究目标

**总体目标**：突破运行时可重构拓扑生成、拓扑-路由协同控制、拓扑感知编译与调度、典型智能场景适配等关键技术，建成完整的TCC技术栈，为智能生态基座的网络底座提供理论依据、技术路径与标准支撑。

**具体目标**：

1. **理论方法层面**：建立智能场景下拓扑中心计算的理论框架、拓扑表征方法与效能评估体系
2. **关键技术层面**：突破运行时可重构拓扑生成、拓扑-路由同步切换、拓扑编译调度、P4拓扑扩展等核心技术
3. **平台工具层面**：建成四大技术平台，形成从P4-T统一编程→拓扑编译调度→仿真验证→FPGA实测的完整工具链
4. **场景验证层面**：完成四类典型智能场景的验证，证明拓扑可重构对算力效能的显著提升作用
5. **标准规范层面**：形成3项专项标准规范草案 + 一套基准测试套件，掌握网算一体拓扑方向的标准定义权

## 四、研究内容与四大平台

### 研究内容一：P4-T统一编程平台

**定位**：四大平台的统一编程入口，实现拓扑结构与数据包处理的联合描述与下发。

**核心内容**：
1. P4语言拓扑扩展（P4-T）设计——在标准P4-16基础上扩展拓扑可编程能力
2. P4-T编译器开发——支持FPGA、仿真、软件交换机三种目标输出
3. P4-T运行时系统——拓扑页管理、切换调度、状态跟踪
4. P4-T示范应用与评估

### 研究内容二：拓扑编译调度平台

**定位**：整个系统的"大脑"，负责把计算任务翻译成最优的拓扑策略。

**核心内容**：
1. 智能任务通信特征建模与提取——建立"通信结构签名"描述方法
2. 拓扑描述语言（TDL）与形式化方法——面向计算语义的拓扑表征
3. 拓扑智能调度算法——"任务-拓扑-路由"三层适配
4. 拓扑编译调度工具链开发——对接主流深度学习框架

### 研究内容三：拓扑仿真验证平台

**定位**：大规模设计空间探索的"探路者"，先在仿真里跑通跑优，再到FPGA精确实测。

**核心内容**：
1. 多尺度仿真平台架构设计——架构级/系统级/体系级三层仿真
2. 动态拓扑切换建模——拓扑页、切换时序、路由同步
3. 智能任务负载建模——典型任务通信负载模型库
4. 设计空间探索工具——自动搜索最优拓扑策略
5. 仿真与FPGA实测对标校准

### 研究内容四：FPGA原型验证平台

**定位**：技术可行性的"实锤"，所有仿真结论最终要在硬件上跑出来。

**核心内容**：
1. 多FPGA可重构拓扑原型系统设计——4~8片高端FPGA，支持≥8种拓扑模式
2. 拓扑配置快照与控制子系统——Topology Page + 原子提交
3. 原型验证平台的调试与测试能力
4. 与现有平台的对标验证

**8种拓扑模式的选取依据**：覆盖规则拓扑族（Ring/Mesh/Torus）、层级拓扑族（Tree/Fat-Tree/Butterfly）、全连接/超立方族（All-to-All/Hypercube）三个维度，确保对主要通信模式的充分覆盖。

### 研究内容五：运行时可重构拓扑生成与拓扑-路由协同控制

**定位**：跨平台的核心技术研究。

**核心内容**：
1. 可重构拓扑生成机制——元拓扑基元 + 可配置通路
2. 拓扑-路由同步更新机制——影子路由表 + 原子提交
3. 拓扑级容错重构技术——故障检测-决策-切换的闭环

### 研究内容六：MilTec-Bench基准与验证体系

**定位**：横切所有平台的统一度量衡。

**核心内容**：
1. 智能典型算法库（测试用例集）——四类场景标准负载
2. 标准化评估指标体系——≥4维度、≥15项具体指标
3. 端到端验证框架——自动化测试、A/B对比
4. MilTec-Bench基准测试套件v1.0

### 研究内容七：典型智能场景验证与标准规范制定

**定位**：成果的集中输出。

**四类典型场景验证**：

| 场景 | 核心通信模式 | 验证目标 |
|---|---|---|
| 分布式态势认知模型训练加速 | All-Reduce、Reduce-Scatter | 训练吞吐率提升≥30% |
| 多平台协同推理加速 | 张量并行、流水线并行 | 推理能效提升≥25% |
| 指挥决策图计算加速 | 不规则消息传递 | 图计算性能提升≥35% |
| 拓扑级容错验证 | 故障恢复 | 恢复时间比路由绕路降低≥10× |

**三项标准规范**：
1. 网算一体拓扑描述与接口规范
2. 智能拓扑效能测试评估规范
3. 智能网络拓扑容错评估规范

## 五、考核指标

### 一级指标体系

| 一级指标 | 二级指标 | 指标内容 |
|---|---|---|

## 九、对专项的价值与贡献

### 技术价值

- 首次系统验证运行时可重构拓扑在智能场景的效能价值，为网算一体提供从理论→仿真→FPGA实测的完整数据支撑
- 突破可重构拓扑生成、拓扑编译调度、P4拓扑扩展等关键技术，填补国际上动态拓扑计算工具链的空白
- 形成的四大技术平台和MilTec-Bench基准，可直接服务于生态基座上的各类智能应用验证

### 标准价值

- 牵头制定3项专项标准规范草案，掌握网算一体拓扑方向的标准定义权
- 效能测试与容错评估规范的制定，确立我们在智能网络效能评估领域的技术引领地位
- P4-T语言扩展为智能网络可编程提供统一的编程接口标准，带动生态向TCC路线靠拢
- MilTec-Bench基准为全行业提供公平可比的拓扑效能评估基准

### 生态价值

- 为智能生态基座提供网络底座的顶层设计与技术支撑，提升整个生态的计算效率
- 四大技术平台可作为生态的公共验证平台，服务全生态的网络技术验证与性能评估
- MilTec-Bench基准测试套件可作为生态的标准评测工具，支撑体系效能测试
- 可重构拓扑IP核与工具链可纳入跨域资源池，赋能生态伙伴

### 范式价值

- 从"计算中心"向"拓扑中心"的范式跃迁，为智能计算提供新的技术路线选择
- 拓扑作为一等体系结构对象，为未来智能从"模型驱动"向"结构驱动"演进奠定技术基础
- 脑科学与连接组学的最新进展表明，拓扑结构不仅是通信效率问题，更是智能涌现的结构性前提——TCC所探索的可变连接计算范式，更接近生物脑的工作方式，为更高阶智能的涌现提供架构可能
- 本项目是底座性、奠基性工作——不仅解决当前算力释放问题，更为下一代智能的架构演进预留技术空间
