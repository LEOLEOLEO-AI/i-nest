### 2.1 Theorem 1：拓扑信息容量定理（2026.Q3-Q4）

> 对于 N 节点物理网络 G，拓扑信息容量 C_topo(G) = log2(可达拓扑配置数)/N。
> 当小世界系数 sigma(G) > 1 时，C_topo(G) 随 sigma 超线性增长。

**证明路径**：
1. 对每个 SDI 化合键可配置状态，定义"有效拓扑自由度" F_topo
2. 对 sigma>1 的小世界网络，利用高聚类系数和短路径长度，证明远端节点信息交互可通过 O(log N) 中间节点完成，冗余路径数 r 正比于 sigma
3. 组合计数：冗余路径组合数随 r 超指数增长，C_topo 正比于 r*log N 正比于 sigma*log N
4. 紧致性验证：sigma=1 时 C_topo = log(N)；sigma>1 时用 SDI 配置熵严格下界

**依赖**：图论（小世界模型）、信息论（信道容量）、组合数学（路径计数）
**参考**：Watts & Strogatz (1998)、Tononi (2004) 信息整合理论 Phi

### 2.2 Theorem 2：临界能效定理（2026.Q4-2027.Q1）

> 对于完成认知任务 T 的物理网络 G，能耗 E(G,T) 在 G 处于自组织临界态（sigma>=4.0，avalanche size 服从幂律分布）时取最小值。

**证明路径**：
1. 能耗分解：E = E_comm + E_comp + E_idle
2. 临界态性质：(a) 雪崩尺寸幂律分布 P(s)~s^(-tau) 最小化大规模级联激活；(b) 分支比 m≈1 最优化信息传播效率
3. 变分原理：自由能 F = E - T_eff*S，临界态是 F 极小值点（与 FEP 对齐）
4. Jensen 不等式：E[E(T)] >= E_crit，等号当且仅当 G 处于临界态
5. CST 闭合：证明 CST(G) -> sigma(G) 是单调映射

**依赖**：统计物理（SOC）、变分法（自由能最小化）、CST 三元组
**参考**：Bak, Tang & Wiesenfeld (1987) SOC、Friston (2010) FEP

### 2.3 Theorem 3：原语完备性与增益可组合性定理（2027.Q1-Q2）

> TCC 的 16 原语集是最小完备生成集：(1) 任一超非线性增益场景可表示为 (R.x 异或 T.y) 原语对的有限序列；(2) 不存在少于 16 原语的完备生成集；(3) 原语序列长度与增益幅度呈线性下界关系。

**证明路径**（已在[待办](http://127.0.0.1:8899/home/work/.openclaw/workspace/30_TCC/34_Projects/待办_原语体系数学统一证明.md)中规划）：

| 子命题        | 内容                                                        | 方法             |
| ---------- | --------------------------------------------------------- | -------------- |
| P1 最小完备性   | 16原语完整覆盖 + 逐个不可消去                                         | 操作语义正交性 + 代数约化 |
| P2 类别正交性   | Route/Transform/Control 直和分解                              | 群论：不可约表示       |
| P3 版本兼容性   | v8->v30->TCC-11 等价链                                       | 原语代数等价映射       |
| P4 专利等价性   | v30 16原语 等价于 TCC-11 11原语                                  | 操作语义模拟         |
| P5 场景覆盖    | 620+ 计算映射点全覆盖                                             | FPGA 实测数据验证    |
| **P6（新增）** | **增益可组合性**：Delta(J/task, D_task, V_transfer) 可通过原语对序列线性叠加 | 线性规划 + 操作语义组合  |

**P6 核心映射**：
- R.PIPE 异或 T.FOLD -> 降低 E_comm（流水归约 + 向量归约）

**依赖**：操作语义学、代数结构（半环/群/格）、FPGA RTL 实测
**参考**：TCC-11 专利（ncc.*）、NCCL 通信原语映射

## 三、三定理的闭合链路

```
Theorem 1 (拓扑容量)           Theorem 2 (临界能效)           Theorem 3 (原语完备性)
       |                            |                            |
 sigma>1 -> C_topo 超线性      临界态 -> E 最小化            16原语 -> 增益可组合
       |                            |                            |
       +----------------------------+----------------------------+
                                    |
                          超非线性增益的完整形式化证明
                          "1+1>2" 从假说到定理的闭合
```

**闭合论证**：
1. Theorem 1 证明 sigma>1 赋予网络额外的拓扑信息容量（"why it is possible"）
2. Theorem 2 证明临界态是能耗最小化的热力学必然（"why it is optimal"）
3. Theorem 3 证明 16 原语可以组合出任意增益路径（"how to engineer it"）
