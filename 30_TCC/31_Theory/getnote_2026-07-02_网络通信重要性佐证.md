# 网络通信重要性佐证

关于“数据搬移能耗显著高于计算能耗”，**“系统与器件层面的多项研究表明，数据搬移能耗通常显著高于基础算术计算，数量级可达数百倍乃至更高。”** 其中，Horowitz 给出的经典45nm量级数据是：16b add 约 0.05 pJ，32b SRAM read 约 5 pJ，32b DRAM read 约 640 pJ；与此同时，Google 工作负载研究显示，数据搬移在所研究场景中平均占总系统能耗 62.7%，在 Google Docs 滚动场景可达 77%。这比直接写成固定“350—700倍”更严谨，也更抗质疑。[Horowitz / ISSCC 2014 引用页](https://www.nationalacademies.org/cdn/materials/9fba0a4f-e3a5-42ba-92e7-7f2865c62bb6) [Google Workloads Paper](https://ghose.cs.illinois.edu/papers/18asplos_googlepim.pdf)

关于“集合通信可占总时长40%—70%”，：**“在大规模分布式训练，尤其是 MoE 等通信密集型训练中，集合通信与相关同步已成为关键瓶颈，其开销可达训练总时间的 40%—70%量级。”** 具体依据是：NeurIPS 2024 的 LSH-MoE 论文给出 all-to-all 通信**平均约占 45%**、**最高可达 67%**，具体模型中约 **40%（RoBERTa-MoE）**、**70%（Swin-MoE-L）**；Huawei Research 则进一步说明，网络已处于 AI 基础设施核心，基础模型训练中不可重叠流量可占总通信的 30%，集合通信在训练与推理中都愈发关键。[NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/61674667d642ae52f6bb281bea90ee29-Paper-Conference.pdf) [Huawei Research](https://www-file.huawei.com/admin/asset/v1/pro/view/1f6f46557899427b9d6b37f0862a550d.pdf)

“方向正确性”：Google 正在强化 ICI/DCN、Virgo、Boardfly 与 XLA 的软硬协同；Huawei 强调网络—计算—同步的系统级协同；SambaNova 明确提出“通信可编程、数据流可重构、最小化数据搬移”；Groq LPU 则从推理场景证明，低延迟、片上SRAM、静态调度、软件调度网络正在成为新一代系统设计重点。**在全球前沿共同逼近的结构性方向上，提出更激进、更原创的中国方案。** [Google Cloud Blog](https://cloud.google.com/blog/products/compute/tpu-8t-and-tpu-8i-technical-deep-dive) [Huawei Research](https://www-file.huawei.com/admin/asset/v1/pro/view/1f6f46557899427b9d6b37f0862a550d.pdf) [SambaNova Whitepaper](https://sambanova.ai/hubfs/23945802/SambaNova_Accelerated-Computing-with-a-Reconfigurable-Dataflow-Architecture_Whitepaper_English-1.pdf) [Groq Blog](https://groq.com/blog/inside-the-lpu-deconstructing-groq-speed) [LPU Paper](https://arxiv.org/html/2408.07326v1)
