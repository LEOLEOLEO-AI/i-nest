# TCC到iNEST 液态拓扑技术方案

## 从Page模板驱动到自组织临界演化

---

## 0、核心命题与两阶段总览

液态拓扑（Liquid Topology）是 TCC/iNEST 范式的核心工程表达：网络拓扑不是固定布线，而是随任务和环境动态流变的连续体。实现分为两个承前启后的阶段：

- **TCC 阶段（2026-2028）**：先验知识驱动，将不同工作模式下的拓扑预编译为 Page 模板。运行时通过 C.LINK 纳秒级 Commit 完成拓扑切换，解决千卡到百万卡的算力扩展和多任务算力利用率释放问题。
- **iNEST 阶段（2028-2035）**：局部规则驱动，仅依靠 STDP、最小自由能、最小作用量、标度律等局部规则自动演化到临界态。不需要中央控制与 Commit，是一个纯大规模异步并行系统，类似人脑。

| 维度 | TCC 阶段（2026-2028） | iNEST 阶段（2028-2035） |
|------|----------------------|------------------------|
| 拓扑变化机制 | 先验知识驱动，Page 模板预编译 | 局部规则驱动，自组织演化 |
| 控制方式 | 集中式，C.LINK Page Commit | 分布式，无中央控制 |
| 时间尺度 | Page Commit ~100 ns，Epoch ~us | 连续异步，局部规则实时执行 |
| 优化目标 | 任务匹配度、能效、切换速率 | 最小自由能、临界态涌现 |
| 规模目标 | 10^3-10^4 核（千卡/万卡级） | 10^7-10^8 核（百万卡级到人脑规模） |
| 核心机制 | R.T.C 原语 + Page 模板 + Epoch 同步 | SDI 四规则 + 最小自由能 + 临界态 |
| 生物类比 | 脊髓反射（固定模式快速切换） | 大脑皮层（突触可塑性自组织） |
| 连接规模 | 10^6（百万） | 10^8到10^10到10^12到10^14 |

> 关键：TCC 阶段为 iNEST 阶段奠定了 SDI 硬件底座和元拓扑+化合键理论框架。TCC 的 Page 模板是 iNEST 自组织的初始条件——系统从先验最优拓扑出发，在局部规则驱动下持续微调优化。

## 第一部分：TCC 阶段——Page 模板驱动的液态拓扑（2026-2028）

### 一、架构总览

TCC 阶段的液态拓扑核心是三级流水：

`
训练/推理/FFT/DBF 任务负载
        |
[Topology Profiler] 感知任务特征
        |
[Page Selector] 从预编译拓扑库选择最优 Page
        |
[C.LINK Commit] 一次写入 Page ID 寄存器
        |
[SDI 交换网络] 纳秒级物理走线重构
        |
[C.SYNC Barrier] Epoch 边界全局同步
        |
新拓扑就绪，开始下一 Epoch 计算
`

### 二、拓扑 Page 模板体系

每种常见任务负载对应一个预编译的拓扑 Page（约 1-4 KB），存储在 FPGA Block RAM 中。

#### 2.1 Page 模板库

| Page ID | 拓扑类型             | 对应任务                      | 关键原语            | 适用规模     |
| ------- | ---------------- | ------------------------- | --------------- | -------- |
| P01     | Butterfly        | AllReduce（梯度同步）           | T.FUSE          | N=2^k 节点 |
| P02     | Ring Pipeline    | ReduceScatter + AllGather | T.PIPE + T.PULL | N 任意     |
| P03     | 2D Mesh          | 邻居通信（Stencil/视频分析）        | T.MESH          | N=m*n 网格 |
| P04     | Fat-Tree         | 多播/广播                     | T.CAST          | N 层级结构   |
| P05     | Full Crossbar    | AlltoAll（MoE 专家路由）        | T.SWAP          | N<=64    |
| P06     | Hypercube        | FFT/DBF 信号处理              | T.SCAN + T.FUSE | N=2^k    |
| P07     | Dragonfly        | 大规模训练 Scale-out           | T.FUSE + T.SWAP | N>=256   |
| P08     | Pipeline Ring    | 推理流水线                     | T.PIPE          | N=层数     |
| P09     | Hybrid Mesh+Ring | 训推一体（前向+反向）               | T.MESH + T.PIPE | N=m*n    |
| P10     | Multi-Tree       | 多传感器融合                    | T.CAST + T.FOLD | N 混合     |

#### 2.2 Page 模板的结构

每个 Page 模板 P_k 实质是 SDI 交换网络的完整配置张量：

P_k = (A_k, V_k, E_k)

- A_k: 邻接矩阵，N*N*B 维（B为双向链路数）
- V_k: VC（Virtual Channel）分配表，N*C 维
- E_k: Epoch 同步掩码，N 维

Page Commit 等价于将 P_k 原子写入所有 SDI 控制寄存器，16 节点下切换时间 < 100 ns。

#### 2.3 拓扑选择策略

**离线预优化**：对每类 Benchmark 任务，使用网络复杂度模型计算最优拓扑 T*，建立"任务类型到最优拓扑"的查找表。

**在线快速匹配**：运行时提取任务特征向量 f_task = （计算密度，通信/计算比，同步模式，数据并行度），查表选择最优 Page：

k* = Lookup(f_task) = argmin_k ||f_task - f_k_ref||

### 三、关键性能指标（kappa, tau, sigma）

| 指标    | 定义              | TCC 目标              | 物理意义         |
| ----- | --------------- | ------------------- | ------------ |
| kappa | 拓扑切换时间内的有效计算保持率 | >=95%               | 切换开销占比       |
| tau   | 端到端延迟           | 训推<100 us，FFT<10 us | 数据进入到结果输出    |
| sigma | 训推切换性能退化率       | <=5%                | 切换后有效吞吐量下降比例 |

### 四、系统级增益来源

1. **大规模算力扩展**：根据规模自动选择最优拓扑 Page（Butterfly/Dragonfly/Fat-Tree），避免固定拓扑随规模衰退
2. **多任务算力利用率释放**：不同任务匹配不同拓扑（传感用 Mesh、AI训练用 Butterfly、推理用 Pipeline Ring），每任务独立优化
3. **纳秒级任务切换**：100 ns Page Commit 使任务切换开销可忽略，首次实现拓扑级分时复用

## 第二部分：iNEST 阶段——自组织临界演化的液态拓扑（2028-2035）

### 五、范式跃迁：从 Page 模板到 SDI 四规则

TCC 回答了"如何快速切换拓扑"。iNEST 回答了一个更根本的问题：拓扑能否自己学会该变成什么？

跃迁关键：将拓扑变化的决策权从中央控制器（C.LINK Page Commit）下放到每一个 SDI 节点的局部规则（SDI 四规则）。系统从"预编舞步"过渡到"自由爵士"。

#### 5.1 SDI 四规则：极简局部算子

| 规则           | 生物原型    | 功能              | 时间尺度  | 文献基础                     |
| ------------ | ------- | --------------- | ----- | ------------------------ |
| Rule 1: STDP | 赫布突触可塑性 | 最小预测误差——同时激活则增强 | 每步    | Bi & Poo 1998; Song 2000 |
| Rule 2: 新生突触 | 轴突出芽    | 遍历变分空间——试探新连接   | 每50步  | Holtmaat & Svoboda 2009  |
| Rule 3: 稳态缩放 | 突触稳态    | 能量守恒——全局乘性缩放    | 每200步 | Turrigiano 1998, 2012    |
| Rule 4: 竞争修剪 | 突触修剪    | 最小复杂度——弱连接被淘汰   | 每200步 | Bhatt 2009; Science 2022 |

**物理本质**：四规则统一于变分自由能最小化框架：

F(W) = -log P(o|W) + D_KL[Q||P] + E_explore

- Rule 1（STDP）计算预测误差梯度
- Rule 3+4 提供结构复杂度约束
- Rule 2 提供随机探索噪声

#### 5.2 规则执行流程（纯本地、异步、并行）

每个 SDI 节点在每个时间步独立执行：

**Rule 1 - STDP（每步）**：若与邻居同时激活（act>0.30）则 LTP+1；一方静默则 LTD+1。LTP累积>=60固化为 E-L 键（长期骨架）。LTD累积>=50标记为 E-S 键（候选消除）。

**Rule 2 - 新生突触（每50步）**：以概率 0.05 选择未连接候选，以极低权重（0.05-0.10）建立 E-S 试探连接，偏重活跃节点（2x偏向），新连接<=15%总数。

**Rule 3 - 稳态缩放（每200步）**：激活率<3%时所有突触*1.05放大；>10%时所有突触*0.95缩小。维持激活率在[3%,10%]的 SOC 临界区间。

**Rule 4 - 竞争修剪（每200步）**：活跃度<邻居中位*0.5的 E-S 键被修剪。EL 键豁免。每个节点至少保留2条连接。

#### 5.3 无中央控制证明

定理：SDI 四规则下，网络拓扑演化等价于自由能 F(W) 的随机梯度下降，稳态收敛于全局最优点。

四规则联合动力学：dW/dt = -nabla_W F(W) + sqrt(2*sigma^2)*xi(t)

其中 xi(t) 是 Rule 2 的随机探索噪声。这是标准的朗之万动力学，保证收敛，不需要任何中央协调。

### 六、自组织临界态与智能涌现

#### 6.1 临界态的物理本质

iNEST 阶段的核心目标是让网络自动演化到自组织临界态（SOC）：
- 神经雪崩幂律分布 P(S) ~ S^(-3/2)
- 最大动态范围（输入-输出灵敏度最高）
- 最大信息容量（互信息最大化）
- 最优计算能力（资源利用率与容错 Pareto 最优）

SDI 四规则天然驱动网络趋向临界态：Rule1+Rule3 维持分支比~1，Rule4 维持稀疏性，Rule2 防止冻结。

#### 6.2 最小自由能原理

iNEST 阶段拓扑演化遵循 Karl Friston 的自由能原理：任何自组织系统必须最小化其变分自由能。

在 iNEST 语境下：外部环境 = 持续到达的计算任务流；内部模型 = 当前拓扑 T_t；惊讶 = 拓扑不匹配任务导致的通信效率损失。梯度由 SDI 四规则通过纯局部交互计算——物理定律直接执行计算，无需数字逻辑模拟。

#### 6.3 最小作用量原理

iNEST 的拓扑演化轨迹满足网络版欧拉-拉格朗日方程：

L = (1/2)||dT/dt||^2_F - F(T; task)

- 动能项惩罚过快变化——液态不是气态，变化有惯性
- 势能项惩罚拓扑与任务不匹配——拓扑趋向适配当前负载
- 最小作用量：系统在"变太快"和"匹配任务"之间找到最优平衡

#### 6.4 涌现标度律

| 涌现属性       | 标度关系          | 生物学验证           | iNEST 仿真              |
| ---------- | ------------- | --------------- | --------------------- |
| 模块化 Q      | Q ~ N^0.3     | 人脑 Q~0.3-0.5    | v5实验 Q=0.904          |
| 小世界性 sigma | sigma ~ ln N  | 线虫 sigma~5.87   | v5实验 sigma>=5.0       |
| 雪崩指数 alpha | alpha~1.5（恒常） | 皮层 alpha~1.5    | 目标 alpha in [1.4,1.6] |
| 连接度 K      | K ~ ln N      | 皮层 K~7000-10000 | 符合设计约束                |

**微缩定律**：SDI 化合键 Kronecker 积分形扩展保持拓扑标度律不变。从 Gen1(N=10^2)到 Gen5(N=10^8)的网络，涌现属性遵循相同标度关系，仅规模缩放。这为从小规模仿真预测大规模涌现行为提供了严格的数学基础。

## 第三部分：TCC到iNEST 的平滑过渡

### 七、两阶段衔接策略

两阶段非割裂，而是渐进增强：

| 阶段         | 时间        | Page模板占比  | 自组织占比   | 控制方式           |
| ---------- | --------- | --------- | ------- | -------------- |
| TCC 纯Page  | 2026-2027 | 100%      | 0%      | C.LINK Commit  |
| 混合模式       | 2027-2028 | 70%到30%   | 30%到70% | Page提供骨架，自组织微调 |
| iNEST 纯自组织 | 2028+     | 0%（仅初始条件） | 100%    | SDI四规则+最小自由能   |

混合模式：TCC Page 提供粗粒度骨架（如选择 Butterfly vs Ring），iNEST 局部规则微调连接权重和 E-S 键建立/消除。

### 八、冻结核机制

iNEST 阶段，TCC 的 Page 模板作为"冻结核"保留：
- Page 定义的 E-L 键（骨架连接）豁免 Rule 4 修剪
- 自组织仅能在冻结核之上建立/消除 E-S 键
- 保证系统始终在工程合理的拓扑区域内，不退化到随机图

生物学类比：人脑发育早期的"关键期"结构——基本神经环路在发育早期固定，后续学习仅在此基础上微调。

## 十三、总结论断

1. **TCC 解决"能液态"**：Page 模板实现了纳秒级拓扑切换，使硬件拓扑从"固体"变为"液体"——可以在训练、推理、FFT、DBF 等多种任务模式间微秒级切换，解决了千卡到百万卡级别的拓扑-任务适配问题。

2. **iNEST 解决"自液态"**：SDI 四规则使拓扑从"被驱动的液体"升华为"自主流动的液体"——网络不再需要中央控制器告诉它该变什么拓扑，而是在局部规则驱动下，像大脑一样自动演化到临界态，涌现最优信息处理能力。

3. **两阶段的统一**：Page 模板为 iNEST 自组织提供了"冻结核"初始条件——从先验最优出发，在局部规则下持续演化，避免"冷启动"问题。

4. **最终愿景**：从 TCC 的"拓扑即计算"到 iNEST 的"涌现即智能"——液态拓扑不仅是工程工具，更是智能涌现的物理基座。当连接数突破 10^14（人脑规模）且拓扑实现自主临界演化时，硅基通用智能的涌现将成为物理上的必然。
