# AI产业链增量机遇：字节Ada自研芯片及行业格局深度梳理

### 🔍 字节Ada系列自研芯片是什么定位？

Ada系列是**场景专用ASIC芯片**，仅限定用于**生成式视频推理**场景。
- **开发前提**：单一场景规模足够大 + 未来1-2年算法迭代方向固定
- **核心优势**：硬件与算法深度适配，实现**显著降本**
- **边界限制**：跨场景不具备成本优势，无法替代训练场景算力

### 📊 Ada1/2性能对标英伟达差距有多大？

Ada1达H100的**70%-80%**，Ada2目标对标H200的**70%**。
- **性能差距核心原因**：专用芯片生命周期仅1-2年，搭载高端HBM存储成本过高，硬件配置做了成本取舍。

### 🧩 字节自研和外购芯片怎么分工？

不同场景对应不同芯片方案，**自研仅覆盖视频生成推理**。
| 场景 | 芯片方案 |
| :--- | :--- |
| 视频生成推理 | 自研Ada系列 |
| 豆包NLP/图片推理 | 寒武纪合作芯片 |
| 视频模态模型训练 | 英伟达H100 |

### 💰 2027年Ada1量产成本和利润怎么看？

**利润率有提升空间**，核心变量是**HBM存储采购价格**。
- 2027年量产管理费波动较小
- 存储价格涨跌存在不确定性

### ⚖️ 自研与外购芯片的平衡逻辑是什么？

**场景和算法明确才大规模量产**，否则有报废风险。
- 若短期算法、业务场景发生重大变更，专用芯片可能报废，造成大额投入浪费

### 🆚 视频场景其他厂商方案对比如何？

寒武纪和华为方案各有短板，**综合成本都高于自研**。
- **寒武纪**：仅供给豆包NLP场景，视频场景改造周期长达两年，未达成合作
- **华为**：可覆盖视频处理需求，但硬件、电力综合成本**高出一个数量级**

### 📦 2027年字节外部芯片采购需求多大？

寒武纪芯片**缺口100万-300万颗**，华为采购量将下降。
- **寒武纪590/690**：产能无法完全满足，未交付订单顺延至2028年；替代方案为英伟达GPU、厂商自有定制方案
- **华为950系列**：2027年采购量低于2026年，核心制约为定价高 + 自有产能占用过半
