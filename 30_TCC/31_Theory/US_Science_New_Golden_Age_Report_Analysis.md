# 美国《科学：新的黄金时代》报告深度解析：科研体制改革的机遇与争议

### 📄 这份报告是什么，由谁在什么时候提交的？

2026年7月21日，美国白宫科技政策办公室主任**迈克尔·克拉齐奥斯**向总统提交了**123页**的《Science: A New Golden Age》（科学：新的黄金时代）。
- **历史参照**：81年前，范内瓦·布什提交《科学：无尽的前沿》，为战后美国科研体制奠定基本蓝图。
- **旧框架逻辑**：基础研究 → 应用研究 → 技术开发 → 企业生产（前端是政府指导下的大学基础研究，后端是企业负责的商业化）。
- **核心判断**：81年前的框架帮助美国"赢得20世纪"，但**已无法容纳今天的科学**。

### 🔍 旧科研体制有哪些默认关系，问题出在哪？

旧体制形成了五组默认等式，报告认为这些关系**已严重制约科学发展**。

| 维度 | 旧体制默认关系 |
| :--- | :--- |
| 科学家身份 | ≈ 大学里的项目负责人 |
| 科研资助 | ≈ 项目申请 + 同行评议 |
| 科学机构 | ≈ 大学 + 国家实验室 |
| 科研成果 | ≈ 论文 |
| 基础研究 | ≈ 与产业保持距离的长期自由探索 |
- **同行评议局限**：擅长排除明显糟糕的研究，但**未必能区分"好研究"和"真正异乎寻常的研究"**，非常规、高风险想法容易吃亏。
- **其他弊病**：科研人员花太多时间写申请、行政合规和报告 + 经费越来越集中在少数成熟机构 + 青年研究者独立越来越晚 + 评价体系过分依赖论文和引用 + 复制研究奖励不足。
- **核心观点**：制度并不只负责"支持"科学，制度也在生产科学；随着科学成果井喷，制度反而在制约科学。
  说白了，你在什么机构里做研究，很大程度上决定了你会研究什么、怎么研究、能做出什么成果。

### 🎯 报告提出了哪四个改革目标？

报告开篇提出四大目标，核心是**让科研体系适配AI革命时代**。
- **资源分配**：让资源更多围绕科学家个人，扩大可携带奖学金、青年独立资助和长周期支持。
- **经费评价**：重新设计科研经费的分配和评价方式，在同行评议之外尝试"黄金票"、快速拨款、奖金和二次拨款。
- **产业制造**：为社会设定明确的科技目标并恢复工业和制造能力。
- **AI准备**：让整个科学体系为AI革命做好准备。
- **组织创新**：让聚焦研究组织、X-Labs和ARPA式团队承担规模太大、跨学科太强、商业回报又不明确的问题；重新把技师、工匠和学徒制纳入科学能力培养范畴。

### ❓ 报告的"万能机构"设想为什么被批评？

报告提出用"新机构"补充旧机构不足，但**没有给出具体形态和监管方案**。
- **旧机构缺陷**：大学有院系壁垒，企业受商业回报约束，国家实验室缺少灵活性。
- **新机构答案**：仅用"By design（可以通过设计做到）"回应，缺乏可操作的制度设计。
- **批评核心**：
  - 高校虽有官僚主义，但也承担着维持实验设施、训练研究生、保存学科经验、支持"无用之用"研究的功能，不能简单当作"行政负担"整改。
  - 即使经费跟着科学家本人走，研究者仍需要实验室、设备、技术人员、数据治理和稳定合作网络，**最终还是会流向现有机构**。
- **资源矛盾**：报告要求更大胆的科学家、更多实验、更多AI基础设施、新机构、更强国家实验室等，但所有这些都需要钱、稳定的科研机构、高水平人才和公务员体系支撑。

### 🌐 新的科学生态还能保持开放吗？

报告强调科学要服务国家利益，可能导致**研究方向窄化**。
- **第三主旨**：科学应当转化为美国的技术优势、制造能力、经济繁荣与国家安全。
- **资源倾斜方向**：物理科学与工程、关键技术、国内制造、供应链、产业合作、任务型研究；联邦研发向物理科学和工程、国家科技任务、AI应用、科研基础设施与区域产业生态重新平衡。
- **边缘领域**：难以迅速转化为产品、任务或竞争优势的领域，更容易退到边缘。
- **《自然》杂志批评**：真正的科学黄金时代需要国际人才流动，以及对社会科学、公共卫生和人文学科的充分支持，不能只把科学理解为技术与工程。

### 🤖 AI革命会给科学权力结构带来什么变化？

AI可能导致科学权力从研究者向**平台和管理者转移**。
- **未来图景**：数以万亿计的AI智能体运行实验、检验猜想和提出发现；科学知识可能复杂到没有任何个人能够完整理解，验证系统也可能庞大到没有任何个人能够独立审计。
- **权力转移**：当科学不再依赖研究者亲自理解全部推理过程，它就更依赖数据平台、算力设施、验证标准和系统治理。
- **权力去向**：同行评议的权利也许会减弱，权力可能转移到项目经理、平台运营者、模型开发者、数据拥有者和国家计划的制定者手中。

### 💡 报告最有价值的贡献和真正的争议是什么？

报告最大价值是打破了科学的"唯一格式"迷思，争议核心在于**改革会不会窄化科学的未来可能性**。
- **最有价值贡献**：迫使人们承认，大学、同行评议、项目申请和论文发表，从来不是"科学"的唯一格式。
- **真正的改革方向**：不是找到一种新制度取代所有旧制度，而是承认不同科学问题需要不同的时间、组织、评价与责任关系。
- **争议本质**：美国国内评价分裂，并不是一方支持改革、另一方拒绝改革；争议在于当基础经费收缩、科研规则可能被政治化时，科学研究可能越来越窄化。
- **结语观点**：一个国家的科学能力，既包括选择目标、集中资源和加速突破的能力，也包括支持某些暂时没有目标、无法预测结果，甚至不能立刻证明自身价值的研究。

### 📝 补充细节
- **参议院反对**：据《自然》杂志2026年8月3日报道，白宫这项全面改革美国科研资助的计划正面临参议院反对，由政治任命者掌管研究资助的提案可能被暂时叫停。
- **量子研究者案例**：同一位量子信息研究者，读博时要围绕毕业期限、现有设备、论文叙事和导师经费安排实验；创业后则围绕融资周期、商业故事和投资者信心选择技术路线。
