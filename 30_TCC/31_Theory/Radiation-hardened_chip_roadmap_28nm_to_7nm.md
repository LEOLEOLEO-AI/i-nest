# 星载计算架构：抗辐射芯片从28nm到7nm的太空征程

### 🔬 太空里的芯片怕什么？

太空辐射分**慢性累积**和**突发事故**两类，都会损伤芯片。
- **总剂量效应（TID）**：高能粒子长期轰击 → 氧化层产生俘获电荷 → 阈值电压漂移 → 晶体管无法正常开关
  - 衡量单位：krad（千拉德）
  - 低轨卫星年剂量：**1-10 krad**
  - 地球同步轨道：**100 krad 以上**
  - 军用抗辐射芯片要求：耐受 **100 krad 以上**
- **单粒子效应（SEE）**：单个高能粒子击中敏感区域 → 瞬态电荷脉冲
  - **SEU（单粒子翻转）**：存储单元 0/1 反转，不损坏硬件
  - **SET（单粒子瞬态）**：组合逻辑产生瞬态脉冲，可能被误采样
  - **SEL（单粒子闩锁）**：CMOS 寄生晶闸管导通 → 短路大电流 → **可能烧毁芯片**
  - **SEB/SEGR（单粒子烧毁/栅穿）**：功率器件永久损坏

### ⏳ 为什么太空芯片工艺比地面落后10年？

**先进工艺怕辐射 + 市场小 + 验证慢**，三重因素导致代差。
- **辐射敏感度高**：工艺越小 → 晶体管更小、氧化层更薄、工作电压更低 → 存储电荷更少 → **7nm SEU率比28nm高一个数量级**
- **商业回报低**：抗辐射芯片年需求仅数千颗，先进产线投资超 **200亿美元**，代工厂无动力单独开发
- **认证周期长**：辐射测试 + 温度循环 + 振动测试 → 认证需 **2-5年**，等7nm认证完地面已是2nm

### 🛡️ 抗辐射加固有哪三条技术路线？

工艺级、封装级、系统级三条路线，**强度递减、成本递减**。

| 路线 | 核心原理 | 代表产品 |
| :--- | :--- | :--- |
| 工艺级加固（RHBD） | 设计阶段用抗辐射版图 | Microsemi RT ProASIC3 |
| 封装级加固（Shielding） | 外部加金属屏蔽层 | 卫星铝壳 + 钽贴片 |
| 系统级加固（COTS+容错） | 商用芯片 + 软件容错 | Starcloud-1 H100 |
- **工艺级加固**：环形栅防漏电、封闭版图晶体管消寄生晶闸管 → TID > **1000 krad**，工艺停留在 65nm-28nm
- **封装级加固**：主要降低 TID，**对重离子几乎无效**，对 SEE 效果有限
- **系统级加固**：三模冗余（TMR）、纠错编码（EDAC/ECC）、软件看门狗、定期刷新 → 成本最低，增长最快
  说白了，就是用便宜的商用芯片，靠"多备份+常纠错"来扛辐射错误。

### 🚀 从28nm到7nm，追赶进度如何？

**COTS+容错路线推动代差缩小**，已从65nm推进到4nm验证。

| 年份 | 代表芯片/系统 | 工艺节点 | 加固路线 |
| :--- | :--- | :--- | :--- |
| 2010s | Xilinx Virtex-5QV | 65nm | 工艺级加固 |
| 2020 | Intel Myriad 2（Phi-Sat-1） | 28nm | COTS+容错 |
| 2021-2024 | HPE Spaceborne Computer-2（ISS） | 14nm-7nm | COTS+软件容错 |
| 2025 | NVIDIA H100（Starcloud-1） | 4nm | COTS+系统容错（验证中） |
| 2025 | NVIDIA GPU（Loft YAM-9） | ~7nm | COTS+多节点冗余 |
- **注意边界**：ISS（国际空间站）有地球磁场 + 空间站结构双重屏蔽，辐射环境优于自由飞行卫星，**ISS验证不等同于独立卫星长期可靠性**

### ⚖️ 性能和可靠性的矛盾怎么解？

**分层加固是当前主流**，关键电路求稳、计算电路求快。
- **保守派**：老工艺 + RHBD → 万无一失，但算力低下，跑不了现代AI
- **激进派**：先进工艺 COTS + 系统级容错 → 接受更高 SEU 率，靠冗余扛住，设计复杂度和验证成本上升
- **折中派**：关键控制用 RHBD ASIC（如 LEON 处理器），AI 计算用 COTS GPU/FPGA → 各取所长，当前主流设计哲学

### 📝 补充细节
- 太空芯片用老工艺**不是技术落后**，而是"稳定优先"的刻意设计哲学
- 三种 SEE 中，**SEL（单粒子闩锁）和 SEB/SEGR** 会造成硬件永久损坏，SEU 和 SET 只是数据错误
- 封装级屏蔽对重离子无效，因为高能重离子能穿透任何实际厚度的屏蔽层
