# 交换芯片深度笔记：AI集群的下一个卡脖子环节

### 💡 为什么AI集群的瓶颈从GPU转向了互联？

**GPU利用率不足一半**，核心瓶颈在数据传输而非算力。
- **典型案例**：2026年某AI公司万卡集群，GPU平均利用率仅 **55%**，近半时间在空等数据。
- **核心比喻**：10万辆法拉利堵在早高峰 → 算力够强，但「路」不够宽。
- **关键角色**：交换芯片 = AI集群的「交通枢纽」，负责GPU间高速数据转发。

### 📊 交换芯片市场有多大，垄断程度有多高？

全球市场**55亿美元规模、年增39%**，海外垄断比AI芯片更极端。
- **全球格局（2026年）**：
  - 市场规模：2024年38亿 → 2026年55亿 → 2030年预计 **140亿美元**。
  - 竞争格局：博通 36% + Marvell 22% + 思科 20% = 三家垄断 **77%**；博通在云端数据中心市占约 **90%**。
  - 旗舰产品：博通Tomahawk 5（51.2T）占全球近6成份额，Tomahawk 6（102.4T、3nm、CPO）2025年发布。
- **中国市场**：
  - 海外垄断率 **97.8%**（博通61.7% + Marvell 20% + 瑞昱16.1%）。
  - 国产龙头盛科通信仅占 **1.6%**，远低于AI芯片约48%的国产化率。

### 🏭 国产交换芯片有哪些玩家，各自路线是什么？

三条路线并行，**盛科中立、中兴全栈、华为自用**。

| 厂商 | 路线定位 | 最高量产规格 | 核心特点 |
| :--- | :--- | :--- | :--- |
| 盛科通信 | 第三方中立芯片商 | 25.6T（Arctic系列） | 全行业供货，客户含新华三、锐捷、中兴 |
| 中兴微电子 | 系统级方案商 | 51.2T（凌云） | 7nm Chiplet，绑定中兴超节点系统 |
| 华为海思 | 全栈自研自用 | 51.2T级别 | 技术最强，不外售 |
- **盛科最新进展**：
  - 2026年7月关联交易额度从6亿上调至 **22亿元**，同比增长344%。
  - 获阿里 **3万颗25.6T** 订单，价值约9亿元。
  - 下一代51.2T预计2026下半年回片测试，机构预测2026年有望**首次扭亏**。
- **运营商与云厂动作**：
  - 中国移动2026年3月首次集采RoCE交换机，自主可控占比 **73.2%**。
  - 阿里云发布102.4T国产NPO交换机，由4颗25.6T国产芯片组成。

### ⚡ 超节点为什么是交换芯片的「十倍加速器」？

超节点架构让**交换芯片用量翻十几倍**，需求增速远超GPU。
- **配比变化**：
  - 传统Scale-out：64张GPU配1颗交换芯片（约1:20）。
  - 超节点Scale-up：128张GPU配 **16颗** 交换芯片（约1:8）。
- **价值占比**：交换芯片占集群总成本从 **5%** 向 **20%** 快速逼近（2027年预计接近20%）。
- **2026年中国超节点需求**：
  - 阿里盘古128：1800–2000台（单台16颗25.6T）。
  - 腾讯ETH-64：2300–2400台。
  - 字节大禹72卡：1800台。
- **市场增速**：中国交换芯片市场2026年约70亿元 → 2028年 **242亿元**，CAGR高达 **96%**；其中Scale-up市场CAGR达 **212%**。
  说白了，超节点每多装一台，交换芯片就得多买十几颗，需求是实打实的结构性增长。

### 🚧 国产交换芯片真正的挑战是什么？

**代际差一代、生态是最大短板**，先进制造同样卡脖子。
- **代际差距**：博通已量产51.2T、发布102.4T；国产最高量产25.6T，中兴51.2T刚商用，至少差一代。
- **制造与封装**：博通用3nm+CPO，国产仍在7nm节点；先进封装国产化率仅 **15%**。
- **生态锁定**：博通靠SDK+参考设计形成完整生态，硬件替代易、生态替代慢。
- **供应链**：仍依赖台积电等海外代工厂，CPO封装环节高度依赖海外。

### 🔮 未来格局会怎么演变？

**从「算力经济」转向「互联经济」**，互联价值占比逐年翻倍。
- **价值演变**：2026年交换芯片与GPU价值比约8:100 → 2028年预计接近 **20:100**。
- **两种可能路径**：
  - 务实路径：国产在25.6T–51.2T中端替代，国产化率30–50%，高端仍靠进口。
  - 弯道路径：Scale-up新赛道标准未统一，国产靠开放标准（OISA/UALink等）快速突破。
- **竞争维度切换**：2024年比GPU跑分 → 2026年比集群效率 → 2028年比互联方案。

### 📝 补充细节
- **互联效率对比**：InfiniBand（英伟达生态）约55%、以太网RoCE（开放标准）约65%、国产自研互联（曙光/凌波等）约60%。
- **超节点组件国产化率**：液冷散热85% > 高速PCB 70% > 电源芯片50% > 光模块40% > HBM 20% > 交换芯片15% ≈ 先进封装15%，交换芯片是最薄弱环节之一。
- **国产化率趋势**：中国交换芯片国产化率2020年10% → 2024年15% → 2026年预计37.5% → 2028年预计接近 **57%**。
