# v32 实验计划：CST六阈值严格对齐
## 日期：2026-06-07 | 状态：待启动

## 目标
主动控制σ进入CST六阈值区间，建立σ→智能能力的严格因果关系。

## 核心问题
v22-v31中σ无约束增长（最高19.5），与CST六阈值（上限Δ=4.669）完全脱节。
需要证明：**σ的具体区间对应具体的功能能力涌现**。

## 方法：主动σ控制
```python
# 通过调整Rule4修剪强度来控制σ
σ_targets = {
    'L1_感知': (0.60, 0.80),   # 目标σ ≈ √2/2 = 0.707
    'L2_反应': (0.90, 1.10),   # 目标σ ≈ 1.0
    'L3_适应': (1.50, 1.80),   # 目标σ ≈ φ = 1.618
    'L4_创造': (2.60, 2.90),   # 目标σ ≈ e = 2.718
    'L5_通用': (3.00, 3.30),   # 目标σ ≈ π = 3.14
    'L6_超级': (4.50, 4.80),   # 目标σ ≈ Δ = 4.669
}

# 控制机制：P_PRUNE调整σ
# σ高 → 增加P_PRUNE（加速修剪）
# σ低 → 降低P_PRUNE（减缓修剪）
```
