# 从SDSoW到iNEST基线总纲

## 核心问题

如何将高密度、动态可重构的物理网络转化为可控的系统级效用，并进一步转化为可验证的物理智能能力？资源密度至多是必要条件，不能作为智能已经出现的证据。

## 工作逻辑链

1. **SDSoW**提供可重构物理网络资源。
2. **CST**提出对可用时空协同复杂度的可度量描述。
3. **TCC**将工作负载需求映射到在线拓扑、计算和存储配置；近期目标是面向智算中心的可编程互连。
4. **SDDE**是描述局部状态、时延、记忆、非线性、材料/器件状态和环境反馈的候选模型族。
5. **SDI**是受约束执行器，负责校验、提交、记录和回滚离散拓扑动作。
6. **iNEST**利用局部规则、反馈和拓扑演化研发智涌脑，首先是Gen1感知脑。
7. **iMESO**是拟议的晶圆、芯粒或面板级物理平台，用于集成上述层次并开展工程验证。

## TCC与iNEST边界

| 主题 | TCC | iNEST |
|---|---|---|
| 核心使命 | 动态工作负载下拓扑、计算、存储的在线定义 | 物理智能智涌脑与自组织拓扑/激活 |
| 近期产品 | 可编程互连与系统原型 | Gen1感知脑 |
| 成功条件 | 扣除重构成本后的系统净效用 | 可复现任务能力与有边界的自适应行为 |
| 所需证据 | 公平的B0/B1/T1/T2对照、日志、硬件在环或实测 | 任务协议、消融、回放、鲁棒性和物理/仿真证据 |

## 六级智能操作化框架 `[Planning]`

| 等级 | 能力标签 | 操作化含义 |
|---|---|---|
| L1 | 感知 | 稳定提取与任务有关的环境信息 |
| L2 | 反应 | 低时延感知-行动闭环 |
| L3 | 适应 | 在线调整状态、拓扑或策略 |
| L4 | 创造 | 生成并验证新结构或新策略 |
| L5 | 通用 | 在已定义环境间迁移与整合 |
| L6 | 超级 | 仅开展理论与安全边界研究，不作为近期工程主张 |
