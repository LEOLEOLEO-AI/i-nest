# 苏州实验室 iNEST 先导项目指南

## 苏州实验室 iNEST 先导项目指南

## 从热力学非线性元件到智能涌现网络的全链条创新

领衔：邬江兴院士、徐南平院士

执行负责人：刘勤让

周期：４年

经费：２亿元

协同单位：苏州实验室、北京大学、天津大学、复旦大学、浙江大学、NDSC、中国科学院相关团队

---

## 摘要

本项目建议围绕“热力学非线性元件—复杂网络拓扑—混沌边缘计算系统”三层科学路线，设立从关键材料、非线性器件、晶上集成到智能涌现网络的先导项目。

项目以 Mott 相变、忆阻、相变、铁电、离子迁移等非平衡态材料过程为物理基础，构建可稳定偏置在混沌边缘的局部有源器件；通过电阻、电容、可重构互连和物理场耦合形成复杂动力学网络；进一步借助储备池计算、神经微分方程和动力学网络反馈控制，实现面向强非线性预测、优化搜索和类脑智能的物理可训练计算系统。

项目的核心主线是：**材料产生动力学，器件表达动力学，晶上网络耦合动力学，训练方法调控动力学，任务验证选择动力学。**

---

## 一、立项依据

### １．１　为什么现在必须做

现有图灵／冯诺依曼计算把连续物理世界离散化为符号、逻辑门和时钟步骤，在能量消耗、数据搬运、长时依赖和复杂系统预测方面面临系统性瓶颈。

与此同时，忆阻器、相变器件、功能氧化物、二维铁电材料和晶上集成工艺已经能够把材料内部状态变量、电学可观测量和网络耦合关系连成实验闭环。若此时仍只把新材料用作更小、更快的传统器件，将错过从物理规律重构计算范式的关键窗口。

### １．２　第一性问题

本项目关注的第一性问题是：

**计算是否只能由离散逻辑步骤完成，还是可以由开放非平衡物理系统在能量约束下，通过状态分布的受控演化完成？**

项目的基本判断是：物理计算不是简单的符号执行，而可以是系统从初始状态分布向目标吸引子分布的动力学演化过程。

高维状态展开→动力学搜索→低误差吸引子收敛

---

## 二、核心科学路线

### ２．１　三层科学路线


| 科学层级     | 核心问题                | 关键内容                            |
| -------- | ------------------- | ------------------------------- |
| 热力学非线性元件 | 哪些非平衡态材料过程可承载计算     | Mott 相变、忆阻、相变、铁电翻转、离子迁移、热涨落     |
| 复杂网络拓扑   | 如何把单器件时间复杂度转化为空间复杂度 | 电阻、电容、物理场耦合、可重构互连、小世界网络、高阶耦合    |
| 混沌边缘计算系统 | 如何使系统同时具备稳定性和可塑性    | Lyapunov 指数、传递熵、动态信息存储、储备池和反馈控制 |


### ２．２　核心逻辑

单个非线性器件提供时间非局部性，包括记忆、迟滞、延迟、振荡和分岔。

复杂网络提供空间非局部性，包括长程关联、模块化、层级结构、小世界传播和高阶耦合。

晶上集成的意义在于把材料、器件、耦合、读写、偏置、反馈和环境接口集成在同一物理平台中，使动力学网络能够从少量节点扩展到大规模节点，并逐步与外部环境交互。

## 三、CST 理论更新

### ３．１　CST 的定位

CST 不定义为智能本身，而定义为：

**开放非平衡物理网络在能量约束和环境闭环中，由非平衡态材料容量、空间拓扑组织、多尺度时间动力学和时空协同匹配共同形成的可用时空协同复杂度。**

### ３．２　CST V40 核心公式

CSTcap​(t)=Sc​(t)⋅Tc​(t)⋅exp[αeff​(t)⋅Γstu​(t)]

其中：


| 参数    | 新定义             | 物理含义                    |
| ----- | --------------- | ----------------------- |
| αeff​ | 非平衡态有效状态容量      | 材料内部状态变量可被稳定读出的有效信息容量   |
| Tc​   | 时间非局部性与多尺度动力学   | 记忆、迟滞、延迟、振荡、分岔和混沌边缘     |
| Sc​   | 网络空间非局部性与拓扑组织能力 | 连通性、模块化、层级性、小世界性和高阶耦合   |
| Γstu​ | 可用时空协同因子        | 结构连接、功能连接和任务动力学之间的有效匹配度 |


### ３．３　iNEST 有效涌现指数

IiNEST​=Cenv​⋅(Ediss​+Llat​+Ddrift​+ε)CSTcap​⋅χEOC​⋅χtrain​⋅χemb​​

该公式表明：CST 衡量系统能够提供多少可用复杂度；iNEST 衡量这些复杂度能否在环境闭环中转化为智能行为。

## 四、iNEST 智能涌现路径

### ４．１　定义

iNEST 是“网络时空协同复杂度涌现智能”，其核心不是用更多节点堆叠智能，而是通过局部规则调节非线性器件和耦合网络，使系统在环境反馈下持续接近混沌边缘，并在任务选择中形成稳定吸引子。

### ４．２　四类工程规则


| 规则         | 调控对象        | 动力学作用         | 对 CST 的影响      |
| ---------- | ----------- | ------------- | -------------- |
| STDP       | 连接权重 wij​   | 按因果时序强化或削弱连接  | 提升 Sc​ 和 Γstu​ |
| 局部预测误差     | 状态反馈 ui​(t) | 引导系统向低误差吸引子收敛 | 提升 Γstu​       |
| BCM／稳态可塑性  | 阈值和增益       | 防止全静默或全饱和     | 稳定 Tc​ 和 αeff​ |
| SOC／EOC 调控 | 分支比、增益和耦合强度 | 维持混沌边缘窗口      | 提升 χEOC​       |


需要明确：这四类规则是 iNEST 的工程调控模块，不是已经被证明足以产生通用智能的四条定律。

## 六、iMESO 物理实现承载

### ６．１　定义

iMESO 是介观尺度物理智能涌现系统。其目标是以非平衡态材料和局部有源非线性器件为基本单元，以晶上复杂网络为耦合结构，以 SDI 和物理训练机制为调控手段，使系统稳定运行于混沌边缘并完成智能任务。

### ６．２　五层工程实现


| 工程层级       | 对应科学问题           | 主要建设内容                       | 核心度量                        |
| ---------- | ---------------- | ---------------------------- | --------------------------- |
| L1 关键材料层   | 哪些非平衡态材料过程可承载计算  | Mott 相变、相变、铁电翻转、离子迁移、热涨落     | 相变温区、NDR 窗口、回滞面积、噪声谱、状态变量维度 |
| L2 非线性器件层  | 如何形成局部稳定且局部有源节点  | 忆阻器、Mott 器件、相变振荡器、铁电／离子动力学器件 | Lyapunov 指数、频率自适应、短时记忆、振荡模式 |
| L3 晶上耦合网络层 | 如何把时间复杂度转化为空间复杂度 | 电阻／电容／物理场耦合、随机网络、小世界网络、高阶耦合  | 同步模式、极限环、网络相变、能耗面积          |
| L4 物理可训练层  | 如何调控动力学完成任务      | 储备池、时分复用虚拟节点、神经微分方程、延迟嵌入     | 传递熵、动态信息存储、预测误差、训练稳定性       |
| L5 智能涌现验证层 | 如何证明智能来自物理动力学    | 非线性预测、优化搜索、环境交互、类脑决策         | 能效、任务表现、鲁棒性、可复现实验协议         |

## 八、项目关键创新

第一，把温度、相变比例、离子分布、畴结构、热涨落等材料内部状态变量纳入计算原语。

第二，以“局部稳定且局部有源”定义混沌边缘器件，建立从 NDR、回滞、噪声谱到 Lyapunov 指数、传递熵和动态信息存储的表征体系。

第三，通过晶上集成实现非线性节点与高阶耦合的空间组织，把器件时间复杂度转化为网络空间复杂度。

第四，发展面向物理动力学的训练方法，使知识不仅存在于权重矩阵，也存在于具体硬件的状态分布、偏置点、耦合结构和吸引子形态中。

## 九、证据等级与风险控制

为保证项目科学性，建议所有理论和指标采用证据标签。


| 标签      | 含义               |
| ------- | ---------------- |
| ［已实测］   | 已有公开实验或项目实测数据支持  |
| ［可复现仿真］ | 指定模型、参数和代码下可复现   |
| ［工程候选］  | 可作为项目里程碑或设计目标    |
| ［理论假设］  | 需要进一步数学证明和物理实验验证 |
| ［待测］    | 需要材料、器件或系统实测确认   |


例如，CST 阈值、六级智能等级、材料 αeff​ 取值、混沌边缘工作窗口、Route-Transform 同构等，均应标注为［理论假设］或［工程候选］，不得直接表述为已经证明的普适定律。

## 十、最终凝练表述

本项目的创新链条可概括为：

**非平衡材料给出时间，复杂拓扑给出空间，混沌边缘给出计算，环境反馈选择智能。**

更完整地说：

**CST 是度量非平衡物理网络可用时空协同复杂度的工具；iNEST 是局部规则把这种复杂度转化为智能行为的路径；Master SDDE 是材料内部状态、非线性器件、复杂拓扑和环境反馈共同演化的动力学语言；iMESO 是用晶上集成和 SDI 把混沌边缘物理可训练网络工程化的介观承载。**
