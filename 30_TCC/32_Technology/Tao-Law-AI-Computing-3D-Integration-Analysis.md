# 王志敏ICDIA 2026演讲：韬定律与AI生产力深度解读

### 🎤 这场演讲是谁在哪讲的？

**HIPI联盟副理事长王志敏**在**ICDIA 2026**发表主旨报告。
- **时间地点**：2026年8月20日，南京江北。
- **演讲主题**：《韬定律与AI生产力》。
- **讲者身份**：HIPI联盟副理事长、华为半导体产业生态高级顾问。

### ⚠️ 当下半导体产业面临什么局面？

产业正遭遇**三重叠加冲击**，大国竞争核心是AI生产力鸿沟。
- **三重压力**：AI算力浪潮 + 摩尔拐点 + 外部人为断链。
- **竞争本质**：AI生产力差距 → 决定数字化国力水平。
- **摩尔定律三重枷锁**：
  - 物理极限：7nm之后**量子隧穿效应**凸显。
  - 成本拐点：3nm建厂投资超**200亿美元**，流片成本同步抬升。
  - 人为脱钩：中国大陆叠加EUV、EDA、关键材料及设备管制。
- **核心矛盾**：AI算力实际需求 > 摩尔传统路径供给上限。

### 🧩 AI生产力由哪几部分构成？

王志敏提出**AIF5五力模型**，AIaaS已进入"开局即淘汰赛"。
- **五大核心要素**：智力、算力、存力、网力、生态力。
- **行业阶段**：创新周期急剧压缩 → AIaaS赛道开局即淘汰赛。

### 📐 韬定律到底是什么？

**以时间缩微替代几何缩微**，是后摩尔时代的新演进范式。
- **首发信息**：2026年5月，华为于**IEEE-ISCAS**全球首发。
- **核心思路**：摆脱对晶体管几何缩小的路径依赖，打破晶体管工艺崇拜。
- **核心目标**：把全层级**时间常数τ最小化**作为核心目标。
- **技术手段**：逻辑折叠 + 三维集成 + 全栈架构重构 + 软硬件协同。
- **达成效果**：同步提升等效晶体管密度、芯片性能与能效。
- **生态底座**：依托HIPI国标（**GB/T 46280**）与HAI协议，构建自主标准化生态。

### ⏱️ 芯片时延最大的瓶颈在哪？

**电路RC寄生延迟占整体时延80%**，而非晶体管器件本身。
- **时延分层**：总时延τtotal = 器件层 + 电路层 + 芯片层 + 系统层。
- **最大瓶颈**：电路RC寄生延迟，占整体时延**80%**。
  说白了，现在芯片慢，主要不是晶体管本身不够小，而是线路之间绕来绕去耽误时间。

### 🔺 逻辑折叠和普通封装堆叠有什么不一样？

逻辑折叠是**芯片空间哲学重构**，衍生出VIFER全新结构。
- **逻辑折叠本质**：以立体垂直分层替代二维平铺，消除长距离水平布线 → RC延迟断崖式下降。
- **VIFER结构**：vertical integrated wafer，垂直集成晶圆。
  - 顶层：I/O接口层 + 电源分配层（对外通信与供电管理）
  - 中间层：核心逻辑层 + CPU/GPU/AI计算单元（主算力实体）
  - 下层：片上存储层 + SRAM/高速缓存（低延迟数据缓冲）
  - 底层：HBM集成存储层（大容量数据带宽）

### 🚧 三维集成产业化要过哪几关？

需要攻克**五大工程关卡**，同时带来三大产业机遇。
- **五大工程关卡**：
  1. 电磁光力热多物理场耦合
  2. 真三维AI-EDA工具
  3. 纳米级层间对准
  4. 多层堆叠良率管控
  5. VIFER跨层协同设计
- **产业机遇**：设计方法学革新 + EDA工具革新 + AI4CHIP深度革新

### 🧭 国内产业该怎么突围？

正视短板、用好优势，**聚焦长板比补救短板更重要**。
- **SRDPM长周期创新链**：科学探索 → 技术研究 → 工程开发 → 产品化 → 规模化量产。
- **IF3创新三要素**：创新强度 × 创新密度 × 创新速度。
- **国内产业短板**：基础研究薄弱 + 协同机制不足 + 先进工艺落后。
- **国内产业优势**：内需市场大 + 全链条产业基础 + 成熟特色工艺 + "标-专-生"协同。
- **发展建议**：
  - 全国一盘棋，强化产教协同有组织创新。
  - 补齐三条链条：人力→人才、学术→技术、产品→产业。
- **地方战略提醒**：聚焦本地既有优势，迅速做大做强，打造重量级产业长板 > 补救地方短板。

### 🏛️ HIPI联盟是什么组织？

是国内**Chiplet领域**具有法人实体地位的核心行业组织。
- **全称**：中关村高性能芯片互联技术联盟。
- **会员规模**：近**200家**会员单位，覆盖集成电路全产业链。
- **核心工作**：Chiplet产业链全要素研究、产学研资源协同创新、自主标准体系建设、产业资源持续优化。
- **定位**：推动我国高性能芯片互联技术的标准化、产品化与生态化协同发展。
