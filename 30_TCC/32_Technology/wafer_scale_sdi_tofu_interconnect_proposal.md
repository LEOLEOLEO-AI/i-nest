# 晶上软件定义拓扑织构（ToFu）互连架构申报方案（优化版）

# 晶上软件定义拓扑织构互连架构与关键技术研究（优化版申报方案节选）

## 二、立项依据与研究意义

### 2.1 问题背景

当前智能计算系统面临三重瓶颈的叠加挑战：

**通信墙**：大模型训练中集合通信占总时间的 30%-60%，模型越大、并行度越高，通信占比越大。当集群规模从千卡迈向万卡、十万卡，算力利用率（MFU）从 50% 以上骤降至 20%-30%，大规模扩展性受限于互连效率。华为仿真数据显示，10 万卡集群中，4096 卡超节点架构与 8 卡服务器三层组网相比，MFU 相差 2.75 倍，互连架构对系统效能的决定性作用已成为产业共识。

**工艺墙**：摩尔定律放缓，单纯依赖先进工艺制程提升性能的边际效益递减。3nm 到 2nm 的性能提升已不足 20%，而成本指数级上升。行业亟需从架构层面寻找算力提升的新路径——从"靠工艺堆算力"转向"靠架构提效率"。

**拓扑墙**：现有计算系统从芯片级到集群级普遍采用固定拓扑。芯片级多为 2D Mesh，晶圆级系统（如 Cerebras WSE）同样采用固定 2D Mesh；集群级多为 Fat-Tree 或 Torus。固定拓扑在匹配单一通信模式时效率较高，但无法适配不同应用的多样化通信模式——规则稠密计算效率高，而全局集合通信、稀疏交换、图计算、MoE 专家路由等场景下，固定拓扑的跳数多、延迟高、带宽利用率低。

**三重瓶颈汇聚到同一个根源**：拓扑被当作计算的附属管道，而非决定系统效能的第一性变量。当通信模式从训练的规则并行转向推理的稀疏全局交换（如 Google TPU v8 训推拓扑分化所揭示的），固定拓扑的效率天花板必须靠架构创新来打破。

### 2.2 国内外研究现状

国际上已在多个方向探索拓扑优化与重构的突破路径，按层级可分为晶圆级、芯片级、集群级三类：

#### （1）晶圆级集成：规模验证完成，拓扑仍是短板

Cerebras 公司的 WSE-2 芯片实现了 85 万核单晶圆集成，验证了 12 英寸晶圆级计算的制造可行性。但其采用固定 2D Mesh 拓扑，全局通信需要多跳转发，在 All-to-All、MoE 路由等全局交换场景下效率受限。晶圆级计算的"工艺可行"已经证明，但"拓扑高效"仍待突破。

国内在晶圆级集成方向也已布局，但目前公开成果仍集中在制造工艺和良率提升层面，晶圆级互连拓扑的架构创新尚未见系统性报道。

#### （2）芯片级可重构：数据流重构成熟，系统拓扑仍固定

**SambaNova** 最新发布的 SN50 芯片基于可重构数据流架构（RDU），通过软件配置计算单元的数据通路实现算子级深度融合，推理性能号称达到 B200 的 5 倍。但其重构粒度限于算子级数据流，系统级互连拓扑仍为固定结构，无法根据全局通信模式动态调整物理拓扑。

**Intel** 在 22nm 工艺下流片验证了混合电路/分组交换 NoC，电路交换模式每跳延迟仅 407ps，证明了混合交换模式的技术可行性。但该工作仅停留在单路由器微架构层面，未形成系统级的拓扑重构能力。

**学术界**（MIT 等）在可重构 NoC 方向已有多年积累，包括面向暗硅问题的 3D NoC 静态重构、FPGA 中的 NoC 架构实践等。但研究重心多在核间通信优化，未上升到晶圆级尺度的拓扑织构设计。

#### （3）集群级拓扑重构：光交换验证可行，但粒度粗、延迟高

**Google TPU 系列**是集群级拓扑重构的代表。从 TPU v4 引入光路交换（OCS）实现机间拓扑重构，到 TPU v8 进一步分化为训推两套拓扑：

- 训练端 TPU 8t 采用 3D Torus + OCS + Virgo 兆级网络，单数据中心可扩展至 13.4 万颗芯片，每芯片带宽 400 Gbps；
- 推理端 TPU 8i 针对 MoE 推理的 All-to-All 通信模式，采用 Boardfly 拓扑，最大跳数从 16 跳降至 7 跳，并内置集合加速引擎（CAE）将集合运算延迟降低 80%。

TPU v8 用两颗芯片、两套物理拓扑分别适配训练与推理，本质上是**用硬件冗余换拓扑匹配度**，印证了"拓扑必须匹配通信模式"的架构趋势，但也暴露了光交换重构的局限——重构粒度为机间级，切换时间在毫秒到秒级，且仅支持有限几种预设拓扑。

**NVIDIA** 从三个维度推进拓扑优化：封装级 NVLink/NV-HBI 实现高带宽直连（双 die 间 10 TB/s）；机群级推动 Dragonfly（蜻蜓）拓扑替代传统 Fat-Tree，减少交换机层级、缩短通信路径；SHARP 技术将集合通信卸载到交换机中。但三者均基于固定拓扑的分组交换，拓扑本身不可动态重构。

**华为**最新发布的昇腾 960 超节点代表了国内最高水平：采用 NPO 近封装光学技术，单超节点 4096 卡，二层 CLOS 四平面扩展至 51.2 万卡，结合多轨道拓扑支持百万卡规模；灵衢 UnifiedBus 实现内存统一编址和集合通信卸载。其路径特点是光互连密度优先 + 固定拓扑下的极致带宽工程，芯片级和芯粒级拓扑仍为固定结构。

#### （4）网内计算：从协议卸载到拓扑重构的升级空间

NVIDIA SHARP、华为灵衢、Google CAE 分别在交换机级和芯片 I/O 级实现了集合通信加速，验证了网内计算的价值。但这些方案有一个共同局限：**都是在固定拓扑上做协议优化或计算位置调整**，无法为特定集合通信模式重构出最优物理拓扑。例如 AllReduce 在物理规约树上执行，效率远高于在固定 Mesh 或 Fat-Tree 上通过协议模拟。

**共性不足**：上述技术分别在晶圆级制造、数据流重构、光交换拓扑、网内计算等单点上取得突破，但尚未在晶圆级尺度上形成"拓扑可重构 + 多模交换 + 网内计算 + 全系统协同"的统一架构范式。拓扑重构要么停留在机间/机群级（粒度太粗、延迟太高），要么停留在算子级（不涉及系统拓扑），**晶圆级物理拓扑的软件定义动态重构仍是国际空白**。

### 2.3 本项目的核心思想

提出**拓扑织构（ToFu, Topologically Fused Wafer Fabric）**的架构理念：以拓扑为第一性变量，通过软件定义的三模混合交换机制，在晶圆尺度上构建可动态重构的互连织物，实现计算、通信、存储的全隐藏协同。

核心创新逻辑：

> **拓扑不再是计算的附属管道，而是决定系统效能的第一性变量。** 通过物理层拓扑的软件定义重构，让互连结构精准匹配应用的通信模式，从架构层面突破固定拓扑的效率天花板。

这一理念的提出有三个层面的依据：

- **理论依据**：小世界网络理论严格证明，5-10% 的长程连接即可显著降低平均路径长度；复杂网络中，拓扑结构对信息传播效率的影响远大于节点本身的处理能力。
- **产业依据**：Google TPU v8 的训推拓扑分化、NVIDIA Dragonfly 拓扑优化、华为超节点光互连演进，都指向同一个趋势——互连架构正在从配角变为主角，"网络定义算力"时代已经到来。
- **技术依据**：混合交换 NoC、晶圆级集成工艺、网内计算等关键技术均已得到单点验证，具备在晶圆级尺度上进行架构级整合的条件。

## 三、研究内容

### 研究内容一：三模混合交换的软件定义可编程互连芯粒架构

**针对指南要求**：软件定义可编程互连芯粒架构、可扩展动态组网机制、动态切换与可编排互连

**研究目标**：研制支持电路交换/虚电路交换/分组交换三种模式混合的软件定义互连（SDI）芯粒，作为拓扑织构的基本交换单元。

**研究动机与定位**：
现有方案中，电路交换（如 Google OCS）延迟低但粒度粗、切换慢；分组交换（如传统 NoC）灵活但延迟高、有缓冲开销；虚电路交换（如 ATM、TDM NoC）有 QoS 保证但实现复杂。本项目将三种模式统一到同一套物理交换资源中，通过 TDM 时隙划分实现动态共享，既保留各模式的优势，又避免硬件冗余。

**具体研究内容**：

1. **三模共享交换微架构设计**
   - 设计统一的交叉开关矩阵，通过时分复用（TDM）时隙划分，动态支持电路交换、虚电路交换、分组交换三种模式
   - 电路交换模式：全时隙预留，零缓冲直通，提供最低延迟的大块数据传输通路（对标 Google OCS 功能但下沉到晶上，延迟从毫秒级降至微秒级）
   - 虚电路交换模式：部分时隙预留，端到端确定性带宽/延迟保证，支持细粒度带宽分配（1/16 链路带宽粒度）
   - 分组交换模式：剩余时隙动态共享，分布式路由，承载不规则控制流量
   - 关键创新：同一套物理交换资源支持三种模式，面积效率远高于三套独立交换平面

2. **源同步低延迟中继技术**
   - 针对晶圆级长线传输，采用源同步（source-synchronous）设计，避免全局时钟分布难题
   - 电路交换/虚电路模式下，中继节点直通转发，每跳延迟降至亚周期级
   - 已有流片验证基础：Intel 22nm 混合 NoC 的电路交换模式每跳延迟仅 407ps

3. **可扩展动态组网机制**
   - 设计层次化 SDI 控制平面：本地控制器负责带内交换配置，全局控制器负责跨带拓扑编排
   - 支持芯粒级的级联扩展，从 4 倍光罩局部验证区域平滑扩展至完整晶圆级规模
   - 双缓冲配置切换机制：新配置预加载到备用寄存器，验证无误后一键切换，实现无损重构

**关键技术指标**：

| 指标 | 目标值 | 对比基准 |
|------|--------|---------|
| 交换模式数 | ≥3种（电路/虚电路/分组） | 指南要求≥2种，超出50% |
| 单芯粒端口数 | ≥16个双向端口 | — |
| 电路交换每跳延迟 | ≤2个时钟周期 | Intel 22nm 验证为亚周期级 |
| 虚电路带宽粒度 | ≤1/16链路带宽 | — |
| 动态切换时间 | ≤1μs（虚电路级），≤100μs（电路交换级） | Google OCS 为毫秒级，快10-100倍 |

### 研究内容二：近邻-长程双层拓扑织构与晶圆级高密度互连

**针对指南要求**：晶圆级高密度互连架构、跨区域布线、电热协同设计、可制造可测试

**研究目标**：基于 4 倍光罩重复套刻的工程约束，设计近邻-长程双层互连拓扑结构，实现以 5-10% 的互连资源增量换取 40% 以上全局通信效率提升的效果。

**研究动机与定位**：
Cerebras 等晶圆级系统采用纯 2D Mesh，全局通信跳数随芯片尺寸线性增长；Google TPU 8i 用 Boardfly 拓扑降低推理跳数，但是固定拓扑、无法动态调整。本项目借鉴小世界网络理论，通过近邻 Mesh 保证局部效率、稀疏长程连接降低全局跳数，同时结合物理直连与 SDI 中继的分层实现策略，在光罩约束下最大化拓扑灵活性。

**具体研究内容**：

1. **近邻-长程双层互连架构**
   - **近邻层**：2D Mesh 规则近邻互连，提供高聚集的局部通信能力（对应小世界的高聚集系数）
   - **长程层**：稀疏分布的长程直连链路（约占总链路数的 5-10%），提供低跳数的全局直达能力（对应小世界的短平均路径）
   - 两层协同工作，同时保证局部通信效率和全局通信效率
   - 可重构性：长程链路的通断与路由通过 SDI 芯粒配置，支持多种拓扑形态的动态构建

2. **面向 4 倍光罩约束的分层布线方案**
   - **1 倍光罩内**：固定金属布线，计算带内部核间通信
   - **1-2 倍光罩（邻罩边界）**：通过 A/B 两版光罩的边界连接图案组合，实现可定制的长程直连物理链路
   - **2 倍光罩以上**：通过 SDI 芯粒的虚电路/电路交换中继级联，构建等效的全局长距通路
   - 中继方式采用直通式转发，每跳延迟远低于传统分组交换路由器

3. **电热协同设计与可制造性优化**
   - 长程链路的功耗密度分布建模与热优化
   - 冗余链路设计与良率提升方法
   - 晶圆级可测试性设计（DFT），支持边界扫描和内建自测

**关键技术指标**：

| 指标 | 目标值 | 对比基准 |
|------|--------|---------|
| 局部互连设计区域 | ≥4倍光罩 | 满足指南要求 |
| 长程连接占比 | 5-10% | 小世界网络理论最优区间 |
| 全局平均通信跳数降低 | ≥40% | 相比固定2D Mesh |
| 网络聚集系数 | ≥0.5 | 保持局部高效通信 |
| 支持扩展规模 | 12英寸晶圆 | 满足指南要求 |

### 研究内容三：拓扑自适应演化与网内计算加速技术

**针对指南要求**：拓扑自适应演化规则、复杂拓扑自动生成、负载动态适配、网内通信加速与路由重构、不少于 3 种集合通信的网内硬件加速

**研究目标**：建立面向典型智能计算负载的拓扑自动生成与动态适配方法，实现集合通信的网内硬件加速，验证拓扑织构架构在大模型训练/推理等场景下的效能增益。

**研究动机与定位**：
NVIDIA SHARP、华为灵衢、Google CAE 已验证了网内计算的价值，但都是在固定拓扑上做协议优化。本项目将网内计算从"固定拓扑上的协议优化"升级为"拓扑重构下的物理路径优化"——先根据通信模式重构出最优物理拓扑，再在拓扑路径上完成计算，实现数量级的性能提升。

**具体研究内容**：

1. **面向典型通信模式的拓扑自动生成算法**
   - 分析大模型训练（数据并行、张量并行、流水线并行、专家并行）和科学计算（MPI 集合通信）的通信模式特征
   - 研究基于通信模式的拓扑优化生成算法，在带宽、延迟、面积、功耗多目标下做 Pareto 优化
   - 支持 ≥6 种拓扑形态的自动生成与映射：
     1. 2D Mesh（基准，通用局部计算）
     2. 规约树拓扑（AllReduce/Reduce-Scatter 加速）
     3. 小世界拓扑（All-to-All/MoE 全局交换）
     4. 环形拓扑（流水线并行/环形 AllReduce）
     5. 广播树拓扑（权重广播/KV 缓存分发）
     6. 胖树拓扑（多级全局汇聚）

2. **拓扑自适应演化与负载动态适配机制**
   - 运行时通信模式监测与识别（基于性能计数器的流量特征提取）
   - 拓扑配置的预生成与快速切换（编译时预生成多种候选拓扑，运行时识别模式切换后快速加载）
   - 双缓冲无损切换：切换过程不中断正在进行的通信，重构时延 ≤100μs

3. **网内集合通信硬件加速**
   - 在 SDI 芯粒中集成规约计算单元（加法、最大值、最小值，支持 FP16/BF16 精度）
   - 利用可重构拓扑构建最优集合通信物理路径（如 AllReduce 走物理规约树，数据在传输路径上直接完成规约）
   - 支持不少于 3 种集合通信的网内硬件加速：
     1. AllReduce（规约树拓扑 + 网内规约）
     2. AllGather / Reduce-Scatter（环形/树形拓扑）
     3. All-to-All（小世界拓扑 + 虚电路交换）
   - 与 NVIDIA SHARP、华为灵衢的本质区别：后者在固定拓扑交换机上做集合通信卸载，本项目将其下沉到晶上 SDI 芯粒，并与拓扑重构深度结合，延迟降低一个数量级以上

4. **拓扑感知的计算-通信协同调度**
   - 研究拓扑驱动的计算核映射方法，让通信密集的计算单元在物理上"邻近"
   - 实现计算与通信的深度重叠，进一步提升系统效能
   - 借鉴 SambaNova 数据流架构的计算-通信融合思想，但提升到拓扑级优化的维度

## 五、创新点

### 创新点一：架构原创——三模混合交换的软件定义互连芯粒

首次提出电路交换/虚电路交换/分组交换三模混合的 SDI 芯粒架构。不同于传统方案中多种交换模式各自独立、硬件冗余的设计，本方案通过 TDM 时隙划分实现同一交叉开关矩阵对三种模式的共享，以 20-30% 的面积增量获得 3-5 倍的通信延迟降低和 2-3 倍的能效提升。相比 Google OCS 的毫秒级光交换，本方案将拓扑重构速度提升 10-100 倍，达到微秒级。

### 创新点二：方法创新——近邻-长程双层拓扑织构

将复杂网络的小世界效应首次工程化应用于晶圆级互连架构设计。通过近邻 Mesh 保证局部通信效率，通过 5-10% 的稀疏长程连接大幅降低全局通信跳数。结合物理直连（2 倍光罩内）+ SDI 中继（2 倍光罩外）的分层长距实现方案，在 4 倍光罩重复套刻的工程约束下，实现全局平均跳数降低 40% 以上。相比 Cerebras 的固定 2D Mesh，全局通信效率显著提升；相比 Google TPU 8i 的固定 Boardfly 拓扑，本方案支持动态重构，可适配更多通信模式。

### 创新点三：范式创新——拓扑第一性的计算-通信-存储全协同

提出"拓扑第一性"的架构设计理念：拓扑不是计算的附属管道，而是决定系统效能的第一性变量。这一理念已被 Google TPU v8 训推拓扑分化、NVIDIA Dragonfly 拓扑优化、华为超节点光互连演进等产业趋势所印证。本项目通过拓扑的软件定义重构，让计算、通信、存储在拓扑结构中自然协同，实现集合通信延迟降低 60% 以上、系统级训练效率提升 30-80% 的效果，探索一条不单纯依赖先进工艺的算力提升新路径。

### 创新点四：系统创新——拓扑可重构与网内计算的深度融合

将网内计算从"固定拓扑上的协议优化"升级为"拓扑重构下的物理路径优化"。不同于 NVIDIA SHARP、华为灵衢、Google CAE 等在固定拓扑上做集合通信卸载，本方案可根据集合通信的类型动态重构出最优物理拓扑（如 AllReduce 走物理规约树），数据在传输路径上直接完成计算，实现数量级的通信加速。这是网内计算从"协议层优化"迈向"物理层优化"的关键一步。
