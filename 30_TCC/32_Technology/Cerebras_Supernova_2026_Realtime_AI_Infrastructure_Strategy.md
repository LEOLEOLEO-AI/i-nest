# Cerebras Supernova 2026 战略全解：从极速推理到实时AI基础设施底座

### 🏆 这次大会的核心结论是什么？

Cerebras 战略从「最快AI加速器」升级为**实时AI时代的推理基础设施底座**，靠时间预算、分离式推理、超大规模部署三大支柱构建壁垒。
- **三大核心支柱**：时间预算（Time Budget）定义AI价值边界 + 分离式推理（Disaggregation）重构算力分工 + 超大规模部署（Hyperscale）构建长期壁垒
- **核心产品发布**：新一代 **CS-4 系统** 与 **Nexus 机架平台**，已开启早期体验，本季度晚些时候正式发布
- **性能跃升**：CS-4 推理速度比传统顶级 GPU 方案**最高快 30 倍**，每瓦词元数最高提升 10 倍

### ⏱️ 为什么「时间预算」是AI产品的生死线？

超过时间窗口的推理结果**商业价值归零**，极速推理打破了模型能力与响应速度的两难。
- **三大典型时效红线**：
  - 网络安全渗透阻断窗口：**27 秒**
  - 实时语音交互上限：**200 毫秒**
  - 金融交易清算窗口：**50 毫秒**
- **传统路径困境**：更强模型 → 更多推理 → 更高延迟 → 实时体验受损（死循环）
- **Cerebras 路径**：更强模型 → 更快 Token 生成 → 延迟余量充足 → 支持 Agent 多轮推理
  说白了，以前想用聪明的大模型就得等半天，现在大模型也能秒回，还能多轮思考不超时。

### 🧩 什么是异构分离式推理？为什么是最优解？

把 Prefill 和 Decode 拆给不同硬件，**兼顾超低延迟与高并发吞吐**。
- **两阶段特性对比**：

| 阶段 | 硬件适配 | 核心特点 |
| :--- | :--- | :--- |
| Prefill（预填充） | GPU / ASIC 集群 | 计算密集、内存带宽要求低、高并发 |
| Decode（解码） | Cerebras WSE | 内存带宽密集、逐Token串行、超低延迟 |
- **性能收益**：比纯 GPU 方案**快 10 倍**，比纯晶圆级系统**吞吐高 5 倍**
- **关键瓶颈**：跨设备传输数十 GB KV 缓存 → CS-4 翻倍 I/O 带宽 + 低延迟直连 → 压缩首词元时间（TTFT）
- **产业分工定位**：英伟达在保吞吐前提下提速度，Cerebras 在保速度前提下扩吞吐，分离式推理打破规模定律下的推理瓶颈

### 💻 CS-4 与 Nexus 平台有哪些硬核升级？

系统级性能**提升 6 倍**，部署周期从数天压缩到数小时。
- **CS-4 核心参数**：
  - 搭载 **3 颗 WSE-3 Turbo** 晶圆级引擎
  - 计算力、内存带宽、架构带宽均为上一代的 **6 倍**
  - Token 生成速度达 CS-3 的 **2 倍**（最高达传统顶级 GPU 的 30 倍）
  - 每瓦词元数最高提升 **10 倍**
  - 前瞻兼容 2027 年 CS-5 及后续 CS-6
- **WSE-3 Turbo 晶圆级引擎**：
  - 片上 SRAM 带宽：**43 PB/s**（是英伟达 Rubin 的 2000 倍）
  - 模型权重**全部常驻片上**，消除片外 HBM 与机架线缆通信延迟
  - 单晶圆网络带宽：**2.4 Tbps**（上一代 1.2 Tbps）
  - 直接晶圆链路（Direct Wafer-Link）延迟：**2 微秒**
  - 10T 参数模型流水线聚合 I/O 延迟：**0.2 毫秒**
- **Nexus 机架平台**：
  - 电力、计算、I/O **彻底解耦**，独立演进
  - 零部件数量减少 **50%**，自动化制造比例达 **60%**
  - 部署周期从 Days → **Hours**（数小时）

### 🤝 产业生态联盟都有哪些核心玩家？

向上绑定前沿模型，横向补齐算力与网络，底层锁定电力资源。
- **前沿模型层（OpenAI）**：
  - **GPT-5.6 Sol Ultrafast**：速度达标准模式的 **14 倍**
  - Humanity's Last Exam 全量测试：从 3 天以上缩短至 **11 小时 11 分钟**
  - 内部优先用于核心排障与前沿研究，同时通过 API 对外输出
- **算力协同层（AMD）**：
  - AMD **Helios 机架**（72 颗 GPU）+ EPYC CPU 负责高吞吐 Prefill 及调度
  - 后端对接 Cerebras 晶圆级系统完成 Decode
- **网络层（Arista）**：
  - 三维网络架构：Scale-up（晶圆级互连）+ Scale-out（机架间）+ Scale-across（跨数据中心）
  - 带宽规划向 **3.2–6.4 Tbps** 演进
- **垂直场景验证**：
  - **Cognition（AI 软件工程）**：Sweet Grab 搜索模型 680–2800 Token/s，Sui 1.7 编码模型近 1000 Token/s，端到端任务延迟降低 **2–4 倍**
  - **Figma（设计协同）**：私有微调模型，多人画布实时多轮交互
  - **CrowdStrike & Armis（安全）**：27 秒窗口内执行 **5–10 倍**深度关联分析，代码漏洞扫描时间缩短至 **1/3**
- **电力储备**：已锁定 **600+ MW** 数据中心电力容量（已签约/规划）
  - 北美：Santa Clara、Toronto、Dallas、Minneapolis、Montreal、Oklahoma City、Alabama
  - 欧洲：法国 Lyon、芬兰 Mäntyharju、挪威 等

### 📈 规模化落地与未来路线图是什么？

目标是**每年速度翻番**，2027 年前实现 20 倍吞吐提升。
- **吞吐扩展路线**：推理速度每年翻番，下半年实现约 **20 倍**于当前的吞吐能力
- **交付状态**：CS-4 已开启 Early Access，本季度晚些时候正式发布
- **需求趋势**：模型能力提升驱动推理需求增速持续超出集群扩容速度，极速推理成为刚性基础设施
- **关键验证维度**：
  - 超大规模生产环境交付确定性
  - 分离式方案在多租户、长上下文负载下的工程稳定性
  - 综合 TCO（总拥有成本）表现

### 📝 补充细节
- **片上内存 = 消除通信瓶颈**：传统 GPU 权重存在片外 HBM，需穿过狭窄内存总线；Cerebras 权重全部在片上 SRAM，单晶圆带宽 43 PB/s，是英伟达 Rubin 的 2000 倍。
- **Nexus 模块化 = 部署革命**：机架前部先布电力模块，后部直接插入计算背包（Backpack），无需现场复杂布线，部署时间从数天压缩到数小时。
- **分离式推理不止一种形态**：除 Prefill-Decode 解聚外，还有 Attention-FFN 解聚等新范式，CS-4 的 I/O 模块是可编程通用接口，可兼容未来形态。
