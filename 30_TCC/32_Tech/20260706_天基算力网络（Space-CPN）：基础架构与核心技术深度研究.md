# 天基算力网络（Space-CPN）：基础架构与核心技术深度研究

### 📑 论文基础概况

该研究由清华大学姜春晓教授团队联合上海科技大学石远明等研究人员完成，发表于中国工程院院刊*Engineering*2025年11月第54卷，属于“Views & Comments”观点评论类文章，为开放获取成果，文章DOI为10.1016/j.eng.2025.06.026。
研究针对海量空间信息处理的传输瓶颈与计算资源限制，首次系统性提出**天基算力网络（Space-CPN）**架构，为实现安全、快速、准确的星载智能数据处理提供了完整工程框架。

### 🚀 天基算力网络的崛起背景与核心挑战

#### 行业痛点催生新架构

随着遥感等空间业务快速发展，卫星获取的数据量呈爆发式增长，传统“先下载后处理”模式受限于卫星过境时间短、传输带宽不足的短板，已无法满足应急场景下的实时处理需求。
Space-CPN架构对传统地面算力网络概念进行了延伸：将**低轨（LEO）、中轨（MEO）、高轨（GEO）**不同轨道的通信计算一体化卫星作为突发事件的空间计算中心，地面站则承担高算力需求的地面计算任务，实现天地算力的协同调度。

#### 三大核心技术挑战

实现Space-CPN落地需要突破三大关键瓶颈，具体对应关系如下表：
| 挑战维度 | 传统方案痛点 | 技术演进方向 |
| :--- | :--- | :--- |
| 通信模式 | 基于香农定理的面向数据通信，无法适配海量遥感图像处理等特定任务需求 | 转向面向任务的通信机制 |
| 计算架构 | 冯·诺依曼架构存算分离，星载场景下能耗过高 | 引入低功耗类脑计算架构 |
| 资源调度 | 空间网络拓扑高度动态、业务需求不确定性强，传统调度方案鲁棒性不足 | 实现通信、计算、存储资源的鲁棒分配 |

### 📡 面向任务的通信：特征压缩与空中计算

该技术方向聚焦通信与计算的无缝集成，从信息压缩和信息传输两个层面提出创新方案：
1.  **鲁棒特征压缩**：针对卫星图像云层遮挡等噪声干扰问题，提出鲁棒信息瓶颈（RIB）和基于Fisher信息的F-RIB方法，核心目标是最大化推理结果与标签的互信息，同时最小化特征对云层噪声的敏感度，在不增加通信开销的前提下，大幅提升特征传输鲁棒性与下游推理准确性。
2.  **高效信息传输**：针对星载联邦学习的模型聚合延迟问题，引入**编码空中计算（AirComp）**技术，利用无线信道的波形叠加特性，允许多颗卫星同时发送信号，在空中直接完成加法运算；结合基于格量化的数字调制方案，无需依赖完美信道状态信息即可抵抗噪声干扰，显著降低模型聚合延迟。

### 🧠 类脑计算：高能效星载处理架构

针对星载平台严苛的功耗限制，研究选取脉冲神经网络（SNNs）这一具备稀疏性、离散性、事件驱动特性的高能效计算模型，设计了两套适配空间场景的学习架构：
1.  **卫星联邦类脑学习网络**：利用同一轨道内卫星形成的稳定环形拓扑，采用Ring-AllReduce算法实现轨内高效模型聚合；配套设计联邦异构混合平均算法，纠正数据和硬件异构性引发的收敛偏差。
2.  **完全在轨去中心化类脑架构**：摆脱对星地链路的频繁依赖，针对跨轨道平面通信拓扑不稳定的问题，引入**中继求和（relay sum）**策略，在控制通信开销的同时，加速模型更新的跨区域扩散与全局收敛。

### ⚙️ 鲁棒资源分配：应对动态与不确定性

针对空间网络动态拓扑和突发任务的不确定性，研究提出微服务驱动的星载处理架构，将复杂推理过程拆分为低耦合的微服务模块进行分布式部署，形成两套成熟的调度方案：
1.  **鲁棒微服务部署**：将突发任务（如火灾监测）的部署问题转化为部分可观测马尔可夫决策过程（POMDP），引入扰动智能体开展对抗性训练，通过鲁棒强化学习得到极端场景下仍可稳定运行的微服务部署策略。
2.  **高效任务调度优化**：将遥感图像处理任务调度建模为多对多背包匹配问题，采用**分布式鲁棒优化**方法，结合核密度估计与Wasserstein距离构建模糊集，在避免调度策略过度保守的前提下，实现动态环境中计算资源与通信带宽的高效协同，最小化平均处理延迟。

### 🔍 结果与价值总结

Space-CPN架构为实现全球无缝连接、支撑多样化星载计算任务提供了可行的系统方案。通过“面向任务的通信策略+高能效类脑计算架构+不确定性鲁棒资源分配”三大技术体系的协同，可系统性解决动态空间网络中的资源调度与计算瓶颈，未来随着相关技术逐步成熟，将为各类先进星载计算服务提供坚实的工程基础。
