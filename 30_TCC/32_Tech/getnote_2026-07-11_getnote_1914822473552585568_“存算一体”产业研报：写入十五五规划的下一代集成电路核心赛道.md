# “存算一体”产业研报：写入十五五规划的下一代集成电路核心赛道

### 🏛️ 政策与行业核心背景
1.  **政策定位**：2026年，**存算一体**首次被正式写入《中华人民共和国国民经济和社会发展第十五个五年规划纲要》，在“培育壮大新兴产业和未来产业”章节中，与**三维集成**、**光电融合**并列，被明确列为下一代集成电路重点突破方向。
2.  **算力需求爆发**：国家数据局公开数据显示，截至2026年3月，我国日均AI Token调用量已突破140万亿，相较2024年初增长超过千倍，传统计算架构的瓶颈被快速放大。

### 📚 存算一体的技术逻辑与行业痛点

#### 传统冯·诺依曼架构的核心瓶颈

沿用数十年的冯·诺依曼体系将计算与存储模块完全独立，AI推理过程中需要海量数据在CPU/GPU与DRAM/Flash等存储器件之间频繁搬运，最终催生两大行业瓶颈：
| 瓶颈类型 | 具体表现与关键数据 |
| :--- | :--- |
| **存储墙** | AI运算需要接近1PB/s的存算通道速率，传统DRAM带宽完全无法匹配算力增长速度 |
| **功耗墙** | 图灵奖得主约翰·轩尼诗测算，AI计算中数据搬运成本已达到计算成本的100倍，7nm工艺下数据搬运功耗占比超过63% |
- 现有HBM高带宽存储方案仅通过3D封装优化传输效率，并未改变“存算分离”的底层架构，无法从根源破解上述痛点。

#### 存算一体的核心思路与技术路线分类

存算一体通过让数据直接在存储阵列内部完成运算，最大限度减少数据搬运的次数与距离，同步实现效率提升、功耗降低、延迟缩短。当前行业主流技术路线分为两大方向：
| 技术路线 | 核心特性 | 优势 | 现存挑战 |
| :--- | :--- | :--- | :--- |
| **模拟存算一体** | 依托RRAM、Flash等器件物理特性，在模拟域完成矩阵乘加运算 | 能效表现突出 | 长期面临精度漂移、噪声敏感、环境稳定性不足等问题 |
| **数字存算一体** | 在存储单元周边集成逻辑电路，以数字方式完成运算 | 可靠性、通用性更强 | 整体功耗略高于模拟路线 |

不同存储介质适配不同落地场景：SRAM适配云端高性能推理、Flash适配端侧低功耗设备、RRAM被视作下一代核心介质，此外DRAM-PIM、MRAM、PCRAM等路线也在同步演进。

### 🚀 国内核心卡位企业全景梳理

国内存算一体赛道未出现统一技术路线，初创企业在存储介质、计算方式、落地场景上形成差异化布局，覆盖端侧、边缘、云端全层级市场：
1.  **知存科技：率先跨过量产死亡谷的端侧标杆**
    - 成立于2017年，由北大微电子系校友创立，锁定**NOR Flash模拟存算一体**路线，专注端侧低功耗AI市场。
    - 核心产品：2021年推出国际首款存算一体加速器芯片WTM1001，后续量产的标志性产品WTM2101 SoC芯片，典型工作功耗达到微瓦级、待机功耗接近零，适配TWS耳机、智能手表、智能语音等终端设备。
    - 落地进展：已打通晶圆制造、封测到终端集成的全链条，产品进入万魔声学、科大讯飞等头部客户供应链，率先证明存算一体可以实现标准化、规模化出货。
2.  **亿铸科技：面向数据中心的全数字路线探索者**
    - 2020年成立，团队核心成员来自NVIDIA、AMD、高通、华为等企业，选择**ReRAM全数字存算一体**路线，面向数据中心大算力场景。
    - 核心优势：不使用ADC/DAC模数转换器，从根源避免模拟计算的精度损失，精度可达32bit及以上，系统稳定性大幅提升。
    - 产品进展：2023年研发出首颗28nm工艺高精度存算一体POC芯片，单卡算力突破1000TOPS（INT8），目前正推进从POC验证向量产落地，面向数据中心、云计算、自动驾驶等场景。
    - 生态布局：从指令集层面兼容CUDA、Triton等主流开发体系，搭配自研算子自动优化编译器，引入RISC-V核完善异构计算体系，降低开发者迁移成本。
3.  **后摩智能：转型切入端边大模型赛道的架构创新者**
    - 2020年成立，创始人吴强为AMD GPGPU/OpenCL创始团队核心成员，拥有丰富的高端芯片量产经验。
    - 战略转型：最初聚焦智能驾驶芯片，2023年发布算力256TOPS的鸿途H30智驾芯片，2023年下半年转向端边大模型增量市场。
    - 核心产品：2025年发布漫界M50芯片，采用第二代自研天璇IPU架构，单芯片算力达160TOPS@INT8、100TFLOPS@bFP16，典型功耗仅10W，可在端侧运行1.5B到70B参数的本地大模型。
    - 落地进展：已推出M.2加速卡、计算盒子等多元产品，进入联想、科大讯飞、中国移动的头部供应链，同时启动下一代DRAM-PIM技术研发，目标突破1TB/s片内带宽。

### 🔍 行业关键洞察与未来展望

当前存算一体赛道仍处于早期成长阶段，距离大规模商业化仍需突破三大核心挑战：
1.  **工艺与量产挑战**：不同存储介质均存在阵列一致性、可靠性、良率等工程难题，模拟存算方案对噪声、温度漂移的敏感度较高。
2.  **软件生态挑战**：全球AI产业已围绕CUDA建立起完整的开发工具链，新架构需要实现主流生态兼容，才能降低开发者迁移门槛。
3.  **场景验证挑战**：存算一体并非适配所有AI任务，核心落地场景集中在矩阵运算密集、功耗敏感、访存压力大的领域，商业化价值的挖掘仍需时间沉淀。

但与此同时，赛道的产业窗口正在快速打开：依托成熟工艺即可实现高能效、高带宽、低成本优势，存算一体已经成为国内半导体产业实现差异化突围的关键落点，写入“十五五”规划仅仅是产业爆发的起点。
