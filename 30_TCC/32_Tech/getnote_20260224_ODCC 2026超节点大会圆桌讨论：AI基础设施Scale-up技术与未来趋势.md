# ODCC 2026超节点大会圆桌讨论：AI基础设施Scale-up技术与未来趋势

### **🎯 核心讨论背景与主题**

**会议概况**
- **时间**：2026年（马年春节前）
- **主持人**：ODCC新测组组长、中国信通院云大所总工程师郭亮
- **嘉宾**：腾讯何泽坤（网络工作组组长）、阿里云王伟（决策委员）、字节跳动宋东阳（网络专家）
- **核心议题**：围绕**ETH-X**、**UALink**、**EthLink**等前沿Scale-up技术，探讨技术适配痛点、产业实践经验与未来创新方向，聚焦AI大模型推理场景对基础设施的需求。

### **🔍 GPU互联协议与生态挑战**

#### **(一) UAL协议发展与生态建设**
- **发展历程**：UAL协议自2024年提出，2025年成立工作组并发布1.0标准，2.0标准处于研讨阶段。
- **生态瓶颈**：标准先行但硬件落地滞后，**UAL Switch芯片**成为关键制约因素。2026年将有多家企业推出国产化UAL Switch（如楠菲微计划年内量产）。
- **竞争格局**：GPU厂商呈现“**百家争鸣**”态势，头部企业（如NVIDIA）采用自研协议+Switch芯片的“全家桶”闭环方案，中小厂商倾向拥抱开放生态（如UAL）。

#### **(二) 多协议并存的挑战**

| 协议类型 | 特点 | 应用现状 |
| :------- | :--- | :------- |
| **UAL** | 开放标准，内存语义访问 | 2.0标准研讨中，Switch芯片2026年量产 |
| **NVLink** | 封闭生态，高带宽（利用率70%-85%） | NVIDIA主导，支持GPU间直接互联 |
| **EthLink** | 基于以太网，带宽利用率达90% | 字节跳动等企业关注，三网融合潜力 |
| **ETH+** / ESUN / SUE | 非传统以太网协议 | 新兴技术，生态成熟度待提升 |

### **🚀 AI推理场景对超节点的需求演变**

#### **(一) 集群规模变化**
- **训练 vs 推理**：训练需万卡/十万卡集群，推理仅需**超节点级规模**（64-256卡，部分场景需512卡）。
- **云厂商视角**：公共云追求资源利用率，超节点规模可能扩展至**千卡级**，以提升调度灵活性。

#### **(二) 技术挑战**
- **存储与IO扩展**：GPU需直接访问外部存储（SSD）和IO设备，避免通过CPU绕行导致的带宽瓶颈。
- **TPOT时间压缩**：机器间对话场景要求TPOT（Time Per Output Token）从50毫秒降至**10-20毫秒**，以提升产品竞争力。
- **序列长度需求**：输入sequence长度从4K向**64K-128K**演进，对内存和算力提出更高要求。

### **🏗️ 硬件架构转型：从CPU中心到GPU中心**

#### **(一) 架构变革方向**
- **核心观点**：打破传统“CPU中心”架构，构建**GPU中心互联体系**，类比PCIe协议为CPU扩展外设的模式，通过Scale-up协议为GPU扩展存储、IO和计算能力。
- **技术路径**：NVIDIA通过**NVLink C2C**连接GPU与Grace CPU，AMD采用**xGMI4**（UALink底层协议）连接MI450 GPU与Venice CPU，均追求内存一致性与低延迟。

#### **(二) 厂商实现差异**

| 厂商 | 架构特点 | 关键连接技术 |
| :--- | :------- | :----------- |
| **NVIDIA** | GPU与CPU通过NVLink C2C直连，网卡（CX8/CX9）集成PCIe Switch | NVLink C2C、PCIe Gen6 |
| **AMD** | GPU与CPU通过xGMI4连接，支持UALink与PCIe双协议 | xGMI4（Infinity Fabric）、UALink 800G |

### **🔗 三网融合与互联技术创新**

#### **(一) 三网融合趋势**
- **定义**：Scale-up（超节点内）、Scale-out（集群间）、DCN（数据中心网络）三网融合，降低运维复杂度。
- **实现路径**：博通TH6/TU1交换机等硬件支持多协议，推动统一网络架构。

#### **(二) 互联介质演进**
- **铜缆**：成本低，单机柜内成熟，但512卡超节点规模下可能面临带宽与距离限制。
- **光互联**：需解决**可靠性**（提升可用率）、**延迟**（去除DSP减少3-50ms延迟）、**成本**（接近铜缆）三大挑战，VCSEL与硅光技术为潜在解决方案。

### **📈 未来技术突破方向**
1. **协议标准化**：从开放生态走向适度统一，减少厂商碎片化选择（如华为UBA、海光HSL逐步开放）。
2. **外设协同**：SSD、内存等外设需支持GPU直连，探索存储计算卸载（如KV Cache优化）。
3. **Chiplet与异构集成**：通过Chiplet技术灵活适配多协议，解决GPU互联协议切换难题。
4. **高速IO工艺**：国内需突破224G/448G高速信号技术，借鉴NVIDIA 448G实现路径（从112G演进）。

### **📝 补充细节**
- **MoE模型影响**：专家数量与激活策略推动超节点规模需求，预计2028年国产算力下512卡超节点成为主流。
- **计算外溢效应**：AI推理从“全计算”向“计算+查找”混合模式演进，带动内存、SSD需求激增（如KV Cache导致存储涨价）。
- **国产替代进展**：2026年国产PCIe 6.0和UALink Switch进入量产阶段，加速开放生态建设。
