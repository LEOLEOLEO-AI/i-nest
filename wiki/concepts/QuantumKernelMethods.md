## Definition
A class of quantum machine learning algorithms that map classical data into quantum feature spaces via kernel functions, enabling classification without explicit quantum circuit training. These methods can be embedded into in-network neuromorphic processors to perform high-dimensional pattern recognition directly on data streams, reducing latency in TCC architectures.
