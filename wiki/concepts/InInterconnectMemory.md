# InInterconnectMemory

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A storage paradigm where data is retained in the physical properties (e.g., resistance) of the interconnect elements themselves, rather than in dedicated memory cells. This eliminates the memory-compute bottleneck, enabling faster and more energy-efficient event processing in topology-centric architectures.
