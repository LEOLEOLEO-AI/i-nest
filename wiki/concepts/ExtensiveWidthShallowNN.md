# ExtensiveWidthShallowNN

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A shallow neural network whose hidden layer width scales linearly with the number of training samples, placing it in a high-dimensional regime distinct from typical overparameterized networks. This scaling regime is relevant to TCC/iNEST because it provides a tractable theoretical framework for understanding learning dynamics in distributed or in-network neuromorphic hardware where layer widths are constrained by physical interconnect topologies.
