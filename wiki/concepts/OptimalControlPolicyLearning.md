**Domain**: Cross

## Definition
The process of using reinforcement learning to iteratively approximate the optimal control policy that minimizes a cost function for distributed agents. This provides a data-driven path to achieving near-optimal performance in complex network topologies without explicit system models, which is valuable for iNEST adaptive hardware.
