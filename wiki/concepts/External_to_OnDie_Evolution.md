# External_to_OnDie_Evolution

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A design progression from using SDI as an external chip-to-chip interconnect to embedding it as an on-die NoC component, shifting from board-level to package-level integration. This evolution enables tighter coupling between compute and communication, essential for realizing high-throughput, low-latency TCC architectures.
