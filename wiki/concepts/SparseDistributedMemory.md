# SparseDistributedMemory

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A memory architecture where information is stored across a large population of sparsely active neurons, with each memory item represented by a distributed pattern of activity rather than a localized address. This is foundational for topology-centric computing because it leverages high-dimensional sparse connectivity to achieve fault tolerance and content-addressable recall, which are key for in-network processing.
