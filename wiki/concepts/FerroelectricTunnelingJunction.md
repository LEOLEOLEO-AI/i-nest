# FerroelectricTunnelingJunction

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A type of self-rectifying memristor that uses a ferroelectric barrier to modulate tunneling current, providing both memory and rectification in a single device. Offers a promising material-based solution for high-density crossbar arrays, enabling low-power analog synaptic behavior for neuromorphic computing in iNEST.
