# ReservoirComputing

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
A recurrent neural computation paradigm in which a fixed random dynamical system, the reservoir, maps inputs into a high-dimensional state space while only the readout is trained. It provides a core computational substrate for neuromorphic and topology-centric architectures where complex dynamics replace full network training.
