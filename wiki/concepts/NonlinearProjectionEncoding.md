# NonlinearProjectionEncoding

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The mapping of input signals into a high-dimensional nonlinear state space via the reservoir's dynamics, which separates and encodes signal features for easier reconstruction. Enables linear readout to recover the original waveform, simplifying the reconstruction algorithm and making it robust to noise and sampling jitter.
