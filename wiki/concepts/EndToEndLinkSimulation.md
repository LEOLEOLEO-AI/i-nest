# EndToEndLinkSimulation

**Domain**: TCC
**First mentioned**: auto-extracted

## Definition
A simulation methodology that models the complete signal path from transmitter PHY through interposer/package traces to receiver PHY, including all parasitic and non-ideal effects. Provides realistic performance estimates for TCC designs, where inter-chiplet links are the primary bottleneck for distributed computing and memory access.
