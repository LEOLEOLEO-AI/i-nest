# ChipletIntegration

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-22

## Definition
Chiplet integration is a modular hardware design approach that partitions a system into separately fabricated dies assembled into a single package or interconnect fabric. It supports heterogeneous scaling and topology-aware composition of neuromorphic and topology-centric compute tiles in TCC/iNEST systems.
