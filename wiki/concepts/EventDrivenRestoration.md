# EventDrivenRestoration

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-06

## Definition
A processing paradigm where image restoration operations are triggered only by relevant spiking events, rather than processing every pixel uniformly, mimicking biological neural efficiency. Reduces computational load and energy use in TCC/iNEST pipelines by focusing computation on informative temporal changes, critical for real-time edge neuromorphic systems.
