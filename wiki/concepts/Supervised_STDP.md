# Supervised_STDP

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
A hybrid learning scheme that modulates the local STDP update rule with a global supervised error or teacher signal so that plasticity remains local while still converging on a labeled task. It reconciles biologically plausible local plasticity with task-directed accuracy, addressing the key iNEST challenge of supervised learning on spiking neuromorphic substrates.
