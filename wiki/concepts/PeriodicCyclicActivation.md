# PeriodicCyclicActivation

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
A large-scale cortical functional network state in which multiple brain networks reactivate in a repeating temporal sequence rather than appearing as stochastic Markov switches. Provides a deterministic temporal scaffold for in-network neuromorphic systems to coordinate cognitive and homeostatic tasks over behaviorally relevant timescales.
