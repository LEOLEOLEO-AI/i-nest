# AdaptersInSpikingNetworks

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
Lightweight trainable modules inserted into frozen spiking network layers to enable task-specific fine-tuning without altering the original spike-based computation paths. Provides a scalable way to specialize pre-trained spiking models for multiple point cloud tasks in resource-constrained in-network environments, avoiding full retraining.
