## Definition
A three-layer Ag/Ga2O3/Pt memristor using wide-bandgap Ga2O3 that integrates UV light sensing, data storage, logic operations, and neuromorphic behaviors. Provides a multifunctional building block for in-network neuromorphic hardware by merging sensing, memory, and processing in a single nanoscale device.
