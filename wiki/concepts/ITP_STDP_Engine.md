# ITP_STDP_Engine

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
An intrinsic-timing power-of-two learning engine that implements spike-timing-dependent plasticity (STDP) using simplified power-of-two weight updates to reduce computational complexity. Provides a hardware-friendly STDP implementation that accelerates on-chip learning in neuromorphic processors, critical for adaptive iNEST systems with limited power budgets.
