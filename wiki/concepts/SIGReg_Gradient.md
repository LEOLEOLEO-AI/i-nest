# SIGReg_Gradient

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A local synaptic learning rule that computes a gradient-like signal for synaptic weight updates without requiring global backpropagation, using only information available at the synapse. Enables biologically plausible and energy-efficient learning in neuromorphic hardware, crucial for scaling iNEST systems to large topologies.
