# Photonic_InMemory_Computing

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-02

## Definition
A computing paradigm where memory and processing are co-located and optically controlled within the same device to overcome data movement bottlenecks. It addresses von Neumann bottlenecks in iNEST systems by enabling ultra-fast, low-power synaptic operations directly in the optical domain.
