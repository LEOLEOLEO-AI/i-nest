# MemoryDrivenRouting

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A routing paradigm where packet paths are determined by pre-stored memory patterns rather than computed on-the-fly, enabling deterministic and low-latency photonic switching. Reduces routing overhead in large-scale photonic circuits, critical for scalable TCC interconnects where optical path setup latency dominates.
