## Definition
The graph-theoretic structure of paths along which correlation propagates, treated as a first-class topological object that constrains which network components can influence one another's learning. It supplies TCC with a topology-centric criterion for placing compute, memory, and plasticity elements so that correlation reaches the synapses that need updating.
