# BEOL_Pass_Gate

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
An access transistor whose channel is deposited in the back-end-of-line metal stack (here an IGO semiconductor) so the pass-gate sits in routing tiers instead of the front-end silicon footprint. It demonstrates that switching elements can be embedded inside the interconnect stack itself, a hardware realisation of the TCC premise that topology and wiring participate in computation.
