# HeterogeneousSynapticDelays

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A mechanism in recurrent spiking neural networks where synaptic transmission delays vary across connections, enabling temporal information to be stored and processed through delay-based working memory. This is critical for iNEST as it provides a biologically plausible and hardware-friendly method for implementing working memory in neuromorphic systems without relying on external memory circuits.
