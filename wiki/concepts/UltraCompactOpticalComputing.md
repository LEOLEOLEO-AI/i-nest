# UltraCompactOpticalComputing

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A computing paradigm where optical signal processing is performed in sub-wavelength-scale photonic structures, drastically reducing the physical size of compute nodes. Allows dense integration of compute and memory in chiplet architectures, enabling tighter coupling between processing elements and reducing interconnect distance in TCC systems.
