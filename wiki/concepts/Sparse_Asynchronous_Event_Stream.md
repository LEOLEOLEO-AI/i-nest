# Sparse_Asynchronous_Event_Stream

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-01

## Definition
An input modality from event cameras and low-power edge sensors composed of sparse, asynchronous, strongly time-correlated events rather than dense frame-based samples. It defines the unique temporal workload that iNEST neuromorphic systems must process under strict energy, latency, storage, and bandwidth constraints.
