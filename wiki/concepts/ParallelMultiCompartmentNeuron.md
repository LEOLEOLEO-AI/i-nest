# ParallelMultiCompartmentNeuron

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A spiking neuron model with multiple parallel compartments, each processing different temporal scales of input, enabling multi-scale temporal integration within a single neuron. This architecture allows a single neuron to capture both fast and slow dynamics simultaneously, which is crucial for temporal feature extraction in neuromorphic systems without increasing network depth.
