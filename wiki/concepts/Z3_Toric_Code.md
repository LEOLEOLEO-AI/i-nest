## Definition
A topological quantum error-correcting code based on a three-state Z_3 gauge symmetry on a torus, generalizing qubit toric codes to qutrit degrees of freedom. It extends topological error correction beyond qubits, which is relevant for TCC architectures seeking robust qutrit-based topological memories and fault-tolerant operations.
