# Symmetric_Memory

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-17

## Definition
A memory architecture in which all participating chips or nodes share a uniform, symmetric address space to reduce explicit data movement and synchronization overhead. It is proposed as a mechanism to break the communication wall in 10k-GPU clusters, informing TCC and iNEST memory-interconnect co-design.
