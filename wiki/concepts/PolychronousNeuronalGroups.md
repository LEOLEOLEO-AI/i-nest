# PolychronousNeuronalGroups

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
Groups of neurons that fire in precise, reproducible time-locked sequences (polychrony) that emerge from spike-timing-dependent plasticity (STDP) and network topology. These groups serve as functional computational primitives in neuromorphic substrates, enabling temporal coding and memory without explicit clocking.
