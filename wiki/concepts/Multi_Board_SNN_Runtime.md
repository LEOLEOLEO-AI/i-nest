## Definition
A system architecture that partitions and runs a single spiking neural network across multiple FPGA boards, synchronizing spike exchange to scale up neural networks beyond a single chip. This enables large-scale neuromorphic computing on commodity hardware, relevant for distributed iNEST nodes.
