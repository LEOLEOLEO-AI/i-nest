# TopologyAwareUnlearning

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
An unlearning strategy that leverages the graph or network topology to identify and update only the most influential nodes/edges connected to the data to be forgotten. Reduces computational and memory write overhead in graph-centric computing, making unlearning scalable for large-scale topological data stored on CIM arrays.
