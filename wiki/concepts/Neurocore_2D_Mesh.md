**Domain**: TCC

## Definition
A processing element in Loihi 2 containing ~1000 LIF neurons, arranged in a 2D mesh topology on the chip. The 2D mesh arrangement of neurocores defines the physical communication graph, which is a key constraint for mapping TCC topologies onto neuromorphic hardware.
