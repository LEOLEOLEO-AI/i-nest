# Wafer_Scale_LLM_Inference

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-11

## Definition
The use of wafer-scale integration to host entire LLM inference workloads on a single substrate, minimizing off-wafer memory access. Reduces memory latency and energy consumption, making it a key enabler for real-time, large-model inference in TCC systems.
