## Definition
A computational pattern where probabilistic (P) and deterministic (D) inference mechanisms are interleaved across network nodes, each with distinct latency and fidelity characteristics. Captures the core heterogeneity in iNEST designs, requiring new contracts to manage mixed-fidelity reasoning in real-time network paths.
