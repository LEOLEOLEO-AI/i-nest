# Memristor

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A two-terminal non-volatile memory device whose conductance is programmable by applied electrical history, used to implement synaptic weights in neuromorphic hardware. Memristive arrays are critical for scaling neuromorphic chips with dense, energy-efficient synaptic storage and in-situ learning in iNEST deployments.
