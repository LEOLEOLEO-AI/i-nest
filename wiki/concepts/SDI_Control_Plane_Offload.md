# SDI_Control_Plane_Offload

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
Offloading SDI control-plane functions (e.g., flow management, resource allocation) into the NPU's NoC routers or endpoints, rather than keeping them in a separate host processor. This tight coupling allows TCC/iNEST to achieve deterministic, low-overhead reconfiguration of network and compute resources, critical for dynamic topology adaptation.
