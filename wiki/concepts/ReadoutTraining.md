# ReadoutTraining

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The process of training only the output layer (readout) weights from reservoir states, leaving the recurrent connections fixed. Enables fast, low-cost learning in iNEST hardware, as only simple linear or shallow nonlinear readouts need adaptation.
