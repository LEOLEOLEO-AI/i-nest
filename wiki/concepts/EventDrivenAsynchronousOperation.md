# EventDrivenAsynchronousOperation

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
An operational mode with no global clock in which the chip's circuits react to incoming spikes only when input stimuli occur. This eliminates continuous clock power draw, making ultra-low-power spike processing feasible for IoT edge devices.
