# Cross_Node_Event_Propagation

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The transmission of spike events between neurons or network partitions residing on different NUMA nodes, incurring additional interconnect latency and bandwidth usage. Minimizing cross-node event propagation is key to scaling spiking network simulations across distributed memory architectures, directly impacting iNEST's ability to model large-scale brain-like networks.
