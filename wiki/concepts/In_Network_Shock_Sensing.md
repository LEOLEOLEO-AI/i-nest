# In_Network_Shock_Sensing

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
A neuromorphic computation scheme in which spiking nodes embedded within the network fabric locally detect and encode shock features for downstream classification. Enables iNEST architectures to perform distributed, low-latency shock classification without offloading raw signals to a host processor.
