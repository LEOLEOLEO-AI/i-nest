# Memory_Bandwidth_Density

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-09-24

## Definition
The amount of memory bandwidth per unit area or per watt achieved by co-locating memory and compute on a wafer-scale substrate, such as 25 PB/s in WSE-3. Quantifies how topology-driven memory placement can overcome the memory wall, a critical metric for TCC and iNEST architectures.
