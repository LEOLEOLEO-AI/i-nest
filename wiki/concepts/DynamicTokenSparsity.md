# DynamicTokenSparsity

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A method that adaptively drops or retains tokens per input sample based on task-relevant features, rather than using fixed token grids. This enables variable-rate computation that maps naturally to neuromorphic hardware's event-driven, sparse activation patterns, improving efficiency in in-network inference.
