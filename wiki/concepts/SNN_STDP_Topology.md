**Domain**: iNEST

## Definition
The application of Spike-Timing-Dependent Plasticity (STDP) rules within a spiking neural network (SNN) where the network topology is explicitly designed to influence learning dynamics. This allows topology to directly shape synaptic weight updates, making network structure a first-class learning parameter in neuromorphic hardware.
