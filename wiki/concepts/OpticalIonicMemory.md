# OpticalIonicMemory

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A memory element that stores information as optically-induced ionic charge states, which can be read out as conductance levels for neural network weights. Supports non-volatile, light-programmable synaptic weights, enabling compact in-memory computing for visual pattern recognition in iNEST edge devices.
