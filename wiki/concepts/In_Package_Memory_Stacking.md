# In_Package_Memory_Stacking

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A packaging technique that places memory chiplets vertically or adjacently to compute chiplets to reduce data movement distance and increase effective bandwidth. Reduces memory latency and energy, which is essential for memory-bound recommendation models like DLRM.
