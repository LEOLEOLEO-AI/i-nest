# CGRA_Reconfigurable_Array

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-17

## Definition
A Coarse-Grained Reconfigurable Architecture consisting of a 2D array of word-level processing elements whose datapath and interconnect can be statically or dynamically reconfigured per application. CGRA provides the post-Moore compute substrate whose PE-array topology must be co-designed with TCC mapping and iNEST interconnect constraints.
