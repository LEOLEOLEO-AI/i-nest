# OnChipSNNTrainingEngine

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A dedicated hardware module integrated within a spiking neural network chip that performs local, real-time synaptic plasticity updates without external host intervention. Enables autonomous, low-latency adaptation in distributed iNEST nodes, reducing communication overhead and enabling in-network learning.
