# MemristiveSupervisedLearning

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A supervised learning paradigm implemented on memristive crossbar arrays, where weights are stored as conductance states and updated via programming pulses. This is foundational for TCC/iNEST hardware accelerators, enabling in-memory computing and efficient neural network inference/learning at the edge.
