# Ferroelectric_Synaptic_Devices

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
Hardware synaptic elements using ferroelectric materials whose polarization states represent synaptic weights, enabling non-volatile, analog, and energy-efficient weight updates in spiking neural networks. Enables personalized, on-device learning in neuromorphic systems without external memory, addressing the memory-wall bottleneck in TCC/iNEST edge deployments.
