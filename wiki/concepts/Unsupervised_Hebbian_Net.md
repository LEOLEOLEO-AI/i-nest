## Definition
A neural network architecture that uses Hebbian plasticity (e.g., Oja's rule) for unsupervised learning, where synaptic weights are updated based on local correlations between pre- and post-synaptic activity. Core building block for in-network neuromorphic systems that must learn from streaming data without supervision, aligning with iNEST's goal of autonomous edge intelligence.
