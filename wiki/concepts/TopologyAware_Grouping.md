# TopologyAware_Grouping

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-07

## Definition
A design methodology that partitions compute nodes into logical groups based on the underlying physical network topology (e.g., Dragonfly+ groups) to optimize communication locality and reduce global traffic congestion. This concept is foundational in TCC because it allows application mapping and scheduling to exploit the network structure, directly improving performance and energy efficiency in large-scale systems.
