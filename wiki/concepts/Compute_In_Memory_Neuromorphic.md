## Definition
An architecture where memory and computation are co-located, enabling synaptic operations to occur directly within memory arrays, eliminating von Neumann bottlenecks. This is foundational for iNEST's energy-efficient neural processing, and its integration with signal folding represents a novel cross-domain optimization for TCC and iNEST.
