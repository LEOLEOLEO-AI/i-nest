# Dual_Role_Dendrite

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A dendrite architecture that acts simultaneously as an input integrator for synaptic signals and as a feedback receiver for backpropagating action potentials. This dual function provides a topological template for network nodes that couple feedforward and feedback pathways, a core principle in both TCC and iNEST.
