## Definition
A strategy where the model adjusts its computational path or depth based on the difficulty or content of each input sample, rather than using a fixed forward pass. Aligns with the need for adaptive, event-driven processing in neuromorphic systems, where computation is triggered by input significance, enabling efficient use of network bandwidth and compute.
