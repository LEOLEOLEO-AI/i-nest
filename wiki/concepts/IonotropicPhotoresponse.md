# IonotropicPhotoresponse

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A mechanism where photon absorption drives ion flux or redistribution within a material, altering conductance or charge state for synaptic plasticity. Provides a non-volatile, analog memory mechanism that can be integrated into network nodes for persistent state storage in neuromorphic architectures.
