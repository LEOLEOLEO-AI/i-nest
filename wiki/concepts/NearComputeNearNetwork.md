# Near_Compute_Near_Network

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-09-02

## Definition
A design principle that places computational elements and data processing capabilities in close proximity to network endpoints, reducing the distance data must travel during distributed LLM operations. It minimizes communication latency and power consumption, a critical requirement for real-time LLM inference and efficient training across interconnected compute nodes.
