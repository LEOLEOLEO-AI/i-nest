## Definition
The strategy of assigning spiking network components (neurons, synapses, and event queues) to specific NUMA nodes to optimize memory locality and reduce cross-node communication latency. Proper placement is essential for achieving deterministic and high-performance spiking simulations on multi-socket systems, a core requirement for iNEST neuromorphic workloads.
