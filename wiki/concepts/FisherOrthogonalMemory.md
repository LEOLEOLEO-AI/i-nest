# FisherOrthogonalMemory

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A memory encoding scheme in quantum reservoir computing that uses Fisher information to orthogonalize the reservoir's state representations, minimizing redundancy between stored temporal features. This directly addresses the memory capacity bottleneck in reservoir computing, enabling more efficient temporal information storage in neuromorphic hardware for TCC/iNEST systems.
