# Physical_Reservoir_Computing

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A computing paradigm where a fixed, nonlinear physical system (the reservoir) maps inputs to high-dimensional states, and only a readout layer is trained. Leverages inherent physical dynamics (e.g., optoelectronic responses) for temporal processing, reducing training complexity and enabling real-time signal analysis in TCC/iNEST systems.
