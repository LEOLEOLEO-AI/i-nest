# In_Network_Generative_Inference

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The deployment of generative model inference directly within network switches or routers, rather than at centralized servers, to reduce latency and bandwidth for healthcare AI applications. Enables real-time, privacy-preserving generative processing in medical IoT and telemedicine, a core use case for iNEST's neuromorphic in-network computing paradigm.
