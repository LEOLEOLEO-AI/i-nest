# HeterogeneousIntegration

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The monolithic or 3D co-integration of diverse material and device technologies (e.g., memristors, ferroelectric devices, CMOS) into a single neuromorphic chip or wafer. This is critical for TCC/iNEST because it allows combining the best of each device type (e.g., non-volatility, switching speed, energy) to build scalable, high-density crossbar arrays for spiking neural networks.
