# FivePort_Router

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A per-core router with five ports (up, down, left, right, local), 32-bit bidirectional links, and single-cycle hop latency, embedded in each compute core. This ultra-compact router enables energy-efficient, low-latency local communication, a fundamental building block for scaling topology-aware architectures across millions of cores.
