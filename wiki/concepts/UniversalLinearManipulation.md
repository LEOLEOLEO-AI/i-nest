# UniversalLinearManipulation

**Domain**: Cross
**First mentioned**: auto-extracted

## Definition
A framework for implementing arbitrary linear transformations on quantum states using only routing operations and projective measurements, without requiring direct unitary gates. This enables resource-efficient linear algebra in network-centric quantum computing, aligning with TCC's goal of moving computation into the network fabric.
