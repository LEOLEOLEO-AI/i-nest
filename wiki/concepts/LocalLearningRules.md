# LocalLearningRules

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
Learning rules for spiking neural networks that update synaptic weights using only information available at the local synapse, without global error propagation. Enables online, energy-efficient learning in neuromorphic hardware, avoiding the need for costly backpropagation and global synchronization.
