# Sparse_Distributed_Memory

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A memory model that stores data across many overlapping, sparse binary patterns, allowing content-addressable retrieval and noise tolerance. Mimics hippocampal memory mechanisms, offering scalable and resilient memory for neuromorphic systems without dense connectivity.
