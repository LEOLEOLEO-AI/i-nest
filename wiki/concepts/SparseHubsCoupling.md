# SparseHubsCoupling

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A coupling scheme in which a small number of hub nodes with high degree centrality mediate interactions between otherwise weakly connected dynamical units in an ultra-small-world network. This is essential for iNEST hardware implementations, as it allows neuromorphic circuits to emulate complex brain-like dynamics with reduced synaptic resource usage.
