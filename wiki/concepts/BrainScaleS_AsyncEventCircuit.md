# BrainScaleS_AsyncEventCircuit

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
An asynchronous, event-driven circuit design approach for spiking neural network hardware, modeled after BrainScaleS, where spike events trigger computation instead of a global clock. This enables low-power, low-latency neuromorphic implementations critical for iNEST systems.
