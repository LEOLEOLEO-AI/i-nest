# OnChipNeuralNetworkFabric

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A crossbar array architecture where synaptic weights are stored and computed in-place using memristive devices, eliminating the von Neumann bottleneck. This is foundational for TCC/iNEST systems that require distributed, low-latency computation directly within the network topology.
