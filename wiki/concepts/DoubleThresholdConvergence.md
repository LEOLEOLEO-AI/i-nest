# DoubleThresholdConvergence

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
Double threshold convergence is a simulation criterion where a network model is considered converged only when both predefined high and low threshold conditions are satisfied. This convergence check ensures stable and reliable evaluation of SDI network configurations before deployment in TCC systems.
