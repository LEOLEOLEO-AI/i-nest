## Definition
A D flip-flop used as a fundamental memory element to store spike state (0/1) in spiking neural network circuits, forming the basis for neuron state and delay lines. Provides a low-latency storage unit for temporal spike information, essential for implementing synaptic delays and neuron dynamics in SNN hardware.
