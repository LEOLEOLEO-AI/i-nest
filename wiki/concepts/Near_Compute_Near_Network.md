# Near_Compute_Near_Network

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A placement principle where computation and data processing are co-located with network endpoints to minimize data movement for large language model workloads. It directly addresses LLM inference/training latency by keeping data close to compute and reducing expensive network round trips.
