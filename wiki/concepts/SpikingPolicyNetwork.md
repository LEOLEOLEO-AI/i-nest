## Definition
A neural network policy that uses spike-based communication and temporal coding to represent actions, trained via surrogate gradient methods or reward-modulated plasticity. Provides biologically plausible, low-power computation for continuous control tasks, critical for deploying neuromorphic systems in dynamic environments.
