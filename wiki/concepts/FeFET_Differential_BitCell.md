# FeFET_Differential_BitCell

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A bit-cell architecture using two FeFETs in a differential configuration that can operate in both volatile (DRAM-like) and non-volatile (flash-like) modes within the same cell. Enables hybrid memory functionality in neuromorphic circuits, allowing dynamic synaptic weight updates and persistent state storage without separate memory arrays.
