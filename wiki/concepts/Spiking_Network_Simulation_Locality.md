# Spiking_Network_Simulation_Locality

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The requirement that synaptic connections and neuron state data remain physically close to the processing cores that access them during event-driven simulation. Preserving this locality is essential for minimizing memory access latency and communication overhead in large-scale spiking network simulations.
