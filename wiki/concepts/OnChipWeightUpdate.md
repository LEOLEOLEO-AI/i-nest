# OnChipWeightUpdate

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The process of updating synaptic weights directly within the accelerator hardware during operation, without offloading to external memory or host processor. Eliminates memory bottlenecks and communication overhead, enabling real-time adaptive behavior in resource-constrained network devices.
