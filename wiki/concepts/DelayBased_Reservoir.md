# DelayBased_Reservoir

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-20

## Definition
A reservoir implementation where a single nonlinear node is coupled to a delayed feedback loop, and time-multiplexed 'virtual nodes' along the delay line emulate a spatially extended recurrent network. It provides a minimal-hardware route to in-network neuromorphic computing, since one physical node plus a delay line can realize large effective network dimensionality without fabricating many interconnected devices.
