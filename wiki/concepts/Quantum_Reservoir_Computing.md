**Domain**: Cross

## Definition
A computational paradigm that uses a quantum system as a fixed, high-dimensional reservoir to map input data into a feature space, where only a classical readout layer is trained for tasks like time-series prediction. It bridges quantum hardware and neuromorphic principles, offering a low-training-cost approach that could be integrated into in-network processing for efficient pattern recognition.
