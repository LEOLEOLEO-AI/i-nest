# 3D_Stacking

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A vertical integration technique that stacks multiple dies or memory layers using through-silicon vias (TSVs) to achieve high interconnect density. This reduces signal distance and power consumption in layered compute and memory, which is critical for scaling iNEST computational substrates and TCC topological structures.
