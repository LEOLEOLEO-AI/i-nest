# STDPDrivenTemporalBinding

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The process by which spike-timing-dependent plasticity strengthens synapses between neurons that consistently fire in causal temporal order, binding them into functional groups. Enables unsupervised learning of temporal patterns in neuromorphic systems, critical for real-time sensory processing in iNEST.
