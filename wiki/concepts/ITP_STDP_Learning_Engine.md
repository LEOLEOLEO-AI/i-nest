# ITP_STDP_Learning_Engine

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-20

## Definition
An intrinsic-timing power-of-two spike-timing-dependent plasticity engine that simplifies synaptic weight updates using power-of-two quantization and intrinsic timing signals. Reduces computational and memory overhead of online learning in neuromorphic chips, making it feasible for low-power in-network deployment.
