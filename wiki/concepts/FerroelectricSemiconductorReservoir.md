## Definition
A reservoir computing system that uses a ferroelectric semiconductor's polarization-dependent photocurrent dynamics as the nonlinear transient memory. Offers a compact, energy-efficient hardware implementation of reservoir computing with inherent short-term memory from ferroelectric hysteresis.
