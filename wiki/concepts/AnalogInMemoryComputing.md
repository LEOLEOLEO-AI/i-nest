# AnalogInMemoryComputing

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A computing paradigm where matrix-vector multiplications are performed directly in analog memory devices (e.g., memristors, ferroelectric cells) arranged in crossbar arrays, avoiding data movement between memory and processing units. This is foundational for TCC as it enables high-throughput, energy-efficient computation at the memory level, directly supporting topology-centric dataflow without von Neumann bottlenecks.
