# ParallelWeightUpdate

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-20

## Definition
The simultaneous modification of multiple synaptic weights in a neural network hardware array using a single optical exposure, rather than sequential per-device updates. Dramatically reduces programming time and energy, enabling real-time on-chip learning and reconfiguration in large-scale neuromorphic processors.
