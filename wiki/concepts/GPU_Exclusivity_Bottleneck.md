# GPU_Exclusivity_Bottleneck

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-06

## Definition
The performance and scalability limitation arising when GPU resources are treated as the sole compute engine for all inference workloads, ignoring heterogeneity. Highlights the need for TCC to design network topologies that offload or partition inference tasks beyond GPU-centric clusters.
