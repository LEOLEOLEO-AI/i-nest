## Definition
A methodology where the hardware architecture (e.g., power management units, thermal sensors) and the software stack (e.g., runtime schedulers, power-aware APIs) are jointly designed to enable fine-grained, dynamic energy control across the manycore system. This is crucial for TCC because it allows the runtime to adapt the network topology and computation placement based on real-time power/thermal feedback, enabling resilient and energy-efficient operation in heterogeneous and dynamic workloads.
