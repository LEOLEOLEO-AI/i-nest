# NonvisualGroundClassification

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-10

## Definition
A method to categorize terrain types (e.g., sand, gravel, hard ground) using only proprioceptive signals from the robot's own body, without cameras or external sensors. Bridges TCC and iNEST by demonstrating how local, topology-aware signal processing can replace high-bandwidth visual data, reducing latency and energy in edge computing.
