# Representation_Learning_Disentanglement

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A methodological framework that separates the effects of the neural code (representation) from the learning algorithm (learning) when evaluating noise robustness in spiking neural networks. This enables fair benchmarking between different neuromorphic systems by isolating whether performance differences arise from how information is encoded or how it is learned.
