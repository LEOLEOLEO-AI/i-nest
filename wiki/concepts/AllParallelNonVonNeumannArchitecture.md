# AllParallelNonVonNeumannArchitecture

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-02

## Definition
A fully parallel spiking neural network architecture that removes sequential instruction fetch, shared buses, and the von Neumann bottleneck. It allows direct neuron-to-neuron spike propagation and low-latency inference, which is essential for in-network neuromorphic computing.
