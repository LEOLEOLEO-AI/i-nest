# Neuromorphic_In_Network_Computation

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-17

## Definition
An execution model where spiking or event-driven computation is performed inside the interconnect/routing elements themselves instead of only at endpoint processing nodes. It exploits the reconfigurable CGRA interconnect as a computational resource, reducing data movement and enabling the topology-centric computing paradigm of iNEST.
