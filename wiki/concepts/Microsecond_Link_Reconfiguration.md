# Microsecond_Link_Reconfiguration

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-06

## Definition
The capability to establish or remove physical connections between compute nodes within a microsecond timescale, enabling rapid topology changes during runtime. This makes topology reconfiguration practical for real-time workloads, a key enabler for TCC's promise of adaptive, high-performance computing.
