# EEGSpikeEncoding

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A method to convert continuous EEG signals into spike trains using delta-modulation or threshold-based encoding, preserving temporal dynamics while reducing data rate. Forms the input interface for neuromorphic EEG processors, enabling energy-efficient real-time seizure or cognitive state detection.
