# GeTeBasedCBRAM

**Domain**: iNEST

## Definition
A conductive-bridge RAM variant using germanium telluride as the switching medium, offering fast and low-energy ion migration for analog memory. Provides a scalable and energy-efficient synaptic device candidate for in-memory computing and Hebbian learning in neural networks.
