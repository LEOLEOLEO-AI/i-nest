# STDP_Learning_Rule

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
Spike-Timing-Dependent Plasticity, a biological learning rule where synaptic weights are adjusted based on the relative timing of pre- and post-synaptic spikes. STDP enables in-network learning and adaptation, which is critical for implementing dynamic TCC topologies that can reconfigure based on data flow.
