# SoftwareDefinedInterconnect

**Domain**: TCC
**First mentioned**: auto-extracted

## Definition
A reconfigurable interconnect fabric whose routing and topology are controlled at runtime via software, enabling dynamic mapping of neural network communication patterns onto hardware. This is central to TCC as it allows the physical network topology to adapt to different SNN workloads, bridging the gap between algorithmic connectivity and physical substrate.
