# GlobalDecision_LocalExecution_ControlPlane

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-11

## Definition
A hierarchical control plane architecture where global decisions are made by an off-wafer master server, while each SDI switch node executes lightweight local control logic, with a dedicated out-of-band management channel isolated from the data plane. This separation enables scalable, fault-tolerant, and low-latency network management across wafer-scale TCC systems without burdening the data path.
