# SpikeTimingDependentFeatureExtraction

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A feature extraction mechanism in SNNs that leverages the exact timing of spikes to capture motion and sequence features, unlike rate-based coding that loses temporal precision. This enables the network to distinguish between different motion sequences, which is essential for object detection in dynamic scenes—a key capability for iNEST edge applications.
