# Processing_In_Memory

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-24

## Definition
A compute paradigm that performs operations inside or at the edge of memory arrays, eliminating the need to shuttle data to a separate processing unit. It is central to TCC and iNEST research because it co-locates storage and computation, enabling energy-efficient neuromorphic and in-network processing.
