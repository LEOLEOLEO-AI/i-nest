# Spatiotemporal_Synchronization_Metric

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A quantitative measure used to distinguish between coherent, incoherent, and chimera states based on local and global order parameters over time. Provides a principled way to classify dynamical regimes in coupled oscillator networks, which is essential for designing robust neuromorphic computing substrates.
