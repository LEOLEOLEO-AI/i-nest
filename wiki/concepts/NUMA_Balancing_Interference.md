## Definition
The automatic memory migration and thread placement performed by the OS NUMA balancing mechanism, which can disrupt the locality assumptions of spiking neural network simulations. This interference can severely degrade simulation performance, making NUMA-aware configuration critical for reproducible and efficient neuromorphic workloads.
