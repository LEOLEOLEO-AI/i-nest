# NoiseInjectedForwardPass

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A forward-only inference process where controlled noise is added to activations, and the resulting output variations are used to compute learning signals. Supports in-situ learning in neuromorphic chips without separate backward circuitry, reducing hardware complexity and latency.
