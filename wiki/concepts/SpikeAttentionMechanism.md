# SpikeAttentionMechanism

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
An attention mechanism adapted for spiking neural networks, where attention weights are computed using spike-based operations (e.g., spike timing or rate) rather than dense matrix multiplications. Enables transformers to run on neuromorphic hardware without dense floating-point operations, drastically reducing energy consumption for sequence tasks.
