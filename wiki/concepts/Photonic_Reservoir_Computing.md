# Photonic_Reservoir_Computing

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A neuromorphic computing paradigm that uses a fixed, randomly connected photonic network (the reservoir) to map input signals into high-dimensional nonlinear states, from which a simple readout layer is trained. Enables ultra-fast, low-energy analog computation in optical hardware, bypassing the need for precise synaptic weight programming, which is a key challenge for scalable neuromorphic systems.
