# Z3ToricCode

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A topological quantum error-correcting code defined on a torus with Z3 (three-level) qudits, generalizing the standard Z2 toric code to higher-dimensional local Hilbert spaces. Enables exploration of higher-order topological order and its phase transitions, which can inform the design of fault-tolerant quantum memories in TCC-based interconnects.
