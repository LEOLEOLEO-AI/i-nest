# SimplicialStateEmbedding

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
An embedding of the dynamical state of a simplicial complex into a neural state space, where each simplex's activity is mapped to a neuron or synaptic weight. Bridges higher-order network dynamics with neuromorphic hardware, allowing direct implementation of multi-body interactions in in-network neural substrates.
