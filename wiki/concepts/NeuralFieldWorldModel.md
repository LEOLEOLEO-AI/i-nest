# NeuralFieldWorldModel

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A world model that represents the environment's state and dynamics as a continuous neural field, parameterized by coordinates rather than discrete grid cells. Enables topology-agnostic state representation that can be mapped onto arbitrary network topologies for distributed inference in TCC/iNEST systems.
