# SDI_Interconnect

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-23

## Definition
A software-defined interconnect abstraction in which the routing policy, virtual-channel allocation, and topology mapping of an on-chip network are reconfigurable at runtime or compile time. SDI bridges TCC's topology-centric routing model with iNEST's need to dynamically remap spike traffic paths, enabling adaptive in-network computation policies.
