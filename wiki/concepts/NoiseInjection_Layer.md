# NoiseInjection_Layer

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A network component that injects controlled stochastic perturbations into neuron activations during forward propagation to enable gradient reconstruction. Serves as the key enabler for local learning rules in neuromorphic systems, supporting scalable in-network adaptation.
