# OneFabric_Memory

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-09-02

## Definition
A unified memory and network semantics architecture that eliminates the software boundary between memory access and network communication by treating remote memory operations as first-class local operations. This removes conventional data movement overheads, allowing topology-centric designs to orchestrate computation and data placement seamlessly for low-latency LLM workloads.
