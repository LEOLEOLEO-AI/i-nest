# 3D_Integrated_Chiplet_Stacking

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A packaging architecture where multiple chiplets are vertically stacked using through-silicon vias (TSVs) and interposers to achieve high-density interconnects beyond planar scaling. Enables TCC to exploit vertical communication paths for low-latency, high-bandwidth data movement between compute and memory, critical for topology-aware dataflow.
