# Asymmetric_Interaction_Matrix

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A network connectivity matrix where the influence of node i on node j is not necessarily equal to the influence of node j on node i, breaking the symmetry of pairwise couplings. Enables non-reciprocal signal propagation and richer dynamical behaviors in topology-centric computing, allowing directional data flow and computation beyond symmetric graph constraints.
