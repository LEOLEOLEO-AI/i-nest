# Memory_Caching

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
A technique of storing intermediate RNN hidden states or memory contents in a fast-access buffer to avoid recomputation and support dynamic memory growth. Enables efficient long-sequence inference and continual learning in resource-constrained in-network neuromorphic hardware.
