# EventDrivenStateEstimation

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A method for estimating the robot's state (e.g., joint angles, body orientation) using event-based sensors and spiking neurons, processing only when changes occur. Reduces computational and energy overhead in dynamic environments, critical for real-time neuromorphic control in resource-constrained edge devices.
