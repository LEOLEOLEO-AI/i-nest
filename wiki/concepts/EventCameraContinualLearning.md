# EventCameraContinualLearning

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A learning paradigm where a neuromorphic model incrementally adapts to new action classes from event camera streams without catastrophic forgetting of previously learned actions. Enables lifelong deployment of neuromorphic vision systems in dynamic environments where new behaviors must be learned on-the-fly from sparse, asynchronous event data.
