# NeuromorphicObserverArchitecture

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A hardware-software co-design architecture where the observer is implemented using spiking neurons and synaptic plasticity for online learning of disturbances. This architecture is essential for deploying adaptive control loops directly on neuromorphic chips, reducing latency and power consumption in edge computing.
