# TopologicalObservability

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The property that a system's global topological state can be inferred from a set of local measurements, subject to topological constraints. This is crucial for designing TCC architectures where network-level properties must be derived from node-level data without central coordination.
