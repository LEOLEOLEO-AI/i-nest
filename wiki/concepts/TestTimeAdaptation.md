# TestTimeAdaptation

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A paradigm where a pre-trained model is adapted at inference time using only the current test batch, without access to labeled target data, to handle distribution shifts. Bridges TCC and iNEST by enabling topology-aware, online adaptation of spiking networks, reducing the need for frequent recalibration in dynamic neural environments.
