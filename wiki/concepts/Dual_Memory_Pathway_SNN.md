# Dual_Memory_Pathway_SNN

**Domain**: iNEST

## Definition
An SNN architecture that introduces two complementary memory pathways to preserve both fast transient spike dynamics and long-term temporal context across hundreds of timesteps. It directly addresses the feedforward SNN's inability to retain history, enabling neuromorphic perception on energy-constrained vehicle-edge event streams.
