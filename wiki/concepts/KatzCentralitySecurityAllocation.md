# KatzCentralitySecurityAllocation

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-10

## Definition
A method for distributing security resources across network nodes based on Katz centrality, which measures node influence by counting weighted paths of all lengths. Provides a principled way to prioritize security investments in positive networks, where high-centrality nodes are critical for maintaining overall network integrity.
