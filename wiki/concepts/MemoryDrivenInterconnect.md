# MemoryDrivenInterconnect

**Domain**: Cross
**First mentioned**: auto-extracted

## Definition
An interconnect architecture where routing decisions and path configurations are primarily derived from memory-resident state and data structures, rather than from logic-heavy computation. This bridges TCC and iNEST by enabling memory-centric, adaptive data movement that supports both photonic routing and neuromorphic spike-based communication.
