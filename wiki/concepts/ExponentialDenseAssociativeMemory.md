# ExponentialDenseAssociativeMemory

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A neural network model where memory capacity scales exponentially with the number of neurons, using dense high-order interactions rather than sparse pairwise connections. Enables high-capacity memory storage and retrieval in neuromorphic hardware, critical for complex pattern recognition and cognitive tasks.
