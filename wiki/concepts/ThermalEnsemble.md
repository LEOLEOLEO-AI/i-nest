# ThermalEnsemble

**Domain**: iNEST

## Definition
A collection of network configurations sampled from a Boltzmann/Gibbs distribution at finite temperature, used to average learning signals. It provides a statistical-mechanics framework for robust learning in iNEST thermal and stochastic devices.
