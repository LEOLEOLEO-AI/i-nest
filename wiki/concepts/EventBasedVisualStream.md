**Domain**: iNEST

## Definition
A data representation where visual information is encoded as asynchronous spikes triggered by changes in the scene, rather than as dense frames. This is the core input format for neuromorphic sensors and aligns with iNEST's goal of energy-efficient, spike-driven processing in network nodes.
