# Passive_BCI_Neurofeedback

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A brain-computer interface paradigm that decodes neural states (e.g., sleep stage) from spontaneous signals without requiring the user to perform a task, and feeds this information back to modulate brain activity. Enables closed-loop sleep improvement systems that operate during unconscious states, a key application for in-network neuromorphic processing of continuous physiological streams.
