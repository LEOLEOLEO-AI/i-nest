# EventDrivenInferencePipeline

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
An inference execution model where processing stages are activated only when spike events arrive, rather than on a fixed clock cycle, enabling asynchronous and sparse computation. Reduces idle power consumption and accelerates inference for sparse spike streams, a key requirement for efficient neuromorphic computing in iNEST deployments.
