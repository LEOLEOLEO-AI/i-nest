# SDI_NoC_Fusion

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
An integration scheme where SDI (Serial Data Interconnect) is fused directly into the NPU's Network-on-Chip (NoC) rather than being an external add-on, enabling on-chip data movement between compute and interconnect. This fusion reduces off-chip latency and power overhead, critical for topology-centric computing where data routing patterns dominate performance.
