# Memristive_Crossbar_Array

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A dense 2D array of memristive devices at each crosspoint, used for both storage and computation, enabling analog in-memory operations and parallel matrix-vector multiplications. Serves as the foundational hardware for both TCC's topology mapping and iNEST's synaptic weight storage, enabling scalable and efficient neuromorphic computing.
