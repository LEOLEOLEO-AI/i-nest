# ReservoirTemporalMemory

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The property of a physical reservoir to retain and mix past input states with current inputs, providing a short-term memory that encodes temporal features of the signal. This memory is essential for reconstructing waveforms from sparse samples and for implementing time-dependent computations in neuromorphic hardware.
