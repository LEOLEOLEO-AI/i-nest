# TemporalLearning

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A learning paradigm where synaptic weights are adjusted based on the precise timing of spikes, enabling the network to encode and process temporal information. Essential for neuromorphic systems to handle time-varying data streams, a key requirement for in-network real-time signal processing.
