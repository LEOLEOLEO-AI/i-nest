# Basic_Reproduction_Number_Multiplex

**Domain**: Cross
**First mentioned**: auto-extracted

## Definition
The expected number of secondary infections caused by a single infected node in a fully susceptible multiplex network, generalized to account for inter-layer coupling and heterogeneous layer topologies. Serves as a key metric for predicting outbreak severity and for tuning network parameters in TCC/iNEST architectures that mimic biological or social contagion dynamics.
