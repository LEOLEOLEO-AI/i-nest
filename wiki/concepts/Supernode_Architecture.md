# Supernode_Architecture

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-09-01

## Definition
An architecture where numerous accelerators or chiplets are interconnected via scale-up technologies to act as one massive virtual compute node for large model training. It reduces communication bottlenecks and simplifies programming by presenting a unified memory and compute space, a central goal of TCC research.
