## Definition
A neural network architecture that operates on graphs whose edges and nodes evolve over time, using temporal message passing to learn representations of dynamic connectivity patterns. Enables TCC to analyze and predict changes in network topology over time, which is critical for designing adaptive neuromorphic hardware that mimics biological plasticity.
