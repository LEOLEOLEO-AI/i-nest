# MultiTaskSpikingRL

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A reinforcement learning framework that trains a spiking neural network to solve multiple tasks concurrently using shared synaptic weights and task-specific dendritic modulation. Demonstrates that bio-inspired spiking agents can achieve generalist behavior without task-switching overhead, critical for deploying energy-constrained neuromorphic systems in dynamic environments.
