# Event_Driven_Loopy_Inference

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
Execution of loopy belief propagation on cyclic factor graphs where message updates are triggered only by arriving spike events, yielding sparse, asynchronous convergence dynamics. It decouples inference cost from graph size and loop count, which is essential for scaling in-network neuromorphic inference on recurrent topologies.
