# MultiTimescalePlasticity

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A set of plasticity rules operating across multiple time scales, supporting strong recency-biased memory alongside longer-term stability. It allows online adaptable networks to retain important memories while continuously learning new patterns, a key requirement for lifelong neuromorphic computation.
