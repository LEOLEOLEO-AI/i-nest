# GradientFreeTraining

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A training paradigm that avoids explicit gradient computation, instead using stochastic perturbations and output feedback to update weights. Reduces communication and memory overhead in TCC/iNEST systems, enabling energy-efficient and scalable in-network learning.
