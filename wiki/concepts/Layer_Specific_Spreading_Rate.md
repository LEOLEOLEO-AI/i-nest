# Layer_Specific_Spreading_Rate

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The per-layer transmission probability that determines how fast an epidemic propagates within a single network layer, independent of other layers. Enables the design of heterogeneous multi-layer topologies where different layers can be tuned for distinct computational or memory functions in iNEST systems.
