# EventDrivenLearning

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A learning paradigm where synaptic updates are triggered only by spike events, rather than by periodic clock cycles, aligning computation with actual neural activity. Bridges TCC and iNEST by enabling sparse, asynchronous computation that can be mapped onto network switches and routers for in-network intelligence.
