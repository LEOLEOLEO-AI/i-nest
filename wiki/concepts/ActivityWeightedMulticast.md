# ActivityWeightedMulticast

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
A mapping strategy that weights SNN spike traffic by neuron firing activity to drive multicast routing decisions, so communication cost reflects actual dynamic spike fan-out rather than static connectivity. It aligns NoC resource allocation with real neuromorphic workload dynamics, a core concern for both TCC topology optimization and iNEST in-network spike delivery.
