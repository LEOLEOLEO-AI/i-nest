# Random_Matrix_Neural_Network

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A neural network whose weight matrices are drawn from random matrix ensembles, often with banded or non-Hermitian structure, to study dynamics and capacity. This provides a statistical physics framework for analyzing recurrent network stability, memory, and computational power in neuromorphic substrates.
