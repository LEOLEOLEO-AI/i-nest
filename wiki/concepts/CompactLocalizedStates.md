# CompactLocalizedStates

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
Exactly flat topological bands that host compact localized states, which are wavefunctions confined to a finite number of lattice sites due to local graph topology. These states enable robust, dispersionless transport and localization, which can be leveraged for fault-tolerant signal routing and memory in topological computing and neuromorphic architectures.
