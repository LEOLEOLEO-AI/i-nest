# LinearAttentionKernelView

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
The interpretation of linear transformers as kernel methods, where the softmax similarity is replaced by an explicit feature map so that attention becomes a linear smoothing or Nadaraya-Watson style estimator. It provides a mathematically tractable surrogate for attention that maps naturally onto in-network compute primitives with bounded, streamable state.
