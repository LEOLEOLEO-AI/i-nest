**Domain**: TCC

## Definition
The architectural imbalance where a 3D stacked memory provides TB/s bandwidth, but an improperly designed logic layer makes computation the limiting resource. This forces balanced co-design of storage and logic layers, a key consideration for TCC and iNEST neuro-inspired hardware scalability.
