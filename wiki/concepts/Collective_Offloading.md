# Collective_Offloading

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A mechanism that offloads collective communication operations (e.g., all-reduce, broadcast) from compute cores to dedicated network hardware, freeing SM resources from communication tasks. This is critical for TCC because it decouples computation from communication, enabling topology-centric designs to optimize data movement without stalling compute units.
