# FadingMemory_Property

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-20

## Definition
The requirement that a reservoir's response depends on recent inputs but asymptotically forgets distant ones, ensuring the transient state remains a causal, bounded function of the input history. It is the theoretical criterion for deciding whether a given TCC/iNEST substrate—memristive crossbar, photonic loop, or spiking network—qualifies as a usable reservoir and how long its memory horizon can be.
