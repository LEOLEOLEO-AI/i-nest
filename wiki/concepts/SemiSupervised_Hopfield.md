# SemiSupervised_Hopfield

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A Hopfield network variant that integrates labeled and unlabeled data during training to improve pattern storage and retrieval under partial supervision. Enables robust associative memory in TCC/iNEST systems where labeled data is scarce, supporting adaptive in-network learning with minimal supervision.
