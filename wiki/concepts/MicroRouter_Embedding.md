# MicroRouter_Embedding

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-06

## Definition
A low-radix (≤16) router integrated inside each compute node, replacing external switch ports, with area under 2 mm² and latency around 20 ns. Provides the physical building block for switchless topologies, making per-node routing scalable and energy-efficient for TCC wafer-scale systems.
