# RestrictedConnectivityTopology

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A network topology where each neuron connects only to a local subset of others, rather than fully connected, reducing synaptic overhead while preserving function. Directly maps to TCC's focus on topology-driven computing and iNEST's hardware constraints, enabling scalable on-chip memory with reduced wiring complexity.
