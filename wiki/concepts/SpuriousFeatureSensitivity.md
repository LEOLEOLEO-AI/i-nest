# SpuriousFeatureSensitivity

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A metric quantifying how much a spiking neural network's classification accuracy degrades when spurious (non-causal) features in the input data are altered or removed. Reveals whether SNNs rely on unintended shortcuts, which is critical for deploying trustworthy neuromorphic systems in real-world iNEST applications.
