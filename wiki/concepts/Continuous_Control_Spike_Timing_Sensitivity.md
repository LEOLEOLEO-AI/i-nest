# Continuous_Control_Spike_Timing_Sensitivity

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The property of continuous control tasks where the exact timing of output spikes critically affects the stability and accuracy of the control signal, unlike classification tasks where only spike rates matter. This shifts SNN design focus from rate-based coding to temporal coding for real-time control, impacting neuron models and learning rules in iNEST systems.
