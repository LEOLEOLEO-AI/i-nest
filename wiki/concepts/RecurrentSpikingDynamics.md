## Definition
The complex temporal dynamics arising from recurrent connections in spiking neural networks, which can be tuned by synaptic delays to support short-term memory tasks. Understanding these dynamics is key for designing iNEST architectures that can perform cognitive tasks like working memory while maintaining low power consumption and real-time processing.
