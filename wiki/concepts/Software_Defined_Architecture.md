# Software_Defined_Architecture

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-09-02

## Definition
A system architecture where hardware behavior and inter-chiplet communication patterns are dynamically configured via software, rather than fixed at fabrication time. This enables a flexible path for TCC systems to optimize topology and dataflow while using mature process nodes, shifting competitive advantage from raw process scaling to system-level adaptability.
