## Definition
A non-volatile memory device that acts as a synaptic element, whose conductance can be modulated to represent synaptic weight in a spiking neural network. Provides the physical substrate for scalable, energy-efficient neuromorphic computing, directly supporting iNEST's goal of embedding intelligence in network hardware.
