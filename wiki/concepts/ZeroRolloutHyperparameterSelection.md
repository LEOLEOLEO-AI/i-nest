# ZeroRolloutHyperparameterSelection

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
A hyperparameter selection strategy that uses free-probability kernel statistics to choose reservoir parameters without running costly temporal rollouts. It drastically reduces the simulation cost of configuring reservoir computers, making in-network neuromorphic implementations more practical for TCC/iNEST systems.
