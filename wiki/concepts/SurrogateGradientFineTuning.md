# SurrogateGradientFineTuning

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A training technique that uses differentiable approximations of spike functions to fine-tune spiking point cloud models, enabling gradient-based optimization despite non-differentiable spike events. Essential for adapting spiking models to new point cloud datasets, as it allows stable and efficient parameter updates in neuromorphic hardware without sacrificing spike-based efficiency.
