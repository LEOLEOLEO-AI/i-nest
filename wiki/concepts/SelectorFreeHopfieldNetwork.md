# SelectorFreeHopfieldNetwork

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A Hopfield network architecture implemented without separate selector devices, relying on the intrinsic nonlinearity of the memory cells to prevent sneak paths. Simplifies crossbar array fabrication and increases density, making it feasible to build large-scale associative memory systems.
