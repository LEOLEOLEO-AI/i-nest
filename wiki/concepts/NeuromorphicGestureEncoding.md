# NeuromorphicGestureEncoding

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A spike-based encoding scheme that converts raw gesture sensor data into event-driven spike trains preserving temporal and spatial features. Ensures efficient input representation for spiking transformers, directly impacting recognition robustness in neuromorphic hardware.
