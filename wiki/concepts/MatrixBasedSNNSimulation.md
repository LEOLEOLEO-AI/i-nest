# MatrixBasedSNNSimulation

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A simulation approach for spiking neural networks that represents neuron dynamics and synaptic events as dense matrix operations, enabling efficient parallel computation on hardware accelerators. This is critical for iNEST because it bridges neuromorphic algorithms with conventional high-performance computing, allowing scalable network emulation without specialized neuromorphic chips.
