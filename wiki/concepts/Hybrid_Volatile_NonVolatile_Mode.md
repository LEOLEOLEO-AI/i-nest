# Hybrid_Volatile_NonVolatile_Mode

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A memory operating mode where the same FeFET cell can switch between volatile storage (fast, energy-efficient, but requires refresh) and non-volatile storage (retains data without power) based on application needs. Provides flexibility in neuromorphic systems to trade off between speed and persistence, crucial for adaptive learning and inference workloads.
