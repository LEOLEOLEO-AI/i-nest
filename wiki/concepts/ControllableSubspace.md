## Definition
The set of network states that can be reached by applying external inputs to a subset of nodes, as constrained by the network's connectivity and topology. Defines the fundamental limits of what can be achieved via external control in TCC systems, guiding the placement of computational or memory elements to maximize functional flexibility.
