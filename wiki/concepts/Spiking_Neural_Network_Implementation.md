The hardware realization of SNNs, which use discrete spike events for communication and computation, mimicking biological neural dynamics on FPGA substrates. Provides a biologically-plausible computational framework for energy-efficient, event-driven processing, a core focus of iNEST's neuromorphic computing goals.
