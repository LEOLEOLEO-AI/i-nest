# SDI_NPU_NoC_Integration

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A unified architecture that integrates SDI (Software-Defined Infrastructure) control logic directly into the NPU's Network-on-Chip (NoC) fabric, enabling dynamic reconfiguration of data paths and compute resources. This allows TCC/iNEST systems to adaptively route neural workloads and topology-aware operations without host CPU intervention, reducing latency and enabling in-network neuromorphic processing.
