# In_Situ_STDP

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
Spike-Timing-Dependent Plasticity executed locally at the synapse using only pre- and post-synaptic spike timings available on-chip, without off-chip gradient computation. It removes the need for external training hardware and global error backpropagation, making fully embedded learning feasible in neuromorphic in-network architectures.
