# SensoryInMemoryComputing

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A computing paradigm where sensory data is directly processed and stored within the same neuromorphic hardware, eliminating the separation between sensing, memory, and computation. This concept is central to TCC/iNEST as it enables ultra-low-latency, energy-efficient edge processing of sensory streams, which is critical for real-time neuromorphic systems.
