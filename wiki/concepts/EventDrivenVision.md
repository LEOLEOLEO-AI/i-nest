# EventDrivenVision

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
A vision paradigm that processes asynchronous per-pixel brightness-change events from dynamic vision sensors instead of full image frames. It bridges event-sensor data with TCC/iNEST processing topologies by enabling sparse, low-power, real-time object classification.
