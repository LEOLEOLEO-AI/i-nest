# MemoryComputeIntegration

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
A system design paradigm that merges data storage and processing in the same physical device to overcome the von Neumann bottleneck. It is the application driver for photonic memristors in energy-efficient and high-throughput neuromorphic computing architectures.
