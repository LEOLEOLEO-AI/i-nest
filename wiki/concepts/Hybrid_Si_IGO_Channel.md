# Hybrid_Si_IGO_Channel

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
A bitcell device scheme that pairs a silicon front-end pull-down network with indium-gallium-oxide (IGO) BEOL pass-gates to combine the drive strength of crystalline Si with the low-temperature processability of amorphous oxide semiconductors. It provides a heterogeneous per-tier device substrate, which iNEST can exploit to assign distinct functional roles (storage, logic, synaptic weighting) to different vertical layers of one stack.
