# NeuromorphicAttentionScaling

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The principle of designing attention mechanisms that scale sub-quadratically with input size while remaining compatible with event-driven, sparse spike-based computation. This bridges transformer architectures with neuromorphic hardware constraints, enabling large-scale attention models in TCC/iNEST systems.
