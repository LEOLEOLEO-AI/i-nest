# Neuromorphic_Trigger

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A spiking neural network (SNN) subsystem that generates a sparse, event-driven trigger signal upon detecting a specific audio pattern, enabling downstream processing to be activated only when relevant events occur. This enables ultra-low-power, always-on audio event detection in edge devices, a core iNEST goal for in-network neuromorphic sensing.
