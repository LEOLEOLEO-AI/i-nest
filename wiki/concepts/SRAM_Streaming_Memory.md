**Domain**: Cross
**First mentioned**: auto-extracted

## Definition
An on-chip, SRAM-only memory organization with streaming buffers that hold tensors locally per slice, avoiding caches and external DRAM latency variability during execution. It shows how eliminating unpredictable memory hierarchies stabilizes data supply, a prerequisite for in-network and topology-centric designs that assume bounded, local communication.
