# Emerging_CMOS_Memristor

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A class of non-volatile memory devices based on emerging CMOS-compatible materials that exhibit variable resistance, enabling analog state retention and synaptic-like behavior. These devices provide the physical basis for scalable, energy-efficient neuromorphic reservoirs, which are essential for integrating TCC and iNEST paradigms into practical hardware.
