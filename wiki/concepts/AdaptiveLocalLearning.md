# AdaptiveLocalLearning

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A learning mechanism in spiking neural networks where synaptic weight updates are computed locally at each neuron using only local information, without global error backpropagation. Enables energy-efficient on-chip learning in neuromorphic hardware by avoiding costly global gradient communication, critical for scalable in-network intelligence.
