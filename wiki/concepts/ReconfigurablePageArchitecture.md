# ReconfigurablePageArchitecture

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-06

## Definition
A proposed architecture where one physical base substrate supports multiple interchangeable 'pages' (topology configurations), allowing dynamic switching between torus and non-torus interconnects per workload phase. This is TCC's key differentiator from Google's dual-chip approach, enabling adaptive topology without hardware duplication.
