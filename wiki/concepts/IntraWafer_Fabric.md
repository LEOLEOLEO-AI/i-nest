# IntraWafer_Fabric

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A uniform 2D mesh topology spanning all dies on a wafer via high-level metal routing across scribe lines, forming the on-wafer communication substrate. This fabric realizes a single, tightly coupled compute array at wafer scale, enabling topology-centric design where communication distances and routing paths are managed at the physical layout level.
