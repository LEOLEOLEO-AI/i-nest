# ComplexValuedSNN

**Domain**: Cross
**First mentioned**: auto-extracted

## Definition
A spiking neural network architecture that uses complex-valued weights and activations to jointly encode magnitude (spike rate) and phase (temporal alignment) information. Bridges TCC's topology-based signal routing with iNEST's spiking dynamics, allowing richer information flow and synchronization across network topologies.
