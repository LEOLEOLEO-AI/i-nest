# Rack_Scale_Memory_Fabric

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-11

## Definition
A distributed memory architecture in which on-wafer SRAM near each core cluster is aggregated across wafers into a single addressable, high-bandwidth store accessible to the whole rack-scale machine. For iNEST in-network computing, it defines where synaptic weight and neuron-state storage physically resides, determining whether in-network computation can avoid crossing the costly inter-wafer boundary.
