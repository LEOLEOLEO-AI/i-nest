# KV_Cache_Offload

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-25

## Definition
A technique that moves key-value cache data from GPU memory to network-attached storage or other nodes, treating it as a network-addressable resource rather than a purely local GPU state. Transforms KV cache from a hardware-bound constraint into a network-managed object, enabling dynamic load balancing and memory pooling across distributed inference systems.
