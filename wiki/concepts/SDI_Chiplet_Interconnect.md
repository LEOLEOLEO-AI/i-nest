# SDI_Chiplet_Interconnect

**Domain**: TCC
**First mentioned**: auto-extracted

## Definition
A chiplet-based interconnect architecture using SDI (Serial/Differential Interconnect) for high-bandwidth, low-latency communication between heterogeneous dies. Enables scalable, modular TCC systems where topology-aware routing can be implemented across chiplets without monolithic die constraints.
