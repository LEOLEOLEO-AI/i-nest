# Temporal_Sequence_Learning

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
The ability of a reservoir computing system to learn and predict patterns from time-series data, such as branch history sequences, without explicit recurrent training. This capability is fundamental for in-network neuromorphic processing, allowing the system to adapt to dynamic workloads and improve prediction accuracy in real-time.
