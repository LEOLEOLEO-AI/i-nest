# Immersive_Visual_Analytics

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
An analysis paradigm where network data is rendered in virtual or augmented reality so that users can navigate, manipulate, and reason about topology through embodied spatial interaction. It extends topology-centric computing beyond abstract graph representations by making interconnect structure directly perceivable, which can guide TCC visualization and iNEST debugging of in-network state.
