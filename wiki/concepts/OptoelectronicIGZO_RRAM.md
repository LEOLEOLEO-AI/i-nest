# OptoelectronicIGZO_RRAM

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-20

## Definition
A resistive random-access memory cell based on indium-gallium-zinc-oxide (IGZO) that can be both electrically and optically programmed, combining non-volatile memory with photonic sensitivity. Provides a dual-mode (electrical/optical) synaptic device that bridges photonic input and electronic processing, essential for hybrid optoelectronic neuromorphic systems.
