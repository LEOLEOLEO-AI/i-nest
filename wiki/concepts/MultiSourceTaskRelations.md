# MultiSourceTaskRelations

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A framework for modeling cognitive task relationships derived from multiple fMRI sources simultaneously, rather than a single task or dataset, using transfer learning to capture cross-task neural representations. Enables iNEST systems to build more robust neuromorphic topologies that generalize across diverse cognitive tasks, reducing the need for task-specific retraining.
