# 2_5D_Interposer

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A silicon interposer with through-silicon vias that routes fine-pitch signals between chiplets placed side-by-side on a shared package substrate. Enables dense, low-latency horizontal interconnects, allowing implementation of advanced network topologies for chiplet-based topology-centric computing.
