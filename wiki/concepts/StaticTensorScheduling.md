# StaticTensorScheduling

**Domain**: Cross
**First mentioned**: auto-extracted

## Definition
Compiler-level scheduling of tensor operations and memory transfers into a deterministic instruction stream, eliminating runtime contention and variability. Bridges TCC's topology-centric control with iNEST's in-network processing by making data movement and compute placement statically known.
