# Continual_Learning_Modularity

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A learning paradigm where a network is composed of discrete modules that can be selectively activated or updated to accommodate new tasks without catastrophic forgetting. Enables in-network neuromorphic processors to incrementally learn new tasks while preserving prior knowledge, a critical requirement for real-time adaptive edge computing.
