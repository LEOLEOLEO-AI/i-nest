# Compiler_Orchestrated_Dataflow

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-15

## Definition
A design approach where a static compiler schedules all tensor operations, memory accesses, and inter-node communication onto a spatial architecture, removing dynamic hardware arbitration. It enables predictable, low-overhead mapping of neural network graphs onto in-network and topology-centric substrates.
