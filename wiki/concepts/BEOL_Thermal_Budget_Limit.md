# BEOL_Thermal_Budget_Limit

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
The maximum temperature allowed during back-end-of-line processing so that underlying silicon devices and interconnects are not degraded, which restricts which materials and devices can be built in upper tiers. It sets a hard constraint on how many functional tiers and how fine a vertical interconnect pitch an iNEST/TCC 3D fabric can achieve, directly bounding achievable topology granularity.
