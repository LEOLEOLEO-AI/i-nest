# SRAM_Compute_Proximity

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-06

## Definition
The architectural principle of placing compute units physically adjacent to SRAM arrays to exploit low-latency, high-bandwidth on-chip memory for latency-critical inference stages. In TCC, this proximity reduces data movement overheads and supports fine-grained, topology-driven scheduling of neural network layers across distributed compute nodes.
