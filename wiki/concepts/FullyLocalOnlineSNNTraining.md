# FullyLocalOnlineSNNTraining

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A training paradigm for spiking neural networks where weight updates are computed using only locally available information at each synapse, without global error propagation or backpropagation through time. Enables energy-efficient on-chip learning in neuromorphic hardware by eliminating the need for global memory access and synchronization, a key requirement for scalable in-network neuromorphic systems.
