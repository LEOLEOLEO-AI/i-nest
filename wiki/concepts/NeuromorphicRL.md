# NeuromorphicRL

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A reinforcement learning framework where the policy network is implemented on neuromorphic hardware (e.g., spiking neural networks) rather than conventional deep neural networks. Enables energy-efficient, real-time adaptive locomotion control on resource-constrained edge devices, a core goal of iNEST.
