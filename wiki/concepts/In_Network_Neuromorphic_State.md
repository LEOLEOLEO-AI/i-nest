# In_Network_Neuromorphic_State

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A persistent, history-dependent state distributed across multiple nodes in a network, analogous to synaptic weights or neuronal excitability in biological systems. Offers a pathway to embed memory directly into the network fabric, enabling neuromorphic computing without separate memory units, a key objective for iNEST.
