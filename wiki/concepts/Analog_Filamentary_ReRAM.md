# Analog_Filamentary_ReRAM

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
A ReRAM device that exploits an analog conductive filament in a conductive-metal-oxide/HfOx stack to achieve continuously tunable conductance states rather than only binary switching. It provides the analog synaptic weight element needed for dense, low-power in-memory computing in TCC and iNEST neuromorphic fabrics.
