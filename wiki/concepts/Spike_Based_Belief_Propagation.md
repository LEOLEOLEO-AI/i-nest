# Spike_Based_Belief_Propagation

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
A message-passing scheme in which sum-product belief propagation updates are realized through spiking neuron dynamics, with each message expressed as a spike train rather than a continuous-valued probability vector. It provides the core algorithmic bridge that lets canonical probabilistic inference be compiled directly onto spiking neuromorphic hardware instead of emulated on von Neumann substrates.
