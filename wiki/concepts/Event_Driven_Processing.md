# Event_Driven_Processing

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A computation paradigm where operations are triggered only by incoming spike events, rather than by a global clock, enabling asynchronous and sparse activity. Reduces power consumption and latency in neuromorphic hardware, aligning with in-network processing requirements for real-time sensory streams.
