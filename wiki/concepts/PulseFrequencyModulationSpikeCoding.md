# PulseFrequencyModulationSpikeCoding

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A spike coding method where the instantaneous firing rate of a neuron is proportional to the analog input amplitude, combined with delta modulation for change detection. Provides a biologically plausible and hardware-efficient way to represent continuous signals for downstream spiking neural network processing in iNEST systems.
