# Biological_Neuron_Emulation

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-17

## Definition
The practice of instantiating each reconstructed biological neuron (or enumerated cell type) as a distinct processing unit in a spiking network, rather than abstracting it into a homogeneous layer node. It sets the granularity requirement for in-network neuromorphic substrates, where per-neuron state, fan-in and local plasticity must be supported without centralized aggregation.
