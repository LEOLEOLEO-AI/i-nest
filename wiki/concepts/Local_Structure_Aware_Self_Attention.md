# Local_Structure_Aware_Self_Attention

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-29

## Definition
A self-attention mechanism in Transformer-based spiking neural networks that restricts attention to local structural neighborhoods instead of computing global token interactions. This directly addresses the quadratic computational bottleneck of global self-attention, enabling more efficient and biologically plausible spike-based processing in neuromorphic systems.
