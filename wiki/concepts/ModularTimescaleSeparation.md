# ModularTimescaleSeparation

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The design principle where different modules in a reservoir operate at distinct temporal resolutions, allowing the network to capture both fast and slow features of input signals. This separation enables neuromorphic hardware to process multi-rate data streams efficiently, improving task performance in real-time applications without increasing network size.
