**Domain**: Cross

## Definition
A scalar or vector value assigned to an agent based on its past actions, used as a contextual input to the reinforcement learning policy. This signal acts as a low-bandwidth, localizable feedback mechanism that can be implemented in network switches or neuromorphic cores to guide distributed decision-making.
