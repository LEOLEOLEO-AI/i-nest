## Definition
A framework that dynamically migrates computational tasks across chiplets based on real-time communication topology and link congestion metrics to minimize data movement overhead. Enables adaptive placement of compute relative to network state, directly addressing the core TCC challenge of co-optimizing computation and communication in heterogeneous chiplet systems.
