# Finite_Width_Correction

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
Systematic 1/N (or 1/width) perturbative corrections that quantify how the critical behavior of an infinite-width network limit is deformed when the network has a finite number of units or channels. Real neuromorphic hardware and in-network computing fabrics are necessarily finite-width, so these corrections determine whether idealized criticality survives in physically realizable TCC/iNEST implementations.
