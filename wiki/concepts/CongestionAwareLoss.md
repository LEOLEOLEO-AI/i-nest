# CongestionAwareLoss

**Domain**: TCC

## Definition
A differentiable loss function that penalizes predicted routing congestion hotspots during floorplanning, guiding the optimizer toward routable layouts. Provides a direct, trainable signal for routability, bridging the gap between placement and routing in TCC design flows.
