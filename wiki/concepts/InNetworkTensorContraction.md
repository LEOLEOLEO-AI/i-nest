# InNetworkTensorContraction

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
Performing tensor network contractions (e.g., MPS bond updates) directly within network switches or routers, rather than at host processors, to accelerate reservoir state updates. Reduces data movement and latency in neuromorphic systems, enabling real-time chaotic prediction with low-power in-network computational resources.
