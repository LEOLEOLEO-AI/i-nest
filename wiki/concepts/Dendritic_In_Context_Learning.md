## Definition
A learning mechanism in a single-layer spiking neural network where dendritic compartments enable in-context learning, allowing the network to adapt its responses based on the current input sequence without weight updates. This concept is crucial for iNEST as it demonstrates how neuromorphic hardware can achieve rapid, context-dependent adaptation, a key requirement for real-time in-network processing.
