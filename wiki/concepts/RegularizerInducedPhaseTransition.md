# RegularizerInducedPhaseTransition

**Domain**: Cross
**First mentioned**: auto-extracted

## Definition
A phenomenon where the application of a regularizer during training causes a sudden, discontinuous shift in feature detection behavior within deep linear neural networks, analogous to a phase transition in physical systems. This provides a theoretical framework for understanding how regularization can be used to trigger discrete computational states in neural networks, which is relevant for designing adaptive and reconfigurable TCC/iNEST architectures.
