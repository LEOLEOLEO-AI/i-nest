# Banded_NonHermitian_Matrix

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A random matrix with non-zero entries confined to a diagonal band, where the matrix is non-Hermitian, meaning it does not equal its conjugate transpose. These matrices model sparse, directional connectivity in neural networks and topological systems, bridging random matrix theory with realistic network architectures.
