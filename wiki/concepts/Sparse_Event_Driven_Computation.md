# Sparse_Event_Driven_Computation

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
The computation paradigm in spiking neural networks where neurons process information only when they emit spikes, resulting in inherently sparse, event-triggered activity. This sparsity is key to energy-efficient neuromorphic computing and directly impacts TCC-oriented interconnect and data movement design.
