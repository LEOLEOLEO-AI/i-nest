# ShortTermMemoryReservoir

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A reservoir computing paradigm where the physical system's short-term memory (e.g., via persistent photocurrents) processes temporal information without external recurrent loops. Provides a hardware-friendly approach for temporal signal processing in neuromorphic systems, reducing complexity compared to recurrent neural networks.
