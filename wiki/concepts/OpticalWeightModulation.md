# OpticalWeightModulation

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The process of using light intensity, wavelength, or pulse timing to set or update synaptic weights in an iontronic device. Allows direct optical programming of network parameters, reducing the need for electrical control lines and enabling parallel, high-speed reconfiguration in TCC/iNEST systems.
