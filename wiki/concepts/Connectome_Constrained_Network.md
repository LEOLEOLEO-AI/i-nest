# Connectome_Constrained_Network

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-17

## Definition
A neural network whose connectivity graph is frozen to match a measured biological connectome, so that training or simulation can only modulate neuron and synapse parameters rather than topology. This bridges TCC's claim that topology is the primary computational substrate with iNEST hardware design, turning a static wiring diagram into a deployable, testable in-network computing fabric.
