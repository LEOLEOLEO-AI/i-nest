# HigherOrderTransitionKernel

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A transition probability kernel defined on the incidence matrix of a simplicial complex, governing how random walks move between simplices of different dimensions. Enables neuromorphic systems to implement non-Markovian, topology-driven state transitions, potentially enhancing computational capacity and memory in spiking networks.
