**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
A recurrent neural network with untrained, fixed weights that provides a rich dynamical state space for input projection. Eliminates the need for backpropagation through time, making it hardware-friendly for neuromorphic chips and in-network processing.
