# FerroelectricCrossbarArray

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A dense 2D array of ferroelectric memory devices (e.g., FeFETs or FTJs) used for analog synaptic weight storage and in-situ matrix-vector multiplication. This is a core hardware primitive for TCC/iNEST, providing non-volatile, low-power synaptic plasticity essential for spiking neural networks and in-memory sensory processing.
