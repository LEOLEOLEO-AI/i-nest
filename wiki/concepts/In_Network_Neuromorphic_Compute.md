# In_Network_Neuromorphic_Compute

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A paradigm where neuromorphic computing elements are embedded directly within the network data path (e.g., inside switches or routers), processing packets as they traverse the topology rather than at endpoint hosts. This is foundational for iNEST as it moves intelligence into the network fabric itself, enabling ultra-low-latency, energy-efficient processing for real-time, distributed neural workloads.
