# Memory_Technology_Coexistence

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-06

## Definition
The design strategy of integrating multiple memory technologies (e.g., SRAM and HBM) within a single accelerator, each serving distinct roles in the inference pipeline rather than competing for exclusivity. This enables TCC architectures to balance capacity and speed across heterogeneous compute clusters, improving overall system efficiency and scalability for large-scale models.
