# StateAugmentedLearning

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A supervised learning approach where each memristive synapse maintains an auxiliary state variable that captures device history and drift, used to augment the weight update rule. Enables more robust training on non-ideal memristive devices, addressing the key challenge of state-dependent conductance drift in in-memory computing.
