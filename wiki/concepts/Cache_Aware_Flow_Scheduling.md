# Cache_Aware_Flow_Scheduling

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-25

## Definition
A network scheduling policy that routes inference requests based on the current location and availability of KV cache fragments in the network topology. Minimizes data movement and access latency by aligning request routing with cache locality, a key optimization for TCC-based inference clusters.
