# FFN_Neuron_Sparsity

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The observation that in feedforward networks (FFNs), a large fraction (e.g., 90%) of neurons contribute minimally to the output for a given input, allowing them to be skipped without significant accuracy loss. Enables dynamic neuron skipping in in-network neuromorphic accelerators, reducing compute and energy per inference by up to 11x.
