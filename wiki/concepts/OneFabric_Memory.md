## Definition
A unified memory-and-network semantic architecture that removes the software boundary between memory access and network communication. This cross-layer abstraction is central to TCC/iNEST because it allows compute and interconnect resources to be orchestrated as a single fabric, reducing latency and data-copy overhead.
