## Definition
The assignment of specific memory technologies (like SRAM for fast local caching and HBM for high-capacity storage) to distinct functional roles in a heterogeneous computing system. This concept informs TCC/iNEST hardware design by clarifying how to balance speed, capacity, and power in memory subsystems, critical for real-time inference and learning.
