# EventDrivenSensoryEncoding

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-06

## Definition
The conversion of continuous sensory data (e.g., vision, depth) into sparse, asynchronous spike trains that represent changes or salient features in the environment. Reduces data bandwidth and computational load in network pipelines, critical for scalable in-network neuromorphic processing.
