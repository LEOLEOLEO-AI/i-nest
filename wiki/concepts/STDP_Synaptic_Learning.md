# STDP_Synaptic_Learning

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-02

## Definition
Spike-timing-dependent plasticity implemented in the Ga2O3 memristor, where synaptic strength changes depend on the order and timing of pre- and post-synaptic spikes. STDP provides a biologically inspired learning rule that enables unsupervised and energy-efficient neuromorphic computation in iNEST architectures.
