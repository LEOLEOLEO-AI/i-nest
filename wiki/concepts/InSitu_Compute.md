# InSitu_Compute

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A computing paradigm where data processing and indexing operations are performed at the physical location of data storage, avoiding data movement between memory and processing units. Reduces the von Neumann bottleneck, which is essential for both TCC's topology-aware data flow and iNEST's spike-based neural processing.
