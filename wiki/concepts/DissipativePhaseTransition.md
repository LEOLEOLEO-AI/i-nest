# DissipativePhaseTransition

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A non-equilibrium phase transition in an open quantum system where the steady state changes abruptly as a function of control parameters due to competing dissipation and driving. Provides a mechanism for robust state switching in neuromorphic or topological photonic circuits, enabling reconfigurable computing primitives.
