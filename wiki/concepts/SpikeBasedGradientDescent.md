# SpikeBasedGradientDescent

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A training method that computes gradients through spiking neuron dynamics, often using surrogate gradients to handle the non-differentiable spike events. This is the core learning paradigm for in-network neuromorphic computing, enabling on-chip adaptation and edge learning without external deep learning frameworks.
