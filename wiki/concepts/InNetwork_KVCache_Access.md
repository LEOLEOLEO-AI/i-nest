# InNetwork_KVCache_Access

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-25

## Definition
A network architecture where switches or smart NICs directly read, write, or aggregate KV cache entries, bypassing the host CPU and GPU memory hierarchy. Enables low-latency, high-bandwidth KV cache sharing across inference nodes, a core requirement for scaling LLM serving in TCC systems.
