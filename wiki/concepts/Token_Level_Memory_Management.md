# Token_Level_Memory_Management

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A granular approach to managing memory for transformer-based models where memory allocation and eviction are performed per token or per attention head. Allows efficient use of limited GPU memory, a key enabler for running ultra-large models on consumer hardware in iNEST contexts.
