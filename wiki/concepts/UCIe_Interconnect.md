# UCIe_Interconnect

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
An open industry standard for die-to-die interconnect that specifies physical layer, protocol, and software stack for chiplet-to-chiplet communication. Provides a standardized high-bandwidth, low-latency interface essential for designing reconfigurable and scale-out network topologies in TCC and neuromorphic systems.
