# Near_Memory_Computing

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-09-24

## Definition
An architecture that places compute units physically close to memory, such as DRAM or HBM, to shorten data movement paths and reduce off-chip traffic. It provides a topological placement strategy for TCC to mitigate the memory wall in AI accelerator and chiplet-based systems.
