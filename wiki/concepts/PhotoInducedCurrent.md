# PhotoInducedCurrent

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
Electrical current generated in a ferroelectric semiconductor upon light exposure, which can be modulated by the material's polarization state. Enables optical-to-electrical signal conversion with memory effects, providing a physical substrate for neuromorphic photonic reservoirs.
