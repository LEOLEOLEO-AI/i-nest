# TopologyAsComputeResource

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-09-07

## Definition
The concept that the structure and dynamic state of network topology can be directly programmed to perform computational tasks, turning pipes into processing elements. This is the key theoretical innovation of TCC, enabling network topology itself to contribute computation rather than only carry traffic.
