# CompactMicroLED_Array

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A dense, miniaturized array of light-emitting diodes used as a spatial light modulator to deliver patterned optical signals directly to the RRAM array for parallel programming. This provides a scalable, low-power optical interface for neuromorphic systems, avoiding bulky optics and enabling on-chip photonic integration.
