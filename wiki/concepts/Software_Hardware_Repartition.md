# Software_Hardware_Repartition

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-09-02

## Definition
A design method that redefines which inference tasks are performed in software versus specialized hardware elements, based on communication topology and data movement cost. This repartitioning is essential for TCC because it enables computation to be aligned with the actual network topology of chips and interconnects.
