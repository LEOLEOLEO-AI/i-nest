# EigenvalueDegeneracies

**Domain**: Cross
**First mentioned**: auto-extracted

## Definition
Parameter values at which two or more eigenvalues of a network operator coincide, often marking critical transitions in spectral behavior. Degeneracies can determine stability, memory capacity, and phase transitions in topological computing substrates and in-network neural dynamics.
