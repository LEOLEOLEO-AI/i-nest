# Spiking_Dynamic_Inference

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-01

## Definition
A dynamic computing framework in which spiking neural networks perform inference only when input is present, so energy use scales with input activity. This framework is central to realizing the iNEST goal of 'no input, no energy; energy varies with input' in neuromorphic systems.
