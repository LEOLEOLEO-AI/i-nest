# GeometricRoleEmbedding

**Domain**: TCC
**First mentioned**: auto-extracted

## Definition
A technique that embeds each node's structural role into a continuous vector space, where distances and directions correspond to relational similarities and hierarchical dependencies within the topology. This gives TCC a quantitative tool for clustering, comparing, and evolving network topologies, facilitating automated topology search and optimization for in-network computation tasks.
