# Event_Driven_Asynchronous_Circuit

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
A hardware circuit design paradigm in which computation is triggered by incoming spike events rather than a global clock signal. This approach reduces power consumption and latency in SNN implementations, making it a cornerstone for energy-efficient iNEST processing within network infrastructure.
