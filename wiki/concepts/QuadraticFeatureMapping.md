# QuadraticFeatureMapping

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A fixed nonlinear feature transformation that maps raw inputs into a quadratic feature space, over which a linear readout is trained. Offers a simple, hardware-friendly nonlinearity that can be implemented in neuromorphic circuits, enabling fast and energy-efficient learning in-network.
