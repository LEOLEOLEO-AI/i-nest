# ComputeRelocationOverhead

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The cost in time, energy, and bandwidth incurred when migrating computation between chiplets, including state serialization, transfer, and re-initialization. Must be modeled and minimized for relocation to be beneficial; otherwise, migration can degrade performance worse than static placement.
