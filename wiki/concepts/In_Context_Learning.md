# In_Context_Learning

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The ability of a model to perform a new task from instructions or examples provided in the input prompt, without updating model weights. This is a key neuromorphic-like capability that could be mapped to dynamic synaptic or reservoir states in iNEST, enabling rapid task adaptation without retraining.
