# In_Network_Neuromorphic_Learning

**Domain**: iNEST

## Definition
A method where learning and plasticity occur directly within the network's communication pathways, rather than in separate compute units, using spike-based rules. This reduces data movement and latency, making it essential for real-time, energy-efficient neuromorphic systems in iNEST.
