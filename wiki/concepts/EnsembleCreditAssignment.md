# EnsembleCreditAssignment

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The process of determining how much each individual spiking network in an ensemble contributes to the overall task performance, used to guide evolutionary selection. This is critical for scalable neuromorphic learning, as it provides a principled way to allocate evolutionary pressure across multiple SNNs without requiring global gradient signals.
