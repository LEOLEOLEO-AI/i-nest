# Sequence_First_Processing

**Domain**: iNEST

## Definition
A computational paradigm in hippocampal modeling where temporal order of inputs is prioritized over spatial context, treating memory as a chain of events with strict sequential dependencies. This informs the design of in-network neuromorphic circuits that can efficiently process time-series data, crucial for real-time sensory streams and event-driven computing in iNEST.
