## Definition
A formal framework that maps the relational position of a node within a topology to a geometric representation, treating logical roles as derived from structural context rather than intrinsic properties. This provides a unified language for TCC/iNEST to reason about how information processing roles emerge from network structure across disparate systems, enabling transferable design principles.
