## Definition
Groq's TSP is a statically scheduled accelerator architecture in which a single compiler-generated instruction stream drives all compute and memory units across the die in a deterministic, streaming dataflow fashion. It provides a concrete hardware precedent for TCC research where global topology and data movement, rather than instruction-level reactivity, determine execution semantics.
