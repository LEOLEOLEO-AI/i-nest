# EdgeFeatureEncoding

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The method of encoding link-level properties (e.g., signal strength, distance, delay) as edge features in a graph representation of a vehicular network. This is fundamental to TCC, as it enables topology-aware processing where edge attributes directly influence computational decisions, enhancing network efficiency.
