# FerroelectricSynapse

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A synaptic device using ferroelectric polarization states to store analog weights in spiking neural networks, enabling non-volatile and energy-efficient synaptic plasticity. Provides a hardware substrate for personalized on-chip learning in neuromorphic EEG processors, reducing reliance on external memory and improving energy efficiency.
