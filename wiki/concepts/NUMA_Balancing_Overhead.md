# NUMA_Balancing_Overhead

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The performance degradation caused by the operating system's automatic migration of memory pages and threads across NUMA nodes during spiking neural network simulations. This overhead can significantly distort simulation timing and throughput measurements, making it critical to control or disable NUMA balancing in iNEST benchmarking and deployment.
