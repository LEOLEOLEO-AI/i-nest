# Plasticity_vs_Computation_Separation

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The design principle that separates the plasticity (learning) mechanism from the computational substrate, allowing learning to act solely on access pathways. This separation simplifies hardware implementation in TCC, as only the routing fabric needs to be reconfigurable, not the compute nodes.
