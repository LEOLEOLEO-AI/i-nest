# ActionPrototypeClustering

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A continual learning strategy that maintains a set of prototype vectors in the feature space, each representing a learned action class, and updates them incrementally as new event data arrives. Enables fast, memory-efficient classification and adaptation on neuromorphic hardware without requiring retraining on all previous data.
