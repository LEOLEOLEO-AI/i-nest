# WirelessSplitComputing

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A distributed computing paradigm where a neural network is partitioned across a wireless edge device and a remote server, with intermediate activations transmitted over the air. Reduces on-device computational load while leveraging server resources, key for scalable TCC/iNEST deployments in bandwidth-constrained environments.
