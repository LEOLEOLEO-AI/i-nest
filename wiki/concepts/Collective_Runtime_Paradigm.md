**Domain**: TCC

## Definition
A paradigm shift in which collective communication is moved from static libraries to a dynamic runtime layer that owns, schedules, and adapts communication operations. This enables topology-centric execution where collective patterns can be continuously optimized against the physical network rather than fixed at library initialization.
