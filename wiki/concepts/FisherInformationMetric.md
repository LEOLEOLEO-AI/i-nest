## Definition
A Riemannian metric on the reservoir's state space that quantifies the sensitivity of output probabilities to small parameter changes, used here to define orthogonality between memory states. Provides a principled geometric framework for optimizing memory dynamics in both classical and quantum reservoir computers, applicable to TCC's topology-aware memory design.
