## Definition
An implementation of advection-type PDEs using spike propagation across a spiking neural network, where each spike represents a moving quantity along the flow direction. It demonstrates how hyperbolic PDEs can be naturally realized as event-driven processes, a key capability for real-time neuromorphic simulation in iNEST.
