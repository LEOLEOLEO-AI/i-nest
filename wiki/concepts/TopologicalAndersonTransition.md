# TopologicalAndersonTransition

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The transition between a topological insulator phase and a trivial insulator driven by disorder, where topological invariants survive despite localization. This transition is key for robust topological transport in disordered networks, which can be exploited for fault-tolerant data paths in TCC and stable synaptic weights in iNEST.
