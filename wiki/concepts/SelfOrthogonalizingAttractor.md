# SelfOrthogonalizingAttractor

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
An attractor neural network whose recurrent weight matrix is dynamically adjusted to orthogonalize its principal components, preventing overlapping attractor basins and improving pattern separation. This enables robust memory storage and retrieval in neuromorphic hardware, where weight precision and crosstalk are critical constraints.
