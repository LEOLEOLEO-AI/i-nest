# StochasticBinaryStateDynamics

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A network model where each node occupies a binary state (0 or 1) and transitions between states are governed by probabilistic rules rather than deterministic thresholds. Provides a computationally tractable abstraction for neuromorphic hardware that relies on stochastic switching devices, enabling energy-efficient probabilistic computation.
