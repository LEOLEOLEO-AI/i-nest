## Definition
A method to reconstruct the full coastal ocean state (wave height, velocity fields) from a limited number of distributed pressure or buoy sensors using reservoir computing dynamics. Reduces sensor deployment cost and data bandwidth, critical for in-network processing where only local measurements are available.
