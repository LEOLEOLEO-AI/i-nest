# Randomly_Coupled_Fields

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-09-19

## Definition
A disordered statistical-mechanics model in which each local order-parameter field carries both a quenched random bias and random inter-site couplings, so that ferromagnetic and glassy ordering tendencies compete on the same lattice. It supplies the canonical testbed for TCC when the topology of a computing substrate is itself a random coupling graph rather than a regular mesh.
