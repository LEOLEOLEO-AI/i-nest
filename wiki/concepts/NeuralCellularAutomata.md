## Definition
A computational model where a grid of cells, each with a neural network, updates states based on local neighbor interactions, forming a spatially distributed recurrent system. This is a foundational architecture for iNEST because it maps naturally to in-network neuromorphic substrates, allowing decentralized, parallel processing without global synchronization.
