# Inference_Stage_Decomposition

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-05

## Definition
The process of breaking down a large model inference workflow into discrete stages (e.g., prefill, decode, attention, FFN) that can be independently mapped to different hardware. Provides a modular framework for TCC to place compute stages near data paths, enabling fine-grained optimization and reduced data movement overhead.
