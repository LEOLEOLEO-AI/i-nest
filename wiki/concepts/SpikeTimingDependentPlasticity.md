# SpikeTimingDependentPlasticity

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
A biological learning rule where synaptic weight changes depend on the precise timing difference between pre- and post-synaptic spikes. Enables temporal coding and unsupervised learning in spiking neural networks, critical for real-time in-network processing.
