# CoDesigned_SNN_Online_Learning

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A spiking neural network architecture and learning rule co-designed with Intel Loihi 2's neuromorphic hardware constraints to enable online continual learning without catastrophic forgetting. Demonstrates how hardware-aware network design is essential for practical lifelong learning on neuromorphic chips, a core challenge for iNEST systems.
