## Definition
The default mode network (DMN) contains five of the six cortical types, ranging from eulaminate-III (unimodal) to agranular (limbic), excluding only granular cortex. This diversity imposes heterogeneous processing constraints on TCC topologies, requiring adaptive routing and resource allocation across different cortical laminae.
