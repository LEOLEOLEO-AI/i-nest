# StochasticDelayInference

**Domain**: TCC
**First mentioned**: auto-extracted

## Definition
A method for inferring the probabilistic delay distributions between nodes in a network from observed temporal event sequences, rather than assuming fixed delays. Allows TCC architectures to model real-world communication variability and adapt routing/computation to stochastic timing constraints.
