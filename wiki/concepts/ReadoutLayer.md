# ReadoutLayer

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A simple linear (or logistic) output layer that maps the high-dimensional reservoir state to the desired output, trained via linear regression or ridge regression. Keeps training computationally trivial while leveraging the complex dynamics of the photonic reservoir, bridging TCC's topology-driven processing with iNEST's learning capabilities.
