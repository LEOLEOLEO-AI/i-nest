# Event_Driven_Dataflow_Control

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
A control mechanism in neuromorphic systems where data flow is triggered by spike events rather than clock cycles, enabling asynchronous and sparse computation. Critical for iNEST to achieve energy-efficient, real-time processing in network environments where event sparsity is common.
