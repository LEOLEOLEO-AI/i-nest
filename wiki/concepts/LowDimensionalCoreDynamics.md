## Definition
The finding that high-dimensional neural network computations can be effectively reduced to a low-dimensional dynamical core of only 1-2 dimensions, which captures the essential computational state transitions. This challenges the assumption that high-dimensional state spaces are necessary for neural computation, suggesting that in-network neuromorphic systems can be designed with drastically reduced hardware complexity while preserving core functionality.
