# SerDes_Bandwidth_Convergence

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-06

## Definition
The observation that compute chips (e.g., Tesla DOJO D1) now match or exceed switch ASIC bandwidth (e.g., 12.8 Tb/s) via high-lane-count SerDes, making switchless integration feasible. Highlights the physical tipping point where compute-side I/O capacity rivals switching capacity, enabling TCC to bypass external switches without performance loss.
