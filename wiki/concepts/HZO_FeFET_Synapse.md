# HZO_FeFET_Synapse

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A ferroelectric field-effect transistor using an HZO gate dielectric that stores analog synaptic weights in a nonvolatile polarization state. It delivers low-power, nonvolatile synaptic plasticity within a 2D-material-compatible process, essential for dense crossbar neuromorphic arrays.
