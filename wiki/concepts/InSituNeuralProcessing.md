# InSituNeuralProcessing

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
The execution of neural network inference or learning directly on data packets or streams at intermediate network nodes, rather than at end hosts or centralized servers. This reduces latency and bandwidth consumption, making real-time intelligent network functions (e.g., anomaly detection, traffic classification) feasible.
