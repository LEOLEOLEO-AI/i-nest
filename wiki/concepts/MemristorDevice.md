# MemristorDevice

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A two-terminal resistive switching device whose conductance can be programmed and retained, serving as a non-volatile analog memory element in crossbar arrays. Memristors enable the physical realization of tunable synaptic weights in TCC and iNEST, bridging memory and computation for neuromorphic and topology-centric workloads.
