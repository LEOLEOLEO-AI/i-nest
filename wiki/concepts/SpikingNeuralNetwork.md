# SpikingNeuralNetwork

**Domain**: iNEST
**First mentioned**: auto-extracted

## Definition
A neural network model where neurons communicate via discrete spikes over time, mimicking biological neural dynamics and enabling temporal coding of information. Provides a biologically plausible and energy-efficient computational paradigm for neuromorphic hardware, essential for low-power interactive robotics.
