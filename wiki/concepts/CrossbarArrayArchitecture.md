# CrossbarArrayArchitecture

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A physical layout of memory cells at the intersections of perpendicular wordlines and bitlines, enabling parallel analog multiply-accumulate operations in a single step. Crossbar arrays are the core hardware substrate for TCC, allowing dense, reconfigurable connectivity that maps naturally to graph and network topologies.
