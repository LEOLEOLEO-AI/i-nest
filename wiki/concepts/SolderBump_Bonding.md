# SolderBump_Bonding

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-08-31

## Definition
A chip-to-wafer integration technique using solder microbumps to create high-density electrical and mechanical connections between dies and a wafer substrate. It enables the fine-pitch vertical connectivity required to assemble multiple dies into a single wafer-scale TCC logic plane.
