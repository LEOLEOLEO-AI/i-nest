# ActionWeightedPathEnsemble

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A statistical ensemble of paths in a network where each path is weighted by an exponential of its action, generalizing path integrals to discrete topological structures. Provides a formal framework to model information propagation and self-organization in neuromorphic topologies, linking path statistics to system dynamics.
