# NeuromorphicReplayBuffer

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
A hardware-aware memory structure that stores representative event sequences from past actions and replays them during training to mitigate catastrophic forgetting. Provides a practical solution for continual learning on resource-constrained neuromorphic platforms, where full dataset storage is infeasible.
