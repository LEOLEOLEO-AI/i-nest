# OnlineLearningRule

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
A learning algorithm that updates synaptic weights continuously as data streams in, without requiring offline batch processing or global error propagation. This is critical for real-time neuromorphic applications where data arrives sequentially and memory/storage for offline training is limited.
