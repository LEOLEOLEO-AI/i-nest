# EventDrivenAutoregression

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-04

## Definition
An inference paradigm where token generation is triggered by incoming spikes, with each output token produced only when sufficient spike evidence accumulates. Aligns autoregressive generation with event-driven hardware, enabling low-latency, energy-efficient text generation in TCC/iNEST systems.
