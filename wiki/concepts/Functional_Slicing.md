# Functional_Slicing

**Domain**: TCC
**First mentioned**: auto-extracted
**Last updated**: 2026-09-13

## Definition
Functional slicing partitions the chip into many identical, spatially arranged slices, each owning dedicated memory and datapath lanes that are statically mapped to tensor operations. This spatial decomposition makes on-chip topology a first-class scheduling constraint, directly informing how TCC models locality, routing, and slice-level concurrency.
