# Brain_Scale_Parameter_Baseline

**Domain**: Cross
**First mentioned**: auto-extracted

## Definition
A verified set of human brain parameters—86 billion neurons and 150 trillion synapses—used as a target specification for neuromorphic wafer-scale systems. It provides a concrete biological scale against which TCC interconnect topologies and iNEST memory capacities can be quantitatively validated.
