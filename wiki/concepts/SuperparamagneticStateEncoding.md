# SuperparamagneticStateEncoding

**Domain**: Cross
**First mentioned**: auto-extracted
**Last updated**: 2026-08-23

## Definition
The representation of input data as magnetization states of superparamagnetic particles, whose thermal switching encodes temporal features for reservoir processing. Provides a compact, physically embedded encoding method that can be directly coupled to network interconnects, enabling seamless integration of sensing and computation in TCC/iNEST systems.
