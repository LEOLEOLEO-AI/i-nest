# MemristiveVMM

**Domain**: iNEST
**First mentioned**: auto-extracted
**Last updated**: 2026-09-15

## Definition
Vector-matrix multiplication performed in situ by a memristive crossbar using Ohm's law for weight multiplication and Kirchhoff's current law for column summation. It is the core computational primitive that allows iNEST hardware to execute neural network matrix operations directly in memory without von Neumann data movement.
