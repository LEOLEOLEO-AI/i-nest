# 工程附录：SEI 最小实施协议

状态：`[设计/待测]`。该协议可用于搭建参考仿真、板级原型和后续器件系统；本次交付的运行代码是合成网络参考，不含特定开发板驱动或 RTL。不得将协议完备写成硬件已完成。

## 实施目标与不变量

首个验收问题：**固定节点、端口及读出后，SEI 是否能仅靠合法连接变化，在独立数据上改善规定任务，并满足完整资源预算？** 对应 V-EXP03、V-EXP04。

主试验冻结节点本构、输入编码、输入输出端口、读出函数及其参数；改变这些内容须另开消融条件。候选母图、边的允许方向和符号、电导范围、写入精度、最大扇入/扇出、总边数或总电导等由真实硬件决定。每次变化记录实际值，不能只记录请求值。

首个物理内核采用带固定非线性负载与电容的互易网络，加可编程电阻或模拟开关。负载单调性与泄漏下界须通过测量确认。该内核的证明覆盖所有合法非负电导配置的理想稳态；开关瞬态、电源限制、热效应和测量电路仍单独验收。

固定主读出不妨碍另设诊断读出，但两者的结果必须分栏。训练一个更强的软件分类器可以检验表征潜力，不能计入“纯连接产生的部署收益”。

## 组成与接口

| 模块 | 输入 | 输出与持久状态 | 实施边界 |
|---|---|---|---|
| 物理节点 | 注入电流、邻接耦合 | 电压/器件状态、时间戳 | 节点本构与端口冻结；隐藏状态需辨识 |
| 候选互连 | 写入/断开/交换请求 | 实际连接、写入确认、误差与计数 | 不存在的物理线不能由软件声明为候选 |
| 端点量测 | 边 ID、采样窗口 | 自由/扰动端点差、方差、收敛残差 | 断开边两端的探测也占线路与能量 |
| 反馈接口 | 目标或环境反馈、固定输出 | 误差注入或有界回报 | 反馈来源和延迟公开，不预载目标拓扑 |
| 局部更新器 | 端点差或操作 score、反馈 | 梯度估计、资格迹、候选更新 | 两阶段存储和通信资源入账 |
| 合法性仲裁 | 候选、节点负载、预算 | 准许操作、实际概率、拒绝原因 | 全局约束通常不能仅靠每条边独立判断 |
| 验收与恢复 | 独立评价、总成本、原配置 | 接受/恢复、状态初始化记录 | 改回连接不自动清除器件迟滞 |
| 记录与计量 | 总电源、任务、操作事件 | 可追溯试验轨迹、成本分项 | 主机、ADC/DAC、存储和失败尝试均计入 |

SEI 的状态至少包括：连接及实际电导、资格迹或双相统计、剩余写入/能量预算、当前任务阶段、候选及选择概率、测量不确定度、可恢复配置标识。反馈与候选生成均只能使用当时可得信息。

## 连续电导分支

对每个训练样本固定输入；等到端点变化率与方程残差都满足经标定的阈值，再采集自由响应。施加规定幅度的输出误差注入，重复收敛检查并采集扰动响应。按正文式（16）形成边梯度，结合成本项生成有限小更新。

微扰幅度不能仅追求小：减小幅度会降低截断偏差，也会放大差分测量中的相对噪声。用预实验确定可辨识窗口，并冻结正式试验范围。若窗口不存在，应停止使用双相梯度分支。[设计；V-TH13、V-PHY01]

对电导上下限可在本地裁剪；对总预算、节点共享预算或耦合约束，应实施真实的协调投影或另一明确可行算子。只有满足正文 C4 条件的投影才继承其下降结论。零电导处的候选导数是合法方向上的一侧预测，有限增边仍需重新验收。

## 离散拓扑与时序分支

二值开关采用合法边交换，或预算允许的增删边。每次操作必须核对端口可达性及规定的稳定证书；最小度数条件不保证图整体连通。资源耗尽时不继续探索。

对于完整时序任务，最小可验证参考策略可在可用操作上使用归一化概率，累积真实操作概率的对数梯度，在回合末乘以回报减基线。这直接对应 C6。若先局部提议、再由仲裁器选取，记录的是实际执行操作的条件概率，不能把提议概率当成执行概率。对任意衰减资格迹须单独报告偏差。[设计；V-TH15、V-EXP03]

连接变化可能跨越不同图层，也可能把当前状态带入新的吸引域；因此一回合内频繁重连与回合间重连要分开比较。时序网络的学习不自动沿用平衡双相定理。

以下是两条分支共用的事务协议；`evaluate` 在真实硬件上必须包括状态初始化、实际延迟与计量。

```text
freeze task, ports, nodes, readout, candidate fabric, budget, test split
calibrate device and measurement uncertainty
while training budget remains:
    observe causal local signals
    propose a legal update under the selected learning branch
    arbitrate and record the actual action probability if stochastic
    checkpoint connection and explicitly recoverable state
    execute update; verify actual conductance and operating limits
    evaluate on fresh acceptance data or a valid simultaneous bound
    account for sensing, selection, writes, settling and failed trials
    if feasibility and acceptance rule both pass:
        retain connection; update its consolidation record
    else:
        restore configuration; reinitialize or reidentify device state
freeze the learned system
evaluate once on held-out tasks, devices and resource measurements
```

候选、验收和最终测试的数据角色分开；受共同漂移影响的对照使用配对设计与随机试验次序。固化连接可提高保留时间，但环境变化后允许重新开放。停止更新是协议的一部分。

## 指标、比较与统计

| 指标 | 测法和来源 | 接受条件 | 任务 |
|---|---|---|---|
| 留出任务风险/回报 | 固定任务损失；未参与候选选择的数据 | 配对效应的有效区间超过预登记的最小收益；报告绝对表现 | V-EXP03 |
| 总能量 | 校准电源总表；同质量、同任务时域 | 在规定质量与延迟下达到应用预算；不只测核心器件 | V-PHY04 |
| 端到端延迟 | 从输入可用到合法输出的时间戳 | 包含采集、收敛、转换、读出及必要重配置；达到应用时限 | V-EXP04 |
| 适应成本 | 改变环境后累计样本、时间、能量与写入次数 | 恢复到冻结质量门槛；全过程成本有界且可重复 | V-EXP02、V-EXP03 |
| 写入寿命/保持 | 实际写入计数、回读漂移、失效试验 | 在规定部署期满足器件可靠性要求 | V-PHY01、V-EXP04 |
| 自组织贡献 | 反馈关闭/打乱、冻结图、等成本随机换边 | 真实反馈与合法演化的贡献可由干预分离 | V-EXP01 |
| 时空交互 | 完整因子条件，分别改变空间和时间机制 | 正文交互量及其区间可报告；同时比较强基线 | V-EXP01 |
| 流形或纤维稳定性 | 不同样本与噪声下的秩、谱间隙和投影重现 | 置信范围支持所用几何前提；秩变处停止原模型 | V-GEO01、V-GEO02 |

本表数值均为 `[待测]`。测量工具链、校准日期、误差分布及统计方案随试验卡记录。不能把同一器件的连续时间点当作独立器件重复；跨器件、批次和种子应采用对应层级的区间或模型。正式候选验收采用新数据或预先选择的有效序贯/同时置信方法；最终测试不反馈到算法选择。

基线包括：相同节点与读出的冻结初图、等成本随机重连、允许范围内的标准物理/混合训练，以及“只训读出”的单列条件。训练调用、候选评价、校准、存储、通信和主机优化均匹配或显式计入。条件允许时加入 R29/R40 可实现的强方法，而非只比较未优化随机网络。

## 工程规模与取舍

[推导/设计] 一个可编程连接不能被当成免费参数。直接为每条候选边配置传感、状态存储与写入驱动，会使相应资源至少随被实现的候选边数增长；复用可减面积但增加时延与仲裁。先限制稀疏候选母图，再测量稀疏性损失与布线收益，不能先假定全连接后忽略其代价。

互易、单调、无延迟内核便于证明与校准，但可达功能受限制。需要有向、迟滞、传播延迟或振荡功能时，可以另建器件分支，并保留共同的 SEI 观测、合法性与验收接口；此时重新验证动力学、稳定和学习法则。工程扩展由任务失败边界驱动。

最先值得争取的应用是固定接口下的时序识别、漂移补偿或资源受限自适应。通用推理和复杂规划作为远期能力，用未见任务和强基线另行判决，不以完成小网络拟合替代。
