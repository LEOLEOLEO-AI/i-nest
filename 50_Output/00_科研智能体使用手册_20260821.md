# 科研智能体使用手册

> 面向刘勤让教授与团队。本手册说明：科研智能体是什么、如何启用、能做什么、如何与自进化知识库联动。

## 一、系统构成（三件套）

| 组件 | 位置 | 作用 |
|---|---|---|
| **DSH 科研预设（research）** | `~/.dsh/.agent-presets/research/` | 科研智能体本体：人格（TCC/iNEST 专家）、工具集、纪律（数据真实性/检索语义/目录纪律） |
| **DSH 运行平台（web）** | http://127.0.0.1:3080 | 工作台界面：多会话、后台任务、子代理、工作流 |
| **手稿数学验证引擎** | `~/.agents/skills/manuscript-math-verify/` | 每篇论文的数学严谨性闸门（claim/证明义务/数值一致性/修订报告） |

## 二、启用方法

1. 打开 DSH Web（http://127.0.0.1:3080）。
2. 新会话中选择预设 **"科研模式"（research）**（预设列表会显示 "科研模式 - 复杂网络涌现智能综合科研智能体"）。
3. 会话工作目录保持 `D:\Obsidian\vault`（知识库）即可。
4. 在输入框直接下达任务，例如：
   - "验证 `40_iNEST/45_Simulation/sdi_sim/SDI_Paper_Draft.md` 的数学严谨性"
   - "写 P0-4 专利交底书：Route≡Transform 复杂计算方法"
   - "编写 C.elegans 连接组 SOC 雪崩仿真（exp1 重跑，真实数据版）"
   - "汇总本周 40_iNEST 文献消化情况"

## 三、能力矩阵

| 任务类型 | 智能体动作 | 配套工具 |
|---|---|---|
| 写论文 | 大纲→草稿→manuscript-math-verify→修订 | light-paper-drafting + 验证引擎 |
| 写专利 | 交底书模板→权利要求→说明书 | 52_Patents 模板 + light-ip-application |
| 仿真代码 | 真实数据→仿真→三证据台账 | 45_Simulation + VERSION_LOCK 协议 |
| 工程代码 | SDK/原型/FPGA 映射 | 54_Code + light-backend-coding |
| 项目指南 | 版本治理→正式版→建议书 | 55_Guides + light-competition |
| 文献检索 | 检索语义（AGENTS.md §6）→消化→入库 | pipeline_v3 + light-literature-search |

## 四、与自进化知识库的联动

科研智能体是知识库的**编排者**，知识库自进化底座已就绪：

```
科研智能体（编排+产出）
   │ 产出文档
   ▼
Obsidian vault（语义记忆：00_Inbox→50_Output）
   │
   ▼ 每日 08:00
self_evolve.py（Karpathy 自进化：wiki 编译/概念图谱/健康检查/任务推荐）
   │
   ▼ 每日 21:00
git 同步（单写者：github + gitee）
   │
   ▼ 每周日
周度重组/知识进化 + 健康检查
```

**联动规则**：
- 智能体产出 → 落盘 50_Output 对应子目录 → self_evolve 自动纳入 wiki 图谱
- 智能体发现的重复/中间版 → 移 80_Archive（不删除）
- 每周复盘时，智能体读 self_evolve_log.json + vault_health.md，生成周报

## 五、数据真实性纪律（科研铁律）

1. 所有指标标注来源：[实测]/[仿真]/[引用]/[推导]/[待测]
2. 仿真结果必须有"三证据"：run.log + seed + 代码版本
3. 无 run.log 支撑的结果 JSON 一律不进入论文证据链（见《00_数据真实性审计报告》）
4. 未达标如实报告，不美化（如 exp5 幂律未过即如实写）

## 六、团队并行使用

每个团队线（A 理论/B 互连/C 类脑/D 仿真/E 项目）开独立 DSH 会话（同用 research 预设），
共享 SSOT 与 50_Output，各自独立工作区子目录。任务台账见《00_团队任务分工方案》。

## 七、快速命令

```powershell
# 手稿数学验证（任意论文稿）
python "C:/Users/LEO/.agents/skills/manuscript-math-verify/scripts/verify_manuscript.py" <手稿> --report

# 知识库自进化手动触发
powershell -File "D:/Obsidian/scripts/research_evolution_refresh.ps1"

# 健康检查
powershell -File "D:/Obsidian/scripts/check_sync_health.ps1"
```
