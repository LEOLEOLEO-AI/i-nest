# DESIGN.md · 学术风（Academic）· 介观尺度计算新范式

## 1. 风格 DNA
学术可信、蓝白克制、证据驱动、公式优先。封面/结束页用深蓝仪式版式；内容页撑满优先（C 区累计高 ≥476px），禁用大留白凑版。卡片淡描边浅底；深蓝实色卡仅作语义凸显，全篇 ≤3 张且多卡页禁用。公式用 Math 组件，居中块级渲染。

|---|---|---|
| A 页眉顶条 | 0–80 | 藏蓝 #0E3F8C 实色；标题 32px bold 白字，左 padding 40；右侧小徽标高 28 可用 |
| B 内容区 | 80–660 | 白底 #FFFFFF 或 #F7F9FC；安全边距左右 40；内容撑满 1200×580 |

| 封面/结束 | 自定义深蓝全幅 | 省略 C 区严格母版，仍保留右下页码 |

## 4. 字体（家族 ≤2）
- 正文/标题：思源黑 `Noto Sans SC, "Source Han Sans SC", "Microsoft YaHei", sans-serif`
- 封面英文长 title / 引文：`"Noto Serif SC", "Source Han Serif SC", "Times New Roman", serif`
- 字号阶梯：封面主标 60–72 bold；章节大字 60–80；巨型锚点 72–120 bold；页面主标 32–40 bold；卡内标题 24–30 bold/600；正文 22–26 regular；表格 18–22；脚注/页码 14–16。行高 1.5–1.6。

## 5. 信息密度与可读性
- 内容页 C 区累计高 ≥476px、宽 1200px；卡片填充率 ≥85%，正文软换行禁溢出。
- 公式页：Math 块级居中，width 显式给定（400–760），color #1A2230；参数以浅蓝胶囊/小字排布两侧或下方。
- 文字对比度 ≥4.5:1；蓝底白字，白底深蓝/深灰。
- 正文页复用 ≥3 类组件、≥4 种修辞、≥3 个层次。

## 6. 配图
- L1 主视觉：统一为 **SVG 结构化概念图**（晶圆/晶矩→液态拓扑→智涌脑、尺度轴、材料家族、复合算子、临界窗口、五层闭环、七要素链、路线图）。不混入摄影/3D/插画。
- L2 支撑图：≥280×180，与正文并排。
- L3 母版徽标：≤64×64，全篇位置一致（页眉右或页脚左）。
- 流程图/架构图优先内联 SVG（稳定），不用 Diagram 远程兜底。

## 8. 最终硬闸门（摘要）
1. 内容页未撑满（C区<476px）返工；2. C区深色实底禁用；3. 红+黄>5%或金色返工；4. 正文<22px、卡标<24px 返工；5. 卡片缺 S1/S3/S4 或空白带明显返工；6. 深蓝实色卡超限返工；7. 渐变作卡背景返工；8. 组件/修辞/层次不足返工；9. 多卡页缺双重锚定返工；10. L1 风格混杂或 3D/卡通返工；11. 文字溢出/对比<4.5:1 返工；12. 页眉/页码/顶条全篇不一致返工；13. 公式图缺主图/洞察/关键数返工；14. 占位文未清零返工。
