# 团队任务分工方案（独立并行）

> 依据：50_Output/00_成果总清单、00_项目-论文-专利-技术四线映射表、00_论文总清单、00_专利布局总览。
> 设计原则：**每条线独立闭环、共享 SSOT 理论底座、互不阻塞、可并行验收**。
> 每条线配套一个 DSH 科研子智能体（research 预设下按线定向）与独立工作区。

## 总览：五线并行架构

```
                    ┌─ 理论底座（SSOT: CST/SDI/TCC 唯一真源）┐
  刘勤让教授（总设计师）──┤                                    ├── 验收与决策点
                    └─ DSH 科研智能体（编排+工具+验证）────┘
        ┌──────────┬──────────┬──────────┬──────────┬──────────┐
      A线:理论    B线:互连    C线:类脑    D线:工程    E线:项目
      CST/SDI    SDI-CC     iNEST      仿真平台    指南/申报
      论文       论文+专利    论文+专利   代码+验证    建议书
```

## A 线：CST 基础理论（理论组）
- **负责人建议**：1 名博后 + 1 名博士
- **论文**：A1（主论文，冲刺中）、A2-A10 按序推进、A11（英文统一理论）
- **专利**：P1-5（CST 自适应演化）、P1-6（FEP/STDP 资源分配）
- **依赖**：CST SSOT、190 网络相变数据（需真实仿真，禁止 LLM 拟合）
- **交付**：A1 投稿（2026 Q2-Q3）、A11 英文版
- **智能体**：research 预设 + manuscript-math-verify 每稿必跑

## B 线：SDI-CC 互连与网络中心计算（互连组）
- **负责人建议**：2 名博士（拓扑理论 + 系统实现）
- **论文**：B1（P-Theory 变分理论）、B2（P-Mapping 5+4 完备映射 ⭐）、B3（P-Paradigm）、B7（P-Fabric）
- **专利**：P0-1/2/3/4/5（交底书已完成 4 件，续写 P0-4）、P3-1/2/3（OneFabric 待审批）
- **依赖**：SDI SSOT、拓扑映射仿真验证
- **交付**：B2 v2 全文（2026 Q4）、P0 系列交底书转正式申请
- **智能体**：research 预设 + 拓扑仿真工具链

## C 线：iNEST 类脑计算（类脑组）
- **负责人建议**：1 名博士 + 1 名硕士
- **论文**：C1-C4（SDSoW+SNN+FEP 路线图）
- **专利**：英文批 6 件（Liquid Time-Constant / SyncBrain 等，2026-05-30 已备）
- **依赖**：SDI 四规则仿真（v22-v32 已保全）、Hemibrain/C.elegans 连接组数据
- **交付**：SDI 四规则论文（Neural Networks / PLOS CB，6 实验数据齐全但**需核验真实性**）
- **智能体**：research 预设 + SDI 仿真代码管理

## D 线：仿真与工程代码（仿真组）
- **负责人建议**：2 名硕士/工程师
- **任务**：SDI 仿真平台（v22-v32 代码库治理）、CST 仿真平台（40_iNEST/45_Simulation）、FPGA 原型（PyiNEST-Lite SDK、v24_fpga_mapping）、可视化演示
- **核心职责**：**数据真实性闸门**——所有结果必须有 run.log + seed + 代码版本三证据；LLM 生成数据一律隔离
- **交付**：可复现实验包（VERSION_LOCK 协议沿用）、仿真结果库
- **智能体**：research 预设 + manuscript-math-verify（结果数值一致性）

## E 线：项目指南与建议书（项目组）
- **负责人建议**：1 名博士 + 1 名科研助理
- **任务**：海河 8.0 指南后续版本、苏州 v4.0、NSFC 重大专项、基金委 2000 万、各专项 v1 系列
- **现状问题**：55_Guides 存在大量中间版本（海河 6 变体、NSFC 2 变体）——**先治理后推进**
- **交付**：每项指南唯一正式版 + 版本台账（80_Archive 存中间版）
- **智能体**：research 预设 + 文档工作流

## 共享机制

1. **SSOT 真源**：CST/SDI/TCC 定义只存 `10_Knowledge/SSOT/`，各线引用不复制。
2. **决策点（教授审批）**：投稿目标变更、专利提交、指南对外发布——必须经刘教授确认。
3. **确认点（机器自检）**：论文稿过 manuscript-math-verify + light-self-review；仿真结果过"三证据"闸门。
4. **周节奏**：周一各线智能体出周报（进展/阻塞/下周计划）→ 教授周会决策。
5. **任务台账**：`99_Meta/research_task_proposals.json` + 各线 00_推进面板（51_Papers 已有 00_论文优先级推进面板 模式）。
6. **版本纪律**：文件名 {序号}_{英文}，版本用 [Vx] 前缀 + 唯一正式版，中间版进 80_Archive。
