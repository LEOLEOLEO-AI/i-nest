```markdown
### 2.3 Temporal Complexity (Tc) Calculation

Tc is computed as:

Tc = (λ_eff · Φ · Ψ · Θ)^(1/4)

where each component is standardized to [0, 1]:

**λ_eff (avalanche branching ratio)**: For biological neural networks, 
λ_eff is extracted from published neural avalanche studies (Beggs & Plenz 2003, 
Randi et al. 2024). For ANN, λ_eff is estimated from layer-wise activation 
propagation statistics: λ_eff = median(|active_neurons_L+1| / |active_neurons_L|) 
across 1000 random inputs. [ALGORITHM 1]

**Φ (phase synchronization)**: For BNN, Φ is computed as the mean pairwise 
phase-locking value (PLV) across frequency bands [8-12 Hz theta, 30-100 Hz gamma]. 
Cross-modal calibration to ANN (using Centered Kernel Alignment, CKA) yields 
conversion factor of 1.8× (validated within ±0.04, Randi et al. 2024 + Raghu et al. 2021).

**Ψ (FC temporal variability)**: Ψ = std(FC_matrix over 100-step sliding window) / 
mean|FC_matrix|. For ANN, Ψ is computed over 100 forward passes with random dropout (p=0.1).

**Θ (timescale diversity)**: Θ = Shannon_entropy(intrinsic_timescales) / log₂(10), 
where intrinsic timescales are extracted from autocorrelation decay (BNN) or 
layer response time constants (ANN).

Table S1 lists the source papers for λ_eff, Φ, Ψ values for all 40 systems.
```

#### 修改 2：新增 ALGORITHM 1 - ANN λ_eff 计算伪代码

**位置**：Methods 附加材料或主文件

```
ALGORITHM 1: Compute λ_eff for ANN

Input: network model, 1000 random test inputs
Output: λ_eff ∈ [0, 1]

1. Initialize layer_activations = []
2. FOR each layer L in network:
     FOR each input x in test_set:
         forward_pass(x)
         count_active[L] = |{neurons with output > threshold}|
     layer_activations.append(count_active)
3. branching_ratios = []
4. FOR L = 0 to num_layers-2:
     br[L] = count_active[L+1] / (count_active[L] + ε)  // ε=0.01 防止除零
     branching_ratios.append(br[L])
5. λ_eff = median(branching_ratios)
6. λ_eff = min(1.0, λ_eff)  // 限制在 [0,1]
RETURN λ_eff
```

```markdown
### 2.4 Structure-Function Coupling (Γst)

Γst = NMI(M_s, M_T) · sign(Mantel_r)

where:
- M_s: structural community partition from Louvain(adjacency matrix)
- M_T: functional community partition from Louvain(FC matrix)
- NMI: normalized mutual information
- sign(Mantel_r): Pearson correlation between structural and functional distance 
  matrices, thresholded at |r| > 0.1 and p < 0.05. If not significant, Mantel_r 
  is set to 0, yielding Γst = 0.

[Reference data: n_bootstrap = 1000, α = 0.05]
```
