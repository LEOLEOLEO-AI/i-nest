## 第一层：真问题提取

### 观察到的事实（v44f 真实数据）

```
CST(α=2.56) = 0.376  →  Level=L0（低于L1阈值0.707）
Sc = 0.644  Tc = 0.333  Gst = 0.219

τ₀ = 0.988  H̄ = 1.278  ← 文献目标 H∈[0.55,0.80]，严重超标
τ₁ = 0.174             ← 文献目标 CS∈[0.10,0.35]，刚刚达标
τ₂ = 0.378  Δα = 0.318 ← 文献目标 Δα∈[0.3,0.8]，刚好达标
τ_top = 0.189 τ_av=2.0 ← SOC目标 τ_av∈[1.3,1.7]，严重偏离
n_av = 2               ← 雪崩数量极少

ρ₂/ρ₁² = 0.283 → 0.283  ← 没有变化！
```

### 真问题（不是表面问题）

**真问题不是"CST为什么低"，而是：**

> **为什么 SDI 四规则无法驱动 ρ₂/ρ₁² 从 0.283 向 1.0 运动？**

这是根本问题。三元渗流比静止不动，意味着网络的高阶拓扑结构（三角形密度）
没有被 SDI 规则真正改变。Sc 在演化，Tc 有了信号，但**拓扑洞的生灭没有发生**。

**第二个真问题：**

> **H̄ = 1.28 > 1.0，为什么仿真产生了超布朗运动（Hurst > 1）？**

H > 1 在物理上意味着超扩散/弹道运动，在神经网络中不应出现（文献上界0.80）。
这说明 τ₀ 的归一化虽然公式正确（tanh(2H)），但底层动力学产生了**非物理的时间相关**。

## 第二层：第一性原理挖掘

### 问题一的第一性：ρ₂/ρ₁² 为何静止？

**物理根源**：三角形密度 ρ₂ 需要"三个节点同时强连接"。
当前 SDI 规则的作用机制：

```
STDP → 修改 W[i,j]（单边权重）
稳态缩放 → 全局乘以 scale（保持相对结构不变）
CS对齐 → 加强同社区内连接
```

**根本问题**：这三个规则都是**成对操作（pairwise）**，作用在边 (i,j) 上。
三元渗流需要**三体相变**，即边 (i,j)、(j,k)、(i,k) 同时达到阈值。

> **第一性猜想 A**：SDI 四规则缺少三体协同机制。
> 纯粹的成对 Hebbian 规则无法驱动三元渗流相变，
> 就像二体碰撞无法产生 BEC（玻色-爱因斯坦凝聚）。
> 需要一个"三角形完成"算子：若 W[i,j]>θ 且 W[j,k]>θ，则增强 W[i,k]。

### 问题二的第一性：H̄ > 1 的物理根源

**机制分析**：
当前动力学方程：`h = h*0.95 + tanh(W@h)*0.05`

0.95的指数平滑 = 时间常数 τ = 1/0.05 = 20步的**强持续记忆**。
这不是网络的内在 Hurst，而是**人为引入的积分器**，导致 DFA 测到的是
"积分器+网络"的联合 Hurst，而不是纯网络动力学的时间相关性。

> **第一性猜想 B**：现有 LIF 模型的 α=0.95 平滑系数人为注入了 H>1 的伪相关。
> 真实 LIF 神经元的时间常数 τ_m ≈ 10-20ms，在离散步长 dt=1ms 时
> 对应 α=exp(-dt/τ_m)=0.95，这是正确的，但**DFA 测量应在原始膜电位上进行，
> 而非在 tanh 输出（0-1饱和）上进行**。饱和函数破坏了功率律标度。

## 第三层：理论猜想（可证伪）

### 猜想 C1：三角形完成是 L0→L1 的相变机制

**陈述**：在 SDI 四规则基础上增加第五条规则——
"三角形完成"（Transitivity Reinforcement，TR）：

```
若 W[i,j] > θ_tr 且 W[j,k] > θ_tr，则
W[i,k] += η_tr × (W[i,j] × W[j,k])^0.5
```

此规则的物理本质：**局部传递性假说**（Hebbian 的三体扩展）。
生物证据：突触三角图（synaptic triangles）在皮层中高度非随机（Song 2005 Nature）。

**可证伪预测**：加入 TR 规则后，ρ₂/ρ₁² 将从 0.28 单调增至 0.5 以上（L1 前沿）。

### 猜想 C2：DFA 应在亚阈值膜电位（而非 tanh 输出）上计算

**陈述**：定义 v_i(t) = W@h（突触电位，归一化前），在 v_i(t) 上做 DFA。
此信号保留了幂律标度特性，tanh 截断破坏了尾部分布。

**可证伪预测**：在 v_i(t) 上测量的 H̄ 将落在 [0.55, 0.80] 文献范围内（而非1.28）。

### 猜想 C3：τ_top 偏离 SOC 的根本原因是活动率振荡

**陈述**：当前活动率在 0.10-0.22 震荡（稳态驱动导致），
振荡本身产生了大量"虚假雪崩"——实际上是稳态调节的周期性过冲，
而非 SOC 临界态的幂律雪崩。

**可证伪预测**：将稳态驱动时间常数从 50步 延长至 500步（慢于雪崩时间尺度），
τ_av 将向 1.5 收敛（n_av 从 2 增至 >100）。

## 第四层：理论自证

### C1 的理论自证（数学）

三元渗流相变条件（Bianconi & Ziff 2017）：

```
相变发生当且仅当：dρ₂/dt > 0 且 ∂²ρ₂/∂ρ₁² > 0
```

在随机图中：E[三角形] = N³/6 × ρ₁³（独立边假设）

但真实网络中，三角形密度 ρ₂ ∝ ρ₁² 当且仅当**边独立**。
TR 规则打破独立性，引入正的三边相关：

```
E[W[i,k] | W[i,j]>θ, W[j,k]>θ] > E[W[i,k]]
```

这直接增加 ρ₂ 而不改变 ρ₁，使 ρ₂/ρ₁² > 1，跨越 L1 阈值。

**自证完毕**：TR规则在数学上必然驱动 ρ₂/ρ₁² 上升。

### C2 的理论自证

DFA 对非线性变换的敏感性（Kantelhardt 2002）：

```
若 x(t) 是 H=0.7 的分形过程，则 tanh(x(t)) 的 DFA 给出 H' > H，
因为 tanh 在饱和区压缩波动，在线性区放大小波动，
等效于对时间序列进行非均匀缩放——破坏自仿射性。
```

具体：当 h∈[0,1] 被 tanh(·) 拉平，DFA 的涨落函数 F(s) 在大尺度 s 下
被压缩，斜率估计偏高 → H_measured > H_true。

**自证完毕**：必须在 v_i = W@h 上（线性信号）做 DFA，而非在 tanh(v_i) 上。

## 结论

v44f 的真实数据揭示了两个根本性缺陷，均有第一性原理解释：

1. **ρ₂/ρ₁² 静止** → SDI 缺少三体协同（TR规则）→ v45 新增 Rule5
2. **H̄=1.28 超布朗** → DFA 在 tanh 输出上失真 → v45 改为在 v_i 上测量

这两个发现都是**理论预测在实验中的真实体现**，不是参数调优问题，
是仿真框架本身的根本性修正。

> 颠覆性创新的核心：不是让仿真数值好看，
> 而是找到让真实数据"解释不了"的现象，
> 然后追问它背后的物理机制。
