## 二、第一性原理重建

### 2.1 空间复杂度Sc的物理本质

> "一个静态网络结构，能够承载多少不同的信息状态？"

用**单纯形同调（Simplicial Homology）**框架，信息状态空间由四个正交维度决定：

| 维度 | 拓扑对象 | 物理含义 | 神经科学对应 |
|------|---------|---------|------------|
| 0维（β₀） | 连通分量→k-core | 信息全局可达性+层级深度 | 大规模整合（Tononi IIT）|
| 1维（路径） | 最短路径长度 | 信息快速传播效率 | 全局工作空间（Dehaene）|
| 2维（三角） | 社区/模块 | 功能专一化分化 | 模块化处理（Fodor）|
| ∞维（β₁） | 拓扑洞/环路 | 独立信息循环路径 | 工作记忆容量（Baddeley）|

### 2.2 时间复杂度Tc的物理本质

> "一个活跃网络的动力学，能够表达多少不同的时序模式？"

用**多重分形时序分析（Multifractal Time Analysis）**框架，时序模式由四个正交维度决定：

| 阶次 | 统计量 | 物理含义 | 神经科学对应 |
|------|--------|---------|------------|
| 0阶（均值） | 单节点Hurst均值H̄ | 单节点时间记忆深度 | STDP时间窗口 |
| 1阶（互相关） | 节点间MFD相关Φ_CS | 复杂性同步CS（West2024）| 跨脑区信息整合 |
| 2阶（范围） | 多尺度时间跨度Δβ | 支持的时间尺度广度 | δ到高γ七频段 |
| 临界（指数） | 雪崩幂律指数κ_norm | 时间涌现态（SOC临界）| 神经雪崩τ=3/2 |

### 2.3 Sc↔Tc的物理对应（对称美学）

```
空间维度                    时间维度
────────────────────────────────────────
κ₀（连通深度）  ↔  τ₀（记忆深度）    [单节点特征]
κ₁（路径效率）  ↔  τ₁（同步效率）    [节点对特征]  
κ₂（社区分化）  ↔  τ₂（尺度分化）    [群体特征]
κ_top（拓扑洞） ↔  τ_top（临界态）   [全局涌现特征]
────────────────────────────────────────
静态结构承载力      动态过程表达力
```

**深层物理等价**：拓扑洞（空间循环） ↔ 临界态（时间涌现）
= SOC（自组织临界）理论的核心等价关系（Bak 1987）

这个对称**不是人为设计的**——它来自物理学的底层结构。

## 三、CST V2.0 完整公式

$$\boxed{\text{CST}_{\text{V2}} = S_c^{\text{V2}} \times T_c^{\text{V2}} \times \exp(\alpha \cdot \Gamma_{st})}$$

### 3.1 空间复杂度 Sc_V2（4分量）

$$S_c^{\text{V2}} = \left(\kappa_0 \cdot \kappa_1 \cdot \kappa_2 \cdot \kappa_{\text{top}}\right)^{1/4}$$

| 符号 | 计算方式 | 物理含义 | 文献依据 |
|------|---------|---------|---------|
| κ₀ | tanh(mean(k-core)/max(k-core) × 3) | 0维连通层级深度 | Dorogovtsev 2006 |
| κ₁ | tanh(σ_WS/σ_ER / 10) | 1维小世界路径效率 | Watts-Strogatz 1998 |
| κ₂ | Q_Louvain ∈ [0,1] | 2维功能社区分化 | Fortunato 2007 |
| κ_top | log₁₀(β₁+1)/log₁₀(10⁶+1) | 拓扑洞（1维Betti数）| Reimann 2017 |

**MECE验证**：
- κ₀覆盖0维拓扑（连通性+层级），吸收了旧C和H（去冗余）
- κ₁覆盖1维拓扑（路径），对应旧R_sw
- κ₂覆盖2维拓扑（社区），对应旧M
- κ_top覆盖同调洞（环路），新增维度
- 四者正交：改变任一不必然影响其他 ✓

### 3.2 时间复杂度 Tc_V2（4分量）

$$T_c^{\text{V2}} = \left(\tau_0 \cdot \tau_1 \cdot \tau_2 \cdot \tau_{\text{top}}\right)^{1/4}$$

| 符号 | 计算方式 | 物理含义 | 文献依据 |
|------|---------|---------|---------|
| τ₀ | tanh(mean_i[H_DFA(i)] × 2) | 单节点长程记忆（Hurst均值）| Peng 1995 DFA |
| τ₁ | mean_ij[corr(H_i(t), H_j(t))] | 复杂性同步CS（MFD相关）| West 2024 |
| τ₂ | tanh(H_max - H_min) | 多尺度时间跨度Δβ | Buzsáki 2006 |
| τ_top | exp(-\|τ_av - 1.5\|/0.3) | SOC临界雪崩指数 | Beggs&Plenz 2003 |

**MECE验证**：
- τ₀（单节点记忆）：完全独立于τ₁（跨节点同步）✓
- τ₁（CS）：高阶统计量，独立于τ₀（一阶）✓
- τ₂（多尺度跨度）：合并旧Ψ+Θ（Fourier对偶，去冗余）✓
- τ_top（临界指数）：新增，与τ₀/τ₁/τ₂正交（标度律vs相关）✓

### 3.3 结构-功能耦合（不变）

$$\Gamma_{st} = \text{NMI}(M_s, M_T) \times \text{sign}(\text{Mantel}_r)$$

- Γst保持V1.x定义，已有大量实验验证
- 作为指数放大器进入CST，机制不变

## 七、v41实验的V2.0计算方案

### 7.1 Sc_V2在线计算（每步可计算，无需动力学）

```python
def compute_Sc_V2(W, N):
    A = (np.abs(W) > threshold).astype(int)
    np.fill_diagonal(A, 0)
    G = nx.from_numpy_array(A)
    G.remove_edges_from(nx.selfloop_edges(G))
    
    # κ₀：k-core
    core = nx.core_number(G)
    kappa0 = np.tanh(np.mean(list(core.values())) / max(core.values()) * 3)
    
    # κ₁：小世界
    C_v = nx.average_clustering(G)
    k_mean = 2 * G.number_of_edges() / N
    sigma = C_v / (k_mean/N) / (np.log(N)/np.log(k_mean+1e-9))
    kappa1 = np.tanh(sigma / 10)
    
    # κ₂：模块化
    comms = nx.community.louvain_communities(G, seed=42)
    kappa2 = max(0, nx.community.modularity(G, comms))
    
    # κ_top：Betti数β₁（用tr(A³)/6算三角形，避免精确E₃）
    E1 = G.number_of_edges()
    E2 = int(np.trace(A @ A @ A) / 6)
    E3_approx = int(nx.average_clustering(G) * E2 * 0.3)
    chi = N - E1 + E2 - E3_approx
    beta1 = max(1, 1 - chi)
    kappa_top = np.log10(beta1 + 1) / np.log10(1e6 + 1)
    
    Sc = (kappa0 * kappa1 * kappa2 * kappa_top) ** 0.25
    return Sc, {'kappa0':kappa0,'kappa1':kappa1,'kappa2':kappa2,'kappa_top':kappa_top,'beta1':beta1}
```

### 7.2 Tc_V2计算（需要时间序列，每500步滑动窗口）

```python
def compute_Tc_V2(H_record, avalanche_sizes):
    """
    H_record: shape (T, N)，每步每节点的激活值
    avalanche_sizes: 神经雪崩大小序列
    """
    # τ₀：DFA Hurst指数均值
    H_DFA = [dfa_hurst(H_record[:, i]) for i in range(N)]
    tau0 = np.tanh(np.mean(H_DFA) * 2)
    
    # τ₁：MFD复杂性同步（滑动窗口Hurst相关）
    W = 200  # 窗口大小
    H_ts = []  # 每个节点的Hurst时序
    for i in range(N):
        h_ts = [dfa_hurst(H_record[t:t+W, i]) for t in range(0, len(H_record)-W, W//4)]
        H_ts.append(h_ts)
    pairs = [(i,j) for i in range(N) for j in range(i+1, min(i+20, N))]
    tau1 = np.mean([np.corrcoef(H_ts[i], H_ts[j])[0,1] for i,j in pairs])
    
    # τ₂：多尺度Hurst范围Δβ（按社区分组）
    H_by_comm = [np.mean([H_DFA[n] for n in comm]) for comm in communities]
    tau2 = np.tanh(np.max(H_by_comm) - np.min(H_by_comm))
    
    # τ_top：神经雪崩幂律指数
    if len(avalanche_sizes) > 50:
        tau_av = fit_powerlaw(avalanche_sizes)
        tau_top = np.exp(-abs(tau_av - 1.5) / 0.3)
    else:
        tau_top = 0.5  # 默认中等值
    
    Tc = (tau0 * max(0, tau1) * tau2 * tau_top) ** 0.25
    return Tc, {'tau0':tau0,'tau1':tau1,'tau2':tau2,'tau_top':tau_top}
```
