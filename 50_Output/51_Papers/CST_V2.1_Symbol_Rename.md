# CST V2.1 符号重命名方案

> 目的：让符号本身就能传达物理含义，不再需要对照表才能看懂仿真结果
> 日期：2026-06-08

---

## 一、Sc 分量重命名（空间拓扑）

| 旧符号 | 新符号 | 全称 | 物理含义一句话 | 取值范围 |
|--------|--------|------|--------------|---------|
| κ₀ | **κ_core** | D-Core 指数 | 网络有没有紧密互联的"核心俱乐部" | 0→1 |
| κ₁ | **κ_sw** | Small-World 指数 | 邻居抱团 + 世界很小，两者兼得的程度 | 0→1 |
| κ₂ | **κ_mod** | Modularity 模块化指数 | 网络有没有功能分区（视觉区/运动区/语言区）| 0→1 |
| κ_top | **κ_loop** | 拓扑环路指数 | 网络里反馈回路的丰富程度 | 0→1 |

### 符号助记口诀
```
Sc = (κ_core · κ_sw · κ_mod · κ_loop)^(1/4)
       核心性    小世界   模块化    环路数
```

## 二、Tc 分量重命名（时间动力学）

| 旧符号 | 新符号 | 全称 | 物理含义一句话 | 取值范围 |
|--------|--------|------|--------------|---------|
| τ₀ | **τ_mem** | 记忆性指数（Memory/Hurst） | 单个神经元的活动有没有"长记忆"（今天活跃→明天也活跃）| 0→1 |
| τ₁ | **τ_sync** | 复杂度同步指数（CS Sync） | 不同神经元的复杂度变化是否协同起伏 | 0→1 |
| τ₂ | **τ_frac** | 分形丰富度指数（Fractal/MFDFA） | 信号是"单调简单"还是"多尺度复杂"| 0→1 |
| τ_top | **τ_crit** | 临界态指数（Criticality/SOC） | 是否处于雪崩临界点（既不太沉默也不癫痫）| 0→1 |

### 符号助记口诀
```
Tc = (τ_mem · τ_sync · τ_frac · τ_crit)^(1/4)
       长记忆   协同性    分形性    临界态
```

## 三、完整公式重写（带物理含义）

```
CST = Sc × Tc × exp(α × Γst)

Sc = (κ_core · κ_sw · κ_mod · κ_loop)^(1/4)
     "网络形状好不好"

Tc = (τ_mem · τ_sync · τ_frac · τ_crit)^(1/4)
     "信号复杂不复杂"

Γst = "形状和信号是否协同"（结构-功能耦合）
α   = 器件物理常数（线虫α=2.56，皮层α=3.91）
```

## 四、直觉理解：仿真结果怎么读

### 看 Sc 时问自己：

**κ_core（核心性）低** → 网络没有枢纽节点，信息无法汇聚
→ 症状：所有神经元地位平等，没有"指挥中心"
→ 类比：一个没有领导的团队

**κ_sw（小世界）低** ← **当前最大问题（v48-v49: 0.02-0.09）**
→ 网络变成了"随机电话网"，不再是"六度分隔小世界"
→ 症状：STDP把少数路径强化成高速公路，其余路径荒废
→ 类比：城市道路从四通八达变成了几条单行道

**κ_mod（模块化）低** → 没有功能分区，所有神经元混在一起干同一件事
→ 症状：看不出哪些神经元负责感觉、哪些负责运动
→ 类比：没有部门设置的公司

**κ_loop（环路）高** ← **当前 v48-v49: 0.93-0.96（偏高）**
→ 反馈回路太丰富，信号在网络里循环太多次
→ 症状：STDP过度强化了循环连接
→ 类比：一个到处是回声的山谷

---

### 看 Tc 时问自己：

**τ_mem（记忆性）高→H>0.8** ← **当前 v48-v49: H=1.10（过高）**
→ 神经元活动像随机游走，"太有惯性"
→ 根本原因：指数平滑的 r_i(t) 本质上是随机游走
→ 类比：一个总是跟着昨天状态走、完全没有自主判断的人
→ 正常值：H∈[0.55,0.75]，像一个有经验但偶尔随机的人

**τ_sync（协同性）高→FC>0.5** ← **当前 v49 系列: 0.43-0.96（过高）**
→ 所有神经元步调完全一致，像癫痫
→ 根本原因：SDI的STDP在N=279小网络里把所有节点拉进同一个节拍
→ 正常值：FC∈[0.05,0.20]（线虫），像一支爵士乐队——各自即兴但保持大方向协同
→ 类比：一个人人都在说同一句话的会议（≠智慧），vs 每人各说各的但能听出主题（=智慧）

**τ_frac（分形性）高→Δα>1.5** ← **当前偏高**
→ 信号的大波动和小波动完全不同性质，太"多变"
→ 根本原因：活动率大幅振荡（正弦+burst驱动造成）
→ 正常值：Δα∈[0.3,0.8]

**τ_crit（临界态）低→n_av太少** ← **当前 n_av=10-33（太少）**
→ 没有足够的雪崩统计，无法测幂律
→ 注意：N=279规模天然不够，这个指标对线虫不强求
→ 正常值：只在N>1000时才有意义

这两个问题都有同一个根因：**STDP 在演化中把网络"均质化"了**（强干线+全局同步）。

## 六、修复方向（对应符号含义）

| 要修的符号 | 含义 | 修复方法 |
|-----------|------|---------|
| κ_sw 太低 | 小世界被破坏 | 削弱STDP（ETA=0.0001），保护初始WS结构 |
| τ_sync 太高 | 全局功能同步 | 去掉全局正弦驱动；更稀疏初始连接（k=4） |
| τ_mem 太高 | 记忆性过强 | 换更快速的神经元信号（非指数平滑） |
| κ_core 偏低 | 核心性不足 | 上述STDP削弱后自然改善 |

## 七、论文中的建议写法

**中文（报告/PPT）**：
```
Sc = (核心性 · 小世界性 · 模块化 · 环路丰富度)^(1/4)
Tc = (长记忆性 · 协同性 · 分形性 · 临界态性)^(1/4)
```

**英文（论文）**：
```
Sc = (κ_core · κ_sw · κ_mod · κ_loop)^(1/4)
Tc = (τ_mem · τ_sync · τ_frac · τ_crit)^(1/4)
```

**对外科普（Demo/汇报）**：
```
"大脑的空间智能" = 核心性 × 小世界 × 分区 × 回路
"大脑的时间智能" = 记忆 × 协同 × 分形 × 临界
```
