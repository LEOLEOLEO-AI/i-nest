## 一、核心发现摘要

**SDI 四规则 + TR（Triangle Reinforcement）规则能将 N=279 的 WS 小世界网络驱动通过三角渗流相变阈值，使 ρ₂/ρ₁² 从初始的 0.26–1.04 上升至 3–7，远超临界值 1.0。**

这是 CST 理论 L0→L2 拓扑跃迁假说的首次仿真验证。

---

## 二、背景：三角渗流假说

### 定义

设 ρ₁ = E / N² 为边密度，ρ₂ = T / W 为三角形密度（T=三角形数，W=楔形数），则：

```
ρ₂/ρ₁² = (T/W) / (E/N²)²
```

该比值衡量网络中"三角闭合"超出随机期望的程度：
- ρ₂/ρ₁² ≈ 1：随机图（三角形仅由随机连接产生）
- ρ₂/ρ₁² > 1：超临界（三角形密度超出随机期望）
- ρ₂/ρ₁² > L1=0.707... 对应 CST 拓扑 L1 阈值

### 物理意义

三角渗流比 ρ₂/ρ₁² 是高阶拓扑连通性的核心度量：
- 对应贝蒂数 β₁（一阶拓扑环）的涌现
- 反映网络从"树状传播"（β₁=0）到"环路传播"（β₁>0）的相变
- 在神经科学中对应：局部模块内的三向突触回路（feedforward loop, FFL）
- 文献支撑：Milo et al. Science 2002（网络模体）；Bhatt et al. Neuron 2009（突触三角闭合）

### C.elegans 静态基准

来自真实连接组数据（Varshney 2011，Worm Atlas）：
- N=279, E₁=2287（化学突触）
- ρ₁ = 0.059, ρ₂ = 0.00113
- **ρ₂/ρ₁² = 0.33**（低于随机期望，处于 L0 前临界状态）

### 3.1 无 TR 规则的基准（v44f）

实验配置：SDI 四规则，无 TR，HOMEO_INT=50 步，N=279

```

演化后（step=15000）: ρ₂/ρ₁² ≈ 0.28

```

**结论：SDI 四规则（两两规则）无法驱动三阶渗流。**
物理解释：STDP / 稳态 / 修剪均作用于边对（i,j），不产生三体耦合。

**结论：TR 规则首次驱动渗流上升，验证了三角闭合机制。**

## 四、机制分析

### 4.1 TR 规则的数学形式

当 W_{ij} > θ_TR 且 W_{jk} > θ_TR 时：

```
ΔW_{ik} = η_TR × √(W_{ij} × W_{jk})
```

这是 **Hebbian 三体耦合**：两条强边共享中间节点 j，则直接边 i→k 被加强。

几何意义：将"路径 i→j→k"闭合为"三角形 i→j→k→i"。

### 4.2 为何四规则无法驱动渗流

STDP、稳态、修剪均为两体规则 f(W_{ij})，不含三节点项。
三角形密度 T 由三元组 (i,j,k) 决定，需要三体耦合才能系统性增加。
即使在密集 STDP 演化中，三角形增量 ≈ O(ρ₁³)（随机期望），无超临界增长。

### 4.3 相变速度分析

v48 中，渗流从 1.04 跳升至 7.02 仅需约 2000 步（~7s）。
这符合渗流相变的二阶相变特征：临界点附近存在"渗流雪崩"，
一旦满足 W_{ij}×W_{jk} > θ²_TR，大量三角形同时闭合。

## 五、与 CST 理论的对应

### 5.1 κ_top 分量

CST V2.1 中 κ_top = tanh(β₁_d / 2717)，其中 β₁_d = E_d - N + SCC_count。

三角形密度 ρ₂/ρ₁² 是 β₁（一阶贝蒂数）的宏观表现：
- ρ₂/ρ₁² → 1 对应 β₁ 开始涌现
- ρ₂/ρ₁² >> 1 对应大量一阶拓扑环形成，β₁ 快速增长

v48 中 κ_top = 0.9385（接近1），与 ρ₂/ρ₁² = 4.24 一致。

### 5.2 L1 阈值对应关系

六阈值体系中 L1 = 0.707 = √2/2 对应果蝇级别（~10M 连接）。
三角渗流越过临界（ρ₂/ρ₁² > 1）是达到 L1 的**拓扑必要条件**。

实验验证路径：
```
SDI 4规则（无TR）: ρ₂/ρ₁²=0.28 → L0 ❌
SDI 4规则 + TR:    ρ₂/ρ₁²=4.24 → 超临界 ✅ → CST 向 L1 推进
```

### 5.3 对硬件设计的含义

IP5（Triangle Completion Accelerator）的工程必要性：
- TR 规则不能由现有 IP1-IP4 实现（都是两体运算）
- 需要专用三角形检测 + 权重修正电路
- 关键参数：η_TR=0.02, θ_TR=0.18，每 400 步执行一次
- 硬件面积估算：O(N×k²) 比较操作，k=平均度≈17（v48 网络）
