## 三、从 V1.x 到 V2.0：结构性重建

### 3.1 为什么要重建？——V1.x 的四个根本问题

**问题一：Sc 中 X₁（全局连通 C）与 X₂（层级深度 H）存在冗余**

- X₁ 是最大连通分量（LCC）占比，等价于 k-core 中 k=0 的覆盖
- X₂ 是 k-core 归一化深度，包含 k=0 到 k_max 的层级结构
- 关系：C = LCC ⊆ k-core(k=0)，X₁ 是 X₂ 的特例
- **后果**：几何均值中 X₁ × X₂ 双倍计算了同一物理维度，导致网络层级深度权重虚高

**问题二：Tc 中 Ψ（功能连接时变性）与 Θ（时间尺度多样性）是 Fourier 对偶**

- Ψ 在时域测量 FC 方差（时域多尺度）
- Θ 在频域测量时间尺度香农熵（频域多尺度）
- 数学关系：时域方差 ↔ 频域熵，Parseval 定理约束下二者线性相关
- **后果**：几何均值中 Ψ × Θ 实际只贡献了一个自由度，压制了其他分量的相对权重

**问题三：Φ 是 CM 度量，不是 CS 度量——理论与实验不一致**

- V1.x 中 Φ 定义为跨区域相位同步（一阶激活互相关）
- West (2024) 的复杂性同步（CS）定义为 MFD Hurst 指数的时序互相关，是二阶统计量
- 团队院士 PPT 明确使用 CS（corr[D_i(t), D_j(t)]），不是相位同步
- **后果**：Φ_V1 测量的是复杂度同步（CM），不是 CS；V33 实验中 Φ=0.576 是 CM 度量，不能填入新框架

**问题四：Sc 5分量 vs Tc 4分量——不对称，无法建立物理对应关系**

- 理论上 Sc（空间）↔ Tc（时间）应形成完全对称的物理对应
- 不对称的分量数量意味着必然存在冗余或遗漏
- **后果**：无法从第一性原理推导公式结构，理论说服力弱

## 四、从 V2.0 到 V2.1：有向图修正与精度升级

### 4.1 V2.0 残留的三个问题

V2.0 通过了 MECE 审计，建立了对称结构，但仍有三处物理不精确：

**问题A：κ₀ 和 κ_top 使用无向图——物理错误**

- 神经网络中化学突触是**有向**的（前突触→后突触，方向不可逆）
- 无向 k-core 允许"只接收不发送"的节点留在核心 → 错误的层级深度
- 无向 β₁ 对 C.elegans 的近似计算结果约 1（接近 ER 随机图）→ 物理上不可信

**问题B：τ₂ 用 Δβ_PSD（功率谱幂律范围）——不是真正的多重分形**

- Δβ_PSD 只测量功率谱斜率范围，是单重分形（monofractal）方法
- 真正的多重分形需要 MFDFA，测量 q∈[-5,5] 的广义 Hurst 指数谱 Δα
- 数学独立性：布朗运动 H=1（高 τ₀）但 Δα=0（低 τ₂）——Δβ_PSD 无法区分此情况

**问题C：Γst 中 FC 定义与 τ₁ 定义形式不统一**

- τ₁ 已定义为 MFD CS，但 Γst 的 FC 矩阵构造方式在 V2.0 中表述不清晰
- 需要明确 FC_CS[i,j] = corr(H_i(t), H_j(t))，与 τ₁ 完全一致

### 4.3 有向修正的数学细节

#### 有向 D-core（替换无向 k-core）

**无向 k-core**：度数（总度）≥k 的最大诱导子图  
**有向 D-core**：入度 ≥ k **且** 出度 ≥ k 的最大诱导子图

```
无向k-core允许：A→B→C（B只接收从A，B入度=1，出度=1，仍在核心）
有向D-core要求：每个节点必须同时接收信息（入度≥k）和发送信息（出度≥k）
```

**物理意义**：D-core 节点是信息处理层级的"双向核心"——既是信息汇聚处，也是信息发散处。这才是皮层层级处理（V1→V2→V4→IT→PFC）的真实计算模型。

**计算公式**：
$$\kappa_0 = \tanh\!\left(\frac{\text{mean}(D\text{-core}_k)}{k_{\max}} \times 3\right)$$

#### 有向 β₁_d（替换无向 β₁）

**无向 β₁**：需要计算单纯复形同调，对稀疏图近似值≈1（无信息量）  
**有向 β₁_d**：基于 Euler 公式的精确解析计算

$$\beta_1^d = E_d - N + N_{\text{SCC}}$$

其中 $E_d$ 为有向边数，$N$ 为节点数，$N_{\text{SCC}}$ 为强连通分量数。

**物理意义**：网络中独立有向信息循环路径的精确数量。每一个 β₁_d 对应一个"有向信息闭环"——信息可以沿该环路反复循环，这是工作记忆的拓扑基础（O'Keefe-Burgess 模型）。

**C.elegans 对比**：

| 度量 | V2.0（无向） | V2.1（有向） | 比值 |
|------|-------------|-------------|------|
| β₁ | ≈ 1（近似） | β₁_d = 2717 | **×2717** |
| κ_top | ≈ 极小值 | 0.572 | 定性改变 |
| Sc | 0.274 | 0.566 | **+106%** |

**结论**：V2.0 用无向近似计算 C.elegans 的拓扑环路数量，严重低估了有向化学突触网络的真实拓扑复杂度。V2.1 的有向修正使 Sc 提升 106%，与 C.elegans 神经网络实际承载的信息复杂度更相符。

#### MFDFA Δα（替换 Δβ_PSD）

**Δβ_PSD**：功率谱 S(f) ∝ f^{-β} 中 β 的参数范围。单点估计，无法捕捉多重标度结构。

**MFDFA Δα**：多重分形去趋势波动分析（Multifractal Detrended Fluctuation Analysis）

$$F_q(s) \sim s^{h(q)} \implies \alpha(q) = h(q) + qh'(q) \implies \Delta\alpha = \alpha(q_{\min}) - \alpha(q_{\max}),\; q \in [-5, 5]$$

$$\tau_2 = \tanh\!\left(\frac{\Delta\alpha}{0.8}\right)$$

**数学独立性证明**（τ₀ vs τ₂ 的布朗运动反例）：

- 布朗运动：DFA Hurst H = 0.5，tanh(0.5×2) = tanh(1.0) ≈ 0.76 → **高 τ₀**
- 布朗运动：单重分形，Δα = 0 → tanh(0) = 0 → **低 τ₂**
- 结论：τ₀ 高不意味着 τ₂ 高，两者**数学独立**

相比之下，Δβ_PSD 与 DFA Hurst 在高斯时序下线性相关，无法独立。

**神经科学对应**：
- 人脑神经信号 Δα ≈ 0.4–0.8（Ihlen 2012）
- Δα 大 → 网络同时支持强弱两种时序相关，对应δ(0.5–4Hz)到高γ(>80Hz)七频段并存
- Δα 小 → 时序均质，仅支持单一频段主导

## 六、改进的第一性原理依据

### 6.1 为什么神经网络必须用有向图？

化学突触（占 C.elegans 全部突触的 ~70%）的方向由以下物理机制决定：

1. **突触小泡单向释放**：神经递质只从前突触膜释放，不可逆
2. **受体单侧定位**：受体蛋白只在后突触膜表达
3. **信息流向不对称**：感觉→中间→运动，存在明确的处理层级

用无向图建模有向神经网络，等价于假设突触可以双向传递信号——这违反了基本神经生物学。

**对 Sc 的影响**：无向 k-core 允许"只有传入、没有传出"的节点留在核心，高估了网络的层级处理能力。有向 D-core 要求同时满足传入和传出约束，正确捕捉了有向信息流的层级深度。

### 6.2 为什么 β₁_d 要用有向公式而非同调计算？

**无向 β₁（同调）的问题**：
- 计算复杂度 O(2^N)，对 N=279 不可行
- 近似算法误差大（结果约≈1，与实际有向拓扑差千倍）

**有向 β₁_d 的优势**：
- 基于 Euler 公式精确解析：β₁_d = E_d − N + N_SCC
- 物理意义清晰：等于独立有向循环路径数
- 与强连通分量（SCC）直接挂钩——SCC 是有向网络的"功能模块"

**神经科学验证**：  
C.elegans 有向网络 SCC_count=6（6个强连通分量），β₁_d=2717。这2717个有向环路是线虫行为灵活性的拓扑基础，远非无向近似的"≈1"可以描述。

### 6.3 为什么 τ₂ 必须用 MFDFA 而非 Δβ_PSD？

**信息论视角**：

- Δβ_PSD 测量功率谱斜率范围，属于**频域一阶统计**
- MFDFA Δα 测量多重标度 Hurst 指数谱宽度，属于**时域高阶多尺度统计**

**神经科学视角**：

大脑皮层神经振荡横跨 7 个频段（δ 0.5–4Hz → θ 4–8Hz → α 8–13Hz → β 13–30Hz → γ 30–80Hz → 高γ 80–200Hz → 超高频 >200Hz），形成真正的**多重分形时序**。单一频段主导时 Δα 小，多频段协同时 Δα 大。

MFDFA 的 q 扫描（q∈[-5,5]）覆盖：
- q<0：放大稀疏波动（对应低频慢振荡）
- q>0：放大密集波动（对应高频快振荡）
- Δα = α(-5) - α(+5)：整个时序分形复杂度跨度

这是 Δβ_PSD 根本无法提供的信息。

### 6.4 为什么 Φ 必须从 CM 升级为 CS？

这是 V1.x 最重要的概念修正，影响整个理论体系的一致性。

**V1.x 的 Φ（CM度量）**：
$$\Phi_{CM} = \text{mean}_{i,j}\bigl[\text{corr}(r_i(t),\, r_j(t))\bigr]$$
测量两个节点平均脉冲率（一阶统计量）的相关性。

**West (2024) 定义的 CS**：
$$\Phi_{CS} = \text{mean}_{i,j}\bigl[\text{corr}(D_i(t),\, D_j(t))\bigr]$$
其中 $D_i(t)$ 是节点 $i$ 在滑动时间窗口内的 DFA Hurst 指数——**二阶统计量的时序相关**。

**关键区别**：

| | CM（一阶相关） | CS（二阶相关） |
|--|-------------|-------------|
| 测量对象 | 脉冲率均值相关 | Hurst指数时序相关 |
| 反映 | 激活同步性 | 复杂度共演化 |
| 能区分 | 同步vs异步 | 简单同步 vs 复杂同步 |
| West 2024结论 | — | N=10智能体 MFD互相关>0.95，均值相关≈0 |

West (2024) 的核心发现：可以存在**低CM高CS**的情况——节点的平均激活不相关，但其复杂度演化轨迹高度协同。这正是分布式智能（如线虫神经网络）的工作机制。V1.x 的 Φ 完全错过了这一层信息。
