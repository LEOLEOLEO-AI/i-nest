## 三、Sc_V2.1：空间复杂度

$$S_c^{V2.1} = \bigl(\kappa_0 \cdot \kappa_1 \cdot \kappa_2 \cdot \kappa_{\mathrm{top}}\bigr)^{1/4}$$

### 分量定义

| 符号 | 物理维度 | 计算公式 | 神经科学对应 | 文献 |
|------|---------|---------|------------|------|
| **κ₀** | 0维：有向连通层级 | `tanh(mean(D-core)/max(D-core) × 3)` | 皮层层级处理 V1→PFC | Alvarez-Hamelin 2006 |
| **κ₁** | 1维：有向路径效率 | `tanh(σ_directed / 10)` | 全局工作空间，广播延迟 | Watts-Strogatz 1998 |
| **κ₂** | 2维：功能社区分化 | `Q_Louvain ∈ [0,1]` | 视觉/听觉/运动模块分工 | Fortunato 2010 |
| **κ_top** | ∞维：有向信息环路 | `log₁₀(β₁_d+1) / log₁₀(10⁶+1)` | 工作记忆容量（O-B模型）| Reimann 2017 |

### 关键定义

**D-core**（有向k-core）：入度≥k 且 出度≥k 的最大诱导子图  
→ 比无向k-core更严格，捕捉有向信息流的层级深度

**有向β₁_d**：
$$\beta_1^d = E_d - N + N_{\mathrm{SCC}}$$
其中 $E_d$ 为有向边数，$N_{\mathrm{SCC}}$ 为强连通分量数。  
物理含义：网络中独立有向信息循环路径的数量。

**β₁_d 归一化**（log₁₀，以人类皮层级 10⁶ 为上界）：  
$$\kappa_{\mathrm{top}} = \frac{\log_{10}(\beta_1^d+1)}{\log_{10}(10^6+1)}$$

|--------|--------|------|
| κ₀ vs κ₁ | 层级深度 ≠ 路径效率 | ✓ 独立 |
| κ₀ vs κ₂ | 连通层级 ≠ 社区分化 | ✓ 独立 |
| κ₀ vs κ_top | 层级 ≠ 环路数量 | ✓ 独立 |
| κ₁ vs κ₂ | 路径长度 ≠ 模块结构 | ✓ 独立 |

## 四、Tc_V2.1：时间复杂度

$$T_c^{V2.1} = \bigl(\tau_0 \cdot \tau_1 \cdot \tau_2 \cdot \tau_{\mathrm{top}}\bigr)^{1/4}$$

### 分量定义

| 符号 | 统计阶次 | 计算公式 | 神经科学对应 | 文献 |
|------|---------|---------|------------|------|
| **τ₀** | 0阶：单节点记忆 | `tanh(mean_i[H_DFA(i)] × 2)` | STDP时间窗，突触可塑性 | Peng 1995; Linkenkaer-Hansen 2001 |
| **τ₁** | 1阶：复杂性同步 | `max(0, mean_{i,j}[corr(H_i(t), H_j(t))])` | CS（West2024），超越相位同步 | West 2024; 院士PPT P22 |
| **τ₂** | 2阶：多尺度覆盖 | `tanh(Δα_MFDFA / 0.8)` | δ→γ七频段同时活跃 | Ihlen 2012; Zorick 2013 |
| **τ_top** | 临界指数 | `exp(-\|τ_av − 1.5\| / 0.3)` | 神经雪崩 P(s)∝s^{-3/2} | Beggs & Plenz 2003 |

### 关键定义

**τ₀（DFA Hurst均值）**：
$$\tau_0 = \tanh\!\bigl(2 \cdot \overline{H}_{\mathrm{DFA}}\bigr), \quad \overline{H}_{\mathrm{DFA}} = \frac{1}{N}\sum_{i=1}^N H_i^{\mathrm{DFA}}$$
H=0.5为随机无记忆；H→1为完美持续记忆。

**τ₁（复杂性同步 Φ_CS）**：  
$$\tau_1 = \max\!\left(0,\ \frac{2}{N(N-1)}\sum_{i<j}\mathrm{corr}\!\bigl(H_i(t),\, H_j(t)\bigr)\right)$$
滑动时间窗 W=200步，步长30步。H_i(t) 为节点 i 在窗口 t 内的 DFA Hurst 指数。  
**注**：τ₁ ≠ 旧Φ（一阶激活相关）。此为 West2024 CS 定义，低一阶相关可共存高τ₁。

**τ₂（MFDFA奇异谱宽度）**：
$$\tau_2 = \tanh\!\left(\frac{\Delta\alpha}{0.8}\right), \quad \Delta\alpha = \alpha(q_{\min}) - \alpha(q_{\max}),\ q\in[-5,5]$$
$\alpha(q)$ 为 MFDFA 的广义 Hurst 指数（奇异性标度指数）。人脑 Δα≈0.4–0.8，归一化上界取0.8。  
**注**：τ₂ ≠ τ₀。τ₀ 用 q=2 处单点值；τ₂ 用 q 谱宽度（布朗运动 H=1 但 Δα=0，可以高τ₀低τ₂）。

**τ_top（SOC神经雪崩指数）**：
$$\tau_{\mathrm{top}} = \exp\!\left(-\frac{|\tau_{\mathrm{av}} - 1.5|}{0.3}\right)$$
τ_av 为雪崩大小分布 P(s)∝s^{-τ} 的拟合幂律指数。τ=1.5 为 SOC 临界值（分支比=1）。

### MECE验证（Tc）

| 分量对 | 重叠？ | 验证 |
|--------|--------|------|
| τ₀ vs τ₁ | q=2 单点 vs 跨节点互相关 | ✓ 独立 |
| τ₀ vs τ₂ | q=2 点值 vs q∈[-5,5] 谱宽；布朗运动反例证明独立 | ✓ 独立 |
| τ₀ vs τ_top | 记忆持久性 ≠ 临界雪崩 | ✓ 独立 |
| τ₁ vs τ₂ | 节点对CS相关 ≠ 单节点谱宽 | ✓ 独立 |
| τ₁ vs τ_top | 同步性 ≠ 临界指数 | ✓ 独立 |
| τ₂ vs τ_top | 多尺度覆盖 ≠ SOC相变指数 | ✓ 独立 |
| 遗漏检查 | 相位同步已被τ₁(CS)覆盖（更深层）| ✓ 无遗漏 |

## 五、Γst_V2.1：结构-复杂性同步对齐

$$\Gamma_{st}^{V2.1} = \mathrm{NMI}\!\bigl(M_{\mathrm{struct}},\, M_{\mathrm{func}}^{\mathrm{CS}}\bigr) \times \mathrm{sign}(\mathrm{Mantel}_r^{\mathrm{CS}})$$

| 分量 | 定义 |
|------|------|
| $M_{\mathrm{struct}}$ | Louvain 在突触权重矩阵 W 上的结构社区划分 |
| $\mathbf{FC}^{\mathrm{CS}}_{ij}$ | $= \mathrm{corr}(H_i(t),\, H_j(t))$，MFD Hurst 互相关矩阵 |
| $M_{\mathrm{func}}^{\mathrm{CS}}$ | Louvain 在 $\max(0, \mathbf{FC}^{\mathrm{CS}})$ 上的功能 CS 社区划分 |
| $\mathrm{Mantel}_r^{\mathrm{CS}}$ | $\mathrm{corr}(d_{\mathrm{struct}},\, d_{\mathrm{func}}^{\mathrm{CS}})$，结构与功能距离矩阵的相关 |
| $d_{\mathrm{struct},ij}$ | $= 1/(W_{ij}+\varepsilon)$，突触强度的倒数作为结构距离 |
| $d_{\mathrm{func},ij}^{\mathrm{CS}}$ | $= 1 - \mathbf{FC}^{\mathrm{CS}}_{ij}$，CS 相似度转化为距离 |

**V2.0→V2.1升级**：FC 从一阶激活相关（旧）→ MFD CS 互相关（新）。  
物理意义：结构组织是否决定复杂性同步组织？SDI四规则驱动结构重组 → Γst↑ → CST↑。

```
空间（静态结构承载力）        时间（动态过程表达力）

κ₀  有向连通层级（深度）   ↔   τ₀  时间记忆深度
```

**不变**：τ₀, τ₁, τ_top, κ₁, κ₂，六阈值，α，公式骨架，几何均值指数
