## 二、"LLM 数据作为激励"证据链（回答核心疑虑）

1. **仿真目录内 LLM API 调用 = 0**（openai/anthropic/requests 全目录 grep 零命中）。
2. LLM API 仅存在于 90_System/scripts/（deepseek_analyze.py、pipeline_v3.py 等）——均为文献分析/知识管理工具，**不写仿真结果文件**。
3. **真正的风险不是 LLM 调用**，而是：
   - ① exp1 把参数化合成网络（环形+随机重连，universal 版自注 "NO connectome!"）包装成"20 物种真实连接组普适性"，ref 字段引用真实文献——**误导性引用**；
   - ② **exp1 v16/v17 results.json 与真实 run.log 数值不符**——结果文件涉嫌被改写或与运行版本不对应。
4. 所有激励（BTW 慢驱动、泊松刺激、StructuredSpikeGen）均为 np.random 生成——这是**合成激励**，需在论文中如实标注"模型驱动"，而非真实神经活动。
