### P2 一个数字打开话题——700倍

> *在今天的计算系统里，把一份数据从内存"搬"到计算单元，耗的能量是真正"算"它的**几百倍**。*

| 来源 | 关键数据 |
|------|------|
| **Horowitz, ISSCC 2014** | 一次运算 ~1-5 pJ；一次片外DRAM访问 ~1-2 nJ → **350~700倍** |
| **Google, ASPLOS 2018** | 真实负载中数据搬移占系统能耗 **62.7%**，滚动网页场景 **77%** |
| **NeurIPS 2024 LSH-MoE** | All-to-All通信占训练时间 **45%~67%** |
| **华为研究** | 训练中不可重叠通信 ~30%，万卡集群更高 |

> **结论**：过去七十年拼命优化的"算"，可能一直在优化次要矛盾。**数据搬移既是最大红利区，也是体系创新的空白区。**

---

### P3 根因：拓扑刚性——计算范式的第一性瓶颈

为什么一块芯片做不了又训又推？

```
训练：AllReduce密集 → 环形/树形拓扑 → 大带宽
推理：All-to-All密集 → 细粒度访存 → Token级切换

→ 通信模式、拓扑结构、访存粒度、时隙节奏，四重错配
→ 谷歌 TPU 8t ≠ 8i，华为 950DT ≠ 950PR → 被迫双芯分立
```

**根子**：任务在变，拓扑却焊死——这是系统级低效的第一性根源。

> **TCC 的答案**：让拓扑本身成为可编程对象。**拓扑即计算。**

### P4 全球转向——连接的智慧，不是节点的暴力

```
PCB逐级集成：亚线性，1+1<2
晶圆级异构集成：线性，1+1=2
网络价值超线性：Sarnoff(∝N) → Metcalfe(∝N²) → Reed(∝2ᴺ)
涌现：1+1>N ← iNEST的物理底座
```

**全球风向**：
- Tesla Dojo、Cerebras WSE-3（4万亿晶体管，2024上市）
- 美军 DRBE——晶圆级电磁频谱物理大模型

> **对信创而言**：这不是替代路线，是**第二曲线**。中国必须从"替代"走向"引领"。

> **软件定义节点**拥挤，**软件定义互连**才是红利区+空白区。SDI不是改良——是换维度竞争。

### P7 SDI 的技术实现——四层架构

借鉴自然界"元素+化合键→大千世界"的第一性原理：

```
Layer 4: 拓扑编程语言 → 描述"任务需要什么拓扑"
Layer 3: T-R 原语体系 → Route原语(R) + Transform原语(T)
Layer 2: SDI 化合键 → μs级物理拓扑重构
Layer 1: 物理互连 → 晶圆级高维最优扇出拓扑
```

- **R 类原语**：AllReduce, Broadcast, Scatter, Gather, All-to-All, Reduce-Scatter
- **T 类原语**：FFT, GEMM, Conv, Attention, LayerNorm, Activation

**理论基础**：
1. Route-Transform 完备性定理——任意分布式计算 = R + T 的有限组合
2. FFT-AllReduce 同构定理——蝶形变换底层可图重构

### P10 核心公式——一页讲清楚 TCC

```
计算任务 = R原语 + T原语 + Topology Page + Epoch Commit

  R: Route原语（通信）    T: Transform原语（计算）
  Topology Page: 拓扑态快照与还原（硬件级"上下文切换"）
  Epoch Commit: 原子拓扑事务提交（保证一致性）
```

**六大模块**：

| 模块 | 功能 |
|------|------|
| 元拓扑 | 拓扑模板库，可编程组合 |
| SDI化合键 | μs级物理拓扑重构 |
| TopoColor μRouter | 多色标记无死锁路由 |
| CGRA MacroTile | 粗粒度可重构算子阵列 |
| Topology Page | 拓扑态快照与恢复 |
| Epoch Commit | 原子拓扑事务 |

### P15 iNEST 的理论根基——40系统跨物种验证

**物理复杂网络中集体智能行为涌现的复杂度理论**：

| 维度 | 内容 |
|------|------|
| 结构复杂度 | 连通性、模块性、层级性、小世界性 |
| 动力学复杂度 | 临界分支比、多时间尺度、相位同步、功能可塑性 |
| 时空耦合度 | 结构-功能关联强度（ANN被锁死在 Γ≡0） |
| **跨系统验证** | **≥40系统**，Spearman ρ≥0.90，Kendall τ≥0.83 |

> **关键指标**：数字逻辑架构的能效复杂度比上界，与物理复杂网络的理论预测差距 ≥10⁴倍。
> **这意味着：用传统GPU/TPU范式，能效永远差1万倍。必须换范式。**
