### 第二部分：TCC——算力范式的产业革命（6页）

---

#### P6 TCC 核心原理（一页讲清楚）
- **发现**：任何分布式计算 = Route（路由）+ Transform（变换）的分解
- **关键洞察**：FFT 与 AllReduce 在拓扑上是同构的——同一物理路径可完成计算+通信
- **SDI 软件定义互连**：微秒级拓扑重构，让硬件"流动"起来

```
传统芯片：固定电路 → 固定功能
TCC 芯片：SDI 柔性韧带 + NPC通信原语 + CPC算子原语 → 1μs变阵 → 液态硬件
```

### 第三部分：iNEST——智能涌现的工程化（5页）

---

#### P12 iNEST 核心原理
- **核心论点**：智能的本质是复杂网络的涌现行为，不是图灵计算的产物
- **CST 发现**：协同时空复杂度（连通性×层级性×模块性×小世界性×临界性）= 智能涌现的条件阈值
- **40系统跨物种验证**：从 C.elegans（279节点）到 Drosophila（2,952节点）到 Macaque → ρ=0.92, τ=0.83

---

#### P13 iNEST 突破传统AI的根本逻辑
| 传统AI | iNEST |
|------|-------|
| 精确权重计算 | 非线性动态映射 |
| 更强算力 → 更智能 | 更复杂网络 → 更智能 |
| O(N²)注意力瓶颈 | 物理动力学自然衰减 |
| 器件一致性要求高 | 器件变异 = 涌现驱动力 |
| 能效比逐年恶化 | 能效比随规模改善 |
