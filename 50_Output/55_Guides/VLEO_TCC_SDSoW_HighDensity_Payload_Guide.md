# 颠覆性专项计划项目指南

## （X）技术单元X：自主芯粒高密度集成与软件定义拓扑协同增益技术

面向超低轨卫星载荷系统级指标协同提升需求，探索基于境内自主工艺芯粒、高密度载板集成与软件定义拓扑的系统级增益连乘机制，开辟载荷轻量化、高能效与高灵活性协同提升的新路径。超低轨卫星需同时面对高阻力、高轨道维持功耗、气动热环境复杂等多重挑战，传统分系统离散集成导致载荷质量和体积大、功耗高、热控难，难以平衡在轨寿命与载荷能力。该技术将基带、交换、存储、计算等核心单元进行高密度集成，并通过软件定义实现拓扑动态重构与资源按需调度，旨在“缩得小、耗得少、算得快”，是保障超低轨卫星载荷性能和大规模星座弹性部署的关键“心脏与神经”。

**主要攻关点：**（1）自主芯粒高密度载板集成与轻量化原型：研究境内自主工艺芯粒的高密度互连、低损耗介质与热扩散技术，结合载荷小型化、轻量化和热设计，研制基带—交换—存储—计算一体化载板原型；（2）软件定义拓扑：突破固定互连限制，研究可编程交换矩阵、拓扑页快速配置与故障重映射算法，实现同步、汇聚、点对点、流水等任务拓扑的按需切换与故障重映射；（3）连乘增益验证：通过“分立集成+固定拓扑”“高密度集成+固定拓扑”“高密度集成+软件定义拓扑”对照测试，验证集成增益、架构重构增益和系统连乘增益，重点评价单位质量任务能力、单位体积任务能力、资源利用率、系统能效、任务适配灵活性和单位任务成本，验证物理集成与架构创新协同产生系统级增益连乘的工程技术路线。

**项目要求：**经费不超过500万元，周期不超过24个月；完成地面原型、对照测试和可复现实验数据。各项指标须标注 `实测`、`仿真`、`引用`、`推导` 或 `待测`，并绑定验证任务；本阶段不要求整星在轨验证。
