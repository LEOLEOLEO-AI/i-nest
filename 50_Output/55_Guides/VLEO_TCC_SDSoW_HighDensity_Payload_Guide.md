# 颠覆性专项计划项目指南

## 技术单元：基于高密度基板集成与拓扑重构的超低轨卫星基带载荷技术

超低轨卫星通信面临高速运动引起的多普勒变化、星地/星间链路频繁切换，以及功耗、重量、体积、散热和可靠性强耦合等挑战。现有载荷多采用基带、交换、存储和计算单元分立集成及固定互连，难以同时适配同步、汇聚、点对点转发和智能处理等动态任务，形成“任务与链路快速变化、载荷物理结构固定”的核心矛盾。该技术以晶圆/玻璃/陶瓷等候选基板中的一种为集成载体，将基带处理、交换、存储、计算和健康管理单元高密度集成，并通过软件定义互连和拓扑中心计算，使连接关系随任务按需重构，实现逻辑架构创新与物理集成创新的协同增益，提升超低轨通信载荷的能重比、能效比和性价比。

**主要攻关点：**（1）高密度基板集成：研究高密度互连、低损耗介质、热扩散和故障隔离技术，研制基带—交换—存储—计算一体化原型；（2）软件定义拓扑：突破固定互连限制，研究可编程交换矩阵、Topology Page和快速配置机制，实现同步、汇聚、点对点和流水等任务拓扑的按需切换与故障重映射；（3）软硬件协同验证：开发任务—数据流—拓扑联合编译调度软件，完成多普勒变化、链路切换和节点故障条件下的闭环原型验证，对端到端时延、任务能耗、有效吞吐和切换时长开展 `实测`，形成后续在轨验证方案。

**项目要求：**经费不超过500万元，周期不超过24个月；完成1套地面原型和可复现实验数据。各项性能指标须标注 `实测`、`仿真`、`引用`、`推导` 或 `待测`，并绑定验证任务；本阶段不要求开展整星在轨验证。
