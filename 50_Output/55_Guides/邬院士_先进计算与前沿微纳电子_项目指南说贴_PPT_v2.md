### P3 为什么是现在——三重墙同时逼近

| 瓶颈 | 现状 | 传统方案 | 我们的方案 |
|------|------|------|------|
| **功耗墙** | H100 700W → B200 1000W → 2028破2kW | 液冷/制程微缩 | 液态硬件按需重构，消除暗硅 |

### P5 核心概念——一页讲清楚 TCC

```
传统芯片：固定电路 → 固定功能（冯·诺依曼瓶颈）

TCC 芯片：
  发现：任何分布式计算 = Route + Transform
  关键：FFT 与 AllReduce 在拓扑上是同构的
  方案：SDI 柔性互连 + 通信原语(NPC) + 算子原语(CPC)
  结果：同一物理硬件 → 1μs变阵 → 液态硬件
```

**产品族命名**：拓涌场 TopoSurge Fabric
- TCC-AI → **拓涌智场**（端侧训推一体AI）
- TCC-RF → **拓涌波场**（DBF/FFT/通感一体/射频智算）
- 终局目标 → iNEST **智涌脑**

> **承接语**：**拓涌成场，智涌成脑。**

---

### P6 技术路线——六大核心模块

| 模块 | 功能 | 对标 |
|------|------|------|
| **元拓扑 MetaTopology** | 拓扑模板库，可编程组合 | 传统固化NoC的替代 |
| **SDI化合键** | μs级物理拓扑重构 | 超越NVLink的静态互连 |
| **TopoColor μRouter** | 多色标记无死锁路由 | 替代传统确定性路由 |
| **CGRA MacroTile** | 粗粒度可重构算子阵列 | 替代GPU固定SM |
| **Topology Page** | 拓扑态快照与还原 | 硬件级"上下文切换" |
| **Epoch Commit** | 原子拓扑事务提交 | 确保拓扑切换一致性 |

---

### P7 原语体系——从极简到完备

```
当前 MVP（4R + 3T）：
  通信原语：AllReduce, Broadcast, Scatter, Gather
  算子原语：FFT, GEMM, Conv

演进目标（6R + 6T）：
  增加 → All-to-All, Reduce-Scatter
  增加 → Attention, LayerNorm, Activation
```

- **Route-Transform 完备性定理**：证明这套原语可以覆盖任意分布式计算

### P12 项目二的科学问题

**核心信仰**：**大道至简 —— Complexity comes from simplicity**

大自然没给线虫（302神经元）和人脑（860亿）写两套代码。极简的局部可塑性 + 全局能量约束 → 涌现复杂智能。

| 科学问题 | 核心追问 |
|------|------|
| **Q1** | 复杂网络演化的物理第一性——那条"至简的规则"是什么？ |
| **Q2** | CST时空协同复杂度的物理本源——ANN为什么被锁死在 Γ≡0？ |
| **Q3** | SDI如何映射生物突触可塑性到硅基互连的动态重构？ |

---

### P13 项目二的四个课题

```
课题一：理论奠基
  └→ 非平衡态统计物理 + CST量纲体系 + 自然常数(1/√2,1,φ,e,π,δ)临界点推导

课题二：机制仿真
  └→ 三大极简算子（时空耦合+局部STDP+全局FEP）→ SDI-Bond多尺度仿真器

课题三：架构设计
  └→ SDI柔性韧带 + 液态硬件 + 原语指令集（5通信+4算子）

课题四：原型验证
  └→ 多FPGA液态硬件平台 + 硅基演化闭环（真实数据流驱动网络自组织）
```

> 四个课题从**理论→仿真→架构→原型**，闭环验证"硅基演化"。
