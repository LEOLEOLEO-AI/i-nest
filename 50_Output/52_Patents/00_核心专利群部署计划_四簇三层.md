# TCC iNEST 核心专利群部署计划

> **布局策略：** 对标高通在 CDMA 时代的标准必要专利（SEP）布局——"核心专利 + 外围专利 + 防御专利"三层结构。
> **目标：** 0–3 个月内完成 8–12 件核心专利的同步申报，构建不可绕过的专利壁垒。

---

## 一、专利布局逻辑

采用三层结构：

```
         ┌──────────────────────────────┐
         │     第三层：防御专利（2-4件）    │
         │   应用场景保护，防止竞品规避      │
         │  ┌────────────────────────┐   │
         │  │  第二层：外围专利（3-4件） │   │
         │  │  实施方式保护，锁定实现路径 │   │
         │  │ ┌──────────────────┐   │   │
         │  │ │第一层：核心专利    │   │   │
         │  │ │  (8件，四簇)     │   │   │
         │  │ │ 基础机理+架构    │   │   │
         │  │ └──────────────────┘   │   │
         │  └────────────────────────┘   │
         └──────────────────────────────┘
```

| 层级 | 数量 | 作用 | 类比 |
|------|------|------|------|
| **核心专利** | 8件（四簇各2件） | 保护基础发明构思，建立标准必要地位 | CDMA 基础扩频专利 |
| **外围专利** | 3–4件 | 保护关键实施方式，锁定实现路径 | CDMA 功率控制/软切换专利 |
| **防御专利** | 2–4件 | 覆盖典型应用场景，防止竞品规避设计 | CDMA 终端应用专利 |

## 二、四簇核心专利详述

### 第一簇：TCC 拓扑中心计算架构类（基础专利，2件）

> **战略地位：** 定义"什么是 TCC"——如同 CDMA 定义了"什么是码分多址"。后来者无法绕过。

**专利 1.1：一种基于拓扑中心度量的异构异质集成计算架构**

| 项目 | 内容 |
|------|------|
| **保护范围** | TCC 的基本计算单元定义、拓扑中心节点判定方法、信息汇聚与发散机制 |
| **覆盖要点** | ① 拓扑中心度的可计算度量（如 betweenness centrality 在硬件互连图中的适配）；② 以拓扑中心节点为信息汇聚/发散枢纽的计算组织方式；③ 异构异质计算单元（CPU/GPU/NPU/FPGA）围绕拓扑中心节点的集成方法 |
| **对标** | 冯·诺依曼架构的"以处理器为中心"→ TCC 的"以拓扑中心为中心" |
| **所属专利簇** | 第一簇 — 基础专利 |
| **撰写要点** | 上位概念用"拓扑中心度量"而非具体算法；实施例给出 ≥3 种拓扑度量方法的晶上实现 |

**专利 1.2：软件定义互连的拓扑中心动态重构方法**

| 项目 | 内容 |
|------|------|
| **保护范围** | 运行时拓扑可塑性——互连拓扑从设计时固定变为运行时软件定义 |
| **覆盖要点** | ① SDI 控制器接收拓扑切换指令的接口定义；② 双缓冲原子交换机制的纳秒/微秒级拓扑切换；③ 元拓扑库与 SDI-Bond 转换规则；④ 拓扑切换的代价模型与收益阈值判据 |
| **对标** | 传统固定拓扑（Mesh/Torus/Fat-Tree）→ 可编程拓扑 |
| **所属专利簇** | 第一簇 — 基础专利 |
| **撰写要点** | "拓扑可重构"概念尽量上位，不限定具体交换矩阵规模；实施例覆盖单芯片、多芯粒、晶圆级三种尺度 |

### 第二簇：iNEST 复杂度涌现机理类（机理专利，3件）

> **战略地位：** 将"智能化 = 复杂度比值 > 阈值"这一第一性原理写入专利，锁定智能等级评定的方法论。

**专利 2.1：基于时空协同复杂度比值阈值的智能等级量化评定方法**

| 项目 | 内容 |
|------|------|
| **保护范围** | 核心判据："复杂度比值 > 阈值 → 涌现"——智能化等级的可计算评定 |
| **覆盖要点** | ① 空间复杂度（S_c）的图论度量方法（连通性、层次深度、模块度、小世界系数）；② 时间复杂度（T_c）的动力学度量方法（亚稳态数量、熵、自相关、临界指数）；③ 时空协同耦合项（Γ_st）的互信息计算方法；④ 六级智能阈值的推导与应用 |
| **对标** | 图灵测试（行为主义）→ 复杂度阈值判据（物理主义） |
| **所属专利簇** | 第二簇 — 机理专利 |
| **撰写要点** | 上位用"复杂度比值"而非 CST = (S_c·T_c)·exp(α·Γ_st) 的具体公式；绑定可观测量（如可测的拓扑度量、可测的能耗-性能比）使侵权判定可行 |

**专利 2.2：环境相对复杂度的在线测量与反馈调节装置**

| 项目 | 内容 |
|------|------|
| **保护范围** | 具身智能场景中，对环境的相对复杂度进行实时测量并反馈调节系统行为 |
| **覆盖要点** | ① 环境相对复杂度 ERC 的在线估计算法（基于传感器流的时间序列分析）；② ERC 与系统内部 CST 的差值驱动自适应行为选择；③ 在机器人/无人机/自动驾驶场景中的嵌入式实现 |
| **对标** | 固定策略智能体 → 环境复杂度感知的自适应智能体 |
| **所属专利簇** | 第二簇 — 机理专利 |

**专利 2.3：基于能量最小化原则的物理网络自组织进化方法**

| 项目 | 内容 |
|------|------|
| **保护范围** | 以能量最小化为驱动力，使物理网络拓扑自发向最优态演化 |
| **覆盖要点** | ① 能量函数定义（通信能耗 + 计算能耗 + 互连能耗）；② 基于 FEP（自由能原理）的拓扑自组织更新规则；③ 局部信息驱动的分布式拓扑优化算法；④ 在忆阻器交叉阵列或 SDI 可重构互连上的物理实现 |
| **对标** | 人工设计拓扑 → 自组织进化拓扑 |
| **所属专利簇** | 第二簇 — 机理专利 |

### 第三簇：晶上工程实现类（实施专利，3件）

> **战略地位：** 将理论专利落地到具体的物理实现，使竞争对手无法在不侵犯核心专利的前提下实现 TCC。

**专利 3.1：晶圆级/晶矩异构异质集成的类脑物理复杂网络硬件架构**

| 项目 | 内容 |
|------|------|
| **保护范围** | 在晶圆级或晶矩尺度上，将异构异质计算单元集成为类脑复杂网络的物理硬件架构 |
| **覆盖要点** | ① 晶圆级基板上的计算瓦片阵列布局方法；② 异构异质单元（数字逻辑/模拟神经元/忆阻器/光子器件）的混合集成方案；③ 瓦片间的高密度可重构互连网络（≥10^4 条互连通道）；④ 与 CMOS 后道工艺（BEOL）兼容的制造流程 |
| **所属专利簇** | 第三簇 — 实施专利 |
| **撰写要点** | 给出 ≥3 套晶上实现方案（如：全数字 CMOS + HBM 堆叠 / 数字-模拟混合 + 忆阻器交叉阵列 / 硅光子互连 + 3D 集成） |

**专利 3.2：介观尺度高密度可塑互连的版图与制造方法**

| 项目 | 内容 |
|------|------|
| **保护范围** | 介观尺度（μm–mm）的高密度可编程互连的物理版图设计与制造工艺 |
| **覆盖要点** | ① 介观尺度互连的版图拓扑生成算法（满足无交叉、等长、阻抗匹配约束）；② 可塑互连的物理实现（基于忆阻器/相变材料/纳米机电开关的可编程连接点）；③ 多层互连堆叠的 3D 集成制造流程；④ 互连密度与可编程性的量化折中关系 |
| **所属专利簇** | 第三簇 — 实施专利 |

**专利 3.3：面板级面向具身智能的感知—认知—决策—行动一体化集成结构**

| 项目 | 内容 |
|------|------|
| **保护范围** | 面板级集成结构，将感知、认知、决策、行动四个环节在单一物理基板上闭合 |
| **覆盖要点** | ① 多模态传感器接口（视觉/触觉/惯性/音频）与计算瓦片的直接互连；② OODA（观察-判断-决策-行动）闭环在硬件层面的架构映射；③ 实时性保证（端到端延迟 ≤ 1 ms）；④ 面向人形机器人/自主无人系统的面板级集成方案 |
| **所属专利簇** | 第三簇 — 实施专利 |

### 第四簇：外围与防御性专利（2–4件）

> **战略地位：** 覆盖典型应用场景，防止竞品通过"换个应用领域"来规避核心专利。

| 编号 | 方向 | 覆盖场景 |
|------|------|---------|
| **防御-1** | TCC 架构在移动机器人 SLAM 与导航中的应用 | 移动机器人 |
| **防御-2** | TCC 架构在人形机器人"脑"（中央计算单元）中的应用 | 人形机器人脑 |
| **防御-3** | TCC 架构在自主无人系统（无人机/无人车/无人艇）中的应用 | 自主无人系统 |
| **防御-4** | TCC 架构在智能边缘节点（工业 IoT / 智慧城市）中的应用 | 智能边缘节点 |

以上防御专利可根据资源情况选择 2–4 件，优先级按市场价值排序。

## 三、专利撰写三要点

### 要点 1：上位概念尽量抽象

| ❌ 不推荐 | ✅ 推荐 |
|----------|--------|
| "CST = (S_c·T_c)·exp(α·Γ_st)" | "复杂度比值" 或 "时空协同复杂度度量" |
| "64×64 交叉开关" | "可编程互连矩阵" |
| "纳秒级双缓冲原子交换" | "运行时拓扑重构" |
| "忆阻器交叉阵列" | "可塑互连介质" |

### 要点 2：实施例尽量具体丰富

- 每件核心专利给出 **≥3 套**不同的晶上实现方案
- 每套方案包括：器件选择、互连拓扑、面积/功耗/延迟估计
- 实施例的多样性决定了权利要求的解释范围和等同侵权覆盖

### 要点 3：绑定可观测量

| 权利要求要素 | 绑定可观测量 |
|-------------|-------------|
| 拓扑中心度量 | 可测的 betweenness centrality / closeness centrality（通过读取互连配置寄存器） |
| 复杂度比值 | 可测的能耗—性能比（η_I = CST / P_norm） |
| 拓扑重构 | 可观测的互连配置切换事件（通过监测配置寄存器的写入序列） |
| 自组织进化 | 可测的拓扑度量随时间的变化轨迹 |
