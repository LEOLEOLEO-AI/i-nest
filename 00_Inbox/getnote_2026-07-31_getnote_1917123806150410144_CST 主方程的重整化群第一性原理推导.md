# 第五章 · 与非 RG 推导路径的收敛性证明

## §5.1 Buckingham 与 RG 的对应

　　**Buckingham π 定理** [3]: 一个由  个物理量、 个基本量纲组成的物理关系, 可无损压缩为  个无量纲组合的关系。这等价于：**物理量在"量纲缩放变换"下的不变性**。

　　**RG 变换**  与 **量纲缩放** 在数学结构上是同一群 —— 都是  作用下的乘性变换。RG 只是**在物理系统的具体自由度上**实施的量纲缩放, 具备明确的物理内容 (Kadanoff 块自旋)。

　　**结论**：**Buckingham 定理是 RG 群结构的"量纲版"**——它给出乘积结构的**几何依据**, RG 给出乘积结构的**物理依据**。

　　Jaynes 1957 最大熵原理 [6]: 在给定约束下, 最大化 Shannon 熵得到 Boltzmann 分布 。

　　**RG 视角**: 最大熵原理是在**"平衡态 RG 流终点"**上的推导——β 函数在 Ising 模型高温不动点附近的行为**正是最大熵**。**Wilson 1971** 严格证明: 高温不动点是最大熵态的 RG 意义下的不动点。

　　**结论**: **Jaynes 最大熵是 RG 流特定不动点 (高温)** 附近的态——给出指数结构的**统计依据**, RG 给出指数结构的**动力学依据**。

## §5.3 Shannon-Landauer 与 RG 的对应

　　Shannon 通道容量  与 Landauer 下界  都是**信息容量的对数刻画**。

　　**RG 视角**: 由 L3,  是"离散状态数在  上连续化后的相关算子"——**Shannon-Landauer 是 RG 相关算子物理内容的信息论投影**。

　　**结论**: **Shannon-Landauer 是 RG 相关算子  的信息论刻画**——给出对数斜率的**信息依据**, RG 给出对数斜率的**群论依据**。

## §5.4 三源收敛定理

　　**定理 5.1（Buckingham + Jaynes + Shannon-Landauer 与 RG 的收敛）**：以下三条推导路径给出**同一**函数形式：
