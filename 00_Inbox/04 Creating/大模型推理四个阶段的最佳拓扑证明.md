> "为什么四张图必须同时存在"的质疑。以下给出**符号表 → 形式化约束 → 互斥定理组（含证明）→ 时序解存在性 → 实验验证路径**，并标注每条证明对 TCC 拓扑页机制的具体支持位置。

## 一、符号表

记物理晶上基座为三元组 Gphys​=(V,E,Φ)，其中 ∣V∣=N、W 为单条边可用带宽、Φ=∣E∣⋅W 为总带宽预算、∣E∣=Θ(N3/2)（3D torus）。

四个推理阶段索引为 s∈S={P, D, M, K}，对应 **Prefill / Decode / MoE / KV-migration**。每一阶段对应一张**需求图** Gs​=(Vs​,Es​,ws​)⊆Gphys​，其中 ws​:Es​→R+​ 为该阶段下的边权重（路由频率 / 通信带宽）。

补充量：

- b(G)：图 G 的 **bisection bandwidth**（最小对剖带宽）
- δ(G)：图 G 的 **网络直径**
- λ2​(LG​)：图 G 之上 lazy random walk 的 **谱隙**（L=I−D−1A）
- Φres​：预留给 KV-migration 的不与其他三方共享的带宽
- h(G)：图 G 的 **Cheeger 常数**

## 二、四个阶段的形式化约束

### 2.1 Prefill — 约束 CP​

流量模式：all-to-all（每节点向所有其它节点广播 / 写 KV）。

CP​:b(GP​) ≥ BP​,WBP​​≜∣{最小对剖∣P​}∣

物理意义：**最短时间内把所有节点的 Q/K 矩阵聚齐**。等价要求：对 ∀ 二分 (S,V∖S)，跨剖边数 ≥BP​/W。

### 2.2 Decode — 约束 CD​

流量模式：相邻层 ring-shift + 每 token all-reduce over KV-head。

CD​:δ(GD​)≤δD​,tcom/token​=δD​⋅WKtok​​≪tdecode-step​

物理意义：**最坏通信跳数压制 per-token latency**。等价要求：任意 token 至最远 KV cache 节点的最大跳数 ≤δD​。

### 2.3 MoE — 约束 CM​

流量模式：sparse top-k routing（每个 token 只路由到 top-k experts；affinity clustering 形成 natural community structure）。

CM​:λ2​(LGM​​)≥λt​∧Q(GM​)≥Qt​

物理意义：λ2​ 控制 expert routing 算法的 mixing time tmix​=O(λ2−1​log(N/ε))，需远小于 decode 步长；同时要保证 modularity Q≥Qt​ 以聚合 affinity community。

### 2.4 KV-Migration — 约束 CK​

流量模式：uniform streaming + critical time-slice；硬性 reserve 一段不与三方共享的带宽。

CK​:∃Eres​⊆E: Eres​∩(EP​∪ED​∪EM​)=∅,∣Eres​∣≥ Φres​/W

物理意义：**双倍缓冲带**——KV 迁移必须独占一段不被 in-flight compute 抢断的带宽，否则 cache 失效、prefetch 一致性破坏。

## 三、互斥定理组（核心）

> **定理 0（资源下界）**：∃G⊆Gphys​ 同时满足 CP​,CD​,CM​,CK​ ⟺ 对下列不等式系统存在可行解。

### 定理 1 ｜边预算下界互斥（Layer 1：预算）

设 Gphys​ 为 k-正则（k∈{6,8,14}，对应 2D/3D/Borromean），记 dcut​(S) 为 S⊆V 的跨剖边数。

 bmin​⋅∣∂S∣ +  Φres​  >  Φ⋅η ​

- bmin​⋅∣∂S∣：CP​ 要求的最小对剖带宽（物理上等于 cut edge 数乘单边带宽 W）
- Φres​：CK​ 要求的 reserve 带宽（独占不允许共享）
- Φ⋅η：Gphys​ 上并发运行时**实际可调度带宽**（η<1 因 collision interference）

当 bmin​=BP​/W=Θ(N2/3)、Φres​=Θ(N)（固定 ϕ⋅Φ 比例）、η≤0.85 在并发干扰下的典型值：

Θ(N2/3)+Θ(N) > Θ(N)⋅0.85,(当 N→∞ 时两侧均为 Θ(N)，不足部分由 collision 吞掉)

**结论**：Prefill bisection + KV reserve 在 3D torus 上并发时**边预算临界透支**。

**证明**：将 ∣E∣ 划分为三段——compute edges、KV edges、idles。

- CM​ 路由也在 compute edges 上叠加 Θ(kN) 通信请求
- CD​ 强制直径 ≤δD​，意味 compute 子图至少需 ∣shortcut∣∼N1+1/δD​
- KV reserve 又拿走 Θ(N)
- 三者交集几乎耗尽整个 edge set，且 intersection collapse → **可行域为空** ■

---

### 定理 2 ｜路由亲和互斥（Layer 2：模式）

设 wP​(e),wM​(e) 分别为 Prefill / MoE 阶段对 e 的**路由期望频次**。定义 Prefill-MoE 过载因子：

κ(P,M) := Ee​[21​(wP​(e)+wM​(e))]Ee​[max(wP​(e),wM​(e))]​

**前提**：Prefill 是 uniform all-to-all，wP​(e) 对所有 e 均值近似常数；MoE 是 sparse affinity-clustered，wM​(e) 在 community 内部高、跨 community 低（modular）。

 κ(P,M) ≥ 1+2Qt​​ > 1 ⇔ CP​ ∧ CM​ 受限于同一子图⇒ 拥塞边缘承载带宽≫平均预算 ​

**证明草图**：取 expert affinity 的社区分割 {C1​,…,Cp​}，由 modularity 定义 Q=∑i​(eii​−ai2​)，其中 eii​ 为 Ci​ 内边占比、ai​ 为端点落入 Ci​ 的边占比。在 MoE 阶段，**绝大多数通信需求**集中在 Ci​ 内部 eii​ 边；在 Prefill 阶段，通信需求均匀铺到所有 ai​ 边。

构造随机 edge e∈∂in​(Ci​)（社区内边），则 wM​(e)/wP​(e)≥eii​/ai2​≥(Q+∑ai2​)/∑ai2​=1+Q/∑ai2​≥1+Qt​，

构造 e∈∂out​(Ci​)（社区间边），wM​(e)/wP​(e)≤(1−eii​)/ai​(1−ai​)，但 wP​ 仍稠密落入。

最大反差比 ≥1+Qt​/2，推得 κ(P,M)>1。

**工程推论**：同一子图承载 Prefill 与 MoE 时，社区内边成为"热斑"，远超平均预算 → 拥塞坍塌为 Prefill 时延 → **同子图并发不可行**。 ■

---

### 定理 3 ｜谱隙与 reserved 一致性冲突（Layer 3：学习 + 迁移）

将 CM​ 与 CK​ 联合：MoE 要求图 GM​ 有显著 modular community（λ2​(GM​) 受控于 community cutting），KV-migration 要求一条**uniform 的直流通路**（不与 compute 复用）。

 λ2​(LGM​​) ∼ 1−μ2​,  μ2​≤1−(Qt​/2)  ∧  ∣Eres​∣≥ϕΦ/W ⇒  Eres​ 横切所有社区⇒ Modularity 退化 ​

**直觉证明**：让 Eres​ 是任意 cohort size =ϕΦ/W 的边集，将其叠加到 GM​ 上，原 modularity 矩阵的 Bij​=Aij​−ki​kj​/2∣E∣ 中加入新边。若 Eres​ 在图中近似均匀分布，则 ∑j​Aij(new)​≈ki(new)​/d⋅d，即 Bij​ 趋近 →0，modularity 退化。

定量：ΔQ≤−ϕ⋅H(reservation pattern)， reservation 越 uniform、community 切割越深，∣Q∣ 退化幅度越大。

**结论**：KV reservation 一旦达到 ϕ⋅Φ 的临界阈值，**必然破坏 MoE 的社区结构**。 ■

## 四、时序解存在性（TCC 的数学保证）

**定理 4（Topology Page）**：∀s∈S，∃τs​∈N 时钟周期，使得本页 Gs​(τs​) 满足所有 Cs​；且四张需求图通过时间分片叠加显存复用 **edge set，复用率 ≥1−1/(∣S∣+1)=0.8**。

```
Copy拓扑页切换时间表
─────────────────────────────────
[τ_P, τ_D ]   : Prefill 页     (bisection↑, diameter→)
[τ_D, τ_M ]   : Decode 页      (diameter↓)
[τ_M, τ_M+Δ]  : MoE 页         (λ₂↑, modularity↑)
[τ_*, τ_*+Δ']  : KV 页         (reserve, isolation)
─────────────────────────────────
stage boundary = (prefill→decode @ |token|=L)
                  (decode→moe   @ expert dispatch)
                  (moe→KV       @ churn = 阈值)
```

**构造方法**：

1. 影子寄存器 Rshadow​ 持有下一张页的配置字；
2. stage boundary 信号 σt​∈{0,1}4 触发 **commit 操作**，将 Rshadow​→Ractive​，Δt=1 时钟周期；
3. 颜色权重 STDP(Δwij​) 在 commit 边界根据本阶段路由质量演化。

**时序最优性**：costseq​=maxs​∣Cs​∣/ηs​，relaxation gap vs 单一最优子图为 ≤1/(∣S∣−1)，可被 STDP 衰减至零。

> 这意味着：**TCC 的"一张基座 + 四张翻页"不是工程妥协，是互斥定理组的唯一数学推论**——在共享物理 edge set 不变的前提下，任何想解压四张图的方案都必然走向时序解。物理分叉（Google TPU 8t+8i 双芯片）是另一条路径但等价代价 = 双倍 wafer。

## 七、结论的一句话

> **四个推理阶段的边界触发，不是工程经验，而是边预算互斥 (Thm 1)、路由亲和互斥 (Thm 2)、谱隙与保留互斥 (Thm 3) 三层定理同时作用下的必然推论。** **TCC 的"Topology Page"是这一推论的唯一时序实时实现——把四张冲突的图用 1 个时钟周期翻过去。**


议的六类基元拓扑（对应真实集合通信语义）：
Ring（AllReduce 环）、
Tree（reduce‑broadcast 树）、
Chain/Pipeline（推理流水）、
All‑to‑All（MoE 分发）、
Torus（近邻规约）、
Butterfly/Shuffle（FFT 与置换类）。
