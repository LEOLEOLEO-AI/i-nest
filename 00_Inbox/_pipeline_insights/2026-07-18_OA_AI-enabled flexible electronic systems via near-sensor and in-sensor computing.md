# AI-enabled flexible electronic systems via near-sensor and in-sensor computing

**Zhangyu Xu, Erxuan Xie, Chao Hou** (2026) | *npj Flexible Electronics* | Cited: 3

## Abstract

Artificial intelligence (AI) advances society, spurring interest in integrating it into daily life. AI-enabled flexible electronic systems (AI-FESs) bridge virtual and physical worlds, evolving from detection to analysis. Most AI-FESs rely on external computing, limiting real-time use. Interest in local sensor processing is growing. This review covers progress integrating flexible sensors with processors (including near/in-sensor analyses), advanced processing methods, challenges, and future directions for next-generation AI-FESs.
