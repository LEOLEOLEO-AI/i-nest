# WAIC 2026 华为Atlas 950 SuperPoD深度拆解：业界首个1024卡智算超节点

### 🏆 这次WAIC华为亮出了什么重磅产品？

华为首次线下展出**昇腾950智算超节点**真机，是业界首个公开亮相的**1024卡级超节点**。
- **前代对比**：Atlas 900 A3 SuperPoD 为 384卡 → Atlas 950 SuperPoD 跃升至 1024卡
- **商用进展**：上一代384卡超节点已落地 **750多套**，新一代计划 **2026年第四季度** 批量上市
- **所获荣誉**：荣膺 WAIC 2026 大会最高荣誉 **SAIL大奖**

### 📊 整系统的规模和核心性能有多强？

1024卡配置实现**1 EFLOPS FP8**算力，256TB统一内存像一台计算机协同工作。

| 维度 | 规格参数 |
| :--- | :--- |
| 总算力 | 1 EFLOPS FP8 / 2 EFLOPS FP4 |
| 统一内存 | 256TB 全局统一编址 |
| 单NPU互联带宽 | 1.68 TB/s（双向） |
| 跨柜通信时延 | 低至 3μs RTT |
| 系统组成 | 16台计算柜 + 4台交换柜 |
| 单柜NPU数量 | 64张昇腾950 NPU |
- **CPU配置**：最大支持 **256颗鲲鹏950 CPU**，CPU:NPU = 1:4
- **散热方式**：计算柜 + 灵衢互联柜 全液冷
- **工作温度**：5℃ ~ 40℃

### 💎 昇腾950 NPU芯片有什么特别设计？

采用**「一芯双构」**策略，同一核心Die衍生出PR和DT两款芯片。
- **昇腾950PR**：128GB 片上内存 + 1.6TB/s 带宽 → 面向推荐系统、Prefill、多模态推理
- **昇腾950DT**：144GB 片上内存 + 4TB/s 带宽 → 覆盖大模型预训练、后训练、推理全流程
- **芯片架构**：多Die合封Chiplet = 2个AI Die + 2个IO Die + 高速片上内存
- **核心规格**：
  - 36个第三代达芬奇架构AI子系统
  - 4个AI CPU Cluster（含8颗Linx816 CPU）
  - 128MB 统一访问L2 Cache
  - 灵衢互联Unified Bus 2.0：72路112Gbps HiLink

### 🗄️ 单柜硬件是怎么布局的？

以**单柜64卡**为标准化单元，正面自上而下分层排布。
- **顶部**：整机柜电源管理模块
- **次顶部**：2个灵衢管理刀片
- **中部上下区**：8个CPU托盘（共16颗CPU）
- **正中区域**：8个NPU计算托盘（共64颗NPU）
- **底部**：液冷散热单元

- **NPU托盘细节**：每托盘8颗NPU，每2颗共用1组液冷模组，芯片与背板用**铜缆互联**
- **背面交换托盘**：4个交换托盘，每托盘32个800G端口，整柜对外总带宽 **102.4 Tbps**
- **正交架构**：计算托盘与交换托盘90度垂直插合 → 信号路径更短 → 降低时延 + 提升信号质量
  说白了，就是板卡不用排线绕来绕去，直接对着插，速度更快、干扰更少。

### 🔗 三级互联体系是怎么搭的？

从节点内到单柜再到柜间，构建了**三级全互联**体系。

#### 节点内：8卡Mesh全互联
- 每托盘8颗NPU两两直连，**无中间交换芯片**
- 单NPU节点内总带宽约 **3.136Tbps**
- 转发机制：IO DIE内置片上交换机，跨芯片流量**不进计算DIE、不占DRAM带宽**

#### 单柜内：正交架构全互联
- 8个NPU托盘 + 背面交换托盘 正交对接
- 单NPU连到交换托盘带宽约 **3.584Tbps**
- 单NPU总互联带宽 **1.68TB/s（双向）**，与官方数据一致

#### 柜间：光互联全局Clos架构
- 16个计算柜 + 4个中央UB交换柜 → 全局Clos组网
- 柜内跨托盘带宽 vs 柜间带宽 ≈ **2:1**（推测）
- 全系统共使用 **4096个800G光模块**
- 采用 **LPO线性驱动可插拔光模块** → 降低成本、时延和功耗

### 📝 补充细节
- 统一内存编址支持 **Load & Store指令级操作**，小包场景时延降低50%以上
- 灵衢互联统一协议覆盖芯片级（NVLink/UPI）、单板级（PCIe/CXL）、框级（IB/RoCE），消除协议转换开销
- 交换芯片具体型号未公开，推测分为两类：一类负责Scale-Up互联，一类负责对外I/O与Scale-Out
- 机柜尺寸：计算柜与互联柜均为 2250mm × 600mm × 1400mm（高×宽×深）
