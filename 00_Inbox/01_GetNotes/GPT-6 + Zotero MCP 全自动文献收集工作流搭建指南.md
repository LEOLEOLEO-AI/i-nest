# GPT-6 + Zotero MCP 全自动文献收集工作流搭建指南

### **🤖 这套工作流能解决什么痛点？**

把**搜索、下载、整理**文献的重复操作全交给 AI，用户只提研究需求。
- **传统流程痛点**：AI 只给标题链接 → 手动开网页 → 找全文 → 下 PDF → 导入 Zotero。
- **新工作流全链路**：提出研究需求 → 外部检索 → 筛选查重 → 获取全文 → 分类管理。
- **核心组件**：**GPT-6**（理解任务、调用工具） + **文献收集 Skill**（规定检索/筛选/去重/验收流程） + **Zotero MCP 插件**（操作 Zotero 的通道）。
  说白了，Skill 管"做什么步骤"，MCP 管"怎么碰 Zotero"，俩都得有，缺一个都跑不起来。
---
### **🔧 Zotero 端要做哪三步配置？**

装插件、开服务、开自动附件，三步让 Zotero 能被 AI 调用并自动存 PDF。

#### 第一步：安装 MCP 插件
- **安装路径**：Zotero → 工具 → 插件／附加组件 → 从文件安装 → 载入 `.xpi` 文件 → 重启。
- **注意区分**：`.xpi` 才是 Zotero 插件，Skill 压缩包不是，别装错。

#### 第二步：开启服务与写入权限
- **设置路径**：设置／首选项 → Zotero MCP Plugin。
- **必开开关**：**Enable Server（启用服务器）** + **Write Operations（写入操作）**。
- **端口默认值**：`23120`，一般不用改。
- **获取配置**：点击 **Generate Client Configuration（生成客户端配置）**，拿到连接信息。
- **版本差异**：不同插件版本界面略有不同，以实际为准。

#### 第三步：检查 PDF 自动附件设置
- **设置路径**：设置 → 常规 → 文件处理。
- **必开选项**：「保存条目时自动附加相关 PDF 和其他文件」。
- **边界提醒**：这只是附件保存开关，**不保证所有论文都能下载成功**。

- **测试建议**：先建一个「**音频文章**」分类，方便观察测试结果；执行任务时保持 Zotero 打开。
---
### **💻 ChatGPT 端怎么连 MCP、装 Skill？**

先连 Zotero MCP 服务器，再装文献收集 Skill，两者都要配。

#### 第一步：连接 Zotero MCP
- **适用客户端**：支持本机 MCP 的 **ChatGPT 桌面端**。
- **添加路径**：Settings → MCP servers → Add server。
- **填写参数**：
  - 名称：`zotero`
  - 连接方式：**Streamable HTTP（流式 HTTP）**
  - 地址：`http://127.0.0.1:23120/mcp`
- **授权范围**：允许**读取和写入操作**即可，不必开放删除权限。

#### 第二步：安装文献收集 Skill
- **关键提醒**：Skill 需要**单独安装**，只连 MCP 没用。
- **安装方式**：桌面端本机 Codex 执行环境下，把**完整 Skill 文件夹**放入用户级技能目录，配套脚本和参考文件也要保留。
- **验证标准**：安装后确认技能能被客户端识别。
---
### **📝 配置好后怎么提交任务？**

先单篇测试确认通了，再批量跑；改课题只换四个参数就行。

#### 测试先行
- 先让 AI 试存**一篇可获取全文**的论文，确认目标分类里**既有书目、也有能打开的 PDF**，再开批量任务。

#### 任务指令示例（音频方向）
> 使用 **Zotero Full-text Ingest**，搜索 **2022—2026 年**音频识别与分类的正式期刊、会议论文，最多 **20 篇**，不必凑满。
> 从外部来源检索，依据标题、摘要和发表信息筛选。查重后，让 Zotero 获取全文，归入「**音频文章**」。
> 预印本单列，已有全文复用，不覆盖附件。最后分别报告**新增、复用、待全文及核验结果**。

#### 换课题改什么

只改 **主题、年份、数量、目标分类** 四个变量即可。
---
### **✅ 怎么验收才算真的完成？**

不能只看"已完成"提示，要**进 Zotero 看实际文件**。
- **验收四件事**：是否进对分类 → 书目信息是否对应 → 条目下有没有**实际 PDF** → 打开是不是目标论文。
- **报告四类状态**：新增全文 / 复用已有全文 / 仅书目待全文 / 核验待完成。
- **两个误区**：
  - ✗ 只有标题 ≠ 下载成功
  - ✗ PDF 能打开 ≠ 论文质量过关
- **全文获取限制**：受**开放获取、机构权限、网络条件**影响，Zotero 能保存书目不代表一定能拿到全文。
