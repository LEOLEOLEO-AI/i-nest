# 北大&元空AI开源OpenAI4S：复刻Claude Science的科研智能体

### 🔬 这个开源项目是什么，来头有多大？

**OpenAI4S**是北大与元空AI联合实验室开源的科研智能体，**完整复现Claude Science核心架构**。
- **开源信息**：2026年7月6日GitHub上线，**MIT许可证**，核心零依赖。
- **研发主体**：北京大学深圳研究生院—元空智能AI Agent联合研究实验室。
- **核心思路**：Code-as-Action（代码即行动），独立复现引擎、持久内核、host-RPC协议、安全层。
- **现有能力**：完整科研Web应用 + **30+内置Skills** + 自有算力接入 + 版本化科研产物。

### 🛠️ 跟普通AI Agent比，核心差异在哪？

普通Agent靠「选工具」一步步走，OpenAI4S**直接写代码在持久内核里跑**，能串起长任务。
- **执行逻辑**：生成Python/R代码 → 持续运行的内核环境执行 → 数据/中间结果保留在环境中。
- **直接好处**：
  - 前一步下载的数据，后一步可直接分析
  - 图片、表格、报告自动保存
  - 随时打开Notebook检查代码、接手修改
- **核心定位**：代码即行动，内核即环境。
  说白了，不是AI跟你聊科研怎么做，而是它直接上手把活干了。

### 🧪 实际用起来是什么体验？

像一张**人和AI共用的科研工作台**，从查数据到出结论全流程在一个界面里完成。
- **完整流程**：查公开数据源 → 编写运行分析代码 → 调用专业计算 → 生成图表/结构/报告。
- **版本管理**：所有科研产物自动记录、保存、版本化，方便检查修改复用。
- **修改方式**：用自然语言提调整要求，智能体基于已有数据和代码重新生成，保留版本记录。
- **诚实原则**：外部服务连不上或计算条件不足 → 明确报错，**绝不伪造数据或结果**。

### 📦 内置了哪些专业科研能力？

首批内置**30+科研Skills**，覆盖常见计算科研场景，还能持续扩展。
- **覆盖领域**：蛋白质结构、序列分析、蛋白设计、分子对接、单细胞分析、文献检索、开放数据检索等。
- **GPU能力**：14个Skills封装了需GPU或专业模型的科学计算。
- **扩展机制**：Skills是可被智能体阅读执行的「代码配方」，新数据库/算法/流程可随时接入。

### 💻 算力不够怎么办？

支持**接入自有计算环境**，本地交互、远程跑GPU，结果回流到同一工作流。
- **分工模式**：本地负责交互和任务组织，GPU计算派发到自有服务器执行。
- **适用场景**：蛋白质折叠、突变评分、分子模拟等需专业模型和GPU的任务。
- **数据安全**：数据、模型、算力都留在自己的环境里，智能体只负责串联。

### 🚫 怎么保证它不胡说八道？

有**no-fabrication policy（不伪造策略）**硬约束，宁可报错也不造假。
- **禁止行为**：用np.random假装实验结果、编造保守性数据、拿BLOSUM冒充ESM、用模拟数据集充真数据等。
- **真实案例**：
  - 蛋白序列从**UniProt**真实拉取，结构从**RCSB**真实下载
  - 蛋白结构预测：ssh到**8×A100**机器跑Protenix（AlphaFold3级别）推理
  - 突变效应评分：跑真实ESM打分
- **底线原则**：没配GPU就直接报错，绝不生成假结构。

### 👥 谁做的？背后团队什么背景？

是北大与元空AI产学研协同的成果，核心推动者为**张恭博**同学。
- **核心人物**：张恭博，北大计算机硕士一年级，导师李远教授，研究方向为离散扩散语言模型与AI for Science。
  - 曾实习于微软研究院AI4Science，参与UniGenX（分子、材料、蛋白质通用生成框架）研发
  - 本科毕业于华中科技大学，GPA排名Top 4.8%
- **团队成员**：李昊、王豫、刘宇阳、吕刘正浩、毛奕澄、林慕捷、彭莘尧、姜政祥、王一米等共同参与。
- **出品公司**：元空AI，端侧AI公司，产品线包括**元空AI Work**（智能办公）和**元空AI Science**（科学发现）。

### 🚀 怎么上手？怎么参与贡献？

三行命令启动，无需先配模型Key；项目面向全社会征集贡献者。
- **快速启动**：
  ```
  git clone https://github.com/PKU-YuanGroup/OpenAI4S
  cd OpenAI4S
  ./setup.sh  # 首次运行：使用uv创建环境
  ./start.sh  # 打开http://127.0.0.1:8760/
  ```
- **模型配置**：进入界面后在Customize → Models里填写。
- **自带案例**：Live API工作流、人胰岛素INS真实数据分析、一句话改图、青蒿素/紫杉醇溶解度预测、蛋白质工程等。
- **贡献方式**：
  - 开发新的科研Skills，接入专业数据库、算法、计算平台
  - 完善核心架构、远程计算、安全机制、测试和文档
  - 提交Issue、补充可复现案例、反馈失败任务、提出学科需求
- **已有支持**：兔展智能的Skills UI已给予部分支持。

### 📝 补充细节
- **项目定位**：不止是Demo，目标是成为**可执行、可检查、可扩展**的科研基础设施。
- **开源范围**：核心架构 + 科研Skills + 完整应用，不只是示例代码。
- **面向对象**：高校、科研机构、开发者、产业伙伴均可在此基础上二次开发。
