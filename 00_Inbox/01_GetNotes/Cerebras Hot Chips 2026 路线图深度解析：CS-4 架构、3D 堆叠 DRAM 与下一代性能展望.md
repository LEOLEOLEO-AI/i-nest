# Cerebras Hot Chips 2026 路线图深度解析：CS-4 架构、3D 堆叠 DRAM 与下一代性能展望

### **🚀 Cerebras 这次发布会公布了哪些核心信息？**

在 **Hot Chips 2026** 上，Cerebras 公布了**两代未来晶圆级加速器**、全新 **Nexus 机架设计**，以及 CS-4 机架内三颗 **WS-3T** 晶圆引擎的性能表现。
- **当前业务**：WSE（晶圆级引擎）主打**极低延迟、高吞吐推理**，支撑 OpenAI ChatGPT-5.6 Sol 的 Ultrafast 档位服务。
- **核心挑战**：AI 模型规模 + KV 缓存上下文持续增长 → 内存需求只增不减。
- **行业路径差异**：
  - 传统 GPU → 堆更高、更多 HBM（高带宽内存）
  - 晶圆级设计 → 面积已 100% 占满，300mm 晶圆尺寸不变，必须另辟蹊径

### **🧱 CS-4 系统和 Nexus 机架设计有什么不一样？**

CS-4 采用**模块化「背包」架构**，把三颗 WS-3T 晶圆集成在可插拔模块中，供电、组网、液冷全部自包含。
- **设计理念**：模块化 → 更易建造 + 更快部署 + 供电/计算/IO 可独立创新
- **结构布局**：
  - 机架正面 → 供电模块 + 风冷风扇
  - 机架背面 → 可插拔计算背包（内含晶圆级引擎）
- **升级优势**：未来新一代晶圆级引擎可直接换入，**无需更换整个机架**

### **⚡ Nexus 背包在供电和散热上有什么创新？**

**取消承载 PCB，铜排直连芯片背面**，把供电损耗降到最低，直接转化为性能。
- **供电设计**：
  - 正面每个背包最多 **10 个机架供电单元**，支持 5+1、4+1、3+1、4+2 等多种冗余配置
  - 输入最高 **277VAC**，输出 **54.5VDC**
  - 每个电源模块由 **30A 断路器**保护
- **性能收益**：
  - 供电损耗降低 → 可向晶圆输送**2 倍于以往的电力**
  - 时钟频率提升 → WS-3T 性能最高可达 WS-3 的 **2 倍**
- **散热方案**：晶圆级引擎液冷，背包其他小组件风冷

### **📊 CS-4 对比 CS-3，各项参数提升了多少？**

CS-4 单机架集成 3 颗 WS-3T，核心指标**全面数倍提升**。

| 维度 | CS-3 | CS-4 |
| :--- | :--- | :--- |
| AI 算力 | 125 PFLOPS | 750 PFLOPS |
| 晶圆数量 | 1× WSE-3 | 3× WSE-3 Turbo |
| 内存容量 | 44 GB | 132 GB |
| 内存带宽 | 21.6 PB/s | 129.6 PB/s |
| 片上互连带宽 | 26.7 PB/s | 160.5 PB/s |
| IO 带宽 | 1.2 Tbit/s | 7.2 Tbit/s |
| IO 延迟 | 5 µs | 2 µs |
- **WS-3T 细节**：
  - 基础硅片与 WS-3 相同
  - 稀疏 FP16 算力翻倍，SRAM 内存带宽翻倍
  - 单颗内存仍为 **44GB**，三颗合计 132GB
  - 不公布稠密 PFLOPS 数据（架构专为稀疏性优化）

### **🔗 晶圆间互连和多机扩展怎么做？**

**片上直连 + RoCE 标准协议**双路径，机架内延迟低至 2 微秒。
- **晶圆间直连**：
  - 每片晶圆 **2.4 Tb/s** 直连带宽
  - 机架内总带宽 **7.2 Tb/s**，延迟 **2 µs**
  - 采用全新 Direct Wafer Links，速度提升 **2.5 倍**
- **网络互联**：
  - 支持 **RoCE v2 RDMA** 标准协议，可与其他系统互操作
  - 网络端到端延迟 **3 µs**，比上代快 **1.7 倍**
  - 每晶圆总聚合带宽 **2.4 Tb/s**
- **扩展逻辑**：架构只需在晶圆间传递**模型激活值** → 带宽需求远低于 GPU 方案，不会成为扩展瓶颈
  说白了，GPU 要来回搬整个模型参数，Cerebras 只传计算结果，所以带宽看着小但够用。

### **🔮 未来两代产品路线图怎么走？**

**CS-5（2027 年）** 换全新硅片，**CS-6** 首次引入 3D 堆叠 DRAM。
- **CS-5（2027 年）**：
  - 采用全新 WSE 硅片
  - 小模型（如 Gemma 4 31B、gpt-oss 120B）→ 每用户最高 **10,000 TPS**
  - 大模型（如 DeepSeek、Kimi、GPT 5.6 Sol）→ 每用户最高 **5,000 TPS**
  - 能效比最高 **3M TPS/MW**
  - 覆盖从 30B 到数万亿参数模型
- **CS-6（相隔两代）**：
  - 首次在逻辑 + SRAM 晶圆之上 **3D 堆叠 DRAM**
  - 目标：缩减芯片整体面积 + 保持推理性能领先
  - 潜在收益：面积缩减 → 晶圆总产量提升 → 缓解产能约束
  - 依托公司十年 3D 集成技术积累

### **📝 补充细节**
- **竞品对比（内存容量）**：
  - CS-4 三晶圆合计 **132GB**
  - Vera Rubin NVL72 → **20.7TB** HBM
  - AMD Helios → **31TB**
- **Cerebras 首席系统架构师 JP Fricker** 评价竞品 Rubin NVL72：每个机架 5000 根 NVLink 线缆是「一团糟」，Nexus 片上互连 + 自包含模块设计更整洁、故障点更少。
- **WSE-3T 片上互连带宽**：**53.4 PB/s**，远高于晶圆间互连带宽。
- 所有 CS-4 对比数据均相对于 Cerebras CS-3。
- CS-5 性能数据来源为 **Cerebras 内部性能预测（2026 年 8 月）**。
