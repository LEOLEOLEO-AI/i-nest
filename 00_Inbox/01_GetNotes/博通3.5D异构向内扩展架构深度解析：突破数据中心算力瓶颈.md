# 博通3.5D异构向内扩展架构深度解析：突破数据中心算力瓶颈

### 🔍 为什么需要Scale-In（向内扩展）？

传统扩展方式**已触物理与经济天花板**，Scale-In靠高密度封装打开新空间。
- **三种扩展维度**：
  - **Scale-Out（横向扩展）**：集群规模从1万XPU迈向10万+XPU
  - **Scale-Up（纵向扩展）**：单节点包含数十到数百XPU
  - **Scale-In（向内扩展）**：先进封装下单芯片面积从2000mm²突破至4000mm²以上
- **Scale-In核心优势 = 更低功耗 + 更低延迟 + 更优成本**
  - **功耗**：片上连接能耗 < 0.2 pJ/b vs 片外链路 3~5 pJ/b，能效大幅提升
  - **延迟**：Die-to-Die（芯粒间）链路延迟约5ns vs 传统Chip-to-Chip的30ns
  - **成本**：固定机架成本下，集成更大计算单元摊薄系统级开销

### 🚀 下一代XPU的演进方向是什么？

下一代XPU在**算力、带宽、面积**三个维度全面跃升。

| 维度 | 当前一代 | 下一代 |
| :--- | :--- | :--- |
| 算力（TOPs） | 5000+ | 10000+ |
| 网络带宽 | ~10 Tbps | 25+ Tbps |
| 内存带宽 | ~9 TB/s | 20+ TB/s |
| 芯片面积 | 2000+ mm² | 2.5D：3500+ mm²<br>3D：7000+ mm² |
- **工艺升级**：从5nm/3nm向3nm/2nm/A14演进
- **中介层面积**：从3000+ mm²扩大到6000+ mm²

### 🏗️ 典型3.5D XPU架构长什么样？

3.5D是**异构集成系统工程**，不是简单堆叠，共分四个关键层级。
- **Top-Die（顶层芯粒）**：采用最先进制程的**高性能计算引擎**
- **Base-Die（底层芯粒）**：承载Cache缓存与NoC片上网络，是互联枢纽
- **Interposer（中介层）**：整合3D堆叠单元、IO芯粒、HBM高带宽内存
  - IO芯粒支持800Gb/1.6Tb以太网逻辑，通过die-to-die PHY连接base-die
- **Substrate（基板）**：中介层的载体，负责信号扇出

### ⚡ 从Gen1到Gen2，互连技术有什么质变？

**芯粒间互连密度**是3.5D集成的成败关键，Gen2实现近10倍跃升。

| 维度 | Gen1（F2B堆叠） | Gen2（F2F堆叠） |
| :--- | :--- | :--- |
| 堆叠方式 | Face-to-Back | Face-to-Face |
| 核心技术 | TSV硅通孔 | 混合键合（HCB） |
| 信号密度 | ~1.5k signals/mm² | ~14k signals/mm² |
- **Gen1痛点**：
  - 互连密度低 → 需重新调整2D逻辑架构
  - 寄生负载高 → 必须用专用D2D PHY，增加设计复杂度与功耗
- **Gen2突破**：
  - 密度足够高 → 无需修改现有2D逻辑架构
  - 低寄生特性 → 实现高性能无缝集成，摆脱专用PHY依赖
  说白了，Gen2把芯粒之间的"连接线"做密了10倍，芯片设计不用再为了互连迁就布局。

### ⚠️ 3.5D集成面临哪些工程挑战？

3.5D落地需攻克**时序、散热、良率**三大核心难题。
- **时序收敛难题**：两颗Die间存在PVT（工艺、电压、温度）差异
  - 应对：统一D2D供电、谨慎选择同步时钟方案、管理时序角的排列组合
- **电源与散热**：电流密度超5 A/mm²，热流密度达4 W/mm²以上
  - 应对：建立精准热模型、验证Top/Bottom模块组合散热、早期原型流片确保仿真与实测一致
- **良率管理**：多芯粒集成导致复合良率指数级下降（95%^N）
  - 应对：设计与测试阶段引入冗余与修复机制

### 🔮 3.5D技术的未来前景如何？

3.5D异构Scale-In**已从实验室走向落地**，是下一代数据中心吞吐量跃升的核心引擎。
- **极致能效**：混合键合互连能效低于0.1 pJ/b
- **超低延迟**：D2D接口延迟小于1ns
- **紧凑尺寸**：中介层与基板占用面积更小

### 📝 补充细节
- 报告来源：博通ASIC产品副总裁Harish Bharadwaj在**2026 OCP APAC Summit**（8月11-12日，台北）发表，主题为《Driving Data Center Throughput through 3.5D Heterogeneous Scale-In》
- Gen1原始Die2Die TSV密度为3k/mm²，Gen2原始Die2Die HCB密度为27k/mm²，经有效信号折算后分别为~1.5k和~14k signals/mm²
