# 全球首个3D算力芯片开源框架Open3D-PIMC发布：国产AI生态的规则突围

### 🌍 全球AI竞争的焦点正在转向哪里？

竞争重心已从**硬件性能比拼**转向**底层软件与生态规则**的争夺。
- **传统瓶颈**：大模型参数迈向万亿级 + 芯片制程逼近物理极限，单芯片算力、单模型榜单已不是核心战场。
- **新战场**：底层编程模型、编译框架等算力底座软件 = 定义算力扩展、调度、算法运行的规则体系。
- **核心逻辑**：谁掌握这套标准，谁就掌握产业未来生态的主动权。

### 🚀 Open3D-PIMC是什么，谁做的？

它是**全球首个面向3D算力芯片**的编程模型与开源软件框架，由清微智能与智源研究院联合开发。
- **发布时间**：2026年9月10日，中国算力大会。
- **开源地址**：https://github.com/flagos-ai/Open3D-PIMC/tree/master
- **生态定位**：国产自主AI软件栈**众智FlagOS**面向下一代3D算力芯片的主要解决方案之一。

### ❓ 为什么底层软件一定要走开源路线？

开源是**打破技术垄断、构建自主生态**的战略路径，不只是公开代码。
- **海外模式**：靠专有软件搭建完整生态 + 开放部分工具链汇聚开发者 → 逐步成为行业技术范式。
- **产业粘性**：成熟编程模型会沉淀算法框架、工具库、开发者经验 → 后发硬件即使性能突破，也必须先适配现有生态才能商业化。
- **国内现状**：AI大模型已有DeepSeek、Qwen、GLM等全球影响力开源成果，但**下一代新型AI硬件的底层编程软件仍是短板**。
- **两大痛点**：
  - 部分厂商长期依附国外软件生态。
  - 分散建设"一芯片一软件栈"的**烟囱式开发** → 重复开发 + 迭代滞后 + 生态割裂。
  说白了，同一段业务代码要翻译成多套"方言"才能跑，工程师精力都耗在适配，没法做真正的算法创新。
- **政策导向**：2026年6月工信部明确提出，提升开源供给能力，加大基础软件、AI等领域开源牵引力度，深化全球开源合作。

### 💡 3D算力芯片为什么是下一代核心方向？

后摩尔时代，**传统2D芯片已撞上"三面墙"**，3D存算融合是破局关键。
- **传统架构瓶颈**：功耗墙、内存墙、通信墙层层限制，**有效晶体管利用率不足40%**。
- **3D芯片优势**：存储单元与计算单元堆叠集成 → 数据搬运距离从**毫米级压缩至微米级** → 带宽大幅提升 + 搬运功耗显著降低。
- **清微智能进展**：第二代可重构芯片采用3D存算一体 + Chiplet多芯粒合封技术，把2D单车道传输升级为"算力多车道+多层存储高架"立体架构；依托可重构计算技术，突破灵活性、能耗比、成本"不可能三角"的最优平衡。
- **硬件≠全部**：正如GPU时代有CUDA，3D芯片也需要统一编程入口，否则再先进的硬件也释放不出全部算力。

### ⚙️ Open3D-PIMC具体解决了什么问题？

它建立了**3D算力芯片的统一编程模型**，从根源破解碎片化困境。
- **开发模式**：开发者只需定义数据分布、任务划分逻辑，框架自动完成算法到硬件的适配与优化。
- **兼容设计**：支持多厂商硬件，各家私有指令集、微架构能力以插件形式保留 → 兼顾开源开放性 + 企业核心技术权益。
- **填补空白**：北京智源AI系统研究负责人门春雷表示，该项目填补了国内3D芯片编译器开源项目的空白。

### 🌐 它背靠的FlagOS生态实力如何？

FlagOS是**全球支持芯片种类最多**的开源AI技术栈，已具备规模化实战能力。
- **共建方**：北京智源人工智能研究院牵头，联合清华、北大、中科院及十余家芯片厂商共建。
- **目标**：一次开发，多芯运行。
- **适配规模**：已适配**20家芯片厂商、30多款AI芯片**，覆盖GPU、NPU、GPGPU、DSA、RISC-V AI、ARM等多元架构。
- **适配效率**：主流大模型最新版本，**一天内完成多芯片同步适配**。
- **实战案例**：2026年8月阿里巴巴发布的Qwen3.8-2.4T-A95B超大规模MoE模型，发布当天即由FlagOS社区完成在华为昇腾、沐曦、清微智能等**9家AI芯片**上的适配验证，实现"Day0多芯片适配"。

### 📈 后续有什么规划？

项目将持续推进**标准化迭代与生态完善**，今年四季度有顶会发布计划。
- **演进方向**：编程模型标准化迭代 + 跨厂商硬件适配 + 开发者工具完善。
- **近期动作**：2026年4季度，将在全球科技顶会发布3D芯片算力最新优化成果。
- **产业配套**：国内3D算力硬件已有布局——清微智能、华为、小米玄戒等企业的3D存算算力产品陆续推出，Open3D-PIMC补齐了软件层面的关键拼图。
- **清微智能进展**：成立八年，可重构算力在全国已部署及在建规模**超5000P**。

### 📝 补充细节
- **梅宏院士观点**：每个呈垄断性的软件领域背后都有对应开源版本，"抱团取暖一直是对抗已经形成的技术垄断的有效手段，而开源则是抱团取暖的最佳方式。"
- **战略意义**：全球AI竞争已从性能比拼演进到生态博弈，谁率先建立下一代硬件的编程模型与开源生态，谁就掌握技术路线定义的主动权。
- **比喻定位**：硬件是"筋骨"，开源软件生态是"血脉"，二者贯通才能让国产算力具备从跟跑到并跑、领跑的系统性力量。
