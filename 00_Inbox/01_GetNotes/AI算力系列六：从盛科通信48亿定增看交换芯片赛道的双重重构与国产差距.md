# AI算力系列六：从盛科通信48亿定增看交换芯片赛道的双重重构与国产差距

### 🔧 超节点为什么把交换芯片推到了核心位置？

**AI训练与推理的通信需求**，把交换芯片从配套器件升级为核心组件。
- **超节点定义**：通过高带宽、低时延互联技术将多张GPU互联的系统架构，具备**大带宽、低时延、内存统一编址**三大特征，不改变单卡算力，通过多卡协同提升算力利用率。
- **需求背景**：MoE架构要求高频All-to-All通信 + 推理侧KV Cache随上下文线性增长 → 传统集群逼近带宽与时延物理极限。

### 📊 超节点时代交换芯片的需求密度提升了多少？

**Scale-Up域需求密度是Scale-Out的3倍**，国产方案配比同样惊人。

| 方案 | GPU/NPU与交换芯片比例 |
| :--- | :--- |
| 传统2层Fat-Tree | 64:3 |
| 英伟达GB300 NVL72 Scale-Up | 4:1 |
| 英伟达GB300 NVL72 Scale-Out | 12:1 |
| 英伟达Vera Rubin NVL72 | 2:1 |
| 华为CloudMatrix 384 | 6:7 |
| 腾讯ETH-X | 8:1 |
| 阿里磐久128 | 8:1 ~ 4:1 |
- **单价梯度**：低端几千元/颗 → 25.6T约**1.7万元** → 51.2T**5万元以上**。
- **市场规模测算**：
  - 国海证券：2026-2028年国产超节点市场 = **889亿 → 4151亿 → 11089亿**元。
  - 华泰证券：2028年国产交换芯片市场**242亿元**，2026-2028年CAGR=**96%**；其中Scale-Up交换芯片**129亿元**，CAGR=**212%**。
  - 国泰海通：2025/2026/2027年中国交换芯片总规模 = 257亿 / 356亿 / 475亿元；国内Scale-Up交换芯片2026-2028年CAGR=**231%**。
  - 银河证券：2025-2030年全球以太网交换机芯片市场CAGR=**43%**。

### ⚡ 光电融合为什么是交换芯片的下一代方向？

**电信号传输已逼近物理极限**，CPO把电光转换从面板移到芯片旁。
- **传统痛点**：电信号在铜线中传输，距离越长、速率越高，能耗与衰减越严重；传统"交换芯片+可插拔光模块"架构中，电信号需沿PCB走线**十几厘米**才完成电光转换；SerDes迈向224G后，有效传输距离大幅受限。
- **CPO（共封装光学）核心思路**：硅光子引擎与交换ASIC封装在同一块基板上 → 电信号刚出芯片就转光 → 传输路径缩至**几毫米**。

### 🏭 国内外CPO进展到哪一步了？

**英伟达已量产，国内厂商集中在51.2T原型与验证阶段**。
- **海外标杆（英伟达）**：2026年8月14日，Spectrum-X Ethernet Photonics全面量产，为全球首款量产的200G/lane共封装光学以太网交换机；基于Spectrum-6芯片，单颗容量**102.4Tb/s**。
  - 性能提升：激光器数量↓**75%** + 功耗↓**80%** + 平均故障间隔时间↑10倍 + 链路损耗从22dB降至4dB。
- **国内厂商进展**：
  - **新华三**："光电并行"路线；2026年5月发布H3C S9800系列102.4T智算交换机，引入CPO/NPO、CPC技术，端口带宽较前代↑100%，端到端时延↓15%，整机能耗↓20%；2026年7月完成800G智算网络全场景互通实测；智擎51.2T国产交换芯片已大规模流片并商用批量供货，102.4T已流片、头部客户小批量验证，大规模交付延后。
  - **曦智科技+盛科通信**：WAIC 2026展示51.2T CPO原型，搭载盛科51.2Tbps交换主芯片 + 曦智自研硅光引擎 + 3D先进光电封装，集成128路400G DR4光接口，核心器件均国内自主生产；双方签署长期CPO战略合作协议。
  - **澜昆微电子**：2026年8月展示国内首个符合OCI标准的WDM微环光I/O芯片；自研NPO/CPO光互连交换卡单卡总带宽最高**6.4Tb/s**；与沐创集成电路联合推出国内首款CPO智能网卡。
  - **跨界布局**：美硕科技参股无锡依芯光互联10%布局OCS全光交换机；万通发展控股数渡科技切入PCIe高速交换芯片；矽安光电2DFA多层孔板系列通过大客户认证并量产。
- **行业判断**：TrendForce指出，CPO已成为下一代高带宽交换机核心发展方向；掌握硅光子设计、光引擎制造与先进封装的厂商，将在2027-2028年CPO放量周期中领先。

### 💰 盛科通信48亿定增把钱花在哪？

**超6成投向下一代交换芯片研发**，同时布局光互联与补流。
- **定增基本信息**：2026年9月1日披露，拟向不超过35名特定对象发行不超过**4100万股**（占总股本10%），募资不超过**48.05亿元**；总募资规模约为2025年全年营收（11.5亿元）的**4倍**。
- **三个募投项目**：
  - **下一代高性能交换芯片研发及产业化**：投入**31.81亿元**，周期4年，面向Scale-Up和Scale-Out场景。
  - **下一代互联软硬件及协议研究**：投入**8.24亿元**，周期3年，攻关光电融合核心技术。
  - **补充流动资金**：**8亿元**。
- **公司现状**：
  - 2023年9月登陆科创板，IPO募资约20亿元；截至2026年6月30日，累计投入20.28亿元，占前次募资净额的**101.18%**，已基本使用完毕。
  - 持续亏损：2023年亏1953万 → 2024年亏6826万 → 2025年亏**1.5亿元**；2026年上半年营收6.71亿元，同比↑32.04%，归母净亏1757万；2025年研发费用率约**59%**。
  - 产品进度：12.8T/25.6T产品已进入客户应用阶段，下一代产品研发推进中。
- **外部风险**：2023年3月3日被美国商务部列入**实体清单**；若进一步制裁，将影响新产品研发与供应链保障；公司预警短期内或仍处于亏损状态。

### 📏 国产交换芯片和海外巨头差多少？

**整体约两代差距**，51.2T节点海外已量产、国内刚突破。
- **海外进度**：
  - 博通Tomahawk 6：2026年3月12日批量出货，全球首款量产**102.4Tbps**交换芯片，从送样到量产不到三个季度，采用台积电**3nm**制程+CPO封装。
  - 英伟达Spectrum-X以太网硅光交换机已全面量产；Marvell同期发布102.4T Teralynx T100。
  - 迭代节奏：25.6T→51.2T→102.4T→204.8T，周期约**2年**；博通SDK与参考设计形成完整生态闭环，客户切换成本极高。
- **国产进度**：
  - **盛科通信**：最高量产25.6T；2024年推出Arctic系列12.8T/25.6T高端芯片，2025年小批量出货；51.2T尚未回片，预计2026年底回片，顺利的话2027年下半年贡献收入。
  - **新华三智擎**：51.2T已商用批量供货；102.4T已流片、头部客户小批量验证（信息来源知了社区，非官方权威）。
  - **中兴微电子凌云**：51.2T已完成头部云厂送测验证，2026年Q3开启批量外供（多来自券商研报，无官方信息）。
- **差距实质**：
  - **制程代差**：海外3nm+CPO vs 国产7nm。
  - **产品节奏**：博通2014年起约2年一代，盛科2024年才推25.6T。
  - **生态壁垒**：博通P4可编程流水线、遥测、智能拥塞等AI特性积累更深，经海量集群验证。
  - **CPO成熟度**：博通共封装生态明显领先。
- **替代窗口**：博通51.2T交期已拉长至**70-80周**，产能优先保障头部客户 → 需求爆发+供给受限为国产替代创造窗口。

### 🏟️ 国产交换芯片竞争格局在怎么变？

**盛科的稀缺性被稀释**，中兴微与新华三加速入局。
- **中兴微电子关键进展（2026年7月）**：三大自研芯片同时进入放量周期
  - 珠峰（领域定制处理器）+ 定海（DPU）+ 凌云（交换芯片）→ 覆盖AI算力全链条。
  - 凌云51.2T：国内首批51.2T商用AI交换芯片，**7nm Chiplet**工艺，36×800G端口，原生RoCEv2无损网络，适配万卡Scale-Up超节点，性能对标博通Tomahawk 5。
  - 商业化：已完成阿里、字节、腾讯送测验证，2026年Q3落地并批量外供，出货量从数万颗向**10万颗**爬坡；凌云102.4T预计2026年Q3流片量产，2027年大规模商用。
  - CPO差异化：自研凌云51.2T + 自研硅光CPO光引擎共封装，取消可插拔光模块，已在阿里、腾讯新建万卡集群批量落地。
- **商业模式差异**：
  - 中兴微：芯片主要内部整机自用+整机绑定销售，对外裸片销售为辅。
  - 盛科：独立第三方芯片商，生态开放性更优，整机厂更愿采用以避免竞争。
- **新华三位置**：中国企业网交换机市场份额**37%**，稳居第一；自研+外购芯片并行。

### 🔮 五年后国产交换芯片可能是什么格局？

存在三种情景，当前盛科市值定价对应最乐观情景。
- **情景一（盛科主导）**：盛科51.2T顺利量产、102.4T如期推进，保持独立第三方定位，占据国产主要份额。
  - 前提：51.2T如期回片验证 + 48亿定增有效转化 + 与曦智CPO深度协同。
- **情景二（二分天下）**：中兴微凭CPO+全栈能力主导云厂商市场，盛科在政企和中小客户保持优势。
  - 前提：中兴微CPO持续验证 + 凌云102.4T如期量产 + 盛科51.2T落后半年以上。
- **情景三（封锁加剧）**：海外供货进一步收紧，国产替代加速但高端仍有代差；51.2T及以下国产主导，102.4T以上依赖非美渠道或等待突破。
- **估值对照**：盛科当前约**1500亿市值**对应125倍PS（2026E），定价的是情景一。
