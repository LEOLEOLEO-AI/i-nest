# Celero 2.75亿美元C轮融资 + OCP无交换机AI网络架构深度解析

### 💰 Celero 这轮融资有多少，估值到什么水平？

**C轮融资2.75亿美元**，估值**超30亿美元**，总融资额达4.15亿美元。
- **公司背景**：2024年成立，总部位于加州尔湾，主打AI数据中心相干DSP（数字信号处理器）芯片。
- **核心产品**：相干数字信号处理器 → 加速光纤数据传输 → 缓解AI负载下的传统网络压力。
- **融资明细**：
  - **领投方**：Atreides Management、Valor Equity Partners、Alphabet旗下CapitalG
  - **跟投方**：现有投资者Sutter Hill Ventures、Maverick Silicon
  - **董事会变动**：Atreides管理合伙人兼CIO Gavin Baker加入董事会

### 🔬 Celero 最新技术突破是什么？

**业界首款2nm相干DSP芯片验证成功**，为下一代AI光互连打基础。
- **技术特点**：集成DSP处理 + 先进模拟技术
- **性能目标**：支持**1.6T至3.2T**高带宽、低功耗连接
- **应用场景**：超大规模AI集群、云数据中心扩展
- **CEO表态**：2nm硅验证证明相干技术可满足下一代AI网络的带宽密度、功率效率和可扩展性需求，新资金将加速产品路线图与生产准备
---
### 🤔 OCP这篇论文在挑战什么传统认知？

**AI数据中心未必需要交换机**，可用无源光互连替代集中式交换设备。
- **论文出处**：2023年OCP Future Technologies Symposium，Cerio CTO Matthew Williams发布《Optical Interconnect: Pathways to an Open AI Infrastructure》
- **传统架构痛点**：
  - 经典模式 = 服务器→ToR→Leaf→Spine层层汇聚
  - AI集群从几百GPU扩到几十万GPU → 成本与功耗压力陡增
- **核心主张**：用无源光互连取代大量集中式交换机，把交换能力分散到每个计算节点
- **提出概念**：SHFL（预布线无源光互连），成为OCP光互连重要探索方向

### 💸 为什么说网络才是AI基建里涨得最快的成本？

**光学互连已占数据中心系统成本约1/4**，且比例仍在上升。
- **成本驱动链**：GPU带宽每代提升 → 网络同步升级（25G→50G→100G→200G）→ 交换ASIC更复杂 + 光模块增加 + PCB难度提升 + 散热功耗上涨
- **绑定困境**：传统网络 = 性能与成本强绑定 → 要更高带宽就得换更高速芯片、更多层级交换机 → 成本线性甚至超线性增长
  说白了，以前大家只盯着GPU贵，现在发现网络设备花的钱越来越多，而且越升级越贵。

### 🧱 SHFL到底是个什么东西，为什么说它不是交换机？

**SHFL是一块无芯片的无源光互连板**，内部全是预连接光纤，本身不做交换。
- **三无特征**：无ASIC、无DSP、无Retimer → 也无电源、风扇、散热器
- **三大属性**：
  - **Passive（无源）**：整个设备无需供电
  - **Prewired（预布线）**：所有光纤路径制造阶段就固定
  - **Distributed（分布式）**：交换能力不在中心ASIC，而在每个计算节点
- **工作逻辑**：数据不在中心交换机选路，而是在节点端完成路径选择 → SHFL只提供固定、低损耗的光连接
- **本质类比**：更像超高密度光纤配线架（Optical Patch Panel），而非传统网络设备

### 🖥️ 交换能力下沉到节点，具体怎么实现？

**每个GPU/CPU节点自带轻量交换逻辑**，不连中心交换机，只连若干邻居节点。
- **分布式交换（Distributed Switching）**：
  - 传统模式：所有数据流经交换ASIC，由交换机决定下一跳
  - AI模式：训练大模型以AllReduce、Broadcast、All-to-All等集体通信为主 → 需要的是多条等价路径，而非复杂包交换
- **直接邻居（Direct Neighbor）**：每个节点只维护有限数量的固定光连接 → 通过多维拓扑形成丰富可达路径 → 实现超大规模扩展
- **结论**：未来负责"交换"的可能不是交换机，而是GPU自己

### 🛤️ 为什么说多路径才是AI网络的核心能力？

**Multipathing（多路径）比交换ASIC端口数量更重要**，路径控制权交给终端节点。
- **传统局限**：Spine-Leaf虽支持ECMP（等价多路径），但路径选择完全依赖交换机
- **SHFL优势**：一份梯度数据可同时沿多条不同路径传输 → 根据拥塞情况动态选最优路线
- **三大收益**：
  1. 热点流量易分散，减少单节点拥塞
  2. 多物理路径天然容错，链路失效可快速绕行
  3. 带宽利用率显著提高，适配AI大规模同步通信

### 🏭 为什么说未来网络是"制造"出来的，不是"部署"出来的？

**SHFL光纤连接全部在工厂预焊固定**，机房只需插模块，不用人工布线。
- **拓扑示例**：Track-Mount Cyclic Topology → 每个节点A口连下一机柜、B口连上一机柜 → 形成循环拓扑 → 可扩展为二维、三维乃至更高维结构
- **对比优势**：vs 人工布放MPO光纤，预布线一致性与可扩展性更强
- **扩容方式**：新增机柜无需重新规划网络 → 插入新SHFL模块 → 新节点自动成为Fabric一部分
- **架构定位**：可组合基础设施（Composable Infrastructure）

### 🔌 PCIe和CXL怎么也能跑在同一张光网上？

**协议与光网络解耦**，SHFL只传光信号，跑什么协议由节点侧决定。
- **资源池化构想**：GPU、内存、FPGA、DPU各自成池 → CPU通过SHFL动态访问远程资源 → 打破服务器物理边界限制
- **预期收益**：资源利用率提升 + 减少重复部署浪费 → 机架平均功耗有望降低约**35%**
- **超前判断**：无需等CXL 3.x成熟也能实现远程内存池化
- **升级逻辑**：协议升级不用换光纤 → 只需替换节点侧Fabric Node → 网络即可完成演进

### 🔄 这种架构的升级维护方式有什么不一样？

**光纤网络长期不动，计算节点可热插拔升级**，光互连变成永久基础设施。
- **系统组成**：永久SHFL光纤网络 + 可热插拔Fabric Node
- **升级流程**：协议变化时 → 拔旧节点、插新节点 → 新设备自动发现拓扑并重建路由
- **核心理念**：基础设施长期化、节点快速迭代 → 与可组合数据中心方向一致

### ⚔️ Cerio路线和NVIDIA路线最大区别在哪？

**NVIDIA做强中心交换机，Cerio做几乎无功耗的无源光纤网**，网络哲学完全相反。

| 维度 | NVIDIA路线 | Cerio路线 |
| :--- | :--- | :--- |
| 核心思路 | 构建更强大的交换机 | 减少交换ASIC，用无源光纤 |
| 交换模式 | 集中交换 | 分布式交换 |
| 控制方式 | 软件定义 + 高性能芯片 | 预布线 + 终端节点控制 |
| 共同目标 | 构建超大规模AI集群 | 构建超大规模AI集群 |

### 📅 这项技术离实际落地还有多远？

**目前仍属前沿探索，未成为主流商业方案**，但部分判断已被验证。
- **已验证趋势**：光模块成本持续攀升 + AI集群探索Dragonfly/Rail/OCS等新拓扑 + PCIe与CXL向资源池化演进
- **落地障碍**：
  - 预布线拓扑降低功耗与成本 → 但牺牲网络灵活性
  - 分布式交换要求终端有更复杂控制能力 → 对软件栈和集体通信算法要求更高
- **核心追问**：当AI数据中心迈向百万GPU规模，我们需要更大的交换机，还是重新定义"交换"本身？

### 📝 补充细节
- **Celero成立时间**：2024年，截至融资时成立仅约2年，总融资4.15亿美元
- **论文发布时间**：2023年OCP峰会，站在2026年视角回看，部分预判已兑现
- **功耗数据口径**：机架平均功耗降低约35%，为论文预期值，非实测数据
- **SHFL命名**：全称为预布线无源光互连，是Cerio提出的概念，后成为OCP探索方向之一
