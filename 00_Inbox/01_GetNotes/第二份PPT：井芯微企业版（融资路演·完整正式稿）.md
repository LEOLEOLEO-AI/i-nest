### 第2页 · 为什么是井芯微？

**标题**：为什么是井芯微？
**副标题**：赛道好、壁垒高、确定性强、弹性大——四重逻辑支撑一次估值重算

**四个数字卡片（横排）**：

- **80%+**
  SRIO国内军口市占率
  → 垄断地位 = 利润底板

- **500家**
  累计行业客户
  → 客户基数 = 第二曲线起点

- **20家**
  民口新增客户（5个行业）
  → 民用突破 = 天花板打开

- **全球唯一**
  单芯片三协议融合
  → 技术壁垒 = 具身智能入场券

**底部：三个问题，一页回答**：
- **为什么是现在**：端边侧AI下沉 + Chiplet产业链重组 + 国产替代加速
- **为什么是井芯微**：SRIO垄断基本盘 + 多协议融合唯一玩家 + 五层能力闭环
- **为什么要重新估值**：从军工芯片PS 8-10x → 互联平台PS 15-20x

### 第3页 · 堵点对应——六大堵点，每一个都有解

**标题**：六大堵点 vs 井芯微能力——一一对应
**副标题**：判断一家互联公司的能力，不看它会不会讲趋势，看这六类问题有没有闭环

| 端边侧六大堵点 | 井芯微的对应能力 | 成熟度 |
|---|---|---|
| **协议异构** | 单芯片融合SRIO+PCIe+以太网+FC；0420桥接芯片实现生态互通 | ★★★★★ 全球领先 |
| **确定性时延** | TSN调度、时间同步、冗余链路、P999时延可设计可验收 | ★★★★☆ 军口已验证 |
| **数据搬移** | RDMA/P2P中间件，100G端口RDMA，减少CPU介入与无效拷贝 | ★★★★☆ 工程化中 |
| **拓扑扩展** | 交换Fabric + 路由调度 + 统一网管，从百节点到万节点可扩展 | ★★★☆☆ 军口场景深 |
| **可靠安全** | 内生安全架构 + RAS设计 + 军品级可靠性验证 + 抗辐照规划 | ★★★★★ 军口标准 |
| **工程交付** | 开发套件 + 验证平台 + 工具链 + 网管系统，平台化交付 | ★★★★☆ 快速完善中 |

**底部金句**：
> 前三项（协议/时延/数据搬移）是"能不能活"的问题——井芯微已经跑通了。
> 后三项（拓扑/安全/交付）是"能走多远"的问题——井芯微正在从军口向民口快速复制。
> **六类堵点都有对应产品和工程闭环，这在国内互联公司里是独一份。**

### 第4页 · 爆点对应——五大爆点，卡位全部

**标题**：五大产业爆点，每一个都站在入口
**副标题**：不是押注一个赛道，是一套底座打五个爆点

| 爆点 | 趋势 | 井芯微的位置 | 卡位 |
|---|---|---|---|
| **AI下沉** | 推理从云端走向边缘，45%企业级推理在端侧完成 | PCIe交换 + RDMA + 边缘AI盒子互联 | 端侧算力的"数据枢纽" |
| **具身智能** | 机器人从预编程走向世界模型驱动，多传感器融合是刚需 | 多协议融合交换 = 具身智能的"神经中枢" | 多模态融合入口 |
| **Chiplet/晶上系统** | 从单芯演进到系统集成，互联走进封装级、晶上级 | SDSoW专项核心参与方，晶圆级互联方向 | 晶上时代的"系统架构师" |
| **低空经济** | 2026年突破万亿，无人机/eVTOL/低空监管同步起量 | SRIO + PCIe + TSN，机载+空地协同全覆盖 | 低空智能装备的"航电互联底座" |
| **国产替代加速** | 出口管制升级，国产替代从"可选"变"必选" | SRIO已80%+，PCIe快速突破，多协议融合是空白 | 军民双体系桥接的唯一选择 |

**底部金句**：
> 五个爆点，任何一个爆了都是超预期。
> 就算只有一两个成了，也够支撑未来3年的增长。
> **这就是"一套底座打天下"的好处——东方不亮西方亮，风险分散，弹性叠加。**

### 第5页 · 技术壁垒——三层护城河

**标题**：三层护城河——为什么这个位置别人拿不走
**副标题**：协议积累是地基，软件栈是城墙，生态位是护城河

**三层金字塔（从下到上）**：

**第一层：异构协议积累（地基）**
- SRIO + PCIe + 以太网 + FC，单芯片三协议融合全球唯一
- 每种协议都需要年深日久的调试和验证，多协议融合不是功能叠加，是架构级重构
- 国内没有第二家能在单芯片里做到同样的协议覆盖度
- **类比**：就像一个人同时精通英语、中文、日语、西班牙语，还能做同声传译——不是学不会，是需要时间堆

**第二层：SDI软件栈（城墙）**
- 芯片 + IP + 中间件 + 网管 + 工具链，五层能力闭环
- 硬件可以抄，软件栈和工具链抄不走——客户的系统是围绕你的软件栈建的
- 客户一旦导入，迁移成本极高——不是换一颗芯片的事，是换整个开发环境
- **类比**：英伟达的护城河不是GPU硬件，是CUDA生态。井芯微的护城河也不是交换芯片，是SDI软件栈 + 多协议融合能力。

**第三层：生态位（护城河）**
- 军口垄断地位 + SDSoW专项核心参与 + 联合定义客户 + 军民双体系桥接
- 生态位不是技术问题，是时间、信任、关系、标准参与的综合结果——别人有钱也买不到
- 一旦占据了"军民双体系桥接者"的位置，后来者几乎没有翻盘机会
- **类比**：就像一个城市的交通枢纽——一旦建好了，所有人都从这里走，没人会再建一个一样的

**底部金句**：
> 第一层让你"能做别人做不了的产品"。
> 第二层让你"客户用了就离不开"。
> 第三层让你"站在别人挤不进来的位置上"。
> **三层叠加，就是井芯微真正的壁垒。**

### 第6页 · 范式跃迁——Chiplet与晶上系统的生态位机会

**标题**：Chiplet与晶上系统——互联公司的历史性机遇
**副标题**：产业链正在重组，互联第一次有机会从"配角"变成"系统定义者"

| | 旧范式（单芯片时代） | 新范式（Chiplet/晶上时代） |
|---|---|---|
| **产业链分工** | 设计公司定义芯片 → 制造 → 封测 → 组装 | 标准芯粒 + 先进封装 + 互联架构 + 软件定义系统 |
| **互联角色** | 周边器件、被动配套 | 系统骨架——芯粒怎么摆、怎么连、怎么调度，全由互联定义 |
| **价值分配** | 芯片设计拿大头（60-70%） | 互联与系统调度价值占比大幅上升（30-50%+） |
| **迭代速度** | 2-3年一代，跟着制程走 | 3-6个月一代，靠芯粒组合迭代 |

**中部：美国的验证**
- DARPA等机构持续投入先进封装与芯粒标准
- 核心思路：**不靠先进制程卡脖子，靠系统集成和架构创新超车**
- 这和中国的"SDI/SDSoW"路线异曲同工——殊途同归

**底部：井芯微的位置**
- 深度参与国家SDSoW重大专项（晶圆级互联网络方向）
- 不是"蹭概念"，是晶上时代的核心工程实现方
- 今天的估值不依赖它（军口+民口已经撑得住）
- 但如果路线跑通了，井芯微就不是"一家互连芯片公司"——而是**晶上时代的基础设施提供商**

**最底部金句**：
> 这是一笔免费的期权——下行有军口利润底板，上行有范式跃迁的想象空间。
> 就算晶上系统晚来两年，公司该增长还是增长。
> 但如果它真的来了，今天的估值就是地板价。

### 第7页 · 中心侧vs端边侧对标——盛科vs井芯微

**标题**：中心侧对标盛科——为什么端边侧的风险收益比更好？
**副标题**：同样是互联赛道，中心侧和端边侧的投资逻辑完全不同

| 维度 | 中心侧（盛科模式） | 端边侧（井芯微模式） |
|---|---|---|
| **赛道** | 以太网交换，数据中心 | 多协议融合，端边侧全场景 |
| **市场规模** | 大（百亿美金级） | 中到大（百亿美金级，分散） |
| **竞争格局** | 博通一家独大，国内追赶 | 无单一巨头通吃，多协议融合是空白 |
| **技术门槛** | 极高（先进制程+高速SerDes+生态） | 高（多协议融合+确定性+可靠性） |
| **风险** | 高（制程卡脖子+巨头碾压） | 中低（28nm/16nm可满足+军口打底） |
| **国产化率** | <10%，替代极难 | 15-20%，军口已80%+ |
| **PS估值** | ~30x（市场给的是赛道溢价） | ~13x（市场还在按军工芯片估） |
| **确定性** | 中低（要看制程突破和客户突破） | 高（军口基本盘稳，民口在验证） |
| **弹性** | 高（一旦突破空间巨大） | 中高（五个爆点+范式跃迁期权） |

**底部：为什么端边侧的风险收益比更好？**
> 盛科的逻辑是"在巨人的战场上硬碰硬"——赢了赚大钱，输了可能颗粒无收。
> 井芯微的逻辑是"在巨人的盲区建根据地"——军口已经赢了，民口在复制，范式跃迁还有额外期权。
> **对机构而言，端边侧不是"退而求其次"，是"胜率更高、赔率不差"的更优选择。**

### 第8页 · 估值重算——三重戴维斯双击

**标题**：估值重算：2026年是杠杆最大的一年
**副标题**：扭亏、放量、定位切换——三重戴维斯双击叠加

**三重双击（从上到下）**：

**第一重：业绩双击（扭亏为盈）**
- 2025年：亏损2945万
- 2026E：盈利1645万，同比转正
- 估值体系从"看营收"到"看利润+营收"双轨
- **影响**：从"故事股"切换到"成长股"，估值中枢上移

**第二重：增长双击（第二曲线放量）**
- 从"单产品线"（SRIO）→ "双产品线"（SRIO+PCIe）
- 从"纯军口"→ "军民双轮"
- 从"卖芯片"→ "卖方案"（2026年已有2单解决方案订单）
- 增长确定性大幅提升 → 估值溢价
- **影响**：增长曲线从"稳健"变成"加速"，PS倍数提升

**第三重：定位双击（估值切换）**
- 旧定位：军工芯片公司 → PS 8-10x
- 新定位：端边侧互联平台公司 → PS 15-20x
- 可比公司锚：盛科PS ~30x、裕太微PS ~20x
- 井芯微当前PS ~13x → 被低估
- **影响**：同样的营收，估值差一倍

**底部：三场景测算**

| 场景 | 2030年营收 | PS倍数 | 估值 | 4年回报倍数 |
|---|---|---|---|---|
| **保守**（仅军口增长） | 3亿 | 15x | 45亿 | ~3.5x |
| **中性**（按计划推进） | 4.63亿 | 20x | 92.7亿 | ~7x |
| **乐观**（PCIe超预期+SDSoW落地） | 8亿 | 25x | 200亿 | ~15x |

**最底部金句**：
> 保守场景4年3.5倍，中性场景4年7倍，乐观场景4年15倍。
> **下行有军口利润底板，上行有民口放量+范式跃迁的双重弹性——这就是非对称投资机会。**

### 第9页 · 机构为什么看好井芯微？

**副标题**：四个维度，每一个都指向同一个结论

- 多协议融合是结构性空白，竞争格局友好

- **一句话**：别人想进，不是钱的问题，是时间和生态的问题

**底部综合评价**：
