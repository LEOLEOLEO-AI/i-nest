### 🧠 生物大脑的通信方式是什么？

大脑用**离散脉冲**传递信息，不是连续数值。
- **神经元数量**：约 **860亿个**
- **脉冲特点**：持续约 **1毫秒**、幅度固定，只有"发/不发"两种状态
- **信息载体**：脉冲的**时机和频率**，类似摩尔斯电码
- **通信模式**：长时间静默 → 短暂发放 → 继续静默

### 🆚 传统深度学习和大脑差在哪？

传统人工神经网络（ANN）和生物大脑**差异极大**。
- **ANN神经元计算**：输入乘权重求和 → 套平滑函数 → 输出连续实数（如0.7382）
- **核心区别**：ANN输出每时每刻都有值，生物神经元只在特定时刻发放脉冲
- **形象比喻**：ANN和大脑的关系 ≈ 热狗和狗的关系

### ⚙️ 脉冲神经网络（SNN）的神经元怎么工作？

SNN用**LIF模型**（泄漏-积分-发放）模拟生物神经元，像一个漏水的桶。
- **核心比喻**：
  - 接水：上游脉冲 → 往桶里加水
  - 漏水：水位随时间自然下降（泄漏系数 β，0~1）
  - 溢出：水位超阈值 θ → 发放脉冲 + 桶清空重置
  - 不应期：发放后短暂不响应
- **离散更新公式**：u[t] = β·u[t−1] + W·s[t−1] + I_ext[t]
  - u[t]：当前膜电位（水位）
  - β：泄漏系数，越小漏得越快、神经元越"健忘"
  - W·s[t−1]：上游脉冲乘突触权重（W>0兴奋、W<0抑制）
  - I_ext[t]：外部注入电流
- **发放规则**：u[t] ≥ θ → s[t]=1 并重置u为0；否则s[t]=0
- **伪代码流程**：每步先泄漏 → 加上游脉冲输入 → 加外部电流 → 判断是否发放 → 传给下游

### 📡 SNN里的信息怎么编码？

脉冲只有0/1，信息藏在**统计规律**里，主要有三种方式。

| 编码方式 | 核心逻辑 | 特点 |
| :--- | :--- | :--- |
| 频率编码 | 刺激越强，发放越频繁 | 最直白常用，取时间窗口平均 |
| 时间编码 | 精确到毫秒的发放时机 | 反应快，机制复杂 |
| 恒流直接注入 | 每步注入恒定电流 | 完全确定可复现，适合实验 |
- **频率编码公式**：发放率 r = 脉冲总数 / (神经元数 × 时间步数)
- **恒流注入优势**：同样输入永远得到同样结果，满足科学实验可复现要求

### 📊 SNN和ANN、生物大脑比怎么样？

SNN**更接近生物大脑**，但学习算法仍是难题。

| 维度 | 传统ANN | SNN | 生物大脑 |
| :--- | :--- | :--- | :--- |
| 信号形式 | 连续实数 | 离散0/1脉冲 | 离散脉冲 |
| 时间概念 | 无，逐层计算 | 沿时间步演化 | 持续奔流 |
| 稀疏性 | 每层都输出 | 大部分时间沉默 | 高度稀疏 |
| 能耗 | 极高 | 极低（事件驱动） | 约20瓦（灯泡） |
| 学习方式 | 反向传播 | 无公认方案 | 突触可塑性 |
- **SNN优势**：事件驱动的稀疏计算 → 仅处理发放的神经元 → 计算量和能耗大幅下降
- **典型应用**：低功耗神经形态芯片（如Intel Loihi）
- **SNN痛点**：脉冲不可导 → 反向传播梯度断裂 → 需代理梯度等近似方案
- **果蝇项目特殊点**：不需要训练网络，权重直接从真实大脑连接数据"抄"来

### 📝 三个必记核心概念
1. **脉冲**：神经元唯一语言，信息在发放时机与频率里
2. **LIF模型**：神经元 = 漏水的桶，水位超阈值就发放清空
3. **编码方式**：频率编码最常用，恒流注入最利于复现
