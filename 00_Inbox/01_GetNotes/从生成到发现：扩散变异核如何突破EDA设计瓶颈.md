# 从生成到发现：扩散变异核如何突破EDA设计瓶颈

### 🔍 生成和发现到底差在哪？

**发现**必须同时满足**训练语料之外**、**满足硬性结构约束**、**胜过已有设计**三个条件。
- **生成模型**：学的是「合法设计长什么样」，采样结果在训练分布内。
- **真正的发现**：产出训练分布外的新结构，且在外部评估器下优于现有设计。

### 🧩 SteerGenSE 框架的核心思路是什么？

**扩散模型只负责生成可行结构**，所有判定权交给外部工程工具。
- **提出机构**：伊利诺伊大学芝加哥分校 + Intel，发表于 arXiv。
- **核心分工**：扩散模型 → 提供可行性结构；外部工具 → 仿真、形式验证、工业级物理实现流程。
- **三个验证空间**：32位前缀加法器、模拟放大器、宏单元布局。

### 🚧 为什么设计发现这么难？

**合法设计流形极稀疏 + 评估昂贵且黑盒**，导致新颖结构难寻。
- **难点一：合法设计极度稀疏**：随手生成的电路图大多无法通过仿真或物理约束。
- **难点二：新颖远难于优化**：发现全新拓扑比微调已知结构难度高几个量级。
- **难点三：评估又贵又黑盒**：SPICE、OpenROAD、SAT solver 无梯度可传，代理模型易被「钻空子」。
- **现有范式缺陷**：生成模型不把评估反馈带回后续提议；进化算法靠手工变异算子；代理模型优化容易失真。

### 🔄 扩散变异核是怎么工作的？

**把扩散模型直接变成搜索算子**，无需额外训练。
- **核心观察**：反向扩散不只是解码工具，更是合法工件之间的转移机制。
- **操作方式**：对父代设计加噪到步数 γT 再降噪 → 得到转移核 K_γ。
  - γ=0 → 恒等映射（局部精修）
  - γ=1 → 接近无条件采样（广域探索）
  - 布局/前缀加法器用 γ=0.3，模拟电路用 γ=0.5
- **与现有方法的区别**：
  - vs 生成模型：学 p(x) 但实现 p(x′|x)，支持评估反馈塑造后续提议
  - vs 进化搜索：变异算子从数据中学得，可跨表示迁移（motif图、类别网格、连续坐标通用）
  - vs 代理优化：扩散模型从不预测目标值，性能完全由外部评估器判定（surrogate-free 无代理模型）

### ⚡ 轨迹感知引导怎么省算力？

**中途剪枝无望轨迹 + 重分配算力**，把钱花在刀刃上。
- **两类控制信号**：
  - 当前噪声状态 → 只用于排序和算力分配，**绝不终止轨迹**（噪声态常自我恢复）
  - 预测的干净终点 → 唯一允许剪枝的信号（依据悬空连接数）
- **剪枝校准**：用 conformal risk control（共形风险控制），α=0.1，误剪成功轨迹概率被约束在 10% 以内。
- **算力重利用**：sequential Monte Carlo 重采样，按健康度填充被剪枝的槽位，限制克隆数保多样性。
- **效果**：128 次 SPICE 评估预算下，结构有效性和仿真成功率最优。

### 📊 三个设计空间的硬结果如何？

**加法器双指标碾压经典结构，放大器发现全新拓扑，布局线长大幅缩短**。

#### 前缀加法器：可穷举验证的功能架构
- **训练语料**：16,269 个唯一 32 位结构，覆盖 ripple、Sklansky、Kogge-Stone、Brent-Kung 等。
- **验证流程**：结构检查 → 结构化 Verilog 导出 → SAT solver 形式验证（证明 2^64 组输入全正确）→ 工艺映射后复验。
- **性能指标**：NanGate45 工艺下，最快架构延迟 **0.302 ns**、面积 **373 μm²**，比 Kogge-Stone **延迟低 17%、面积小 18%**。
- **新颖性**：384 个零样本中 325 个不在训练语料，16 个通过全部验证；靠削减中间依赖（而非重调度）减少了 33 个前缀算子。

#### 模拟放大器：轨迹引导收益最大
- **表示方式**：端子感知关联表示，扩散作用在 261 个自动挖掘的 motif 子电路图上。
- **搜索配置**：48 个设计、20 代，内层 NSGA-II 尺寸优化，ngspice 仿真。
- **结果数据**：三次运行共 2,432 个拓扑 → 1,277 个通过仿真 → 22 个进 Pareto 前沿 → **7 个验证为新发现**。
  - 增益范围：**21.9–66.1 dB**
  - 带宽范围：**72.9 kHz–207 MHz**
  - 功耗范围：16.2–696 mW
  - 面积代理：57.7–471 μm²
- **非规范机制**：包含多条增强型输入输出路径、内部节点与输出间的再生回路（提升小信号增益）。
- **引导效果**：结构有效性从 24.2% 提升到 **72.3%**，Pareto hypervolume 从 20.5 提到 27.1。

#### 宏布局：跨空间迁移能力验证
- **模型配置**：T=200 步连续扩散，每宏一个 token 的 Transformer，attention 注入网表连通性。
- **测试基准**：TILOS MacroPlacement + OpenROAD-flow-scripts 九个设计。
- **核心结果**：
  - nvdla：16 个零样本全部跑赢 OpenROAD Auto，搜索后达 **0.68× Auto 线长**
  - ariane136（训练未见过）：0.91× Auto
  - 另有四个留出设计优于 Auto
- **局限**：混合尺寸集合在 bp_quad 上退化到 1.07× Auto（attention 未捕捉长宽比）。

### 🧪 消融实验证明了什么？

**先验、变异核、外部评估反馈三者缺一不可**，退化程度由表示结构决定。
- **去掉变异核（换随机变异）**：
  - 模拟电路：SPICE 可评分后代从 28 → 0，Pareto 拓扑从 5 → 0
  - 布局：直接退回种子
  - 前缀加法器：hypervolume 保住但前沿从 22 缩到 8
- **去掉先验（随机初始化）**：全面落后于完整方法
- **去掉评估反馈**：
  - 前缀加法器前沿从 22 缩到 14
  - nvdla 布局从 0.68× 退到 0.847× Auto
  - 已验证模拟拓扑从 7 个（66.1 dB）降到 3 个（36.2 dB）

### 💡 关键洞察
- **纪律感是核心**：模型只学「可行转移」，判定权全交给不可欺骗的工程工具，这套证据链远超多数 AI-for-EDA 论文。
- **真正的新结构出现**：放大器中的再生回路等非规范机制，说明扩散变异核是在合成新结构而非重组旧模式。
- **没有万能配置**：搜索控制必须匹配设计空间几何——符号空间用 conformal 剪枝，连续空间用可微代理引导更有效。
- **商用尚早但路线明确**：「生成模型学演化而非学分布」的思路，值得 EDA 和模拟设计团队跟踪。
