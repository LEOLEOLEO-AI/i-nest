# 晶上软件定义拓扑织构（ToFu）互连架构申报方案

# 晶上软件定义拓扑织构互连架构与关键技术研究（申报方案）

## 一、项目名称

晶上软件定义拓扑织构互连架构与关键技术研究
（英文：Topologically Fused Wafer Fabric, ToFu）

## 二、立项依据与研究意义

### 2.1 问题背景

当前智能计算系统面临三重瓶颈：

**通信墙**：大模型训练中集合通信占总时间的30%-60%，模型越大、并行度越高，通信占比越大，大规模扩展性受限于互连效率。

**工艺墙**：摩尔定律放缓，单纯依赖先进工艺制程提升性能的边际效益递减，行业亟需架构层面的创新路径。

**拓扑墙**：现有晶圆级系统（如Cerebras WSE）采用固定2D Mesh拓扑，无法适配不同应用的多样化通信模式——规则稠密计算效率高，但全局集合通信、稀疏交换、图计算等场景下，固定拓扑的跳数多、延迟高、带宽利用率低。

### 2.2 国内外研究现状

国际上已在多个方向探索突破：

- **晶圆级集成**：Cerebras WSE-2实现85万核单晶圆集成，验证了晶圆级计算的技术可行性，但采用固定2D Mesh拓扑，全局通信效率受限。
- **可重构数据流**：SambaNova SN40L通过可重构数据流架构实现算子级深度融合，推理性能优于H100，但互连重构粒度限于算子级，系统级拓扑不可变。
- **光电路交换**：Google TPU v4/v5采用OCS光电路交换实现机间拓扑重构，支持多种拓扑切换，但重构粒度为机间级，且仅支持有限几种预设拓扑。
- **网内计算**：NVIDIA SHARP、华为灵衢交换机将集合通信卸载到交换芯片，显著降低通信延迟，但均为机架/数据中心级，且基于固定拓扑的分组交换。

**共性不足**：上述技术分别在晶圆级制造、数据流重构、光交换拓扑、网内计算等单点上取得突破，但尚未在晶圆级尺度上形成"拓扑可重构 + 多模交换 + 网内计算 + 全系统协同"的统一架构范式。

### 2.3 本项目的核心思想

提出**拓扑织构（ToFu）**的架构理念：以拓扑为第一性变量，通过软件定义的三模混合交换机制，在晶圆尺度上构建可动态重构的互连织物，实现计算、通信、存储的全隐藏协同。

核心创新逻辑：

> **拓扑不再是计算的附属管道，而是决定系统效能的第一性变量。** 通过物理层拓扑的软件定义重构，让互连结构精准匹配应用的通信模式，从架构层面突破固定拓扑的效率天花板。

## 三、研究内容

### 研究内容一：三模混合交换的软件定义可编程互连芯粒架构

**针对指南要求**：软件定义可编程互连芯粒架构、可扩展动态组网机制、动态切换与可编排互连

**研究目标**：研制支持电路交换/虚电路交换/分组交换三种模式混合的软件定义互连（SDI）芯粒，作为拓扑织构的基本交换单元。

**具体研究内容**：

1. **三模共享交换微架构设计**
  - 设计统一的交叉开关矩阵，通过时分复用（TDM）时隙划分，动态支持电路交换、虚电路交换、分组交换三种模式
  - 电路交换模式：全时隙预留，零缓冲直通，提供最低延迟的大块数据传输通路
  - 虚电路交换模式：部分时隙预留，端到端确定性带宽/延迟保证，支持细粒度带宽分配
  - 分组交换模式：剩余时隙动态共享，分布式路由，承载不规则控制流量
  - 创新点：同一套物理交换资源支持三种模式，面积效率远高于三套独立交换平面
2. **源同步低延迟中继技术**
  - 针对晶圆级长线传输，采用源同步（source-synchronous）设计，避免全局时钟分布难题
  - 电路交换/虚电路模式下，中继节点直通转发，每跳延迟降至亚周期级
  - 已有流片验证：Intel 22nm混合NoC的电路交换模式每跳延迟仅407ps
3. **可扩展动态组网机制**
  - 设计层次化SDI控制平面：本地控制器负责带内交换配置，全局控制器负责跨带拓扑编排
  - 支持芯粒级的级联扩展，从4倍光罩局部验证区域平滑扩展至完整晶圆级规模
  - 双缓冲配置切换机制：新配置预加载到备用寄存器，验证无误后一键切换，实现无损重构

**关键技术指标**：

- 交换模式：≥3种（电路交换、虚电路交换、分组交换），远超指南要求的≥2种
- 单芯粒端口数：≥16个双向端口
- 电路交换每跳延迟：≤2个时钟周期
- 虚电路带宽粒度：≤1/16链路带宽
- 动态切换时间：≤1μs（虚电路级），≤100μs（电路交换级）

---

### 研究内容二：近邻-长程双层拓扑织构与晶圆级高密度互连

**针对指南要求**：晶圆级高密度互连架构、跨区域布线、电热协同设计、可制造可测试

**研究目标**：基于4倍光罩重复套刻的工程约束，设计近邻-长程双层互连拓扑结构，实现以5-10%的互连资源增量换取40%以上全局通信效率提升的效果。

**具体研究内容**：

1. **近邻-长程双层互连架构**
  - **近邻层**：2D Mesh规则近邻互连，提供高聚集的局部通信能力（对应小世界的高聚集系数）
  - **长程层**：稀疏分布的长程直连链路（约占总链路数的5-10%），提供低跳数的全局直达能力（对应小世界的短平均路径）
  - 两层协同工作，同时保证局部通信效率和全局通信效率
  - 理论基础：复杂网络小世界效应——少量长程连接即可显著降低平均路径长度，已有晶圆级光互连实验验证该效应可带来40%的延迟降低
2. **面向4倍光罩约束的分层布线方案**
  - **1倍光罩内**：固定金属布线，计算带内部核间通信
  - **1-2倍光罩（邻罩边界）**：通过A/B两版光罩的边界连接图案组合，实现可定制的长程直连物理链路
  - **2倍光罩以上**：通过SDI芯粒的虚电路/电路交换中继级联，构建等效的全局长距通路
  - 中继方式采用直通式转发，每跳延迟远低于传统分组交换路由器
3. **电热协同设计与可制造性优化**
  - 长程链路的功耗密度分布建模与热优化
  - 冗余链路设计与良率提升方法
  - 晶圆级可测试性设计（DFT），支持边界扫描和内建自测

**关键技术指标**：

- 局部互连设计区域：≥4倍光罩（满足指南要求）
- 长程连接占比：5-10%
- 全局平均通信跳数降低：≥40%（相比固定2D Mesh）
- 网络聚集系数：≥0.5（保持局部高效通信）
- 支持扩展至：12英寸晶圆规模（满足指南要求）

### 研究内容三：拓扑自适应演化与网内计算加速技术

**针对指南要求**：拓扑自适应演化规则、复杂拓扑自动生成、负载动态适配、网内通信加速与路由重构、不少于3种集合通信的网内硬件加速

**研究目标**：建立面向典型智能计算负载的拓扑自动生成与动态适配方法，实现集合通信的网内硬件加速，验证拓扑织构架构在大模型训练/推理等场景下的效能增益。

**具体研究内容**：

1. **面向典型通信模式的拓扑自动生成算法**
  - 分析大模型训练（数据并行、张量并行、流水线并行、专家并行）和科学计算（MPI集合通信）的通信模式特征
  - 研究基于通信模式的拓扑优化生成算法，自动输出最优拓扑配置
  - 支持≥6种拓扑形态的自动生成与映射：
  1. 2D Mesh（基准，通用局部计算）
  2. 规约树拓扑（AllReduce/Reduce-Scatter加速）
  3. 小世界拓扑（All-to-All/MoE全局交换）
  4. 环形拓扑（流水线并行/环形AllReduce）
  5. 广播树拓扑（权重广播/KV缓存分发）
  6. 胖树拓扑（多级全局汇聚）
2. **拓扑自适应演化与负载动态适配机制**
  - 运行时通信模式监测与识别（基于性能计数器的流量特征提取）
  - 拓扑配置的预生成与快速切换（编译时预生成多种候选拓扑，运行时在毫秒级时间内切换）
  - 双缓冲无损切换：切换过程不中断正在进行的通信
3. **网内集合通信硬件加速**
  - 在SDI芯粒中集成规约计算单元（加法、最大值、最小值，支持FP16/BF16精度）
  - 利用可重构拓扑构建最优集合通信物理路径（如AllReduce走物理规约树）
  - 支持不少于3种集合通信的网内硬件加速：
  1. AllReduce（规约树拓扑 + 网内规约）
  2. AllGather / Reduce-Scatter（环形/树形拓扑）
  3. All-to-All（小世界拓扑 + 虚电路交换）
  
    ：NVIDIA SHARP和华为灵衢在交换机级实现了集合通信卸载，本项目将其下沉到晶上SDI芯粒，延迟降低一个数量级以上
4. **拓扑感知的计算-通信协同调度**
  - 研究拓扑驱动的计算核映射方法，让通信密集的计算单元在物理上"邻近"
  - 实现计算与通信的深度重叠，进一步提升系统效能
  - 借鉴SambaNova数据流架构的计算-通信融合思想，但提升到拓扑级优化的维度

**关键技术指标**：

- 可重构拓扑种类：≥6种（满足并超过指南≥5种的要求）
- 单晶圆内拓扑动态重构时延：≤100μs（远优于指南≤1ms的要求）
- AllReduce端到端延迟降低：≥60%（相比固定Mesh + 软件算法）
- 集合通信吞吐提升：≥3倍
- 网内加速的集合通信模式：≥3种（满足指南要求）

### 研究内容四：物理拓扑可重构的晶圆级网络原型芯片研制与验证

**针对指南要求**：物理拓扑可重构的晶圆级网络原型芯片、多拓扑形态/多通信模式/多负载类型的应用验证、12英寸晶圆规模模拟验证

**研究目标**：研制物理拓扑可重构的晶圆级网络原型芯片，完成功能验证和性能评估，建立12英寸晶圆规模的仿真验证平台。

**具体研究内容**：

1. **4倍光罩验证芯片设计与流片**
  - 基于4倍光罩重复单元（A/B两版光罩交错），设计完整的拓扑织构互连验证芯片
  - 包含：SDI互连芯粒、近邻-长程双层布线、网内计算单元、配置控制模块
  - 工艺节点：选择成熟工艺节点（如28nm或12nm），优先保证架构验证和良率
2. **12英寸晶圆规模仿真平台**
  - 建立晶圆级规模的互连网络仿真平台（支持≥12英寸晶圆规模的网络建模）
  - 支持多拓扑形态、多通信模式、多负载类型的仿真验证
  - 仿真内容：延迟、吞吐、能效、热分布、良率分析
3. **典型场景应用验证**
  - **大模型训练场景**：验证数据并行AllReduce、张量并行All-to-All等集合通信加速效果
  - **大模型推理场景**：验证权重广播、KV缓存交换等推理通信模式的优化效果
  - **科学计算场景**：验证MPI标准集合通信模式的加速效果
  - 每种场景下对比固定Mesh拓扑的性能提升

**关键技术指标**：

- 原型芯片设计区域：≥4倍光罩（满足指南要求）
- 仿真验证规模：≥12英寸晶圆（满足指南要求）
- 验证拓扑形态：≥6种
- 验证通信模式：≥3种集合通信 + 多种常规通信模式
- 验证负载类型：≥3类（大模型训练、大模型推理、科学计算）

## 四、技术路线与可行性分析

### 4.1 总体技术路线

```

                    │              │              │
                    └──────────────┼──────────────┘
                                   ▼
架构创新层      拓扑织构（ToFu）架构 — 拓扑第一性的全协同设计
                                   │
         ┌─────────────────────────┼─────────────────────────┐
         ▼                         ▼                         ▼
关键技术层   三模混合SDI芯粒      近邻-长程双层拓扑      拓扑自适应+网内计算
         │                         │                         │
         └─────────────────────────┼─────────────────────────┘
                                   ▼

                                   │
                                   ▼

```

### 4.2 可行性分析

**理论可行性**：

- 小世界网络效应已被复杂网络理论严格证明，5-10%长程连接即可显著降低平均路径长度
- 混合电路/分组交换NoC已有多项流片验证，Intel 22nm工艺下实现了每跳407ps的电路交换延迟
- TDM虚电路的QoS保证能力已被学术界充分研究
- 网内计算加速集合通信已在工业界（NVIDIA SHARP、华为灵衢）得到产品化验证

**技术可行性**：

- 晶圆级集成工艺：Cerebras已验证12英寸晶圆级芯片的制造可行性
- 4倍光罩重复设计：符合常规DUV光刻工艺能力，工程风险可控
- SDI芯粒设计：基于成熟数字电路设计方法，核心创新在架构层面，不依赖激进的器件创新
- 仿真工具链：已有成熟的NoC仿真工具（Booksim、Noxim等），可扩展至晶圆级规模

**工程可行性**：

- 第一阶段（1-2年）：架构设计 + FPGA仿真 + 小芯片验证，风险低，确定性高
- 第二阶段（2-3年）：4倍光罩验证芯片流片，中等风险，有成熟工艺支撑
- 第三阶段（3-4年）：晶圆级规模仿真 + 应用验证，以仿真为主，流片为辅，风险可控

## 五、创新点

### 创新点一：架构原创——三模混合交换的软件定义互连芯粒

首次提出电路交换/虚电路交换/分组交换三模混合的SDI芯粒架构。不同于传统方案中多种交换模式各自独立、硬件冗余的设计，本方案通过TDM时隙划分实现同一交叉开关矩阵对三种模式的共享，以20-30%的面积增量获得3-5倍的通信延迟降低和2-3倍的能效提升。

### 创新点二：方法创新——近邻-长程双层拓扑织构

将复杂网络的小世界效应首次工程化应用于晶圆级互连架构设计。通过近邻Mesh保证局部通信效率，通过5-10%的稀疏长程连接大幅降低全局通信跳数。结合物理直连（2倍光罩内）+ SDI中继（2倍光罩外）的分层长距实现方案，在4倍光罩重复套刻的工程约束下，实现全局平均跳数降低40%以上。

### 创新点三：范式创新——拓扑第一性的计算-通信-存储全协同

提出"拓扑第一性"的架构设计理念：拓扑不是计算的附属管道，而是决定系统效能的第一性变量。通过拓扑的软件定义重构，让计算、通信、存储在拓扑结构中自然协同，实现集合通信延迟降低60%以上、系统级训练效率提升30-80%的效果，探索一条不单纯依赖先进工艺的算力提升新路径。

### 创新点四：系统创新——拓扑可重构与网内计算的深度融合

将网内计算从"固定拓扑上的协议优化"升级为"拓扑重构下的物理路径优化"。不同于NVIDIA SHARP、华为灵衢等在固定拓扑交换机上做集合通信卸载，本方案可根据集合通信的类型动态重构出最优物理拓扑（如AllReduce走物理规约树），数据在传输路径上直接完成计算，实现数量级的通信加速。
