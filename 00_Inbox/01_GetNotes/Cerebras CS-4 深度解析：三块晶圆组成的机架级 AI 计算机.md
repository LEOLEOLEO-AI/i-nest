# Cerebras CS-4 深度解析：三块晶圆组成的机架级 AI 计算机

### 🏗️ CS-4 整体架构长什么样？

CS-4 是**前后分区的机架级系统**，前部供电、后部装 3 只计算背包。
- **发布时间**：**2026 年 8 月 18 日**，由 Cerebras 发布。
- **核心组成**：Nexus 机架 + 3 只 Wafer-Scale Backpack，每只背包内置 1 块 **WSE-3T 晶圆级引擎**。
- **前后分工**：
  - 前部 = 共享电源系统，最多接入 **6 路硬接线交流电**。
  - 后部 = 纵向挂载 3 只计算背包，分别对应上、中、下三组资源。
- **整柜算力**：3 块晶圆合计 **750PFLOPS AI 算力**、129.6PB/s 片上内存带宽、7.2Tb/s 对外 I/O。
- **模块化优势**：比上一代减少 **50% 组件**，自动化制造比例提高 **60%**，现场部署从数天缩短到数小时。
  说白了，就是把计算做成了可插拔的"背包"，坏了单独换，不用动整个柜子。

### 🔬 一块 WSE-3T 晶圆有多强？

单块 WSE-3T 把计算、内存、互连全做在**一整片晶圆**上，面积是普通芯片的几百倍。
- **物理参数**：面积 **46,225 平方毫米**，集成 **4 万亿个晶体管**、90 万个 AI 核心、44GB 片上 SRAM。
- **单晶圆性能**：
  - AI 算力 = **250PFLOPS**
  - 内存带宽 = 43.2PB/s
  - 片上织构带宽 = 53.5PB/s
  - 对外 I/O = 2.4Tb/s
- **内存策略**：44GB SRAM 容量 < 高端 GPU 的 HBM，但**带宽高出几个数量级** → 高频数据放片内，低流量激活值送其他晶圆。
- **超大模型支持**：模型超过单晶圆容量时，靠**流水执行 + 片外存储**承接更大权重。
- **良率方案**：冗余核心 + 冗余路由 + fail-in-place 机制 → 关闭缺陷区域、绕过继续工作，整片晶圆仍可作为一颗处理器运行。

### ⚡ 供电和冷却怎么设计？

供电推到晶圆旁 **0.5 毫米**，每只背包配独立水冷，损耗和延迟都压到极低。
- **供电路径**：
  - 机架前部：每只背包最多 **30 个风冷 AC/DC 电源模块**，输入最高 277V 交流电，输出 54.5V 直流电。
  - 冗余方式：支持 5+1、4+1、3+1、4+2 等，每个模块配独立 **30A 断路器**。
  - 近晶圆转换：DC/DC 距离晶圆约 **0.5mm**（传统 GPU 板卡约 50mm），大幅降低铜损和发热。
- **液冷路径**：
  - 每只背包有**独立水调节系统**，流量计 + 进出水温度传感器按负载调冷板流量。
  - **干式快接**：拆背包不用排空整柜水路。
  - 漏液/冷凝传感器触发 → 对应背包进入安全状态并切断电源。
- **分区隔离**：前部高压交流、后部计算水路，侧面歧管供回水，光纤通道避开维修路径 → 3 只背包共用机架，又各自有可隔离的电、热、控制边界。

### 🌐 多晶圆和异构系统怎么连？

两种联网方式各司其职：**RoCE 接标准网络，Direct Wafer Links 做晶圆直连**。
- **RoCE v2（RDMA over Ethernet）**：
  - 接入标准以太网交换设施，可与其他厂商加速器组成**异构推理系统**。
  - 公开方案：外部引擎做 prefill（处理输入提示），WSE 做低延迟 decode（逐 token 生成）。
- **Direct Wafer Links**：
  - 同机架或跨机架晶圆直接相连，**中间无交换机**。
  - 晶圆到晶圆最低延迟 = **2 微秒**，适合把多块 WSE 接成连续流水线。
- **灵活部署**：一座 CS-4 可独立运行，也可接入更大的同构或异构系统。

### 🚀 4400 tokens/s 的性能怎么来的？

**4400+ tokens/s/user** 是特定配置下的结果，前提是供电、片上通信、晶圆间链路都跟上。
- **公开测试**：GPT-OSS-120B 模型上超过 **4,400 tokens/s/user**，相对 GPU 方案最高快 **30 倍**。
- **速度来源**：
  更高供电/频率 → 250PFLOPS 单晶圆算力
  + 片上 SRAM + 织构 → 减少晶圆内数据等待
  + Direct Wafer Links → 缩短多晶圆流水线通信时间
- **边界条件**：
  - 实际结果随模型架构、上下文长度、精度、服务配置变化。
  - 44GB 片上 SRAM 装不下多数超大模型完整权重，仍需跨晶圆流水、片外存储、前端 prefill 资源。
  - 最高 30 倍**不适用于训练、任意模型或所有并发负载**。

### 📝 补充细节
- **维护特性**：计算模块与共享电源分离，冷却和 I/O 随背包一起拆装，可在数据中心现场装入已就位的前部电源机架。
- **整柜织构带宽**：3 块晶圆合计 **160.5PB/s** 片上织构带宽。
