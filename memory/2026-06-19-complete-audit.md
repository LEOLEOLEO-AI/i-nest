# 2026-06-19 完整方法论审查

## 核心诊断结果

### 问题等级汇总

🔴 **关键发现**：当前仿真实验是**参数生成系统**而非**验证系统**

| 层级 | 预期 | 实际 | 缺失 |
|-----|------|------|------|
| 1. 数据源 | 真实连接组 | **随机合成** | 90% |
| 2. 公式实现 | 标准网络算法 | **直接生成** | 95% |
| 3. 动力学 | 时间仿真 | **无** | 100% |
| 4. 对照 | 3+ Null Model | **无** | 100% |
| 5. 统计 | p-value + CI | **无** | 100% |
| 6. 功能 | MNIST 任务 | **无** | 100% |
| 7. 硬件 | 对标数据 | **无** | 100% |

### 最严重的问题

🔴 **问题 1：数据真实性**
```
代码流程：
if connectome_path exists:
    load()
else:
    _synthetic()  ← 默认执行，生成随机参数
    
v30 的 connectome_path：未定义
→ 100% 使用合成数据
→ 但论文声称"验证了真实连接组"
→ 自相矛盾
```

🔴 **问题 2：公式缺失**
```
要计算的指标 | 应该 | 实际
------------|------|------
平均度      | k̄ = 2m/n | 直接生成
聚类系数    | C_i = t_i/c_i | beta(2,5)
小世界指数  | (C/C_rand)/(L/L_rand) | lognormal()
度分布幂律  | P(k) ∝ k^(-γ) | 生成值

结果：**所有指标都是随机生成，不是计算所得**
```

🔴 **问题 3：时间动力学完全缺失**
```
声称："3000 步 MNIST 分类任务的神经放电仿真"
代码中：
✓ 无 Hodgkin-Huxley 模型
✓ 无 LIF 积分-发放
✓ 无 STDP 学习
✓ 无放电时间序列
✓ 无功率谱分析

结果：**完全无法验证 SOC（需要时间动力学）**
```

🔴 **问题 4：对照实验 = 0**
```
预期：组 1(iNEST) vs 组 2(ER) vs 组 3(配置模型) vs 组 4(SOC系统)
      进行 KL 散度、Wasserstein、t-test 对比

实际：v30_results.json 仅显示：
      σ = 4.238 vs 目标 4.0 ✅
      α = 2.099 vs 目标 1.5-2.5 ✅
      
问题：自己和自己的目标值对比，无对照组
后果：无法证明这不是人工制品
```

### 方法论现状等级

**当前**：初期概念设计 (PoC) - 参数生成脚本
- ✅ 能生成数值
- ❌ 数值无根据
- ❌ 无物理或数学推导
- ❌ 无验证过程

**应该是**：科学研究的仿真验证系统
- ✅ 真实数据
- ✅ 标准公式
- ✅ 动力学仿真
- ✅ 对照实验
- ✅ 统计检验

**差距**：完成度 1.5/5 (30%)

## 结论的适用范围

### 能说

✓ "我们生成了符合某些参数范围的数值"
✓ "在数值上这些指标与生物网络相似"
✓ "这是一个概念验证的初步设计"

### 不能说

✗ "验证了 iNEST 的 SOC"（需完整验证过程）
✗ "证明了 SDI 优于传统芯片"（无硬件对标）
✗ "多物种多尺度验证"（数据部分虚假）
✗ "神经放电仿真"（实际无时间模型）

### 隐含假设清单

| 假设 | 是否验证 | 风险 |
|-----|--------|------|
| 参数来自真实数据 | ❌ | 🔴 高 |
| 公式实现正确 | ❌ | 🔴 高 |
| 无关键缺失神经元 | ❌ | 🔴 高 |
| 时间常数一致 | ❌ | 🔴 高 |
| 不是 SOC 的人工制品 | ❌ | 🔴 高 |
