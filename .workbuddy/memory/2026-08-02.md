### 踩坑记录（重要）
1. **`.gitignore` 有全局 `*.html` 规则**。把 HTML 原型移到新路径后会静默脱离版本控制，
   必须 `git add -f`。移动 HTML 后务必用 blob 比对校验。
2. **`git add -A` 会吞进 AI 工具残留**。`.claudian-plus/retrieval/index.json` 达 268MB，
   触发 GitHub 100MB 硬限制导致 push 被拒。已把 `.claudian/ .claudian-plus/ .neural_db/
   .openclaw/ .tasks/` 加入 `.gitignore`。提交前应先查大 blob。
3. **`git rm -r --cached a b c` 是原子的**：任一路径未被跟踪则整条回滚，需逐个执行。
4. **校验脚本易错**：`git ls-tree -r` 的哈希在字段 [2]，`git ls-files -s` 在字段 [1]。取错会误报全库丢失。
