### 🧠 脉冲神经网络核心原理

#### 1. 基础运行机制

SNN借鉴生物神经元的工作模式，以**漏积分-发放（LIF）模型**为典型代表：神经元持续累积输入电流提升膜电位，当膜电位越过设定阈值时，会发放一个离散的二值脉冲，随后膜电位复位；无脉冲产生时神经元不输出任何信息。

#### 2. 与传统人工神经网络（ANN）的核心差异

| 维度 | 人工神经网络（ANN） | 脉冲神经网络（SNN） |
| :--- | :--- | :--- |
| 通信方式 | 逐层传递稠密的连续数值 | 传递离散、稀疏的脉冲事件 |
| 信息载体 | 激活值的大小 | 脉冲的数量、脉冲的发放时刻 |
| 计算特性 | 同步全量计算 | 仅脉冲触发时产生计算 |

#### 3. SNN三大核心特性
- **事件驱动、低功耗**：仅在脉冲发生时产生计算与能耗，在适配的神经形态硬件上，功耗远低于常规GPU平台
- **天然带时间维度**：脉冲时刻本身携带信息，对时序数据、音频、事件相机类数据有原生适配性
- **高度类脑**：作为第三代神经网络，和神经科学研究的联系远高于前两代感知机、发放率深度网络

#### 4. 领域核心难点

脉冲是阶跃函数天然不可微，标准的反向传播算法无法直接套用，因此**训练方法**是整个SNN领域的核心研究命题，也是该知识库重点整理的板块。

### 📖 核心章节深度解析

#### 1. 训练方法（知识库篇幅最重的核心章节）

针对脉冲不可微的痛点，目前主流训练方法分为三大范式，不同路线在精度、工程成熟度和生物合理性上各有取舍：
| 训练范式 | 核心思路 | 代表工作 | 特性定位 |
| :--- | :--- | :--- | :--- |
| ANN→SNN转换 | 先训练成熟的传统ANN，再将其权重映射为SNN | 权重/阈值平衡、QCFS、少样本校准 | 精度高、工程成熟度高，但通常推理延迟较高 |
| 代理梯度直接训练 | 用平滑的替代导数实现时间维度上的反向传播 | STBP、SLAYER、TSSL-BP | 目前复杂任务上效果最优的主流路线 |
| STDP生物可塑性规则 | 仅依赖脉冲时序更新权重，无需全局梯度 | 经典STDP系列工作 | 生物合理性最高，但目前难以扩展到大规模网络 |

#### 2. 网络架构与脉冲大模型

该板块是当前SNN领域演进速度最快的方向，覆盖脉冲版ResNet、脉冲Transformer等基础架构，同时收录了SpikeGPT、SpikeBERT、SpikeCLIP等大模型成果，其中中科院自动化所提出的**SpikingBrain**达到7B线性参数规模/76B混合MoE参数规模，支持长上下文能力，可在国产GPU上完成训练。

#### 3. 神经形态硬件

SNN的低功耗优势必须依托事件驱动的专用神经形态硬件才能完全兑现，知识库将主流硬件分为四大类：
| 硬件平台分类 | 代表性产品 |
| :--- | :--- |
| 数字平台 | IBM TrueNorth、Intel Loihi/Loihi2、SpiNNaker、天机·达尔文3、ODIN·ReckOn |
| 模拟/混合信号平台 | Neurogrid、BrainScaleS、DYNAP、Speck(SynSense) |
| 存内计算·忆阻器平台 | RRAM交叉阵列、相变存储(PCM)、全忆阻卷积网络、自旋电子器件 |
| 事件传感器 | DVS动态视觉传感器、ATIS、DAVIS、脉冲相机 |

#### 4. SNN应用版图

SNN的核心适配场景为对功耗、延迟高度敏感，且数据天然具备时间或稀疏结构的领域，覆盖方向包括：事件视觉识别与三维感知、目标检测、光流深度重建、视觉跟踪分割、端到端自动驾驶、机器人神经形态控制、脉冲强化学习、音频语音处理、时序预测、脑机接口生物信号处理、网络入侵检测等。
