# Road to scalability for efficient graph search on massively parallel neuromorphic hardware

🔗 https://arxiv.org/abs/2606.28907

---

## 1. 核心创新

本文提出了NEURO-MAPP（类脑最短路径并行传播算法），这是针对类脑硬件大规模并行、局部计算与异步通信特征设计的分布式最短路径算法。其核心突破在于摒弃了传统CPU架构下Dijkstra算法的全局优先队列依赖，转而利用SpiNNaker 2平台的稀疏脉冲通信实现"极小值-加法"并行传播。相比现有方案，它解决了在大规模动态加权图中计算开销随节点增加剧增的问题，实现了在运行时扩展性与能效比上的双重提升。

## 2. 对 TCC / iNEST 的价值分析

该技术与拓扑中心计算(TCC)及iNEST/SOC愿景高度契合。首先，NEURO-MAPP通过硬件原生互联拓扑映射图论问题，为软件定义互连(SDI)提供了高效的底层路由计算范式。其次，其基于脉冲的传播机制为自组织临界神经网络(SOC)中的动态演化与路径搜索提供了低能耗的执行引擎。对于iNEST团队而言，该算法展示了如何将网络拓扑特征直接转化为神经计算效率，是实现高能效拓扑中心系统的关键技术参考。

## 3. 后续应用方案建议

iNEST/TCC团队后续可采取以下建议：1. 实验验证：在SpiNNaker 2或同类模拟器上部署NEURO-MAPP，测试其在大规模6G互联网络拓扑切换时的收敛速度，评估其作为SDI控制平面的可行性；2. 引用集成：在涉及拓扑敏感神经网络架构的论文中引用该算法作为异步并行最短路径计算的理论基准；3. 改进方向：探索将该算法的"Min-Add"传播逻辑与SOC中的突触可塑性结合，实现具有自愈能力的动态网络路径规划模型。

## 原始摘要

> Efficient computation of shortest paths in weighted graphs is a fundamental problem with many applications. We introduce NEURO-MAPP (Neuromorphic-based Min-Add Parallel Propagation), a distributed shortest path algorithm designed for neuromorphic systems. We find that NEURO-MAPP scales favorably in terms of runtime for many graph types while consuming less energy per shortest-path query than CPU implementation in almost all cases.
