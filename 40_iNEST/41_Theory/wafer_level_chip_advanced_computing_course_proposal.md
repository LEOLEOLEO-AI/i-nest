## 二、课程教学目标

### 1\. 知识目标

系统掌握晶圆级芯片与先进计算领域的基础理论、关键技术与发展趋势，建立从器件到系统的完整认知，理解后摩尔时代集成电路的技术演进路径。

### 2\. 能力目标

具备分析和解决晶圆级集成与先进计算中复杂工程问题的能力，能够围绕相关方向开展文献调研、方案设计与学术研究。

### 3\. 素养目标

了解国家战略需求与学科前沿动态，培养学科交叉思维与学术创新意识，树立投身集成电路领域的使命感。

---

## 三、课程内容体系

本课程以五大问题为牵引，构建"**器件—芯粒—集成—架构—前沿**"五层递进的知识体系。

### 专题一：集成电路演进与先进计算导论（2学时）

**主讲：刘强**

| 节次  | 内容要点 |
| --- | --- |
| 1.1 | 集成电路发展历程与摩尔定律终结 |
| 1.2 | 后摩尔时代的技术路径与先进计算兴起 |
| 1.3 | 晶圆级集成的概念与课程知识体系 |

---

### 专题二：先进封装与晶圆级系统集成（9学时）

**主讲：郑德印**

| 节次  | 内容要点 |
| --- | --- |
| 2.1 封装技术演进与晶圆级封装基础 | 封装技术代际演进与先进封装概念；晶圆级封装（WLP）技术原理；硅通孔（TSV）与高密度互连技术 |
| 2.2 2.5D/3D集成与芯粒技术 | 2.5D中介层与硅桥技术；3D堆叠与混合键合技术；芯粒（Chiplet）设计方法学 |
| 2.3 热管理、测试与可靠性 | 高功率密度热管理与热电协同；晶圆级测试与良率管理；先进封装可靠性评估 |

---

### 专题三：新型器件与芯粒（9学时）

**主讲：于和善**

| 节次  | 内容要点 |
| --- | --- |
| 3.1 存储芯粒：忆阻器与新型存储器件 | 忆阻器的物理机制与材料体系；忆阻器阵列与存算一体；新型存储器件对比与展望 |
| 3.2 计算芯粒：相变器件与神经形态器件 | 相变器件原理与特性；人工突触与神经元器件；神经形态计算的器件基础 |
| 3.3 互联芯粒：光子器件与光互联 | 集成光子学基础与核心器件；光互联与多维复用技术；可重构光子器件与光计算前沿 |

---

### 专题四：先进计算架构（6学时）

**主讲：刘强**

| 节次  | 内容要点 |
| --- | --- |
| 4.1 计算机系统与片上网络 | 并行计算基础与多核架构；片上网络（NoC）：拓扑、路由与流控；存储器层次结构与互连 |
| 4.2 智能计算架构演进 | 深度学习的计算本质；从CPU/GPU到NPU/TPU的专用化演进；存算一体架构与模型压缩 |
| 4.3 晶圆级计算架构与设计考量 | 晶圆级规模下的算力组织；存算传融合的架构设计；架构设计中的安全、功耗与可靠性综合考量 |

---

### 专题五：学科前沿与国家战略（6学时）

**主讲：刘勤让**

| 节次  | 内容要点 |
| --- | --- |
| 5.1 软件定义晶上系统与国家布局 | 软件定义晶上系统的概念与技术路径；国家在先进计算与人工智能领域的战略布局；学科发展趋势与产业应用前景 |
| 5.2 拓扑中心计算与物理智能前沿 | 拓扑中心计算的提出与研究进展；物理智能与智能涌现的研究现状；前沿科学问题与未来方向 |
| 5.3 课程总结与科研入门 | 课程知识体系回顾与梳理；科研方法入门与文献阅读指导；交流答疑 |

## 七、课程特色与创新点

1.  **交叉学科特色**：贯通微电子、计算机、光学、人工智能等多学科知识，适应后摩尔时代集成电路的交叉发展趋势。
    
2.  **问题导向教学**：以五大核心问题为牵引，从"为什么"到"怎么做"再到"未来方向"，形成完整的认知逻辑链。
    
3.  **前沿性与基础性并重**：既保证器件、封装、架构等基础理论的系统讲授，又引入软件定义晶上系统、拓扑中心计算、物理智能等前沿方向。
    
4.  **科研育人结合**：将学科前沿与学院研究方向紧密结合，引导学生进入科研领域，实现课程教学与科研育人的有机衔接。
