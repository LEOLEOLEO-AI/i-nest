# 思科2026广域网AI报告解读：Agent时代，网络要从"服务人"变"服务任务"

### 📑 这份报告讲的是什么？

报告聚焦**跨广域网的AI推理流量**，不是数据中心内部的训练网络。
- **报告名称**：《AI Impact on Wide Area Networks Report 2026》，发布方 **Cisco**。
- **研究方法**：Cisco 真实网络流量分析 + 第三方行业数据 + AI Agent 实验测试。
- **核心观点**：AI时代的网络挑战不只是流量变大，更是**流量的"性格"变了**。

### 🤖 一次Agent任务，背后跑了多少网络交互？

单个Agent任务的流量是人工的 **4.5倍**，其中7成是模型推理流量。
- **测试设置**：用 LangChain 的 Open Deep Research agent 收集Cisco公开信息（投资者关系、社交媒体、新闻等）。
- **交互规模**：Agent 访问了 **44个网页来源**，在Agent、网页代理、OpenAI模型之间形成多轮调用网络。
- **流量构成**：
  - 总触发流量：**26.8MB**
  - LLM推理流量占比：**70%**
  - 流量增长：比人工完成同类任务多 **450%**
- **关键比喻**：Agent与模型之间的连接 = **Agent's Spinal Cord（脊髓）**，是任务执行的新关键路径。
  说白了，Agent不是聊一句发一次请求，它像个自动办事员，跑一趟任务背后已经来回联网几十次。

### ⚡ AI推理流量和普通Web流量，哪里不一样？

AI推理流量不是"大水管"，更像**持续出水的细水管**，三个核心差异：

| 维度 | 普通Web | AI推理 | 差异 |
| :--- | :--- | :--- | :--- |
| 流持续时间 | 643 ms | 1292 ms | 约 **2倍** 更长 |
| 中位流速率 | 3803 Kbps | 338 Kbps | 普通Web约 **10倍** 更高 |
| 上行超下行的流占比 | 0.5% | 9% | AI更常带上下文往上发 |
- **状态压力更大**：防火墙、入侵检测等设备需要维护流状态，AI流持续时间长 → 状态表项压力上升，不只是带宽问题。
- **上行不再边缘**：Agent会不断把任务状态、上下文回传给模型，上行流量占比显著提升，冲击传统"重下行"的网络规划直觉。

### 📈 AI推理流量现在有多大，增长有多快？

目前总量还很小，但**增长速度极快**，需要单独建模。
- **当前规模**：相比视频流媒体等大头，AI推理流量目前占比仍然很低。
- **增长速度**：
  - OpenRouter token 消费数据：年增长接近 **10倍**
  - 部分服务商实测：8个月内AI推理流量增长约 **4倍**

### ⏱️ 网络延迟现在是AI体验的瓶颈吗？

现在还不是主瓶颈，**未来会越来越接近主战场**。
- **当前构成**：LLM延迟 = 首token生成时间 + 单token生成时间 × 输出token数，模型处理时间占大头，网络延迟只是较小部分。
- **未来趋势**：推理硬件提速 → 模型处理时间下降 → 网络延迟在整体体验中的占比会升高。

### 🔮 2035年的流量预测怎么看？

长期数字要当**规划信号**，不要当既定事实。
- **消费网络**：
  - 无AI影响：2025-2035年流量增长 **4倍**
  - 含AI与Agent：增长 **6.6倍**，比无AI情景多约 **63%**
- **企业网络**：
  - 无Agent：2026-2035年流量增长约 **250%**
  - 含Agent：增长可达 **9倍**
- **总量占比**：模型预计2035年AI推理约占总网络流量的 **25%**
- **原文提醒**：长期建模天然有不确定性，未来会随更多数据修正。

### 🧠 真正的新挑战是什么？

网络要从"服务人的点击"，走向**服务任务的执行**。
- **旧模式**：网络服务人类单次动作（点开网页、刷视频），人的操作节奏是天然缓冲。
- **新模式**：Agent按软件速度用网络，一次用户意图拆成多轮机器动作（搜索、抓取、推理、工具调用……），不同链路重要性不同。
  - 工具调用失败可重试，网页慢一点可换来源
  - 模型推理路径不稳定 → Agent整个判断链条变脆
- **新命题**：AI推理路径会成为**战略网络资产**，企业和运营商不能只问"通不通"，还要问关键AI路径稳不稳、能不能观测、能不能保障。
- **待解问题**：AI流量识别、加密下的DPI、QoS差异化、安全设备/SD-WAN/SASE/无线网络的状态表与带宽规划。

### 📝 补充细节
- 报告明确区分了 **AI inference（推理）** 和训练流量，本报告只讨论跨WAN的推理侧流量。
- Cisco 称 Agent 为 **network power users**——它们以软件速度而非人类速度使用网络，拿掉了过去人类操作带来的缓冲垫。
- 原文强调：AI流量不是传统视频流量的放大版，而是"另一种动物"，核心挑战从带宽延伸到上行、状态管理和关键路径保障。
