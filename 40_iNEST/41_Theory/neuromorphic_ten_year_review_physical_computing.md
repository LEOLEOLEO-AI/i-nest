# 类脑计算十年复盘：从形似陷阱到物理计算的新范式

### **🏆 过去十年类脑计算真正跑出来的产品是什么？**

**事件相机**是唯一大规模落地的类脑产品，核心赢在**计算原语**而非仿生形态。
- **代表厂商**：Prophesee、IniVation，已在**自动驾驶、工业检测、机器人**领域出货。
- **核心优势**：微秒级时间分辨率 + **120dB 以上动态范围** + 毫瓦级功耗。
- **解决痛点**：传统相机的**运动模糊、高动态范围失效、数据冗余**。
- **本质突破**：放弃仿真视网膜细胞细节，抓住**异步、稀疏、地址事件表征（AER）**。
  说白了，不是照着眼睛造零件，而是找到了"只在变化时才输出"这个更底层的规律。

### **❌ TrueNorth 和 Loihi 为什么没成？**

它们掉进了**"形似陷阱"**——先固化生物形态，再找应用场景。
- **TrueNorth（IBM，2014）**：
  - **工程指标**：100万神经元、2.56亿突触、**70毫瓦**功耗。
  - **核心问题**：神经模型僵化，编程接口极难，实际应用靠**调参祈祷**。
- **Loihi（Intel）**：
  - **相对进步**：比 TrueNorth 灵活，Intel 投入了大量生态资源。
  - **核心问题**：十年过去仍无**杀手级应用**，脉冲优势被 BPTT 训练开销吃掉大半。
- **共同病根**：在没搞懂大脑"算什么、怎么算"之前，就把"脉冲+突触+树突"烧进了硅片。

### **🧠 SNN 算法现在卡在哪？**

SNN 还在靠**BP 的拐杖**走路，没有自己的原生训练范式。
- **现状**：主流用 surrogate gradient（替代梯度），本质是在脉冲网络里**假装做反向传播**。
- **三大代价**：
  - **内存爆炸**：BPTT 需存 T 步前向激活值，时间分辨率越高开销越大。
  - **训练能耗高**：为了"低功耗推理"，要在 GPU 上跑几十小时反向传播。
  - **超参数地狱**：替代函数、时间步长、发放阈值都要调，更像炼金术。
- **可能出路**：**强化学习**（如 e-prop、R-STDP），不需要存前向激活值，更符合边缘芯片约束。

### **🤖 为什么"数字孪生大脑"是死路？**

它用**图灵机语言**去翻译一个**非图灵的动态系统**，方向从根上就错了。
- **错误假设**：只要扫描够精细、参数够多，就能在硅基上"重建"大脑。
- **大脑本质**：嵌入物理世界、连续演化、与身体和环境耦合的动态系统，不是可隔离的信息处理装置。
- **核心问题**：参数复制 ≠ 机制洞察，百亿参数仿真出的只是**昂贵的动画**，不是可解释的理论。
- **代表案例**：欧盟 **Human Brain Project** 十亿欧元投入，未达预期。

### **🚀 下一个十年该押注什么？**

**放弃仿真大脑，转向利用物理本身做计算。**

| 方向 | 不该押（旧范式） | 该押（新范式） |
| :--- | :--- | :--- |
| 硬件 | 更大的 SNN 芯片 | 事件驱动计算原语 |
| 算法 | 更逼真的神经元模型 | 不依赖 BP 的训练算法 |
| 路线 | 全脑数字孪生 | 让物理本身做计算 |
- **事件驱动计算原语**：从传感器到处理器，异步稀疏成为系统级架构选择。
- **不依赖 BP 的训练算法**：强化学习、局部可塑性、在线学习，让芯片自己进化。
- **物理即计算**：存内计算、模拟计算、神经形态材料，媒介本身的物理过程就是计算。

### **📝 补充细节**
- **时间坐标**：IBM TrueNorth 发布于 **2014 年**，至 2024 年整十年。
- **关键对比**：十年间 GPU 市值翻了**一百倍**，Transformer 统治 AI，而神经形态芯片仍停留在学术 demo 阶段。
- **核心论断**：形态上的仿生，是理解不足时的代偿；没有自己的 BP，类脑芯片永远是深度学习的附庸。
