# 《Science》2026封面研究深度解析：5亿年前脊椎动物脑演化的颠覆性新发现

### 🔍 研究背景与核心缘起

长期以来科学界的主流假说认为：古老脊椎动物的大脑结构相当简陋，复杂脑区是在漫长演化过程中逐步新增出来的。而本次《Science》的重磅研究通过被誉为脊椎动物“活化石”的七鳃鳗作为核心研究模型，推翻了这一传统认知，为早期脊椎动物脑演化提供了全新的解释框架。
七鳃鳗作为无颌类脊椎动物，约4.5亿年前就与有颌类脊椎动物（现代鱼类、两栖类、鸟类、哺乳动物等）分道扬镳，其大脑结构在演化中变化极小，是观测早期脊椎动物脑结构的天然“时间胶囊”。

### 📊 研究核心技术与量化成果

本次研究首次构建了远东溪七鳃鳗（*Lethenteron reissneri*）的三维单细胞脑图谱，核心技术参数如下表：
| 技术维度 | 具体量化指标 |
| :--- | :--- |
| 空间转录组技术 | Stereo-seq，连续切取40张脑组织切片 |
| 单核转录组技术 | snRNA-seq，测定41678个细胞核转录组 |
| 细胞定位规模 | 465778个空间定位细胞 |
| 细胞类型覆盖 | 209种细胞类型 |
| 脑区解析范围 | 完整覆盖14个脑区 |

这套技术组合相当于为七鳃鳗的大脑完成了一次“分子级CT”，最终产出的不仅是脑组织的结构地图，更是一份记录每个细胞身份、位置和功能状态的完整分子说明书。

### 💡 三大颠覆性核心发现
1.  **5亿年前脊椎动物祖先的大脑已完成高度区域化**
    研究团队将七鳃鳗大脑与小鼠等现代脊椎动物对比后发现，嗅球、丘脑、下丘脑、后脑等关键脑区在细胞组成、空间布局、基因表达层面高度一致，这证明所有脊椎动物共同祖先的大脑早在约5亿年前就已经拥有清晰的区域划分，人类复杂脑结构的“设计蓝图”在远古时期就已绘制完成。
2.  **神经元专业化才是脑复杂化的核心动力**
    传统认知认为脑演化的核心是不断新增脑区“零件”，但本研究整合七鳃鳗、斑马鱼、蜥蜴、鸟类、小鼠、猕猴等8个物种的组学数据后发现：早期脊椎动物的神经元大多是同时表达兴奋性、抑制性神经递质相关基因的“全能多面手”，类似“全科医生”；随着演化推进，这类细胞逐步分工，演变为功能单一、连接精准的高度特化神经元，如同细分领域的“专科医生”。正是这种持续数亿年的细胞分工，推动了学习、记忆、高级认知等复杂脑功能的诞生。
3.  **小脑的起源时间被大幅推前**
    此前学界长期争议七鳃鳗是否拥有真正意义上的小脑，本次研究发现七鳃鳗虽没有现代脊椎动物层次分明的小脑结构，但已经具备与现代小脑颗粒细胞、中间神经元高度同源的原始细胞类群，证明小脑并非演化中突然出现，而是从5亿年前的原始细胞框架逐步发育形成，其起源时间远早于此前的普遍认知。

### 🔬 研究价值与行业影响
- 该研究首次将空间转录组技术应用于早期脊椎动物演化研究，验证了空间组学在演化生物学领域的巨大潜力，后续随着更多物种的高精度脑图谱陆续发布，科学家将逐步完整拼接出整个脊椎动物脑演化的全路径。
- 同期《Nature》发表的早期脊椎动物两轮全基因组复制相关研究，与本研究“神经元专业化驱动脑演化”的结论形成交叉印证，为理解复杂大脑的起源提供了完整的遗传-细胞层面证据链。

### 📝 关键洞察

这项封面研究彻底重构了人类对自身大脑起源的认知：我们如今拥有的上百个功能分区的复杂脑结构，并非是数亿年间不断叠加新脑区的结果，而是在5亿年前就定型的基础框架之上，通过神经元持续精细化分工、功能特化逐步演化而来。
