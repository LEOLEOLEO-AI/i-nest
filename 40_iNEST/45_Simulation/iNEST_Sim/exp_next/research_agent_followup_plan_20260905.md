## 2. 优先级与执行顺序

### P0：冻结数据与公式

**任务 V-P0-1：结果可复现封存**

- 输入：v32–v38 的代码、参数、随机种子、数据源路径。
- 操作：建立 `manifest.yaml`，记录 commit、Python 环境、数据哈希、公式版本和输出文件。
- 验收：同一环境重跑，Sc、Tc、Γst、CST 与已记录结果的相对误差不超过 **[待测]**；误差阈值须在运行前写入 manifest。
- 产物：`repro_manifest.yaml`、`rerun_report.md`。

**任务 V-P0-2：α 与 Γ₀ 冻结**

- α 主分析使用 v38 的 C. elegans 值；附加分析使用文献支持的区间。
- Γ₀ 固定为 E1 标定结果，不允许为提高 CST 事后调参。
- 验收：报告中分别列出主值、敏感性范围和来源；不得把区间端点写成实测值。

### P1：C. elegans 主结果重复性

**任务 V-P1-1：多种子重跑**

- 固定 Cook/Varshney 数据版本、Randi 功能连接、Tc 新定义和 α 主值。
- 使用预注册的随机种子集合，数量为 **[待测]**，不得运行后挑选种子。
- 指标：Sc、Tc、Γst、CST、L1 判定、各分量置信区间。
- 验收：报告均值、标准差、95% 置信区间；L1 是否成立以预先冻结的阈值判定。

**任务 V-P1-2：功能连接映射敏感性**

- 比较 Randi 功能连接的原始矩阵、阈值化矩阵和权重保留矩阵。
- Louvain、Leiden 各运行预注册种子；记录社区数、AMI 和 Γst。
- 验收：给出算法和阈值对 Γst/CST 的影响；不能只报告最有利设置。

### P2：Γst 机制验证

**任务 V-P2-1：真实功能连接替代 STDP**

- C. elegans：主分析只使用公开实测功能连接。
- Drosophila/Macaque：在取得真实功能数据前，结果标记为 `[待测]`，禁止使用 STDP 结果宣称生物 Γst。
- 验收：结构社区与功能社区的来源、节点交集、缺失节点处理全部记录；输出 AMI bootstrap 区间。

**任务 V-P2-2：STDP/BCM/FEP 对照**

- 仅作为机制实验，不覆盖真实数据主结果。
- 条件：500 步 STDP、延长 STDP、STDP+BCM、STDP+BCM+FEP；具体步数和学习率在运行前登记。
- 指标：AMI、Γst、权重分布、稳定性、是否出现饱和或发散。
- 验收：每个条件至少 **[待测]** 个独立重复；若没有预注册效应量，不得使用“提升”作结论。

### P3：时间动力学模型对照

**任务 V-P3-1：graded-potential 连续模型**

- 主模型：连续膜电位/电导动力学；LIF 仅作对照。
- 扫描：`dt`、膜时间常数分布、噪声强度、输入统计；参数范围引用文献或标记 `[待测]`。
- 指标：τ 分布熵 Θ、Tc、CST、数值稳定性。
- 验收：收敛性检查至少包含两组时间步长；报告数值误差与边界条件。

**任务 V-P3-2：时间尺度分离判据**

- 测试单体、小网络、扩展网络三种规模。
- 记录 `ĥτc`、最大李雅普诺夫指数、谱半径和网络规模。
- 验收：检验“小网络增大反馈不能替代规模扩展”的预言；斜率和误差范围在运行前冻结。

### P4：规模第一性与跨物种实验

**任务 V-P4-1：√N 标度**

- 网络规模：从真实连接组抽取嵌套子网络，或使用明确的数据生成协议。
- 指标：最大时间深度 `τc,max`、网络规模 `N`、log–log 回归斜率。
- 验收：检验斜率是否落在预注册区间；若不满足，保留阴性结果并回查有限尺寸效应。

**任务 V-P4-2：跨物种比较**

- C. elegans、Drosophila、Macaque 分别使用适配其信号类型的数据和 Tc 定义。
- 禁止把皮层 AP 指标直接移植到 C. elegans graded-potential 网络。
- 验收：输出“同一定义部分”和“物种专属定义部分”，只比较可比分量。

### P5：ANN 基线补全

**任务 V-P5-1：公开激活轨迹基线**

- 选择 GPT-2、ResNet-50、LTC/NCP、Loihi-2 代理模型。
- 采集公开模型在固定任务和固定输入上的层级激活轨迹；记录模型版本、数据集、输入和推理设置。
- 计算 M、Rsw、Φ、Ψ、Θ；缺失数据继续标 `[待测]`。
- 验收：只有 9 个分量全部有数据且来源可追溯时，才允许与生物网络做 CST 排名。

## 3. 推荐的科研智能体调用链

```text
诊断报告读取
  → 数据审计 Agent
  → 公式/适用性审查 Agent
  → 实验设计 Agent
  → 仿真执行 Agent
  → 统计与可复现性 Agent
  → 证据核验 Agent
  → 生成结果卡片与下一任务
```

每个 Agent 必须输出：

1. 输入数据与版本；
2. 参数和随机种子；
3. 公式与适用边界；
4. 实测/仿真/引用/推导/待测标签；
5. 阴性结果；
6. 下一步验证任务编号。
