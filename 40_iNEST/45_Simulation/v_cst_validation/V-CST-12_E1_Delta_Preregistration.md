# V-CST-12 · E1-Δ 预注册协议：CST 对称主方程判别实验

**前置文档**：`V-CST-00`（证据分类与结论规则沿用）、`2026-08-07_CST_V42_审查与修订_V42.1_自洽版`（公理 A1/A2′、机制 T、IIL 判据）、`2026-08-07_第四幕_唯一性证明_最终方案_U4公理化_V1.0`（早期公理化路径，作为证明路径 A 保留）、`2026-08-07_Gamma_st_Definition_Revision_Proposal`（Γst 修订）。

**本协议要回答的问题**（一句话）：在空间宽度、时间深度和结构—功能协同三者之间，协同是否被相关时间完全中介，还是存在不能并入 $T_c$ 的独立协同残差？

---

## 0. 一页摘要

- **目的**：在可复现的 SDI 可重构平台上，以预注册的"协同残差首测＋四臂正交"实验判别：① 完全中介子模型（协同仅经 $\tau_c$ 生效）与独立协同残差；② 规模耦合竞争者；③ 结构/时间缩放对称性；④ 总容量组合律与强度密度组合律。
- **设计**：**臂 0 E1 首测**（单斜率判别，最高优先）＋臂 A 规模扫描＋臂 B 非对称扫描＋臂 C SDI 物理隔离组合性检验＋臂 D 反向耦合机制检验。
- **统计纪律**：TOST 等价检验而非零假设检验；Holm 校正；固定 N、无可选停止；Γst 与 CST 双盲流水线；脚本揭盲前冻结并公示哈希；σε 与 σ_m 由先导批实测。
- **悬崖**：若总容量组合律或密度组合律失败，CST 的模块化解释退回假设状态；若协同残差非零，则 V44 两项律不能作为一般式。此条写入预注册，不回避。
- **申报价值**：这是"固定晶粒数下独立调节 Γst"这一 SDI 能力的直接检验：它不预设协同一定等于记忆延长，而是将三条可证伪机制路径公开区分。

## 1. 理论背景与正式假设

### 1.1 主方程与可检验子模型（V45 版本）

$$c\equiv\ln\mathrm{CST}=s+t+\Lambda_{st},\qquad s=\hat d_\varepsilon\ln M_\varepsilon,\quad t=\hat h_\varepsilon\tau_c.$$

$$\Lambda_{st}=a_{st}\Gamma_{st}+O(\Gamma_{st}^2)\quad[\text{待测}],\qquad \mathrm{CST}=M_\varepsilon^{\hat d_\varepsilon}e^{\hat h_\varepsilon\tau_c}e^{\Lambda_{st}}.$$

- **组合律 A1**：互不耦合子系统的总容量满足 $\ln\mathcal N_{A\otimes B}=\ln\mathcal N_A+\ln\mathcal N_B$；密度满足 $\ln\mathrm{CST}_{A\otimes B}=(n_A\ln\mathrm{CST}_A+n_B\ln\mathrm{CST}_B)/(n_A+n_B)$。
- **完全中介子模型 L1**：$d\hat d/d\Gamma=dM/d\Gamma=d\hat h/d\Gamma=d\Lambda_{st}/d\Gamma=0$，仅 $\tau_c$ 随 Γ 改变。仅 L1 通过时，才可将 Γ 合并进条件时间项。
- **回响态机制 T**：$\partial m/\partial\Gamma$ 对 $\tau_c$ 的贡献是 L1 的候选中介路径，而非 α、器件态数或智能等级的预设唯一来源。
- **约定**：$p=q=1$（U1 基线）为归一化约定，非定理，由臂 B 实测；等权重几何平均（指数 1/4）为置换对称约定（与符号基线一致）。

**与旧公理化（证明路径 A）的对应**：U1 基线约定 ≈ 约定条款；U2′ 强度—广延分工 ≈ 每通道约定；U3 可测性 ≈ 被 A2′ 的可微性吸收；U4 可组合性 ≈ A1 的操作化。两条证明路径（函数方程 Cauchy–Aczél 路径 A、计数＋线性响应路径 B）结论一致，本协议以路径 B（V42.1）为主，路径 A 保留作并列陈述。

### 1.2 竞争假设

| 编号 | 竞争者 | 违反 | 判别臂 |
|---|---|---|---|
| C0 | 存在独立协同残差：$d\Lambda_{st}/d\Gamma\neq0$ | L1 完全中介 | 臂 0：错配零模型残差检验 |
| C1 | 空间状态宽度或熵率亦随 Γ 改变 | L1 完全中介 | 臂 0：全导数中介分解 |
| C2 | 标度耦合：$\ln\mathrm{CST}=u+\beta\Gamma u$ | 固定规模局部律 | 臂 A：$\beta\neq0$ |
| C3 | 非对称缩放：$s^p t^q+\Lambda_{st}$，$p\neq q$ | 结构/时间缩放对称性 | 臂 B：$p\neq1$ 或 $q\neq1$ |
| C4 | A1 不成立（总容量或密度不可组合） | A1 本身 | 臂 C：两条组合方程偏离 |
| C5 | 非线性协同响应 | 局部线性响应 | 臂 0 次级：$\Gamma^2$ 项非零 |

### 1.3 正式假设

- $H_{0M}$（完全中介）：$d\Lambda_{st}/d\Gamma=0$，且 $d\hat d/d\Gamma=d\ln M/d\Gamma=d\hat h/d\Gamma=0$；所有等价界由阶段 0 冻结。
- $H_{0A}$：$\beta=0$（固定规模局部律不随规模漂移）；采用 TOST，只有 $|\beta|<\delta_A$ 才接受等价。
- $H_{0B}$：$p=q=1$（等价界 $\delta_B$）；$H_{1B}$：$|p-1|\ge\delta_B$ 或 $|q-1|\ge\delta_B$。
- $H_{0C}$：总容量可加且 CST 密度按通道数加权几何平均（两个等价界均须通过）。
- $H_{1D}$（臂 D，探索性）：$\Gamma<0$ 工况下，协同残差或任务性能出现预注册方向的变化。

## 2. 平台与对象

### 2.1 计算平台

- **主平台**：SDI（软件定义互连）可重构平台——先 FPGA/仿真器，后晶上（SDSoW）。SDI 提供"固定晶粒数下独立调节 $\Gamma_{st}$"的能力，是臂 0/臂 A 的前提，也是本实验的独占技术优势。
- **辅助平台**：公开生物数据集（区域级）仅作外部一致性检查（见 §2.2），不承担判别任务。

### 2.2 网络对象族与规模档位

| 族 | 用途 | 规模档位（节点数） |
|---|---|---|
| 同质随机（ER） | 基线、零模型对照 | 1k / 2k / 5k / 10k / 20k |
| 小世界（WS） | 结构复杂度下界扫描 | 同上 |
| 分层模块（HM） | $S_c$ 高值区 | 同上 |
| 无标度（BA） | 度异质性扫描 | 同上 |
| SDI 可重构晶上网络 | 臂 0/臂 A 主战场（$\Gamma$ 独立调节） | 按晶粒规模，满足 $\Delta u\ge3$ |

**规模跨度要求（go/no-go）**：$\Delta u=\ln(S_cT_c)$ 全程跨度 $\ge3$（$S_cT_c$ 跨度 $\ge20$ 倍）。若平台只能覆盖 2 倍跨度（$\Delta u=0.69$），竞争者斜率仅变化 14%，臂 A 失明——该工况下臂 A 降级为可行性报告，但**臂 0 仍可执行**（单斜率判别不依赖规模跨度）。

### 2.3 版本与复现基线

- 软件栈、网络生成器版本、SDI 配置脚本、数据文件均入库 Git，记录 SHA-256；JSON/二进制数据不入库（沿用目录管理三定律）。
- 每份数据集配 `.md` 元数据（来源、版本、许可证、下载日期、SHA-256、ID 映射覆盖率，沿用 V-CST-11 约定）。

## 3. 测量协议（操作化，全部冻结）

> 原则：**每个量都有独立于主方程的测量路径**；任何指标不得用理论公式回填。所有算子参数在阶段 0 冻结，冻结后不得因观察结果修改。

### 3.1 CST 观测量的独立测量（防循环）

- **语义**：CST 是系统可达可分辨状态的容量（"状态数"量纲，$\ln Z$ 语义）；每通道强度密度 $\mathrm{CST}=\mathcal{N}^{1/n_{ch}}$。
- **主操作化**：$H_{\text{eff}}$ = 粗粒化群体活动轨迹的香农熵（NSB 无偏估计，Nemenman et al. 2002），$\mathrm{CST}_{\text{obs}}=\exp(H_{\text{eff}})$。
  - 粗粒化规则、时间窗长、bin 数、估计器参数：**阶段 0 冻结**（冻结的是流程，不是事后挑选的数值）。
- **备选（一致性报告）**：协方差谱参与比有效维数、相关维数（correlation dimension）估计的状态空间体积指数。
- **盲态**：CST 流水线在不知 $\Gamma_{st}$ 值的情况下运行（§7）。
- **噪声底**：$h_\varepsilon$ 测量须显式报告观测噪声底与所选 $\varepsilon$；噪声底以内的熵不算内在复杂度（防止把观测噪声计入 $T_c$）。

### 3.2 $S_c$ 四算子

$$S_c=\big(Q\cdot\sigma\cdot\kappa\cdot h\big)^{1/4}$$

| 算子 | 定义 | 工具/参数（阶段 0 冻结） | 证据 |
|---|---|---|---|
| $Q$ 模块度 | Louvain 模块度（随机图校正） | 固定分辨率 1.0、固定随机种子、100 次重启取共识划分 | `[引用]` Newman 2006；`[待测]` 冻结参数 |
| $\sigma$ 小世界性 | $\sigma=(C/C_{\text{rand}})/(L/L_{\text{rand}})$ | Humphries & Gurney 2008 定义；ER 基线 | `[引用]` |
| $\kappa$ 度异质性 | 度分布变异系数或熵 | 公式在阶段 0 冻结 | `[待测]` |
| $h$ 层级度 | k-core 比率或层次模块性 | 公式在阶段 0 冻结 | `[待测]` |

**正交性前提（K5 前置）**：报告八指标间相关性；若强相关，几何平均定理（T2）的适用前提动摇，须在结果中显式讨论。

### 3.3 $T_c$ 四算子

$$T_c=\big(\mathrm{MSE}\cdot W_\tau\cdot\Lambda\cdot d_{\text{eff}}\big)^{1/4}$$

| 算子 | 定义 | 工具/参数（阶段 0 冻结） | 证据 |
|---|---|---|---|
| $\mathrm{MSE}$ 多尺度熵 | 多尺度样本熵 | Costa et al. 2002/2005；尺度数、嵌入参数冻结 | `[引用]` |
| $W_\tau$ 时标谱宽度 | 自相关/去趋势涨落分析的时标范围 | 窗口与阶数冻结 | `[待测]` |
| $\Lambda$ 雪崩标度指数 | 雪崩规模分布幂律指数 | Beggs & Plener 2003；bin 规则与替代分布比较冻结 | `[引用]` |
| $d_{\text{eff}}$ 动力学有效维数 | 活动协方差谱参与比 | 公式冻结 | `[待测]` |

### 3.4 $\Gamma_{st}$：一个定义、三级估计量（V42.1 R3）

| 层级 | 定义 | 用途 | 证据 |
|---|---|---|---|
| 理论定义 | $\Gamma_{st}=\dfrac{\langle \hat L,\hat C\rangle_F}{\|\hat L\|_F\|\hat C\|_F}$（Frobenius 余弦） | 进入推导，光滑可导，天然 $[-1,1]$ | A |
| 晶上估计量 | $\Gamma_{st}=(n_+-n_-)/n_{ch}$（通道对齐计票） | 在片实时测量、SDI 反馈环 | B |
| 神经数据估计量 | $\Gamma_{st}=\tanh\!\left(\dfrac{I(M_s;M_T)-\mathbb{E}[I]_{\text{null}}}{k\,\sigma_{\text{null}}}\right)$（z-score AMI） | 与皮层/生物数据对标 | B |

- **Frobenius 余弦约定**（理论定义）：去对角项、中心化（去均值）、符号约定——结构用归一化拉普拉斯 $L=I-D^{-1/2}AD^{-1/2}$，功能用去均值协方差；同向对齐为正。
- **神经数据估计量参数**：$I(M_s;M_T)$ 为结构 vs 功能划分互信息（Louvain，参数同 §3.2）；$\mathbb{E}[I]_{\text{null}}$、$\sigma_{\text{null}}$ 来自 §4 零模型；$k$ 默认 2，**阶段 0 先导批定标后冻结**；k∈{1,2,3} 作敏感性报告（次级）。
- **序一致性约束（可证伪工程约束）**：三级估计量之间要求 Kendall $\tau>0.8$；不满足则报告层级间偏差来源，并冻结所用层级。
- 交叉验证项（不改变主定义）：O-information（约定 $\Omega<0$ 协同主导，若采用 $\Gamma_{st}\propto-\Omega$）。

### 3.5 $m$、$n_{\text{ch}}$ 与有效态数的独立测量

- **回响态分支比 $m$**：MR 估计量（Wilting & Priesemann, *Nat. Commun.* 9:2325, 2018）用于估计回响动力学；其窗口、亚采样率、去趋势和重复误差在阶段 0 冻结。该文献支持亚采样下的集体动力学推断，不等同于 $m$ 是 CST 的充分统计量。
- **候选时间中介路径**：报告 $\partial m/\partial\Gamma$、$\partial\tau_c/\partial\Gamma$ 及二者的模型关系；只有与全导数分解一致，才可支持“回响态—时间深度”路径。不得将 $(\partial m/\partial\Gamma)/(1-m)$ 预定义为 α。
- **$n_{ch}(\ell,\varepsilon)$**：尺度标注的有效独立通道数。分块尺度、容差、估计器、数据长度与置信区间在阶段 0 冻结；不使用单一链路计数冒充独立通道数。
- **$M_\varepsilon$**：由预注册动态范围 $R$、分辨率 $\varepsilon$ 与判决准则独立确定的有效可分辨态数，例如 $M_\varepsilon=R/\varepsilon$。SNR 仅可作为代理并报告映射误差；不得以拟合系数反推 $M_\varepsilon$。
- **判别**：在至少两个 $n_{ch}$ 水平重复臂 0/臂 A，报告 $a_{st}$、各中介路径和规模依赖，禁止预设斜率随 $n_{ch}$ 的形式。

## 4. 零模型规格

### 4.1 空间约束配置模型（SCCM）

- **约束**：① 保度序列（double edge-swap，拒绝自环/重边）；② 保空间嵌入（节点坐标不变）；③ 边概率随距离衰减——核函数形式（指数或重力模型）在阶段 0 由观测网络拟合后冻结。
- **目的**：$\mathbb{E}[I]_{\text{null}}$ 与 $\sigma_{\text{null}}$ 吸收"结构距离与功能距离天然空间自相关"这一 Mantel 失效来源，把原 bug 变成显式参数。

### 4.2 置换次数与诊断

- 每个观测网络：**1000 次**零模型抽样（预注册固定，不改）。
- 诊断统计量（全部报告）：度序列保持（KS 检验）、空间自相关匹配（Moran's I）、交换接受率、$I$ 零分布的形状（均值/标准差/偏度）。

### 4.3 冻结规则

零模型代码、核参数、置换种子在阶段 0 冻结；任何修改须走 §10 变更协议。

## 5. 实验设计

### 5.1 阶段 0 · 先导批（10 组态）

**目的（仅可行性，不做任何假设检验）**：
1. 定标 $k$（§3.4）并冻结全部算子参数（§3.2/3.3/3.5）；
2. 实测 $\sigma_\varepsilon$ 与 $\sigma_m$（沿用文献估计**禁止**）；
3. go/no-go 检查：$\Delta u\ge3$（仅臂 A 需要）、设计矩阵 $\mathrm{VIF}<2.5$、零模型诊断通过、MR 估计量重复误差达标；
4. 依据 $\sigma_\varepsilon$、$\sigma_m$ 计算所需 N（§6.4），**冻结 N**；
5. 检查 SDI-Γ 控制分辨率满足稳定性约束：$|\delta\Gamma|\ll(1-m)/(\partial m/\partial\Gamma)$（示例 $m=0.98$、$\partial m/\partial\Gamma=0.068$ 时 $\ll0.294$，取 $\delta\Gamma=0.03$ 提供约 10% 余量；余量随实测斜率缩放）`[推导·参数示例]`。

**先导失败处置**：未过 go/no-go ⇒ 如实报告可行性结论，不得重新解释为验证证据。

### 5.0 臂 0 · E1-Δ 首测（协同残差与中介分解，最高优先）

**目的**：直接判别 V44 的关键前提。测量 Γ 对空间宽度、时间深度与协同残差的全部响应路径，而不是预设所有经验内容可压缩为一个回响态斜率。

- **设计**：在同一 SDI 晶上系统，施加受控结构扰动扫描 $\Gamma_{st}$（水平数、覆盖区间和重复数由阶段 0 功效计算冻结）；独立测量 $\hat d_\varepsilon$、$M_\varepsilon$、$\hat h_\varepsilon$、$\tau_c$、$\mathcal N_{\rm v}$ 与错配零模型 $\mathcal Q_0$。MR 估计量 $m$ 仅作为 $\tau_c$ 候选机制测量。
- **主分析**：
  1. 计算 $\Lambda_{st}=n_{ch}^{-1}\ln(\mathcal N_{\rm v}^{obs}/\mathcal N_{\rm v}^{\mathcal Q_0})$，以 TOST 或预注册模型比较检验 $d\Lambda_{st}/d\Gamma$ 是否等价于零；
  2. 拟合全导数分解：$dc/d\Gamma=\ln M\,d\hat d/d\Gamma+\hat d\,d\ln M/d\Gamma+\tau_c\,d\hat h/d\Gamma+\hat h\,d\tau_c/d\Gamma+d\Lambda_{st}/d\Gamma$；
  3. 对每条路径报告效应量、置信区间、误差传播和等价界；只有全部非时间路径等价于零才接受 $H_{0M}$；
  4. 次级：拟合 $\Lambda_{st}=a_{st}\Gamma+b_{st}\Gamma^2+\varepsilon$，以预注册标准判断局部线性响应；检验 $m$ 对 $\tau_c$ 的解释力，但不将其等同为 α 或 $\ln M$。
- **执行顺序**：先导批（5.1）冻结后，臂 0 先于臂 A 执行；若资源受限，先完成协同残差与中介分解，不能以单一 $m$ 斜率替代。

### 5.2 臂 A · 规模扫描（主判别，标度耦合）

- **设计**：$\ge4$ 个 $\ln(S_cT_c)$ 水平（$\tilde u\in\{-1.5,-0.5,0.5,1.5\}$ 目标）× $\ge5$ 个 $\Gamma$ 水平（$\Gamma\in\{-0.6,-0.3,0,0.3,0.6\}$ 目标），正交设计（VIF 门槛 §5.1），每格 ≥5 重复。
- **模型**：

$$\ln\frac{\mathrm{CST}_{\text{obs}}}{S_cT_c}=\alpha_0\Gamma_{st}+\beta\,\Gamma_{st}\tilde u+\varepsilon,\qquad \tilde u=\ln(S_cT_c)-\overline{\ln(S_cT_c)}$$

- **主检验**：$|\beta|<\delta_A$（TOST）；$\delta_A=0.1\alpha_0/\Delta u$（$\Delta u=3$ 时 $\delta_A=0.033\alpha_0$，含义：全程斜率漂移 $<5\%$）。
- **次级检验**：截距 $=0$；二次项系数 $=0$；斜率随 $n_{\text{ch}}$ 线性缩放（§3.5）。

### 5.3 臂 B · 非对称扫描（测 $p,q$）

- **设计**：固定 $\Gamma$（取 2 个水平：$0.3$、$0.6$），$\ln S_c$ 与 $\ln T_c$ 正交变化（2×2 因子设计）。
- **模型**：$\ln\mathrm{CST}_{\text{obs}}=p\ln S_c+q\ln T_c+c+\varepsilon$。
- **检验**：$H_0:p=q=1$（等价界 $\delta_B=0.1$，TOST 或置信区间判据）。

### 5.4 臂 C · 组合性检验（直接称重 A1）

- **设计**：SDI 物理隔离同一晶粒上两个子网 $A$、$B$（无跨网流量），分别测量与联合测量。
- **检验**：同时检验 $\ln\mathcal N_{A\otimes B}=\ln\mathcal N_A+\ln\mathcal N_B$，以及 $\ln\mathrm{CST}_{A\otimes B}=(n_A\ln\mathrm{CST}_A+n_B\ln\mathrm{CST}_B)/(n_A+n_B)$。两条检验均采用 TOST，等价界由阶段 0 依实测误差冻结。
- **地位**：唯一直接检验公理（A1 容量可加）本身的臂；失败即悬崖（§8）。

### 5.5 臂 D · 反向耦合机制检验（D 级假说）

- **设计**：$\Gamma<0$ 工况（结构横切功能流的 SDI 配置）下，2–3 个规模档位，测量整合信息量（$\Phi$/O-information/相关长度）。
- **检验**：整合信息随规模单调下降（单侧趋势检验）。
- **目的**：把"$\Gamma<0$=反向耦合"从解释升格为可判别假说；失败则该解释降级，不进入公理层。

## 6. 统计分析与推断

### 6.1 主分析模型

见 §5.0/5.2/5.3/5.4/5.5；所有模型在揭盲前冻结（脚本+哈希）。

### 6.2 等价检验（TOST）

- "未能拒绝零效应"不是"零效应成立"的证据。完全中介、规模项、缩放对称和两条组合律均使用预注册的双单侧等价检验或预注册模型比较；等价界由阶段 0 的测量误差和最小科学效应冻结。
- 报告等价界内置信区间，而非仅 p 值。

### 6.3 多重比较

主假设（臂 0 的 $H_{0M}$、臂 A 的 β、臂 B 的 p=q、臂 C 的两条组合律）用 **Holm 校正**控制族错误率 0.05。非线性项、反向耦合方向性和外部数据对照均标注探索性，不进入主结论。

### 6.4 功效与样本量规则

- **臂 0 · 斜率 $\partial m/\partial\Gamma$**：m vs Γ 回归，$\mathrm{SD}(\Gamma)=0.424$（目标水平下）：

$$\mathrm{MDE}(\partial m/\partial\Gamma)=\frac{(z_{0.975}+z_{0.80})\,\sigma_m}{\sqrt{N}\cdot 0.424}=\frac{13.9\,\sigma_m}{\sqrt{N}}\quad[\text{推导}]$$

  - 例：$N=100$ ⇒ $\mathrm{MDE}=1.39\sigma_m$ `[推导，基于假设 σ_m]`；σ_m 由先导批实测后按 $\mathrm{MDE}(\partial m/\partial\Gamma)\le 0.02$（使 α 的 MDE $\le1$，即 $M_{\text{eff}}$ 判读在一个数量级内）取 N 并冻结。
- **臂 A**：正交设计下 $\mathrm{SD}(\Gamma\tilde u)=\mathrm{SD}(\Gamma)\cdot\mathrm{SD}(\tilde u)=0.424\times1.118=0.474$ `[推导]`；

$$\mathrm{MDE}(\beta)=\frac{(z_{0.975}+z_{0.80})\,\sigma_\varepsilon}{\sqrt{N}\cdot 0.474}=\frac{5.91\,\sigma_\varepsilon}{\sqrt{N}}\quad[\text{推导}]$$

  - 例：$N=100$（20 组态 × 5 重复）⇒ $\mathrm{MDE}=0.59\sigma_\varepsilon$ `[推导，基于假设 σε]`；规则：取满足 $\mathrm{MDE}(\beta)\le\delta_A$ 的 N 并冻结。
- **臂 B**：主效应设计下 $\mathrm{MDE}(p)\approx5.91\sigma_\varepsilon/\sqrt{N_B}$ `[推导]`；规则同上（目标 $\le\delta_B$）。
- **臂 C**：配对设计；$\mathrm{MDE}_C$ 依 $\sigma_{\varepsilon,C}$ 冻结。
- 所有功效计算脚本入库，参数与公式在阶段 0 冻结。

### 6.5 诊断与敏感性

- 残差正态性、异方差、异常值处理规则（先验定义，非事后）；
- $\Gamma_{st}$ 与规模的相关性报告（预注册 $\mathrm{VIF}<2.5$）；若真实系统两者天然相关，臂 A 功效崩塌须如实报告（臂 0 不受影响）；
- $k\in\{1,2,3\}$、零模型变体、CST 备选操作化的敏感性报告（次级）；
- MR 估计量的亚采样率、重复误差、去趋势选择报告；$m$ 的 σ_m 与 $\Gamma$ 水平的独立性检查。

- **人员分工**：实验配置（SDI 组）、Γst 测量（第三方）、CST/m 测量（独立组）、统计分析（预注册脚本）四分离。

## 8. 停止规则与结局判读

**停止规则**：固定 N，无可选停止；仅在阶段 0 做可行性中途查看（k 定标、σε、σm、VIF、Δu、MR 重复误差），不做任何假设检验。

| 结局 | 判读 | 行动 |
|---|---|---|
| ① $H_{0M}$ 通过 ∧ β 等价 0 ∧ p=q=1 ∧ 臂 C 双检验通过 | V44 两项约化在预注册工作域获支持；V45 一般式仍成立 | 发布带完整中介条件的两项约化版；不得把 α 与器件态数直接等同 |
| ② 协同残差或非时间路径非零 | 完全中介不成立 | V45 三项对称式保留为主方程；报告 $a_{st}$ 和各路径 CI，不吸收到 $T_c$ |
| ③ β 显著非零 | 存在规模依赖或非线性响应 | 主方程仅作局部工作域模型；扩展规模项并重新预注册 |
| ④ p≠q 显著 | 结构/时间缩放对称性不获支持 | 保留可辨识的非对称模型，解释其物理边界；不事后重标定为对称 |
| ⑤ 臂 C 任一组合律失败 | A1 不成立，模块化容量解释失效 | **组合性论证退回假设状态**，公开报告并暂停外推 |

结局 ②③④⑤ 均不视为失败而是理论修订信号——预注册的价值在于把"修订"从事后自由裁量变成有据决策。
