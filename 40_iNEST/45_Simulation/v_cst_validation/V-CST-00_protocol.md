# V-CST-00 CST V2.1 验证协议

**状态**：冻结初版，2026-07-24  
**目的**：在真实、可追溯的结构与功能数据上检验 CST V2.1 的可计算性、重复性、尺度关系和能力映射。

## 1. 理论对象

本轮固定使用：

```text
CST = Sc * Tc * exp(alpha * Gamma_st)
Sc = (kappa_0 * kappa_1 * kappa_2 * kappa_top)^(1/4)
Tc = (tau_0 * tau_1 * tau_2 * tau_top)^(1/4)
Gamma_st = NMI(M_struct, M_func_CS) * sign(Mantel_r_CS)
```

公式、阈值和参数解释以 `50_Output/51_Papers/CST_V2.1_Theory_FINAL.md` 的冻结版本为准。本协议不允许因观察到结果而改写公式、阈值或缺失值策略。

## 2. 证据分类

- `[实测]`：数据文件中直接观测并可追溯到原始数据集。
- `[引用]`：公开论文、数据发布页或数据手册。
- `[推导]`：由已标注数据按固定公式计算。
- `[仿真]`：用于软件、空模型或鲁棒性测试，不作为生物学验证。
- `[待测]`：指标定义已固定但数据尚未获得。

任何 `Sc`、`Tc`、`Gamma_st` 或 CST 数值都必须携带证据分类和数据指纹。

## 3. 验证任务与门禁

| 编号 | 目标 | 当前方法 | 通过条件 |
|---|---|---|---|
| V-CST-00 | 冻结公式、单位、版本和缺失策略 | 本协议 + Git 版本 | 运行前固定；无结果后改参数 |
| V-CST-01 | 统一计算 Sc | 真实有向结构、化学/电突触、拓扑分析 | 输入、脚本、版本、哈希可复现；所有组件有来源 |
| V-CST-02 | 统一计算 Tc | 神经元 ID 可映射的活动时序 | 预注册窗口、采样、去趋势、重复误差和失败样本 |
| V-CST-03 | 标定 Gamma_st | 同一对象的结构/功能匹配与消融 | 置换、时间错配、结构错配对照；CI 可计算 |
| V-CST-04 | 标定 alpha | 独立器件或生物物理数据 | 独立样本、拟合残差和单位公开；不得跨域偷换参数 |
| V-CST-05 | CST 重复性 | 跨个体、会话、任务、设备 | 预注册 ICC/重复误差、CI、失败样本公开 |
| V-CST-06 | 能力映射 | 独立能力任务 | CST 不作为能力标签来源；与简单竞争模型比较 |
| V-CST-07 | 竞争模型 | 节点数、密度、模块度、脑体积等 | 留一对象/物种交叉验证；报告效应量和 CI |
| V-CST-08 | 干预方向 | 结构或动力学干预 | 预注册方向、空模型、干预后能力指标 |
| V-CST-09 | 外部验证 | 未参与调参的数据集/物种 | 不重新调参仍达到预注册标准 |
| V-CST-10 | RG 尺度关系 | 全脑、脑区、逐级粗粒化 | 分别报告绝对值和归一化流；不预设脑区等于全脑 |

## 4. 当前数据门禁

### 已可执行

`C. elegans` 结构文件 `40_iNEST/45_Simulation/connectome_v8_data.json`：节点、化学边、电突触边和节点类型可读取。该文件只支持 V-CST-01 的结构部分。

### 尚不可执行

当前主库审计未发现可确认的原始“神经元 ID × 时间”线虫活动时序。结果表、随机活动、模型输出和无法核对 ID 的文件不能进入 V-CST-02 或 V-CST-03。

因此在获得活动数据前：

- `Tc = NOT_EXECUTED`；
- `Gamma_st = NOT_EXECUTED`；
- `CST = NOT_EXECUTED`；
- 不允许用常数、随机数或早期 V31/V32 输出补齐。

## 5. RG 假设

待测假设不是 `CST_region == CST_whole`，而是：

```text
CST_whole 与孤立脑区 CST 一般不相等；
统一归一化后，逐级粗粒化的 CST 流可能出现可重复的平台或尺度关系。
```

每个尺度必须报告：原始 CST、按节点数归一化、按总边权归一化、粗粒化规则、边界耦合处理、空模型和不确定区间。

## 6. 结论规则

本协议只能支持以下类型结论：可计算性、重复性、关联/预测价值、尺度关系或被拒绝的预注册假设。单次拓扑结果不能宣称证明 CST、SOC、SC-FC 或智能等级因果关系。
