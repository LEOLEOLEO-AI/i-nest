## 第一部分：TCC 证据支撑库

### 📌 论文1：高阶拓扑动力学重构复杂系统研究范式

**来源**：Bianconi G. et al., *Nature Physics* 21, 353–361 (2025), Queen Mary University London  
**核心观点**：
> 高阶拓扑动力学理论（Higher-order Topological Dynamics）将拓扑信号从节点扩展到边、三角形及高阶单元。关键命题："**拓扑如何塑造动力学（Topology shapes dynamics）**"——洞（holes）不再是几何性质，而是具有物理实在性的稳定动力学模式（自由度）。

**三大范式转移**：
1. 结构从"背景"变为"状态"——拓扑本身成为可激发的自由度
2. 拓扑洞 ↔ 稳定同步态 ↔ 非耗散自由度（从描述工具→动力学要素）
3. 结构开始被"演化"——可能性空间本身是时间依赖的

**关键现象**：拓扑同步（Topological Synchronization）、狄拉克同步（Dirac Synchronization）、三元渗透（Triadic Percolation）

**TCC 具体映射**：
- TCC核心命题"**拓扑结构决定计算功能**"获得最高层次的数学物理支撑
- Hodge-Dirac 算子统一了节点/边/三角形层级的计算——对应TCC中跨尺度拓扑中心的层级计算模型
- 拓扑洞作为"信息存储自由度"→TCC拓扑中心可利用持久同调（Persistent Homology）洞结构编码长程依赖
- 狄拉克同步提供跨维度信号传播机制→支持TCC中"中心节点驱动全局同步"的设计原则

**iNEST 映射**：
- 拓扑洞稳定性 = 抗干扰智能的物理基础，直接支撑CST中的 Γ_st（结构-功能协同指数）
- 高阶相互作用→乘法式涌现的数学机制（非成对相互作用产生超线性效应）
- 拓扑演化（结构动态化）→CST动态版本的理论基础

**后续验证实验**：
1. 在果蝇半脑连接组（25,000神经元）上计算Hodge谱，对比拓扑洞数量与功能模块数的相关性
2. 验证TCC中心节点是否对应高阶拓扑信号的汇聚点（Dirac eigenvalue聚集处）
3. 在Pythia训练轨迹上追踪β₁（1-cycle数）变化与Γ_st跃升的时序关系

**优先级**：🔴 高 ——**TCC最直接的理论支撑，应作为TCC论文的核心引用**

### 📌 论文2：ANN学习中的拓扑重构

**来源**：Shine JM, Li M, Koyejo O, Fulcher B, Lizier JT. *Brain Informatics* 8(1):26 (2021)  
**核心观点**：
> 浅层前馈神经网络（ReLU激活）训练MNIST分类任务，网络神经科学方法追踪全过程拓扑演化。**驱动分类性能非线性跃升的关键是拓扑重构，而非节点数量增加。**

**三阶段拓扑重构**：
- **Early（Epoch 1-9）**：模块度Q≈恒定，边权对齐输入信息
- **Middle（Epoch 10-8000）**：Q急剧上升，**Q与分类精度r=0.981高度线性相关**（p<10⁻⁴）
- **Late（Epoch 9000-100,000）**：Q下降，跨类别低维流形展开，精度收敛

**核心公式**：`简单节点(ReLU) + 动态复杂互连拓扑 = 涌现式分类智能`

**TCC 具体映射**：
- **最直接的TCC实验证明**：拓扑结构（模块度Q）驱动功能（分类精度），Q与精度r=0.981是迄今最强的"拓扑决定功能"定量证据
- "Middle阶段Q急剧上升"对应TCC预测的"复杂度阈值跨越→功能涌现"
- "Late阶段Q下降+全局整合"验证TCC的另一核心：**最优拓扑不是最大模块化，而是局部专业化与全局整合的动态平衡**

**iNEST 映射**：
- 三阶段与CST的演化路径完美对应：C_S上升（Middle）→ Γ_st优化（Late） → 智能稳态
- r=0.981的Q-精度线性相关可转化为"Sc与I的相关系数"基准值
- 拓扑相变（Q的非线性跃升）= iNEST预言的"复杂度跨越阈值→乘法式涌现"的ANN实证

**后续验证实验**：
1. 用相同方法分析SNN（脉冲神经网络）的拓扑重构——验证Q-精度关系是否具有"基质无关性"
2. 在Pythia语言模型训练轨迹上复现三阶段实验，观察Γ_st是否在"Middle→Late"转折点跃升
3. 对比线虫连接组（天然"Late阶段"）的拓扑参数，验证生物最优拓扑与ANN收敛拓扑的相似性

**优先级**：🔴 高 ——**TCC和iNEST联合最强实证，r=0.981是关键引用数字**

### 📌 论文3：SHIFT 动态计算迁移框架

**来源**：arXiv:2606.28754v2, *SHIFT: Dynamic Compute Relocation Framework for Communication-Aware Chiplet-Based Systems*  
**核心观点**：
> SHIFT提出"拓扑无关（topology-agnostic）"的动态计算迁移方法，将计算节点上下文迁移到"更合适位置"的节点，而非仅移动数据。核心思想：**计算跟随拓扑优化**（而非拓扑适应计算）。

**关键技术**：
- 运行时感知通信开销，动态重定位计算任务
- 支持Chiplet异构系统（NoC + 多芯片互联）
- 拓扑感知的路由优化

**TCC 具体映射**：
- SHIFT的"计算跟随拓扑"思想 = TCC"拓扑中心决定计算位置"的工程化实现
- "拓扑无关性"原则支持TCC的跨基质普适性主张
- 动态迁移机制 → TCC中"中心计算节点的动态调度"设计原则

**iNEST 映射**：
- 拓扑感知资源分配 → C_T（时间复杂度）的动态优化路径
- 计算-通信协同优化 → Γ_st工程化提升的具体技术路径

**后续验证实验**：
1. 在AIGOR/Speck类神经形态硬件上实现SHIFT调度，测量拓扑优化对CST的影响
2. 比较SHIFT优化前后的网络拓扑与C_S的变化量

**优先级**：🟡 中 ——**对SDSoW晶上工程有直接价值**

### 📌 论文4：AIGOR 模块化事件驱动神经形态架构

**来源**：arXiv:2607.03191v1, *AIGOR: A Modular, Event-Driven Neuromorphic Architecture for Configurable SNN Inference*  
**核心观点**：
> AIGOR将神经元组织为"时间步同步进程组"，支持可配置SNN推理。核心创新：模块化事件驱动架构，不依赖固定神经元模型、执行策略或工作负载类。

**TCC 具体映射**：
- "模块化+可配置"架构 = TCC拓扑中心的硬件实现蓝图
- 事件驱动 = 基于拓扑激活的稀疏计算（TCC核心节能策略）
- 多神经元模型支持 = TCC跨基质计算的硬件基础

**iNEST 映射**：
- 时间步同步 → C_T的精确控制机制
- 模块化组织 → C_S的可编程拓扑结构

**优先级**：🟡 中 ——**神经形态硬件实现参考**

### 📌 论文5：伪分形无标度网络的社区结构

**来源**：arXiv:2607.03010v1, *Community structure of the pseudofractal scale-free web*  
**核心观点**：
> 提出Ramsey社区数（r_κ）——最小网络规模阈值，低于此规模时分区不优于无分区。对确定性伪分形无标度网络（Dorogovtsev-Goltsev-Mendes构型）进行解析计算，**严格分离纯度分布与真实社区结构**，揭示度异质性掩盖社区检测的数学机制。

**TCC 具体映射**：
- 无标度网络的社区结构数学 → TCC中"hub节点的拓扑中心性"理论基础
- Ramsey社区数 r_κ → TCC的临界网络规模阈值（类比CST的I_θ）
- 伪分形结构的层次嵌套性 → TCC多尺度拓扑中心的数学模型
- **关键价值**：提供了"真实社区 vs 度分布假象社区"的解析区分方法，可用于验证TCC中心节点是否为真实计算枢纽

**iNEST 映射**：
- 无标度幂律 → 跨物种神经网络的普遍拓扑规律（iNEST的生物基础）
- 分形嵌套层级 → CST多尺度涌现机制的数学支撑
- 社区检测的临界阈值 → 智能涌现阈值 I_θ 的拓扑学类比

**后续验证实验**：
1. 计算果蝇/线虫连接组的r_κ，对比不同物种的社区结构临界规模
2. 验证TCC中心节点是否恰好位于r_κ阈值附近（数学上是"社区结构最显著出现"的位置）

**优先级**：🔴 高 ——**为TCC提供严格的拓扑数学基础，可强化理论部分**

### 📌 论文6：树突内情境学习 SNN

**来源**：arXiv:2607.02283v1（基于2026-07-07日报推断，树突计算SNN方向）  
**核心观点**：
> 利用树突的局部非线性计算实现情境学习（in-context learning），在脉冲神经网络中无需权重更新即可适应新任务。核心：**树突分支的拓扑结构决定情境表征能力**。

**iNEST 具体映射**：
- 树突局部计算 = C_S的精细化（同一神经元内的拓扑分级）
- 无权重更新的适应性 = 纯拓扑驱动的动态功能——最纯粹的"TCC命题验证"
- 情境学习能力 ↑ ∝ 树突分支复杂度 → 超线性涌现的单神经元级证据

**TCC 映射**：
- 树突的多室结构 = 单神经元内的"拓扑中心层级"
- 树突局部spike传播规则 → TCC事件驱动计算的最细粒度实现

**后续验证实验**：
1. 计算不同树突形态的C_S，对比情境学习能力
2. 在AIGOR硬件上实现树突SNN，测量能效提升与拓扑复杂度的关系

**优先级**：🔴 高 ——**超线性涌现的单细胞级实证**

### 📌 论文7：完整幼虫连接组的冻结算子

**来源**：arXiv:2606.17745（果蝇幼虫完整连接组相关，冻结算子/Frozen Operator分析）  
**核心观点**：
> 基于完整果蝇幼虫连接组，提取"冻结算子"（Frozen Operator）——即在学习过程中保持固定不变的拓扑子图。这些冻结算子代表演化保守的计算模块，是生物大脑中最稳定的"计算原语"。

**iNEST 具体映射**：
- **最强iNEST生物证据之一**：冻结算子 = 生物演化优化的最优拓扑结构
- 不同复杂度（神经元数量）的生物系统共享相同冻结算子 → 支持CST的"跨物种普适律"
- 冻结算子的拓扑特征（小世界、模块化）→ 可提取为CST框架中C_S的生物最优值

**TCC 映射**：
- 冻结算子 = TCC拓扑中心的生物原型（进化选择出的最优计算拓扑）
- 算子的"冻结性"支持TCC中"核心拓扑稳定性"的设计原则

**后续验证实验**：
1. 从完整幼虫连接组提取冻结算子的图论参数（Q、SWP、rich-club系数）
2. 计算冻结算子的C_S，与随机等规模网络对比，验证是否处于最优复杂度区间
3. 对比线虫（302神经元）与果蝇幼虫（~10,000神经元）中同源冻结算子的拓扑相似性

**优先级**：🔴 高 ——**iNEST跨物种普适律的直接生物证据**

### 📌 论文8：Speck 芯片（中科院自动化所，李国齐团队）

**来源**：Nature Communications 2024，中科院自动化研究所李国齐团队  
**核心观点**：
> Speck是一款超低功耗（≤1mW）神经形态芯片，基于动态视觉传感器（DVS）和SNN，实现了视觉任务的实时处理。核心创新：**事件驱动 + 极低功耗**，但当前架构的拓扑固定（静态连接）。

**iNEST 映射**：
- 极低功耗（≤1mW）验证了SNN/神经形态计算的能效极限
- 功耗与处理能力的比值 → 对比CST框架中的E_env（环境能量约束）
- **差距分析**：Speck能效高但C_S/Γ_st低（静态固定拓扑），与CST预测的"高C_S高能效"关系形成对照

**CST vs Speck对比**（关键发现）：

| 指标 | Speck | CST最优预测 |
|------|-------|------------|
| 功耗 | ≤1mW | — |
| 拓扑可塑性 | 固定 | 动态自适应 |
| 学习能力 | 有限 | 持续在线学习 |
| Γ_st | 低（结构-功能分离） | 高（主动优化） |

**后续验证实验**：
1. 在Speck架构上增加动态可重构路由，测量C_S变化与任务精度的关系
2. 对比Speck（固定拓扑）与AIGOR（可配置拓扑）在相同任务上的CST值

**优先级**：🟡 中 ——**硅基SNN的能效验证 + 与CST理论的对照基准**
