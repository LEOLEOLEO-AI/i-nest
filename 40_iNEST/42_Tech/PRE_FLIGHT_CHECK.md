## Sc 空间复杂度：4个分量校验

---

### P1：κ₀ — 有向D-core层级深度

**理论定义**（Theory_FINAL.md L37）：
```
κ₀ = tanh( mean(D-core层级) / max(D-core层级) × 3 )
D-core：入度≥k 且 出度≥k 的最大诱导子图（有向k-core）
归一化：网络中各节点所属最大k-core的平均值 ÷ 最大值
```

**物理含义**：层级处理深度（V1→PFC流水线深度）

校验项：
- [ ] 使用**有向** k-core（同时约束入度≥k 和出度≥k）
- [ ] 计算每个节点的 core_number，取 mean/max 比值
- [ ] 归一化公式：`tanh(mean_core / max_core × 3)`
- [ ] 验证：全连接有向图 → 所有节点同一core → mean/max=1 → κ₀=tanh(3)≈0.995

❌ 禁止：无向 k-core（只约束度≥k，不区分方向）
❌ 禁止：`tanh(k_max / 20)`（只取最大值，丢失层级分布信息）

---

### P2：κ₁ — 有向小世界路径效率

**理论定义**（Theory_FINAL.md L38）：
```
κ₁ = tanh( σ_directed / 10 )
σ_directed = (C_directed/C_rand) / (L_directed/L_rand)
C_directed：有向聚类系数（Fagiolo 2007）
L_directed：有向平均路径长度（采样）
```

**物理含义**：全局广播效率，类比工作空间理论

校验项：
- [ ] σ 使用**有向**聚类系数和有向路径长度
- [ ] 归一化分母为 **10**（理论定义），不是8
- [ ] 验证：C.elegans实测 σ≈3.0 → κ₁=tanh(0.3)≈0.29（小世界但非饱和）

❌ 禁止：`tanh(σ/8)`（分母8无文献依据）
⚠️ 注意：大N时σ可能>30，tanh饱和；如需标度律实验改用 `min(σ/σ_ref, 1.0)` σ_ref=3.0

---

### P3：κ₂ — 功能社区分化

**理论定义**（Theory_FINAL.md L39）：
```
κ₂ = Q_Louvain ∈ [0, 1]
Q：Louvain模块度，直接使用，无需额外归一化
```

**物理含义**：功能专一化程度（视觉/听觉/运动模块分工）

校验项：
- [ ] Louvain 社区检测作用于权重矩阵 W
- [ ] 直接输出 Q 值，Q ∈ [0,1]
- [ ] 验证：完全随机网络 → Q≈0；完美模块网络 → Q≈1

✅ 当前实现基本正确，无需修改

---

### P4：κ_top — 有向拓扑环路数

**理论定义**（Theory_FINAL.md L40）：
```
κ_top = log₁₀(β₁_d + 1) / log₁₀(10⁶ + 1)
β₁_d = E_d - N + N_SCC
E_d：有向边数；N：节点数；N_SCC：强连通分量数
上界：人类皮层级 β₁_d ≈ 10⁶，log₁₀(10⁶+1)≈6
```

**物理含义**：独立有向信息循环路径数（工作记忆容量）

校验项：
- [ ] 使用**对数**归一化：`log10(β₁_d+1) / log10(1e6+1)`
- [ ] β₁_d 计算：`E_d - N + N_SCC`（Tarjan算法求SCC数）
- [ ] 验证：β₁_d=0（树状网络，无环路）→ κ_top=0；β₁_d=10⁶ → κ_top=1.0

❌ 禁止：`tanh(β₁_d / 2717)`（分母2717无理论依据，tanh非对数）

## Tc 时间复杂度：4个分量校验

---

### P5：τ₀ — 单节点时间记忆（DFA Hurst）

**理论定义**（Theory_FINAL.md L79）：
```
τ₀ = tanh( 2 · mean_i[H_DFA(i)] )
H_DFA(i)：节点i的激活时间序列的DFA Hurst指数
H=0.5：随机无记忆；H→1：强持续记忆
```

**物理含义**：STDP时间窗内突触持久性（Linkenkaer-Hansen 2001）

校验项：
- [ ] DFA 应用于每个神经元的激活时间序列（非集群均值）
- [ ] 公式：`tanh(2 × H̄)`，H̄ = mean over sampled neurons
- [ ] 验证：H̄=0.5（随机）→ τ₀=tanh(1.0)=0.762；H̄=0.75 → τ₀=tanh(1.5)=0.905

✅ 此公式由理论文档明确定义（tanh(2H)），代码一致，无需修改
📌 注：H=0.5→τ₀=0.76 是理论设计意图（弱记忆网络仍有一定τ₀基线）

---

### P6：τ₁ — 复杂性同步（CS互相关）

**理论定义**（Theory_FINAL.md L87，West 2024）：
```
τ₁ = max(0, mean_{i<j}[ corr(H_i(t), H_j(t)) ])
H_i(t)：节点i在滑动窗口t内的局部DFA Hurst指数
窗口参数：W=200步，步长STR=30步
```

**物理含义**：跨神经元的多重分形维数时间共进化（复杂性同步）

校验项：
- [ ] 输入为 **H_i(t)**（Hurst指数时间序列），不是 h_i(t)（速率序列）
- [ ] 实现步骤：
  1. 将 H_arr[T×N] 按 W=200 步、步长30步切窗口
  2. 每窗口对每神经元计算局部DFA → 得 D_i（标量）
  3. 拼接所有窗口 → D_i(t)（形状：n_windows × N）
  4. pairwise corr(D_i(t), D_j(t)) over sampled pairs
  5. τ₁ = max(0, mean of correlations)
- [ ] 验证：所有神经元 H_i(t) 完全相同 → corr=1 → τ₁=1；完全独立 → τ₁≈0

❌ 禁止：`mean|corr(h_i(t), h_j(t))|`（速率相关，非CS定义）
❌ 禁止：用整段 H_arr 做静态相关（需要时间序列，不是单点）

---

### P7：τ₂ — 多尺度时间覆盖（MFDFA谱宽）

**理论定义**（Theory_FINAL.md L92）：
```
τ₂ = tanh( Δα / 0.8 )
Δα = α(q_min) - α(q_max)，q ∈ [-5, 5]（奇异谱宽度）
α(q)：MFDFA广义Hurst指数（奇异性标度指数）
生物参考：健康脑 Δα ≈ 0.3-0.8（Zorick 2013）
```

**物理含义**：同时活跃的时间尺度数量（δ→γ七频段覆盖）

校验项：
- [ ] MFDFA 应用于**多个神经元各自的时间序列**，取中位 Δα
- [ ] q 范围：[-5, 5]，至少9个q值
- [ ] 归一化：`tanh(Δα / 0.8)`
- [ ] 验证：单频段信号（正弦波）→ Δα≈0 → τ₂≈0；多尺度信号 → Δα≈0.5-0.8 → τ₂≈0.5-0.9

⚠️ 当前问题：MFDFA应用于集群均值pop_log（单一时间序列），信息量不足
改进：对 N_SAMPLE 个神经元各自计算Δα，取中位数

---

### P8：τ_top — SOC神经雪崩临界指数

**理论定义**（Theory_FINAL.md L95，Beggs & Plenz 2003）：
```
τ_top = exp( -|τ_av - 1.5| / 0.3 )
τ_av：雪崩大小分布 P(s) ∝ s^(-τ) 的幂律拟合指数
临界值：τ_av = 1.5（SOC临界态，分支比=1）
```

**物理含义**：神经雪崩是否处于SOC临界态

校验项：
- [ ] **速率模型**（rate model）：无法产生真实空间雪崩
  → 强制设 `τ_top = 0.5`（中性值，表示"未测量"）
- [ ] **LIF脉冲模型** + N≥500 + n_av≥100：可尝试实测
  - 雪崩大小 = 单次雪崩中激活的神经元总数
  - 雪崩检测：以时间bin为单位，任一bin无激活则雪崩结束
- [ ] 验证：若测量，τ_av=1.5 → τ_top=1.0；τ_av=2.0 → τ_top=exp(-5/3·0.3)≈0.19

❌ 禁止：用集群均场 pop_log 的"连续超阈段"代替雪崩统计
❌ 禁止：n_av<50 时使用实测值（统计不可靠）

### P10：Γst — 结构-功能耦合

**理论定义**（Theory_FINAL.md L114）：
```
Γst = NMI(M_struct, M_func_CS) × sign(Mantel_r_CS)

M_struct  = Louvain(W)                         结构社区
FC_CS_ij  = corr(H_i(t), H_j(t))              CS功能连接矩阵
M_func_CS = Louvain(max(0, FC_CS))             功能CS社区
d_struct  = 1/(W_ij + ε)                       结构距离
d_func    = 1 - FC_CS_ij                       功能距离（连续值）
Mantel_r  = spearmanr(d_struct_vec, d_func_vec) 距离矩阵相关
```

**物理含义**：结构拓扑模块化是否与复杂性同步功能模块化一致
**生物参考**：Honey 2009 人脑 Mantel_r ≈ 0.486

校验项：
- [ ] M_struct：Louvain(W) ✅
- [ ] FC_CS：corr(H_i(t), H_j(t))，**H_i(t) 同 P6 定义的滑窗DFA序列**
- [ ] M_func_CS：Louvain(max(0, FC_CS))，不是固定分组
- [ ] d_func：`1 - FC_CS_ij`（连续值，非二值社区标签差异）
- [ ] Mantel_r：spearmanr on 上三角元素对

❌ 禁止：`comm_labs(N, k)` 固定等分分组作为 M_func
❌ 禁止：二值距离 `(comm_i ≠ comm_j)` 作为 d_func
❌ 禁止：周期性按组BURST驱动（会人为对齐功能社区与刺激分组）

## 额外机制校验（非CST分量，但影响仿真正确性）

---

### P11：STDP 实现

**文献依据**：Bi & Poo 1998；Rate model 下简化为 Hebb 规则

- [ ] Rate model 简化：`dW_ij = η · h_i(pre) · h_j(post)`（Hebb）
- [ ] 或非对称STDP：xp 追踪 pre-synaptic，xn 追踪 post-synaptic，threshold 不同
- [ ] ETA 量级检验：`ETA × 平均trace × STEPS` 应 ≥ 0.05（否则STDP实质无效）

❌ 禁止：xp = xn（相同threshold，对称规则）

---

### P12：结构锚定机制

**文献依据**：Bhatt 2009 — spine turnover ~10%/月，约束拓扑而非权重

- [ ] 锚定对象：保护连接**存在**（拓扑），不拉回权重**绝对值**
- [ ] 实现：`W[W_init>θ] = clip(W[W_init>θ], θ_min, W_MAX)`（防止归零）
- [ ] 锚定强度 vs STDP 变化量：不得让锚定拉回量远大于 STDP 累积变化量

❌ 禁止：`W = λ·W + (1-λ)·W_init`（拉回绝对权重值，压制可塑性）

---

### P13：驱动信号

**文献依据**：White 1986 C.elegans — 感觉输入为连续随机化学梯度

- [ ] 外部驱动：全局随机高斯噪声 或 泊松过程
- [ ] 无周期性按组轮流刺激（BURST_INT × N_COMM 结构）

❌ 禁止：BURST_INT 周期 × comm 轮流（人为污染Γst）

---

### P14：时间尺度分离

**文献依据**：Turrigiano 1998（稳态~24-48h）；Bi&Poo 1998（STDP~ms）

- [ ] STDP：每步
- [ ] 稳态缩放 HOMEO_INT：≥ 1000步（100×STDP步长）
- [ ] 结构修剪 TR_INT：≥ HOMEO_INT

⚠️ HOMEO_INT < 500：警告，稳态过快可能干扰STDP

---

### P15：小网络/大网络制度区分

- [ ] N < 1000：WS 均匀环（C.elegans制度，合适）
- [ ] N ≥ 1000：必须使用**层级模块WS**（模块内WS + 模块间稀疏长程连接）

❌ 禁止：将 WS 均匀环线性放大至 N=5000 代表皮层
