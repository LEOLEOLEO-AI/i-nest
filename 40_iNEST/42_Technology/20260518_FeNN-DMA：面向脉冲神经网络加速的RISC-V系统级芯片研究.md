# FeNN-DMA：面向脉冲神经网络加速的RISC-V系统级芯片研究

### **🔬 研究背景与核心问题**

传统人工神经网络（ANN）依赖密集矩阵乘法，适合GPU/TPU等加速器处理。但**脉冲神经网络（SNN）** 采用事件驱动机制，神经元仅在达到阈值时发放"脉冲"，具有天然稀疏性和能效优势。其核心矛盾在于：**计算简单但数据搬运与稀疏事件处理复杂**，传统GPU/TPU难以高效支持。

### **🎯 FeNN-DMA的设计目标**

现有SNN加速器存在三大局限：支持神经元模型简单（如LIF）、网络结构灵活性不足（难支持循环连接/突触延迟）、片上存储容量有限。FeNN-DMA旨在平衡**灵活性、容量与能效**，主要贡献包括：
- 升级向量核心，加入lane-local memory支持稀疏连接和突触延迟
- 设计专用DMA控制器，优化片外DDR与片上存储数据搬运
- 提供Python工具链PyFeNN简化开发
- 实现单核/双核SoC，单核支持1.6万神经元和2.56亿突触

### **🏗️ 整体架构解析（图1）**

FeNN-DMA基于AMD Kria KV260平台实现，采用三层架构：

#### **(一) ARM处理系统**
- **功能**：运行Ubuntu Linux和PyFeNN工具链
- **作用**：将用户定义的SNN编译为RISC-V代码和数据，写入片上BRAM或DDR

#### **(二) RISC-V标量核心**
- **核心型号**：CV32E40x 32位RISC-V
- **职责**：执行控制逻辑（循环、分支、DMA调度）

#### **(三) 向量协处理器（VEC）**
- **配置**：32-lane、512bit宽度、3级流水线
- **能力**：并行处理32个16位数据，支持自定义SNN向量指令
- **关键模块**：DMA控制器（含AXI DataMover、Controller、Arbiter），实现权重流式搬运

### **💾 存储系统设计**

FeNN-DMA整合多种存储资源，针对SNN特性优化：

| 存储类型 | 用途 | 优势 |
| :------- | :--- | :--- |
| **BRAM** | 指令存储、标量数据、lane局部存储 | 低延迟，适合随机访问 |
| **URAM** | 神经元状态、输入电流、临时缓冲 | 容量高、密度大，适合宽SIMD访问 |
| **DDR** | 大规模权重存储 | 容量大，通过DMA双缓冲隐藏延迟 |
| **lane-local memory** | 稀疏连接/突触延迟处理 | 每个lane独立寻址，避免SIMD串行化 |

**设计亮点**：URAM处理"大块连续数据"，lane-local BRAM处理"随机稀疏访问"，实现存储层次化优化。

### **⚙️ SNN定制向量指令集（表1）**

未采用标准RISC-V向量扩展，设计轻量级专用指令：

| 指令类型 | 关键指令 | 功能描述 |
| :------- | :------- | :------- |
| **算术运算** | VADD/VSUB/VMUL | 固定点加减乘，支持饱和运算和移位舍入 |
| **比较判断** | VTEQ/VTLT/VTGE | 神经元脉冲发放阈值判断 |
| **存储访问** | VLOAD.V/VSTORE.V | 向量存储访问（URAM） |
| **稀疏处理** | VLOAD.L/VSTORE.L | lane-local memory访问 |
| **随机数生成** | VRNG | 每个lane独立随机数，支持神经元噪声模拟 |

**技术细节**：VMUL指令集成DSP block与barrel shifter，支持round-to-zero、round-to-nearest和随机舍入，减少低精度固定点数误差累积。

### **🚀 脉冲传播与DMA优化（图3）**

SNN推理核心流程包括神经元状态更新和脉冲传播，后者是性能瓶颈。FeNN-DMA采用**双缓冲技术**隐藏DDR访存延迟：
1. **数据搬运**：DMA将当前脉冲对应权重行从DDR搬至URAM buffer
2. **计算重叠**：处理当前权重行时，DMA同时搬运下一行权重
3. **带宽匹配**：DMA实测吞吐4.9GB/s，满足最大需求2.8GB/s

**效果**：实现"计算-搬运"流水线，避免处理器空闲等待。

### **🔄 连接类型支持能力**

FeNN-DMA通过算法1和lane-local memory结构，支持三类连接：

#### **(一) 稠密连接**
- 直接加载权重矩阵行，与目标神经元输入电流向量相加

#### **(二) 稀疏连接（图4A）**
- 连接编码为16bit（低位目标神经元索引，高位权重）
- 目标输入分布在lane-local memory，支持非结构化稀疏

#### **(三) 延迟连接（图4B）**
- 神经元输入槽含多个delay slot
- 脉冲写入未来时间槽，实现突触延迟模拟

### **🛠️ 软件工具链PyFeNN**

降低使用门槛的关键组件：
- **编程模型**：类似PyTorch的网络定义方式
- **编译流程**：将神经元更新规则（C-like语言）编译为RISC-V向量指令
- **兼容性**：支持Neuromorphic Intermediate Representation，可导入其他SNN框架模型

### **📊 实验结果与性能分析**

#### **(一) 实现指标**
- **频率**：单核175MHz，双核143MHz
- **规模**：单核支持1.6万神经元、2.56亿突触
- **功耗**：动态功耗约0.53W
- **吞吐**：稠密连接0.92 GSOP/s（实测达理论峰值70%）

#### **(二) 任务性能**

| 任务 | 模型配置 | 准确率 | 关键优势 |
| :--- | :------- | :----- | :------- |
| **SHD语音识别** | 带循环连接和可训练突触延迟 | 90.32±0.01% | 较Spiker+（72.99%）精度提升显著 |
| **N-MNIST图像分类** | 512神经元，99%循环稀疏 | 98.46±0.02% | 高于稠密模型（98.11%），参数量仅1/4 |
| **Braille触觉分类** | 量化模型 | 92.86% | 接近最佳软件后端水平 |

#### **(三) 规模扩展能力（图6）**
- **稠密连接**：实时模拟10000神经元
- **90%稀疏连接**：快于实时模拟16000神经元
- **稀疏增益**：90%稀疏时有效吞吐提升3.2×，75%稀疏时提升2.1×

### **💡 核心价值与创新点**
1. **精准定位瓶颈**：聚焦SNN的稀疏事件处理、权重搬运和存储协同问题
2. **平衡设计理念**：RISC-V+向量协处理器架构，兼顾可编程性与效率
3. **完整软硬协同**：PyFeNN工具链降低使用门槛，提升实用性

### **⚠️ 局限与未来方向**

#### **当前局限**
- 相比固定功能加速器有3-4倍吞吐差距（脉冲传播循环由软件实现，每32权重向量需4-7周期）
- 多核间缺乏spike interconnect，仅支持数据并行而非模型并行

#### **未来计划**
- 集成固定功能流水线提升小模型吞吐
- 加入核间通信支持大规模SNN拆分
- 连接事件相机构建完整spiking视觉系统
- 探索EventProp等基于事件的训练算法

### **🎯 研究启示**

FeNN-DMA展示了神经形态计算的务实路线：围绕SNN"事件驱动、低算术强度、访存敏感、结构复杂"特性，采用**RISC-V+向量协处理器+专用DMA+Python工具链**的组合方案。对于快速演进的SNN领域，这种"半定制"架构可能比纯固定功能硬件更具长期价值。
