# 2026新思开发者大会：台积电罗镇球谈AI时代的半导体产业与技术路线

### 📅 这场演讲是谁在什么场合做的？

台积电中国区总经理**罗镇球**在**2026年新思科技开发者大会**发表主题演讲。
- **时间**：2026年9月16日上午
- **核心定位**：AI驱动的半导体产业正经历**第四次工业革命（智能革命）**

### 💰 2030年全球半导体市场会有多大？

台积电最新预估**2030年全球半导体产值达1.5万亿美元**，较此前1万亿美元的预期大幅上修。
- **上修原因**：AI热潮驱动 + 存储芯片供不应求、价格暴涨
- **历史对比**：台积电创始人张忠谋数年前提出的1万亿美元预估，当时曾被质疑过于激进，如今已被证明偏保守

### 🏭 2030年半导体产业结构会怎么变？

**无晶圆厂设计公司（Fabless）将主导产业**，占比超三分之二。
- **结构变迁**：2000年以IDM（整合元件制造商）为主 → 2023-2024年Fabless产值已超过IDM → 2030年Fabless占比 > 2/3
- **背后推力**：系统公司纷纷切入自研芯片（如小米），目的是掌控技术主导权、实现产品差异化

### 📊 2030年1.5万亿美元产值怎么分布？

**AI与HPC将成为第一大应用，占比过半**。

| 应用领域 | 2030年占比 |
| :--- | :--- |
| AI与HPC | **55%** |
| 智能手机 | 约20% |
| 汽车 | 约10% |
| IoT | 约10% |
| 工业及其他 | 约5% |
- **代际更替**：1980-90年代PC主导 → 2000年后手机接棒 → 2020年后AI/HPC成为最大应用

### ⚡ AI算力需求和摩尔定律的缺口有多大？

**算力需求增速远超摩尔定律，供需缺口是核心矛盾**。
- **训练算力**：文字/图片类模型年增约**5倍**；多模态模型（文+图+声+影）增速将超**10倍/年**
- **推理算力**：2022-2025年三年间，全球Token消耗增长约**500倍**；智能体AI时代将进一步指数级增长
- **供给侧**：摩尔定律每2年晶体管密度翻一倍，且增速还在放缓
- **先进制程增速**：2023前年复合增长率10%-15% → 生成式AI出现后超**30%**；该增速受限于晶圆厂/封装厂产能（建厂到量产需数年），而非需求

### 🔧 台积电怎么填补算力缺口？

**先进制程 + 3D先进封装 + 光互连三线并进**。

#### 1. 先进制程：继续推进摩尔定律
- **N2（2nm）**：2025年Q4大规模量产，采用第一代纳米片（Nanosheet/GAA）晶体管，高雄Fab 22与新竹厂同步生产
  - 对比N3E：同功耗速度提升**10%-15%**，同速度功耗降低**25%-30%**，芯片密度增加超**15%**
- **后续路线**：N2P（2026年下半年量产）→ A16（1.6nm级，背面供电）→ A14/A13/A12，均在2030年前推出

#### 2. 3D先进封装：靠堆叠补算力
- **核心逻辑**：垂直堆叠多颗芯片，提升系统级算力
- **2030年目标**：单个封装内含多芯片堆叠、晶体管总数超**1万亿**
- **技术矩阵**：InFO、SoW、CoWoS系列2.5D封装 + CoW/WoW等晶圆级3D封装（TSMC 3DFabric®）
- **攻坚难题**：散热、集成、堆叠良率
  说白了，单颗芯片做不大了，就把多颗芯片摞起来用，靠"数量堆"换算力。

#### 3. 光互连：用光代替铜线传数据
- **作用**：突破电互连带宽瓶颈，支撑更多算力芯片整合
- **演进路径**：封装外连接 → 封装内连接 → 最终进入芯片内部特定区域

### 🤝 台积电和新思科技在合作什么？

**双方从设计端协同优化，重构AI时代的芯片设计生态**。
- **合作历史**：自1986年（新思）/1987年（台积电）成立之初即建立合作

#### 1. DSO.ai：数字设计AI优化
- **定位**：用强化学习在庞大设计空间中自动寻优，替代传统"老师傅经验"
- **效果**：平均功耗降低**7%**（其中APR流程优化贡献5%，金属方案优化贡献2%），同时面积更小、设计更快

#### 2. ASO.ai：模拟设计AI自动化
- **定位**：业界首个落地模拟与混合信号（AMS）设计全流程的AI工具
- **作用**：解决模拟电路依赖人工试错的效率瓶颈，缩短制程迁移的设计与认证时间

#### 3. DTCO：设计与工艺协同优化
- **定位**：让设计意图与制造工艺在早期阶段就对齐，是行业公认的难题
- **目标**：晶圆厂 + EDA厂商 + 芯片设计厂商三方深度协同，提升产品效率、缩短上市时间

### 📝 补充细节
- 罗镇球的演讲呼应了新思科技CEO盖思新（Sassine Ghazi）提出的三大创新方向：Agentic AI（AI智能体）、Co-design（协同设计）、电子数字孪生
- 先进逻辑制程30%的年增长率是**受产能限制**的结果，并非需求只有这么多
