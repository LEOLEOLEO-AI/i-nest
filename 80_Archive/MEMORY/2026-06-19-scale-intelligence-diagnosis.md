## 规模-智能映射

### iNEST 理论的自身要求

```
规模        │ 应该支撑的智能        │ 需要的特性
───────────┼──────────────────────┼───────────────
10² (300)   │ 感知+反射 (条件反射) │ 固定拓扑，无学习
10³ (1000)  │ 简单习惯化           │ 局部可塑性
10⁴ (10K)   │ 学习+记忆            │ STDP + 强化学习
10⁵ (100K)  │ 推理+工作记忆        │ 多模块+递归
10⁶ (1M)    │ 意识+元认知          │ 全息编码
```

### 当前 V25 的问题

```
使用的规模：C.elegans (302) + Drosophila (25K)
声称支撑：TCC 范式（实际需要 10⁵+）
差距：3-4 个等级的外推
```

## 三种修正方案

### 方案 A: 降低声称（保守）

不改变现有工作，只改表述
```
删除：
- "验证了 SOC"（绝对声称）
- "支持 TCC 范式"（范式级声称）

改为：
- "观察到小规模网络中的 SOC 特征"
- "为后续规模升级奠定基础"
```

**优点**：快速、现有工作有效
**缺点**：贡献度下降

### 方案 B: 分阶段验证（推荐）⭐

明确各阶段的规模与目标

```
V25（当前）→ 拓扑层 (10² 规模)
  验证：小规模网络的 SOC 拓扑特性
  交付：规模独立的拓扑假设

V26（下季）→ 学习层 (10⁴ 规模)
  验证：Drosophila + STDP + 学习曲线
  交付：学习涌现的规模阈值

V27（后季）→ 推理层 (10⁵ 规模)
  验证：小鼠脑子集 + 工作记忆任务
  交付：推理涌现的规模阈值

V28+ → 完整 TCC 范式验证
```

**优点**：理论自洽、长期规划清晰、可投稿
**缺点**：需要 6-12 月投入

### 方案 C: 参数化理论（最严谨）

定义量化的"规模-智能函数"

```
I(N, τ, γ, ε) = log(N) × exp(-τ/τ₀) × (γ-1) × ε

其中：
- N: 神经元数
- τ: 学习时间常数（迭代数）
- γ: 拓扑幂律指数
- ε: 神经可塑性强度

定量预测：
I(302, ∞, 2.1, 0) = 感知级
I(25K, 100, 2.1, 0.01) = 学习级
I(100K, 50, 2.1, 0.1) = 推理级

按预测逐步验证
```

**优点**：理论最严谨，可完全自洽
**缺点**：工作量最大，需要参数校准
